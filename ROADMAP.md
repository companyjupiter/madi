# Roadmap

This is a direction, not a promise or release schedule. Issues and pull requests
are the source of truth for work in progress.

## Now

- Developer ID signing and notarized macOS distribution
- reliable local transcription, speaker attribution, and export on Apple Silicon
- transparent open-source builds, licensing boundaries, release provenance, and
  reproducible release checks

## Next

- improve onboarding and failure recovery for model downloads and permissions
- expand accuracy and performance regression coverage with redistributable audio
  fixtures
- make translation and summary capability boundaries clearer in source-only
  builds
- improve accessibility and English/Japanese/Chinese documentation parity

## Later / research

- cross-platform engine ports without weakening the native macOS experience
- broader model and hardware coverage backed by measured quality and memory gates
- contributor-friendly benchmark corpora and reproducible performance reports

To propose or claim an item, open an issue with the user problem, constraints,
and the evidence that would show it is complete.
