# Support

Madi currently supports Apple Silicon Macs running macOS 14 or later. The latest
stable release is the supported binary; source builds are supported on a
best-effort basis.

- Installation and usage: [user manual](docs/manual/en/01-getting-started.md)
- Bugs: [bug report](https://github.com/companyjupiter/madi/issues/new?template=bug_report.yml)
- Feature ideas: [feature request](https://github.com/companyjupiter/madi/issues/new?template=feature_request.yml)
- Development: [CONTRIBUTING.md](CONTRIBUTING.md)
- Security or sensitive privacy reports: [private vulnerability report](https://github.com/companyjupiter/madi/security/advisories/new)

Include the Madi version, macOS version, Mac model/memory, expected and actual
behavior, and minimal reproduction steps. Do not attach transcripts, recordings,
models, debug bundles, or other sensitive material to a public issue.

There is no guaranteed response time for ordinary support requests. Security
reports should receive an initial response within one week.
