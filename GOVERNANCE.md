# Governance

Madi is an open-source project maintained by Juyoung Song (`@jupitersong`) under
the `companyjupiter` GitHub organization.

## Decision making

The maintainer has final responsibility for product direction, releases,
security response, licensing, and use of the Madi name and marks. Routine changes
are decided in issues and pull requests using technical evidence, user impact,
and fit with the local-first product direction. Material changes should start as
an issue so the contract can be agreed before implementation.

The project prefers small, reviewable changes. Performance, accuracy, latency,
and memory claims need reproducible measurements. A rejected experiment may be
recorded when it prevents the same dead end from being repeated.

## Maintainer responsibilities

- keep the public build, tests, release notes, and security policy current;
- review contributions and disclose material conflicts of interest;
- preserve contributor attribution and agreement records;
- make security fixes available promptly; and
- explain reversals or breaking decisions in the relevant issue or pull request.

## Contributors

Contributors retain copyright in their work and submit it under the terms in
[CLA.md](CLA.md). The contribution process is documented in
[CONTRIBUTING.md](CONTRIBUTING.md). Recognition is recorded in
[AUTHORS.md](AUTHORS.md) after the first merged contribution.

## Conduct and security

Participation is governed by [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Security
reports must use the private process in [SECURITY.md](SECURITY.md), not a public
issue.
