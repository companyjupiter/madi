# AI 摘要与问答

转写完成后，设备端 LLM 会把会议提炼成结构化的摘要，你也可以用自然语言就会议内容提问。摘要与问答使用与翻译相同的、按硬件自动选定的模型（8 GB 上为 DNA3.0-2B，16 GB 及以上为 4B），并且**转写稿和摘要都不会离开这台 Mac。**

> Madi 的界面可在 **설정 (⌘,) → 표시 → 언어 / Language** 中于 한국어 / English / 日本語 之间切换（暂无中文界面）。下文以韩语标签为准，括号内为中文说明。

## 第一步：翻译/摘要模型

摘要与问答使用与翻译相同的设备端模型。没有它时，**摘要按钮不会出现**。下载方法参见**实时翻译**或**设置**。

## 生成会议摘要

1. 转写完成后（不是录音进行中），按顶部工具栏的 **✦（星光）按钮**。也可以从 **⌘K** 命令面板中选择 **요약 생성**（生成摘要）。
2. **회의 요약**（会议摘要）面板打开，本地 LLM 开始生成摘要，并附有“转写稿绝不会离开这台 Mac”的提示。
3. 顶部的 **전체 / 화자별**（整体 / 按说话人）开关用于切换视图。
   - **전체**（整体）—— 把整场会议归为一整份（具体有哪些板块，取决于下文的摘要模板）。
   - **화자별**（按说话人）—— 每位说话人各自谈了什么（首次选择时生成）。
4. 其右侧的 **회의 / 강의 / 인터뷰**（会议 / 讲座 / 访谈）开关用于选择**摘要模板**。紧邻下方会用一行显示该模板给出的板块构成 —— 例如选 **회의**（会议）时显示 “요약 · 액션 · 결정”（摘要 · 待办 · 决定）。默认值会依据第一个界面里选的会议模式自动确定，平时保持原样即可。参见下文的**摘要模板**。

**说明**
- 只有在存在转写稿且不在录音状态时，✦ 按钮才可用。转写稿为空时它会变暗。

### 摘要面板中的按钮

- **복사**（复制）—— 把摘要文本复制到剪贴板。
- **다시 생성**（重新生成）—— 基于同一份转写稿重新生成摘要。
- **슬라이드(HTML)**（幻灯片，HTML）—— 导出可离线查看的 HTML 幻灯片，并在访达中显示。每个板块生成一张幻灯片，**待办**与 **후속 조치**（后续跟进）会以复选框样式呈现。
- **리캡 카드**（回顾卡片）—— 打开可分享的一页纸摘要（见下）。
- **내보내기…**（导出…）—— 把摘要保存为 `.md` 文件。

## 摘要模板

同样一份转写稿，是会议、是讲座还是访谈，该留下的东西并不一样。用摘要面板顶部的 **회의 / 강의 / 인터뷰**（会议 / 讲座 / 访谈）开关决定要提炼什么。

| 模板 | 会给出什么 | 适用场合 |
|---|---|---|
| **회의**（会议） | **요약**（摘要）· **액션 아이템**（待办）· **결정 사항**（决定事项） | 通用会议、1:1、站会 |
| **강의**（讲座） | **요약**（摘要）· **핵심 요점**（核心要点）· **용어·개념**（术语与概念） | 讲座、发表、研讨会 |
| **인터뷰**（访谈） | **요약**（摘要）· **문답**（问答）· **후속 조치**（后续跟进） | 访谈、咨询、问诊 |

三种模板都以 **2～4 句的摘要**开头，其下的各个板块则一行一条地罗列。访谈的 **문답**（问答）会以一行提问（`Q:`）紧跟一行回答（`A:`）的形式呈现。

**说明**
- **회의**（会议）模板的结果与此前完全一致。以前保存的摘要和导出的文件也照常打开。
- 三种模板在 8 GB Mac（DNA3.0-2B）与 16 GB 及以上 Mac（4B）两种模型上都已确认。

### 默认模板由 회의 모드（会议模式）决定

模板会依据你在第一个界面选的 **회의 모드**（会议模式）自动确定，平时不必特意去选。

| 회의 모드（会议模式） | 自动使用的模板 |
|---|---|
| **일반**（通用）· **1:1** · **스탠드업**（站会） | **회의**（会议） |
| **강의**（讲座） | **강의**（讲座） |
| **인터뷰**（访谈） | **인터뷰**（访谈） |

会议模式的选择方法参见**录音与转写**一章的 **회의 모드**（会议模式）。

### 在面板中切换会当场重新生成

- 切换模板时，已经做好的摘要会**连同整体与按说话人一并作废**。当前正在看的一侧会立即重新生成，另一侧则在你切到那个标签时生成。（按说话人的归纳方式本身与模板无关。）
- 摘要生成期间这个开关会变暗、无法选择。生成结束后恢复可用。
- 在面板中切换的模板只是**仅对本次会话生效的临时改动**。它不会被单独保存，一旦改动会议模式就会退回按模式确定的模板。如果今后都想用某个模板，请在第一个界面改会议模式。

### 후속 조치（后续跟进）会接到待办上

访谈模板的 **후속 조치**（后续跟进）与待办按同一类处理。因此它会一并进入回顾卡片的待办清单。

讲座模板既没有决定事项也没有待办，所以回顾卡片的决定事项与待办清单会是空的，取而代之的是 **핵심 요점**（核心要点）与 **용어·개념**（术语与概念）。这是刻意如此 —— 讲座要留下的正是这些。

### 较长的会议与讲座

长到无法一口气读完的转写稿，会先分段折叠再合并成摘要。此时**折叠时保留什么**会随模板而变 —— 讲座优先保留核心要点与术语，访谈优先保留成对的问答与后续跟进。

## 回顾卡片

一页纸的可分享会议摘要。在摘要面板中用 **리캡 카드** 打开。它包含：

- 标题 + 日期
- 一句话结论（TL;DR）
- 模板专属板块 —— 讲座的 **핵심 요점**（核心要点）、**용어·개념**（术语与概念），以及访谈的 **문답**（问答），会原样接在 TL;DR 下方（会议摘要中没有这些）
- 决定事项清单
- 按负责人归类的待办 —— 访谈的 **후속 조치**（后续跟进）也一并计入
- 各说话人的发言时长
- 一句代表性引述

用 **복사**（复制）以 Markdown 形式复制，或用 **내보내기…**（导出…）保存为文件。

## 向会议提问（问答）

用自然语言就会议内容提问，本地 LLM 会基于转写稿作答。它位于摘要面板的底部。

1. 在 **회의록에 물어보기**（向会议记录提问）输入框中输入问题。例如 “무엇을 결정했나요?”（我们决定了什么？）、“김부장이 맡은 일은?”（金部长负责什么？）。
2. 按纸飞机按钮或回车。
3. **이 회의 / 전체 워크스페이스**（本次会议 / 整个工作区）开关用于设定检索范围。
   - **이 회의**（本次会议）—— 只依据当前打开的转写稿作答。
   - **전체 워크스페이스**（整个工作区）—— 跨**所有**已保存的转写稿检索。例如 “지난달 보안 결정은?”（上个月有哪些安全相关的决定？）。

**说明**
- 回答期间会显示 “로컬 LLM이 답하는 중…”（本地 LLM 正在作答…）。

## 隐私

摘要与问答都在这台 Mac 上运行。转写稿和摘要都不会离开设备。
