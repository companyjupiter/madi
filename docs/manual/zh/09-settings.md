# 设置

用 **⌘,（Command + 逗号）**打开设置 —— 左侧面板的齿轮按钮效果相同。这里放的是**“设一次就好”**的选项，而不是每场会议都要动的东西。顶部的标签页依次是 **녹음 · 저장 · 번역 · 단어장 · 모델**（录音 · 保存 · 翻译 · 词汇表 · 模型）。

> Madi 的界面可在 **설정 (⌘,) → 표시 → 언어 / Language** 中于 한국어 / English / 日本語 之间切换（暂无中文界面）。下文以韩语标签为准，括号内为中文说明。

> **每场会议单独选择的项目**（输入/输出语言、会议模式、说话人数量）**不在**设置里 —— 它们在第一个界面的 **회의 정보**（会议信息）中。参见**录音与转写**。

> **说明：** 录音中或暂停时 **녹음**（录音）标签页会被锁定。停止录音后才能修改。

---

## 녹음（录音）

音频如何采集、实时转写如何表现，以及外观。

### 입력（输入）

- **음원**（音源）—— 要监听什么。
  - **마이크**（麦克风）—— 你的声音 / 线下面对面会议。
  - **시스템 오디오**（系统音频）—— Mac 上正在播放的声音（Zoom、Teams、Slack、YouTube 等）。首次使用会请求屏幕录制权限（仅使用音频，屏幕内容从不保存）。
  - **마이크+시스템**（麦克风+系统）—— 最适合线上会议（你的声音加上对方的声音）。
- **마이크**（麦克风）—— 使用哪个输入设备（当音源为 마이크 或 마이크+시스템 时）。默认是 “시스템 기본”（系统默认）。
- **언어**（语言）—— 固定转写语言或保持自动：**자동 감지**（自动检测）**/ 한국어 / English**。

### 화자（说话人）

- **화자 분리**（说话人分离）—— 区分是谁在说话。
- **중첩 발화 감지**（重叠发言检测）—— 检测两个人同时说话的位置（详细视图中的重叠标记）。

### 실시간（实时）

- **반응 속도**（响应速度）—— **빠름 (5초)** / **보통 (7초)** / **정확 (10초)**（快速 5 秒 / 普通 7 秒 / 精确 10 秒）。快速会更频繁地把文字送上屏幕，体感更快；精确能看到更多上下文，读起来更顺。
  - *当输出语言为 2 种或以上时，这一项会降到 **보통 (7초)** 的下限 —— 即使你选了快速，也会变成 7 秒。双向场景（`한국어` 加上恰好一种其他语言）不受此限。*
- **실시간 프리뷰**（实时预览）—— 在窗口最终确定前以灰色显示临时文字。它与确定转写共用同一个 Whisper 进程，不会启动第二个模型。

### 표시（外观）

- **언어 / Language** —— App 的界面语言：**한국어 / English / 日本語**。无需重启即时切换。（本手册另有中文版，但 App 界面暂无中文。）
- **외관**（外观）—— 跟随系统 / 浅色 / 深色主题。

### 자막 오버레이 (진료실)（字幕浮层 —— 诊室）

口译字幕窗口与第二块（患者）显示屏的尺寸设定。参见**实时翻译**。

- **직원 자막 크기**（工作人员字幕大小）—— 主显示器上的字幕文字（14–48 pt）。
- **환자용 대형 자막 (별도 화면)**（患者用大字幕 —— 独立屏幕）—— 以隔着房间也能看清的字号，用患者的语言显示第二个面板。开启后会展开：
  - **환자 자막 크기**（患者字幕大小）—— 24–96 pt。
  - **환자 화면**（患者屏幕）—— 连接了多块屏幕时，使用哪一块。
  - **환자 언어**（患者语言）—— 自动（对方的语言）或固定。

## 저장（保存）

文件保存与识别阈值。

### 자동 저장（自动保存）

- **완료 시 .md 자동저장**（完成时自动保存 .md）—— 转写结束时写出一个 Markdown 文件。
- **폴더 / 변경…**（文件夹 / 更改…）—— 选择保存文件夹。该文件夹就是浏览器中显示的工作区。

> 同样的设置也在工作区浏览器底部。

### 음성 인식（语音识别）

- **저신뢰 표시 기준 (VAD)**（低置信标记阈值）—— 识别置信度低于此值（默认 0.55）的词会被标记为 **검토 필요**（需复核）。范围 0.35–0.9；调高会标记出更多词。参见**复核与校正**。

## 번역（翻译）

设备端翻译（韩语、英语、日语、中文）的开关所在。

> 在不含翻译引擎的构建中，这个标签页会被完全隐藏。

### 번역 모델 —— 翻译模型（8 GB：DNA3.0-2B · 约 1.31 GB / 16 GB 以上：DNA3.0-4B · 约 2.78 GB）

- **상태**（状态）—— 설치됨（已安装）/ 검증 중（校验中）/ 下载进度 / 미설치（未安装）。
- **번역 모델 다운로드**（下载翻译模型）—— 获取为这台 Mac 选定的模型。它不随 App 一起打包。实测引擎进程占用：2B 约 2.4 GB，4B 约 5.1 GB。下载过程中可以 **취소**（取消）；安装完成后，**Finder에서 보기**（在访达中显示）可打开其所在位置。

### 실시간 번역 (다중 대상) —— 实时翻译，多目标

- **한국어 / English / 日本語 / 中文** —— 切换目标语言（最多 3 种）。每一行都会一次性翻译成全部所选语言，并显示在原文下方（源语言会被自动排除）。
- 需要先安装模型。目标语言为 2 种以上时，响应速度会降到 “보통 (7초)” 的下限 —— 参见录音标签页。

### 번역 반응 (실시간) —— 实时翻译响应

- **마지막 줄 대기 (초)**（等待最后一行，秒）—— 在最后一行发言不再变化后，再等待这么久（0.5–5.0 秒，默认 3）才去翻译它。设得越短字幕出现越早，但可能翻译到没说完的句子。**已确定的行（下一行开始之后）无论此值为多少都会立即翻译**，并且它与 STT 的响应速度设置相互独立。

### AI 교정 (세션 종료 후) —— AI 校正（会话结束后）

- **화자·언어 자동 교정**（自动校正说话人与语言）—— 录音结束时，设备端 LLM 会通读对话，保守地修正明显的说话人切分错误和语种错误的行。说话人校正可以**一次点击撤销**。
- 需要按硬件自动选定的 DNA3.0 翻译/摘要模型。

## 단어장（词汇表）

Madi 会学习你对经常听错的专业术语和人名所做的更正，并在之后的会议中自动修正类似错误。参见**复核与校正**。

- **학습한 교정 자동 적용**（自动套用已学习的更正）—— 控制已学习的更正是否真的被套用。**学习始终在进行**，这个开关只控制是否套用。（默认关闭 —— 需要你自己打开。）
- **최소 확인 횟수**（最少确认次数）—— 同一条更正需要被看到多少次（1–5）才会被自动套用。数值越高越保守，一次误改就不会覆盖之后的转写稿。
- **已学习更正列表** —— 显示每条规则（错词 → 正确词、命中次数）。垃圾桶按钮忘掉某一条；**전체 지우기**（全部清除）清空所有规则。

---

## 모델（模型）

转写（Whisper）模型的状态与管理。

- **상태 / 위치**（状态 / 位置）—— 模型是否已安装，以及它的文件路径。
- **모델 재다운로드**（重新下载模型）—— 再取一次。
- **Finder에서 보기**（在访达中显示）—— 打开模型所在位置。

> 选定的 DNA3.0 翻译模型在 **번역**（翻译）标签页中管理。

> **系统听写**将在之后提供，因此当前测试版**没有 받아쓰기（听写）标签页。**（参见**系统听写（后续提供）**。）
