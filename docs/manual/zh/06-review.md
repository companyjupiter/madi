# 复核与校正

转写完成后，你可以干净地通读，也可以凑近逐句修改。Madi 会记住你做的修改，并在之后的会议中自动套用。

> Madi 的界面可在 **설정 (⌘,) → 표시 → 언어 / Language** 中于 한국어 / English / 日本語 之间切换（暂无中文界面）。下文以韩语标签为准，括号内为中文说明。

## 내용（内容）视图与 상세（详细）视图

窗口顶部的切换开关可在两种视图之间切换。

- **내용**（内容）—— 干净的阅读视图，没有时间码和各类标记。
- **상세**（详细）—— 额外显示时间码、把握不足的词（琥珀色）以及说话人重叠标记（**⟨+姓名 겹침⟩**）。

复核和编辑都在 **상세**（详细）视图中进行。

## 编辑某一行

1. **双击**你想修改的那一行（或在 **상세** 视图中按铅笔按钮，提示文字为 **“이 문장 편집”** / 编辑这一句）。
2. 从 **내용** 视图双击会自动切换到 **상세** 并打开编辑器。
3. 修改文字后按 **저장**（保存，⌘↩）。想放弃则按 **취소**（取消，Esc）。
4. 编辑过的行会被标记为 **편집됨**（已编辑）。

当你修改原文时，仍在基于旧文本生成的译文会被丢弃，并针对你更正后的文本重新翻译。迟到的 AI 结果绝不会覆盖你的更正。

## 校正译文

**双击**已完成的译文，会打开 **번역 교정**（译文校正）输入框，可直接修改该语种的译文。

- 保存后的译文会带上铅笔标记，多目标翻译中的其他语言不受影响。
- 更正后的原文、译文和说话人姓名都会保存进 Markdown 和 JSON，重新打开 Markdown 转写稿时译文依然保留。
- SRT/VTT 始终使用最终更正后的原文。

## 검토 필요（需复核）—— 扫过把握不足的词

**상세** 视图会用琥珀色高亮识别置信度低于阈值（默认 0.55）的词。

1. 顶部的横条显示 **검토 필요 N개**（N 个词需复核）以及你当前的位置（**N/总数**）。
2. 用 **∧**（上一个标记词）和 **∨**（下一个标记词）在它们之间跳转。
3. 逐个确认，必要时就地修改。

阈值可在 **설정 (⌘,) → 저장 → 음성 인식**（设置 → 保存 → 语音识别）中的 **저신뢰 표시 기준 (VAD)** 调整。调高会标记出更多词。

## 听音复核

对于文件转写，Madi 可以为每个被标记的词回放对应音频，让你用耳朵确认。

1. 按复核横条中的播放按钮（提示文字为 **“저신뢰 단어 귀로 검토”** / 用耳朵复核低置信词）。
2. 被标记的词会按顺序播放并自动前进 —— 无需动手。进度显示为 **재생 N/총수**（播放 N/总数）。
3. 再按一次同一个按钮即可停止（提示文字为 **“귀로 검토 멈춤”** / 停止听音复核）。

> **说明：** 听音复核**只对文件转写生效**，因为那时原始媒体文件仍然存在。实时麦克风录音没有源文件，因此不会出现该功能。

## AI 校正（录音结束后）

录音结束后，设备端 LLM 会通读整场对话，保守地修正**明显的说话人切分错误**和**被转写成错误语种的行**。

- **开启方式：** **설정 (⌘,) → 번역 → AI 교정 (세션 종료 후)** → **화자·언어 자동 교정**。
- 应用后，转写稿上方会出现一条提示，并带有 **화자 교정 되돌리기**（撤销说话人校正）按钮 —— **一次点击即可全部还原。**
- 需要按硬件自动选定的 DNA3.0 翻译模型。

## 个人词汇表 —— 从你的更正中学习

当你修改某一行时，Madi 会学下这条更正。开启 **단어장**（词汇表）开关后，它会在之后的会议中自动修正同样的专业术语或人名。

**开启方式：** **설정 (⌘,) → 단어장**（设置 → 词汇表）中的 **학습한 교정 자동 적용**（自动套用已学习的更正）开关。

> **说明：** 学习是**始终**进行的，与开关无关 —— 开关只控制是否*套用*。因此一打开它，此前学到的内容会立即全部生效。

### 置信阈值（最少命中次数）

- **최소 확인 횟수**（最少确认次数）滑块设定同一条更正需要被看到多少次才会被信任并自动套用（1–5）。
- 数值越高越保守 —— 可以防止一次误改覆盖之后的转写稿。

### 管理已学习的更正

在 **설정 → 단어장** 下的列表中管理已学习的规则。

- 每条规则显示为 `错词 → 正确词`，并附带命中次数。
- 规则旁的垃圾桶按钮可以只忘掉这一条。
- **전체 지우기**（全部清除）会清空所有规则。

## 选中与复制文本

你可以在整份转写稿上拖动选中，并用 **⌘C** 复制。
