# 说话人

Madi 会自动判断会议中是谁在说话。所有这些处理都在这台 Mac 上完成。

> Madi 的界面可在 **설정 (⌘,) → 표시 → 언어 / Language** 中于 한국어 / English / 日本語 之间切换（暂无中文界面）。下文以韩语标签为准，括号内为中文说明。

## 自动说话人分离

在录音与转写的过程中，Madi 会自动按说话人切分发言。

- 每位说话人会获得各自的**颜色**和 **화자 N**（说话人 N）标签。
- 左侧面板的**说话人条**用一行呈现整场会议中谁在什么时候说话。

**说明**
- 你可以在 **설정 (⌘,) → 녹음 → 화자**（设置 → 录音 → 说话人）中用 **화자 분리**（说话人分离）开关关闭它。

## 固定说话人数量

如果你知道房间里有几个人，设置它可以提高准确度。

1. 在第一个界面进入 **회의 정보 → 화자**（会议信息 → 说话人）。
2. 选择 **자동**（自动）**/ 2명 / 3명 / 4명 / 5명 이상**（2 / 3 / 4 / 5 人以上）。没有“1 人”这一项 —— 单人主讲时改为关闭 **화자 분리**。

**说明**
- 在你确定的情况下固定人数，说话人的切分会更干净。如果不确定，就保留 **자동**（自动）。
- 请在录音**之前**选择 —— 录音一旦开始就会锁定。

### 미확인（未确认）说话人

当你**固定**了说话人数量时，凡是明显与你指定的这几个人都对不上的声音，都会被归入 **미확인**（未确认）。这样可以避免路人的一句插话或一阵噪声被错误地算到某位真实说话人头上。

- **미확인** 不是一个人，它的含义是“这段没有地方可放”。你无法为它命名。
- 当人数保持为自动时，它绝不会出现。

## 为说话人命名

1. 在转写稿中点击说话人标签（例如 **화자 1** / 说话人 1）或说话人标记。
2. 在 **이름 (예: 김부장)**（姓名，例如 金部长）输入框中填入真实姓名。
3. 按 **저장**（保存）。该姓名会应用到**这位说话人的所有行以及导出内容**。

**说明**
- 姓名**只对这一份转写稿生效**。下次会议时 Madi 不会自动认出同一个人 —— 每次都需要重新命名。
- **미확인**（未确认）无法命名。

## AI 说话人校正（录音结束后）

录音结束后，设备端 LLM 会通读对话，保守地修正**明显的说话人切分错误** —— 同一个人的发言被拆成两位说话人，或者某一行被算到了错误的人身上。

- 在 **설정 (⌘,) → 번역 → AI 교정 (세션 종료 후)**（设置 → 翻译 → AI 校正（会话结束后））中的 **화자·언어 자동 교정**（自动校正说话人与语言）开关处切换。
- 应用了校正后，转写稿上方会出现一条提示，并带有 **화자 교정 되돌리기**（撤销说话人校正）按钮 —— **一次点击即可全部还原。**
- 需要按硬件自动选定的 DNA3.0 翻译模型。

## 重叠标记

当两个人同时说话时，**상세**（详细）视图会显示 **⟨+姓名 겹침⟩**（重叠）标记，指出插话进来的第二位说话人。

**说明**
- 重叠标记**只**在 **상세**（详细）视图中出现。请在窗口顶部从 **내용 → 상세** 切换。
- 需要在 **설정 (⌘,) → 녹음 → 화자** 中开启 **중첩 발화 감지**（重叠发言检测）。
