# 录音与转写

Madi 会在人们说话的同时实时转写会议，也能转写你已有的音频和视频文件。所有处理都在这台 Mac 上完成 —— 你的转写稿不会离开设备。

> Madi 的界面可在 **설정 (⌘,) → 표시 → 언어 / Language** 中于 한국어 / English / 日本語 之间切换（暂无中文界面）。下文以韩语标签为准，括号内为中文说明。

## 第一个界面 —— 会议信息与开始

打开 App 后，第一个界面分为两半。左侧告诉 Madi **这是一场什么样的会议**，右侧用来**开始**。

### 회의 정보（会议信息）—— 左侧

在录音前设置好这些内容能提升结果质量。**录音期间会被锁定。**

- **입력 언어**（输入语言）—— 正在被说的语言。可以自动检测，也可以固定为某种语言。
- **출력 언어**（输出语言）—— 要翻译成的语言（可多选）。需要翻译模型。参见**实时翻译**。
- **회의 모드**（会议模式）—— 会议的性质。见下文。
- **화자**（说话人）—— 房间里有几个人。见下文。

### 시작하기（开始）—— 右侧

- **파일로 시작하기**（从文件开始）—— 选好或拖入文件后按此按钮。
- **지금 녹음 시작**（立即开始录音）—— 选择麦克风后立即录音。

## 实时麦克风录音

1. 在 **시작하기**（开始）中选择麦克风（默认是 “시스템 기본” / 系统默认）。
2. 按 **지금 녹음 시작**（立即开始录音）。正式录音前会有一小段倒计时 —— 期间可以**取消**。
3. 随着人们说话，转写稿会在窗口中间实时滚动。
4. 在左侧面板中按 **일시 정지**（暂停，⌘P）暂停，或按 **정지**（停止，⌘R）结束。

**说明**
- 停止会把到目前为止采集的内容全部收尾。若已开启自动保存，会写入文件。
- 若未开启自动保存，Madi 会在你离开前提醒你 —— 可以先用 **내보내기**（导出）保存。

### 에너지 흐름（能量流）

左侧面板底部的 **에너지 흐름** 曲线用一条线呈现会议的质感 —— 它是**语速、重叠发言与沉默**的综合结果。

- **点击曲线上的某一点即可跳到那个时刻。** 用来找出会议最热烈的一段很方便。
- 在发言量还不够时会显示 “발언이 쌓이면 흐름이 표시됩니다”（发言累积后会显示流势）。

### 录音中更换麦克风

在实时录音过程中，左侧面板的 **입력 마이크**（输入麦克风）一行可以**在不中断录音的前提下**切换麦克风 —— 会议进行到一半插上耳机时很有用。

### 你一停下来，字幕就出现

Madi 不会等到窗口被填满。当你**说完一句停顿片刻**时，它会提前关闭那个窗口并立即输出转写 —— 在问诊那样一来一回的短对话中，等待感会明显缩短。轻声和远场的说话也不会被切断：判定阈值会自动适应。

## 系统音频采集（Zoom / Teams / 视频）

你可以转写 Mac 上正在播放的任何声音 —— 线上会议、视频等等。

1. 进入 **설정 → 녹음 → 입력**（设置 → 录音 → 输入）。
2. 在 **음원**（音源）下选择采集方式：
   - **마이크**（麦克风）—— 只采集你面前的声音
   - **시스템 오디오**（系统音频）—— Mac 上正在播放的声音：Zoom、Teams、Slack、YouTube 等
   - **마이크+시스템**（麦克风+系统）—— 用于线上会议：你的声音加上对方的声音
3. 照常开始录音。

**说明**
- 第一次使用系统音频时，macOS 会请求**屏幕录制**权限。只会使用音频，屏幕内容从不保存。

## 文件与视频转写

1. 把文件**拖放**到窗口上，或点击 **파일 선택 or 드래그 앤 드롭**（选择文件或拖放）区域来挑选。拖动过程中会显示 **드롭하여 전사**（放开以转写）。
2. 按 **파일로 시작하기**（从文件开始）。
3. 进度显示为 **전사 중 · N%**（转写中 · N%）。
4. 完成后结果会显示在屏幕上。

**说明**
- 拖入文件本身**不会**自动开始转写 —— 必须按 **파일로 시작하기**。这个间隔正是你先调整会议信息的机会。
- 视频（mp4、mov、m4v、mkv、webm、avi 等）中的音频会被自动提取，无需事先转换。
- 有两项功能**只**对文件转写生效：逐行**音频回放**和**听音复核**。参见**复核与校正**以及**工作区与导出**。

## 회의 모드（会议模式）

一组预设，按会议的性质调整说话人数量与侧重点。在第一个界面的 **회의 정보 → 회의 모드** 中选择。

| 模式 | 调整内容 |
|---|---|
| **일반**（通用） | 默认 · 自动检测说话人 |
| **1:1** | 2 位说话人 · 侧重决定事项与后续跟进 |
| **스탠드업**（站会） | 自动检测说话人 · 侧重待办与阻塞项 |
| **인터뷰**（访谈） | 2 位说话人 · 保留一问一答的结构 |
| **강의**（讲座） | 1 位说话人 · 围绕要点组织内容 —— **会自动关闭说话人分离** |

**说明**
- 请在开始录音**之前**选择会议模式。录音期间会被锁定。

## 화자（说话人数量）

如果你知道房间里有几个人，设置它可以改善说话人分离。在第一个界面的 **회의 정보 → 화자** 中选择 **자동**（自动）**/ 2명 / 3명 / 4명 / 5명 이상**（2 / 3 / 4 / 5 人以上）。**没有“1 人”这一项** —— 只有一位主讲人时，请在 **설정 → 녹음 → 화자** 中关闭 **화자 분리**（说话人分离）（**강의**（讲座）模式会自动这样做）。

在你确定的情况下固定人数，说话人的切分会更干净。如果不确定，就保留 **자동**（自动）。详情参见**说话人**一章。

## 切换转写视图

窗口顶部的切换开关可在两种视图之间切换。

- **내용**（内容）—— 干净易读的转写稿。默认视图，最适合阅读。
- **상세**（详细）—— 额外显示时间码、把握不足的词（以琥珀色高亮）以及说话人重叠标记。最适合复核与修改。

用顶部的 **A− / A+** 按钮调整文字大小。

## 隐私

Madi 中的每一份转写稿都在这台 Mac 上处理。你的转写稿不会离开设备。
