# 实时翻译与口译

Madi 的翻译 100% 在你的设备上运行 —— 不经过云端，也不需要账号。会议进行期间，每一行发言都会被翻译成韩语、英语、日语和/或中文，并显示在原文正下方。Madi 会在 8 GB 的 Mac 上自动使用 DNA3.0-2B，在 16 GB 及以上使用 DNA3.0-4B。

> Madi 的界面可在 **설정 (⌘,) → 표시 → 언어 / Language** 中于 한국어 / English / 日本語 之间切换（暂无中文界面）。下文以韩语标签为准，括号内为中文说明。

## 第一步：下载翻译模型

翻译需要一个未随 App 一起打包的独立模型。在 8 GB 的 Mac 上下载一次 DNA3.0-2B（约 1.31 GB），在 16 GB 及以上下载 DNA3.0-4B（约 2.78 GB）。

1. 打开 **설정 (⌘,) → 번역**（设置 → 翻译）。
2. 按 **번역 모델 다운로드**（下载翻译模型）。
3. 下载完成后，翻译相关选项即可使用。

实测引擎进程占用：2B 约 2.4 GB，4B 约 5.1 GB。模型安装之前这些开关是禁用状态，并会显示 “번역 모델을 먼저 다운로드하세요.”（请先下载翻译模型。）

> **如果你看不到 번역 标签页** —— 说明你的构建不包含翻译引擎，翻译功能完全不可用。

## 选择输出语言

两个位置，同一项设置 —— 哪个顺手用哪个。

- **第一个界面 → 회의 정보 → 출력 언어**（会议信息 → 输出语言）—— 在开始一场会议时设置。
- **설정 (⌘,) → 번역 → 실시간 번역 (다중 대상)**（设置 → 翻译 → 实时翻译（多目标））—— 한국어 / English / 日本語 / 中文 的各个开关。

每一行都会被翻译成你选中的所有语言，并直接显示在原文下方，各自标注语种。源语言会被自动排除。

**说明**
- 最多可以选择 **3 种**输出语言。
- 没有翻译模型时，完全无法选择输出语言。

## 译文会自己一个字一个字打出来

Madi 不会等到整句翻译完成才显示。文字会随着生成过程逐步填入屏幕。仍在书写中的行末会有一个 **▍** 光标闪烁，让你知道它还在继续，而不是被截断了。

当某人还在说话时，会先出现一版临时译文，标记为 **진행 중**（进行中）。当该行最终确定后，临时译文会平滑地替换为最终译文 —— 而且临时译文会一直留在屏幕上直到最终版到达，因此译文绝不会中途消失。

## 面对面口译 —— 双向模式

Madi 专为同一个房间里使用不同语言的两个人而设计（例如一位韩国工作人员和一位日本或中国来访者）。

只开启 **`한국어` 加上另外一种语言**（例如 한국어 + 일본어），它就会变成双向口译模式。

- **逐行判断翻译方向。** 日语的一行只翻译成韩语，韩语的一行只翻译成日语。没有多余的工作，因此更快。
- **即使两种语言交替出现，双方也都能被正确转写。** 语种会逐段重新判定，因此一人说韩语、另一人说日语时，两边的转写都准确。
- 该组合不受下文的延迟下限限制。

## 常用语词典（即时翻译）

对于需要反复说同一段说明的场合（例如诊所的术后注意事项），你可以预先存好常用语句的译文。当命中已存的语句时，译文会**瞬间（0 秒）**出现，完全不经过模型。

系统默认自带了一些语句，你也可以自行添加或修改。

- 文件：`~/Library/Application Support/Sovereign/faq_translations.json`
- 出于安全考虑，只在**完全一致**时才会触发。

## 延迟与翻译质量

当输出语言为 **2 种或以上**时，源文本的边界错误会传播到每一种语言 —— 因此响应速度会降到 **보통 (7초)**（普通，7 秒）这一下限。如果你原本选的是 **빠름 (5초)**（快速，5 秒），它会自动变为 7 秒。**정확 (10초)**（精确，10 秒）仍然可用。

> **例外：双向**模式（`한국어` 加上恰好一种其他语言）不受此限制，因为每一行实际的目标语言数量降为一种。面对面口译时字幕出现得更快。

当翻译跟不上时，你会看到 **“번역 중 · N줄 대기”**（翻译中 · N 行排队）。这并不是卡住了：已确定的转写行会先于可丢弃的预览处理，同一行的陈旧版本也会被合并。8 GB 配置会保持四轮的实时队列上限，并在录音停止后补齐被延后的持久化行。

## AI 语言校正（录音结束后）

录音结束后，设备端 LLM 会通读对话，保守地修正**被转写成错误语种的行**。在 **설정 (⌘,) → 번역 → AI 교정 (세션 종료 후)** → **화자·언어 자동 교정** 处开关。参见**说话人**一章。

## 字幕浮层

**字幕浮层**是一个悬浮在所有窗口之上的实时译文字幕窗口。把它停在 Zoom 或 Teams 通话上，或者放到诊室显示屏上，就能实时跟上对方在说什么。

用顶部工具栏的**对话气泡图标**开关它。**只有在你至少选择了一种输出语言之后，这个按钮才会出现。**

- 该窗口始终保持在最前，但从不夺取焦点，因此你可以继续在通话 App 里点击和输入。
- 它会浮在全屏 App 之上，你可以拖动它的背景把它放到任何位置。
- 最大的文字是译文，下方较小的文字是原文。
- 多人场景下，字幕会带上**说话人的颜色和姓名**，让你知道是谁在说。
- 等待发言时，会有一条**麦克风电平条**在动，确认系统正在监听。
- 状态文字（“진행 중 / 번역 중… / 음성을 기다리는 중…”）会以**观看者的语言**显示 —— 日语字幕上是「翻訳中…」，中文字幕上是「翻译中…」。

### 工作人员字幕 + 患者字幕（双屏显示）

用于诊室口译时，你可以把字幕拆成**两个**面板。

- **工作人员字幕** —— 小号，显示在主显示器上，使用工作人员的语言。
- **患者字幕** —— 大号，显示在外接显示器上，便于远距离阅读，使用患者的语言。

在 **설정 (⌘,) → 녹음 → 자막 오버레이 (진료실)**（设置 → 录音 → 字幕浮层（诊室））中开启。你可以设置工作人员文字大小（14–48 pt）、患者文字大小（24–96 pt）、使用哪块显示器以及患者的语言。较大的字号是为了在治疗椅与显示屏之间 1.5–2.5 米的距离上依然清晰可读。
