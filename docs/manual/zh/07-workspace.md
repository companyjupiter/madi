# 工作区与导出

Madi 把你的整个保存文件夹当作一个工作区来呈现。窗口右侧的**工作区浏览器**可以让你重新打开过往会议、更改保存位置，并按需要的格式导出。

> Madi 的界面可在 **설정 (⌘,) → 표시 → 언어 / Language** 中于 한국어 / English / 日本語 之间切换（暂无中文界面）。下文以韩语标签为准，括号内为中文说明。

## 工作区浏览器

浏览器**始终显示**在窗口右侧。上半部分是会议列表，下半部分是自动保存、文件夹和导出的控件。

### 会议列表

- **파일**（文件）标签页按时间倒序列出保存文件夹中的转写稿。
- 点击某份转写稿即可重新打开那场会议。

## 自动保存

- 开启 **자동저장**（自动保存）开关后，转写完成时会把转写稿保存为 **Markdown (.md)**。
- **폴더**（文件夹）一行显示当前的保存位置。按 **변경**（更改）可以另选一个。
- 你选定的文件夹同时是**保存**和**导出**的默认位置。

> 同样的设置也在 **설정 (⌘,) → 저장**（设置 → 保存）中。哪个顺手用哪个。

**提示** —— 按 **⌘K** 并输入 **작업 폴더 변경**（更改工作区文件夹），可以直接挑选文件夹。

## 导出

按浏览器底部的 **내보내기**（导出），Madi 会询问 **내보내기 형식**（导出格式）。选定后再选择保存位置。

| 格式 | 用途 |
|---|---|
| **Markdown (.md)** | Markdown 转写稿。包含说话人姓名、译文和更正内容 |
| **字幕 (.srt)** | SRT 字幕 |
| **字幕 (.vtt)** | VTT 字幕 |
| **纯文本 (.txt)** | 纯文本 |
| **JSON (.json)** | JSON 数据 |

**说明**
- 转写稿为空时，**내보내기** 按钮会变暗。
- SRT/VTT 始终使用最终更正后的原文。参见**复核与校正**。

## 点击即可听到那一刻

对于**由音频或视频文件**转写而来的会话（原始文件仍在磁盘上），每一行都会有一个播放按钮。

1. 按你想听的那一行上的播放按钮（提示文字为 **“이 구간 오디오 재생”** / 播放这一段的音频）。
2. 原始媒体会从这一行被说出的那一刻开始播放。

> **说明：** 实时麦克风会话没有源文件，因此不会出现逐行播放按钮。

## 快速找到过往会议

在 **⌘K** 命令面板中输入会议名称，即可直接跳到那份已保存的转写稿。也可以按说话人姓名检索。
