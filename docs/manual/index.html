01

시작하기

Madi(마디)에 오신 것을 환영합니다. Madi는 회의를 전부 이 Mac 안에서 받아쓰고 옮기는 앱입니다. 실시간 받아쓰기, 오디오·영상 파일 전사, 화자 분리, 온디바이스 번역까지 — 모든 처리가 여러분의 Mac 안에서 일어납니다.

Madi가 하는 일

  • 실시간 전사 — 마이크나 회의 음성을 들으며 말이 끝나기 무섭게 텍스트가 나타납니다.
  • 파일·영상 전사 — 녹음 파일이나 영상을 끌어다 놓으면 전체 대화를 받아씁니다.
  • 화자 분리 — 누가 언제 말했는지 구분하고, 이름을 붙일 수 있습니다.
  • 온디바이스 번역·통역 — 한국어·English·日本語·中文을 실시간으로 옮기고, 화면 위 자막으로 띄웁니다.
  • AI 요약·질의응답 — 회의가 끝나면 요약·결정·액션을 정리하고, 회의 내용에 대해 자연어로 질문할 수 있습니다.
  • 검토와 교정 — 잘못 들은 단어를 찾아 고치고, 고친 내용을 기억해 다음 회의에 적용합니다.
  • 시스템 받아쓰기 — 어느 앱에서나 단축키를 누르고 말하면 그 자리에 글로 들어갑니다.

100% 온디바이스 — 내 데이터는 Mac을 떠나지 않습니다

Madi의 핵심 약속은 주권(sovereign) 입니다. 음성도, 전사문도, 번역도 클라우드로 전송되지 않습니다. 모델을 받아 둔 뒤에는 인터넷이 끊겨 있어도 동작합니다. 회의 내용은 오로지 여러분의 기기 안에만 존재합니다.

모델 안내

Madi는 두 종류의 AI 모델을 씁니다.

  • Whisper 음성 모델 — 받아쓰기를 담당합니다. 앱에 기본 동봉되어 있어 따로 받을 필요가 없습니다.
  • DNA3.0-4B 언어 모델 (약 2.6 GB) — 번역, AI 교정, 요약·질의응답에 쓰입니다. 앱 용량을 줄이기 위해 처음 쓸 때 다운로드합니다.
    • 받는 곳: 설정(⌘,) → 번역의 “번역 모델 다운로드” 버튼.
    • 다운로드 약 2.6 GB, 디스크 공간도 그만큼 필요합니다.

번역·요약·질의응답을 쓰지 않는다면 이 모델은 받지 않아도 됩니다. 전사와 화자 분리는 동봉된 Whisper만으로 완전히 동작합니다.

메모리 안내 (솔직하게)

  • 8 GB Mac (예: M1 MacBook Air) — 받아쓰기와 화자 분리는 원활히 돌아갑니다.
  • 번역을 켜면 약 3 GB가 추가로 필요합니다. 8 GB Mac에서도 쓸 수 있지만 여유가 빠듯해집니다.
  • 실시간 프리뷰를 켜면 약 830 MB가 더 듭니다.

Madi가 요청할 수 있는 권한

권한은 미리 한꺼번에 묻지 않고, 그 기능을 처음 쓸 때 필요한 것만 요청합니다.

  • 마이크 — 녹음할 때. 녹음을 처음 시작할 때 요청합니다.
  • 화면 기록 — 시스템 오디오(Mac에서 재생되는 소리, 예: Zoom·Teams·YouTube)를 녹음할 때만. macOS가 오디오 캡처를 화면 기록 권한으로 묶어두기 때문이며, 화면은 저장하지 않습니다.
  • 손쉬운 사용(Accessibility) — 시스템 받아쓰기를 쓸 때만. 받아쓴 텍스트를 다른 앱에 넣으려면 필요합니다. (시스템 받아쓰기 참고.)

권한을 거부했다가 나중에 켜고 싶으면 시스템 설정 → 개인정보 보호 및 보안에서 해당 항목(마이크 / 화면 기록 / 손쉬운 사용)을 찾아 Madi를 켜면 됩니다.

처음 실행 빠른 시작

  1. Madi를 엽니다. 첫 화면에 회의 정보와 시작하기 두 칸이 보입니다.
  2. 회의 정보에서 이번 회의에 맞게 골라 둡니다 — 입력 언어, (번역을 쓴다면) 출력 언어, 회의 모드, 화자 수.
  3. 시작하기에서 마이크를 고르고 지금 녹음 시작을 누르거나, 오디오·영상 파일을 끌어다 놓습니다.
  4. 화면 가운데에 실시간 전사문이 나타나는 것을 지켜봅니다.
  5. 정지를 누르면 거기까지의 기록이 정리됩니다. 자동저장이 켜져 있으면 파일로 저장됩니다.
번역을 쓰려면 먼저 설정(⌘,) → 번역에서 번역 모델(약 2.6 GB)을 받아야 합니다.

창 구조

녹음이 시작되면 창은 세 칸으로 나뉩니다.

  • 왼쪽 — 세션 패널: 녹음 버튼(일시 정지·정지), 총 시간, 화자 막대, 에너지 흐름 그래프. 설정(톱니)도 여기 있습니다.
  • 가운데 — 전사문: 받아쓴 내용. 여기서 읽고 고칩니다.
  • 오른쪽 — 작업 폴더 탐색기: 지난 회의 목록, 자동저장 스위치, 저장 폴더, 내보내기.

단축키

단축키하는 일
⌘,설정 열기
⌘K명령 팔레트 (아래 참고)

명령 팔레트 (⌘K)

⌘K를 누르면 검색창이 뜹니다. 메뉴를 뒤지지 않고 이름으로 바로 실행합니다. (View 메뉴의 명령 팔레트로도 열 수 있습니다.)

  • 요약 생성 / 화자별 요약 — 회의 요약 시트 열기 (전사문이 있을 때).
  • 새 세션 — 현재 전사를 비웁니다.
  • 작업 폴더 변경 — 저장 위치를 고릅니다.
  • 화자 이름 — 이 회의의 화자로 바로 이동합니다.
  • 지난 회의 이름 — 저장된 회의록을 열어 줍니다.

도움말 메뉴

  • Madi 사용자 매뉴얼 (⌘?) — 이 문서를 엽니다. 인터넷 없이 열립니다.
  • 업데이트 설치… — 새 버전이 있는지 확인하고 설치합니다.
  • 정보 — 버전과 라이선스를 보여 줍니다.

준비 완료입니다. 더 자세한 내용은 녹음, 화자, 번역, 받아쓰기, 설정 등 다른 페이지를 참고하세요.

02

녹음과 전사

Madi는 회의 음성을 실시간으로 받아 적고, 이미 녹음된 오디오·영상 파일도 전사합니다. 모든 처리는 이 Mac 안에서만 이루어지며, 전사 내용은 기기를 떠나지 않습니다.

첫 화면 — 회의 정보와 시작하기

앱을 열면 첫 화면이 두 칸으로 나뉩니다. 왼쪽에서 이번 회의가 어떤 회의인지 알려 주고, 오른쪽에서 시작합니다.

회의 정보 (왼쪽)

녹음을 시작하기 전에 골라 두면 결과 품질이 좋아집니다. 녹음 중에는 잠깁니다.

  • 입력 언어 — 말하는 언어. 자동 감지 또는 특정 언어로 고정합니다.
  • 출력 언어 — 번역해서 보여 줄 언어(여러 개 선택 가능). 번역 모델이 있어야 쓸 수 있습니다. (실시간 번역·통역 참고.)
  • 회의 모드 — 회의의 성격. 아래 참고.
  • 화자 — 방 안의 인원수. 아래 참고.

시작하기 (오른쪽)

  • 파일로 시작하기 — 파일을 고르거나 끌어다 놓은 뒤 누릅니다.
  • 지금 녹음 시작 — 마이크를 골라 바로 녹음합니다.

실시간 마이크 녹음

  1. 시작하기 칸에서 마이크를 고릅니다(기본은 “시스템 기본”).
  2. 지금 녹음 시작을 누릅니다. 짧은 카운트다운이 지나면 녹음이 시작됩니다. 이때 취소할 수 있습니다.
  3. 말하기 시작하면 가운데에 전사가 실시간으로 흘러나옵니다.
  4. 왼쪽 패널의 일시 정지(⌘P)로 잠시 멈추고, 정지(⌘R)로 끝냅니다.

참고

  • 정지하면 거기까지의 기록이 정리됩니다. 자동저장이 켜져 있으면 파일로 저장됩니다.
  • 자동저장이 꺼져 있으면 나가기 전에 안내가 뜹니다 — 내보내기로 먼저 저장할 수 있습니다.

에너지 흐름

왼쪽 패널 아래의 에너지 흐름 그래프가 회의의 분위기를 한 줄로 보여 줍니다 — 발언 속도·겹침·침묵을 종합한 흐름입니다.

  • 그래프의 한 지점을 클릭하면 그 구간으로 이동합니다. 회의에서 가장 뜨거웠던 대목을 바로 찾아갈 때 좋습니다.
  • 발언이 쌓이기 전에는 “발언이 쌓이면 흐름이 표시됩니다”라고 안내합니다.

녹음 중 마이크 바꾸기

실시간 녹음 중에는 왼쪽 패널의 입력 마이크 줄에서 마이크를 녹음을 끊지 않고 바꿀 수 있습니다. 회의 도중 헤드셋을 연결했을 때 유용합니다.

말을 멈추면 자막이 바로 뜹니다

한 구간(윈도)이 다 차기를 기다리지 않고, 말을 멈추고 잠깐 조용해지면 Madi가 그 구간을 앞당겨 마감해 전사를 바로 내보냅니다. 짧게 주고받는 대화(예: 진료 상담)에서 대기 시간이 크게 줄어듭니다. 멀리서 들어오는 작은 목소리는 잘리지 않도록 자동으로 기준을 맞춥니다.

시스템 오디오 캡처 (Zoom·Teams·영상)

Mac에서 재생되는 소리(온라인 회의, 영상 등)를 그대로 전사할 수 있습니다.

  1. 설정(⌘,) → 녹음 → 입력으로 갑니다.
  2. 음원에서 입력 방식을 고릅니다.
    • 마이크 — 내 앞의 소리만
    • 시스템 오디오 — Zoom·Teams·Slack·YouTube 등 Mac에서 재생되는 소리
    • 마이크+시스템 — 온라인 회의용. 내 목소리와 상대 목소리를 함께
  3. 평소처럼 녹음을 시작합니다.

참고

  • 시스템 오디오를 처음 쓸 때 macOS가 ‘화면 기록’ 권한을 요청합니다. 오디오만 사용하며 화면은 저장하지 않습니다.

파일과 영상 전사

이미 가지고 있는 오디오 또는 영상 파일을 전사합니다.

  1. 파일을 창에 끌어다 놓거나, 파일 선택 or 드래그 앤 드롭 영역을 눌러 고릅니다. 드래그 중에는 드롭하여 전사가 표시됩니다.
  2. 파일로 시작하기를 누릅니다.
  3. 진행률이 전사 중 · N% 로 표시됩니다.
  4. 전사가 끝나면 결과가 화면에 나타납니다.

참고

  • 파일을 놓기만 해서는 전사가 시작되지 않습니다. 파일로 시작하기를 눌러야 시작합니다. 그 사이에 회의 정보를 고쳐도 됩니다.
  • 영상(mp4·mov·m4v·mkv·webm·avi 등)의 음성은 자동으로 추출됩니다. 별도 변환이 필요 없습니다.
  • 파일 전사에서만 쓸 수 있는 기능이 있습니다 — 줄별 오디오 재생과 귀로 검토. (검토와 교정, 작업 폴더와 내보내기 참고.)

회의 모드

회의의 성격에 맞춰 화자 수와 강조 항목을 한 번에 맞춰 주는 프리셋입니다. 첫 화면 회의 정보 → 회의 모드에서 고릅니다.

참고

  • 회의 모드는 녹음을 시작하기 전에 골라야 합니다. 녹음 중에는 잠깁니다.

화자 수

방 안의 인원수를 알고 있다면 미리 지정해 화자 분리 정확도를 높일 수 있습니다. 첫 화면 회의 정보 → 화자에서 자동 / 1명 / 2명 / 3명 / 4명 이상 중 고릅니다.

인원수가 분명할 때 고정하면 화자가 더 정확하게 나뉩니다. 확실하지 않다면 자동을 두세요. 자세한 내용은 화자 페이지를 참고하세요.

전사 보기 전환

화면 상단의 토글로 두 가지 보기를 오갑니다.

  • 내용 — 깨끗한 회의록 읽기 보기 (기본값). 읽기에 집중할 때 좋습니다.
  • 상세 — 시각(타임코드), 신뢰도가 낮은 단어(호박색 강조), 발언 겹침 표시까지 보여 줍니다. 검토·수정할 때 좋습니다.

글자 크기는 상단의 A− / A+ 버튼으로 조절합니다.

개인정보

Madi의 모든 전사는 이 Mac 안에서만 처리됩니다. 전사 내용은 절대 기기를 떠나지 않습니다.

03

화자

Madi는 회의에서 누가 말했는지를 자동으로 구분합니다. 이 모든 처리는 이 Mac 안에서만 이루어집니다.

자동 화자 분리

녹음·전사가 진행되는 동안 Madi는 발언을 화자별로 자동으로 나눕니다.

  • 각 화자에게 고유한 색과 화자 N 라벨이 붙습니다.
  • 왼쪽 패널의 화자 막대가 회의 흐름에서 누가 언제 말했는지를 한 줄로 보여 줍니다.

참고

  • 화자 분리는 설정(⌘,) → 녹음 → 화자의 화자 분리 스위치로 끌 수 있습니다.

화자 수 고정

방 안의 인원수를 알고 있다면 미리 지정해 정확도를 높일 수 있습니다.

  1. 첫 화면 회의 정보 → 화자에서 고릅니다.
  2. 자동 / 1명 / 2명 / 3명 / 4명 이상 중에서 선택합니다.

참고

  • 인원수가 분명할 때 고정하면 화자가 더 정확하게 나뉩니다. 확실하지 않다면 자동을 두세요.
  • 녹음을 시작하기 전에 골라야 합니다. 녹음 중에는 잠깁니다.

미확인 화자

화자 수를 고정했을 때, 고른 인원 중 누구와도 뚜렷하게 다른 목소리가 들어오면 Madi는 그 발언을 미확인으로 따로 모읍니다. 지나가는 사람의 한마디나 갑자기 섞인 잡음이 정해 둔 화자 중 한 명으로 잘못 붙는 것을 막아 줍니다.

  • 미확인은 사람이 아니라 “여기 넣을 곳이 없다”는 표시입니다. 이름을 붙일 수 없습니다.
  • 자동(화자 수 미고정)에서는 나타나지 않습니다.

화자 이름 지정

  1. 전사에서 화자 이름(예: 화자 1)이나 화자 칩을 클릭합니다.
  2. 이름 (예: 김부장) 입력란에 실제 이름을 입력합니다.
  3. 저장을 누릅니다. 입력한 이름이 그 화자의 모든 발언과 내보내기에 적용됩니다.

참고

  • 이름은 지금 이 회의록에만 적용됩니다. 다음 회의에서 같은 사람을 자동으로 알아보지는 않습니다 — 회의마다 다시 지정해야 합니다.
  • 미확인에는 이름을 붙일 수 없습니다.

AI 화자 교정 (녹음이 끝난 뒤)

녹음이 끝나면 온디바이스 LLM이 대화를 읽고 명백한 화자 오분리를 보수적으로 바로잡습니다. 한 사람의 말이 두 화자로 쪼개졌거나 한 줄이 엉뚱한 화자에게 붙은 경우를 정리합니다.

  • 설정(⌘,) → 번역 → AI 교정 (세션 종료 후) 의 화자·언어 자동 교정으로 켜고 끕니다.
  • 교정이 적용되면 전사문 위에 안내가 뜨고, 화자 교정 되돌리기 버튼으로 한 번에 되돌릴 수 있습니다.
  • 번역 모델(DNA3.0-4B)이 있어야 씁니다.

발언 겹침 표시

두 사람이 동시에 말하면 상세 보기에 ⟨+이름 겹침⟩ 표시가 나타나, 그 구간에 끼어든 두 번째 화자를 알려 줍니다.

참고

  • 겹침 표시는 상세 보기에서만 나타납니다. 화면 상단에서 내용 → 상세로 전환하세요.
  • 설정(⌘,) → 녹음 → 화자의 중첩 발화 감지가 켜져 있어야 합니다.
04

실시간 번역·통역

Madi의 번역은 100% 기기 안에서 동작합니다. 클라우드도, 계정도 필요 없습니다. 회의가 진행되는 동안 각 발화를 한국어·영어·일본어·중국어로 즉시 옮겨 원문 아래에 함께 보여 줍니다. 모든 번역은 온디바이스 LLM(DNA3.0-4B)이 처리합니다.

먼저: 번역 모델 받기

번역은 별도의 모델(DNA3.0-4B, 약 2.6 GB)이 필요하며 앱에 동봉되어 있지 않습니다. 켤 때 한 번 내려받습니다.

  1. 설정(⌘,) → 번역 탭을 엽니다.
  2. 번역 모델 다운로드 버튼을 누릅니다.
  3. 다운로드가 끝나면 번역 항목이 활성화됩니다.

메모리는 사용 중에 약 3 GB가 추가로 필요합니다. 모델을 받기 전에는 번역 토글이 비활성 상태이고 “번역 모델을 먼저 다운로드하세요.”라는 안내가 표시됩니다.

번역 탭이 안 보인다면 — 번역 엔진이 포함되지 않은 빌드입니다. 이 경우 번역 기능 자체를 쓸 수 없습니다.

번역할 언어 고르기 (출력 언어)

두 곳 중 편한 곳에서 고릅니다. 같은 설정입니다.

  • 첫 화면 → 회의 정보 → 출력 언어 — 회의를 시작하며 바로.
  • 설정(⌘,) → 번역 → 실시간 번역 (다중 대상) — 한국어 / English / 日本語 / 中文 토글.

선택한 모든 언어로 각 줄을 한꺼번에 번역해 원문 바로 아래에 표시하며, 각 번역에는 언어 태그가 붙습니다. 원문과 같은 언어는 자동으로 제외됩니다.

참고

  • 출력 언어는 최대 3개까지 고를 수 있습니다.
  • 번역 모델이 없으면 출력 언어를 고를 수 없습니다.

번역이 타이핑되듯 나타납니다

번역이 다 만들어질 때까지 기다리지 않습니다. Madi는 단어가 생성되는 대로 화면에 바로바로 채워 넣습니다. 아직 쓰는 중인 줄 끝에는 커서 ▍ 가 깜빡여, 잘린 문장이 아니라 계속 이어지는 중임을 알려 줍니다.

말하는 도중에도 임시 번역이 먼저 뜨고 진행 중 으로 표시됩니다. 그 줄이 확정되면 임시 번역이 정식 번역으로 자연스럽게 바뀌며, 확정 번역이 도착할 때까지 임시 번역이 화면에 그대로 남아 있어 “번역이 잠깐 사라지는” 공백이 없습니다.

대면 통역 — 양방향 언어

Madi는 서로 다른 언어를 쓰는 두 사람의 대면 대화(예: 한국인 직원과 일본인·중국인 손님)를 위해 설계되었습니다.

출력 언어로 한국어와 다른 언어 하나만 켜면 (예: 한국어 + 일본어) 양방향 통역 모드가 됩니다.

  • 줄마다 방향을 자동으로 판별합니다. 일본어로 말한 줄은 한국어로만, 한국어로 말한 줄은 일본어로만 번역합니다. 불필요한 번역이 없어 더 빠릅니다.
  • 두 언어를 번갈아 말해도 양쪽 전사가 모두 정확합니다. 세그먼트마다 어느 언어인지 다시 확인하기 때문에, 한 사람은 한국어·다른 사람은 일본어로 대화해도 각자의 말이 제대로 받아쓰기됩니다.
  • 이 조합에서는 반응 속도가 자동으로 느려지지 않습니다(아래 참고).

자주 쓰는 문구 사전 (즉시 번역)

같은 안내를 반복하는 현장(예: 진료실의 시술 후 주의사항)을 위해, 자주 쓰는 문구의 번역을 미리 저장해 둘 수 있습니다. 저장된 문구와 같은 말이 나오면 모델을 거치지 않고 즉시(0초) 번역이 표시됩니다.

기본으로 몇 가지 문구가 들어 있으며, 직접 문구를 추가·수정할 수 있습니다.

  • 저장 위치: ~/Library/Application Support/Sovereign/faq_translations.json
  • 안전을 위해 정확히 일치하는 문구에서만 동작합니다.

반응 속도와 번역 품질

출력 언어를 2개 이상 고르면 원문 줄 경계 오류가 여러 언어로 번지므로, 반응 속도가 최소 보통(7초) 으로 내려앉습니다. 빠름(5초) 을 골라 두었더라도 자동으로 7초가 됩니다. 정확(10초) 은 그대로 쓸 수 있습니다.

예외: 한국어 + 다른 언어 하나만 켠 양방향 통역 모드에서는 줄마다 실제 번역 대상이 한 개로 줄어들기 때문에 강제하지 않습니다. 대면 통역에서 자막이 더 빨리 뜹니다.

번역이 밀릴 때는 “번역 중 · N줄 대기” 가 표시됩니다. 멈춘 것이 아니라 순서대로 처리 중이라는 뜻입니다(모델은 한 번에 한 줄씩 번역합니다).

AI 언어 교정 (녹음이 끝난 뒤)

녹음이 끝나면 온디바이스 LLM이 대화를 읽고 잘못된 언어로 받아쓴 줄을 보수적으로 바로잡습니다. 설정(⌘,) → 번역 → AI 교정 (세션 종료 후) 의 화자·언어 자동 교정으로 켜고 끕니다. (화자 참고.)

자막 오버레이

자막 오버레이 는 화면 맨 위에 떠 있는 실시간 번역 자막 창입니다. Zoom·Teams 같은 통화 화면 위에, 또는 진료실 디스플레이에 올려 두고 상대의 말을 실시간 번역으로 따라갈 수 있습니다.

상단 도구 막대의 말풍선 아이콘으로 켜고 끕니다. 출력 언어를 하나 이상 골랐을 때만 이 버튼이 나타납니다.

  • 창은 항상 맨 앞에 머물지만 포커스를 빼앗지 않으므로, 통화 앱에서 계속 클릭·입력할 수 있습니다.
  • 전체 화면 위에서도 떠 있고, 배경을 잡아 원하는 위치로 끌어다 놓을 수 있습니다.
  • 가장 큰 글씨는 번역문, 그 아래 작은 글씨는 원문입니다.
  • 여러 명이 있을 때는 자막에도 화자 색과 이름 이 붙어 누구 말인지 알 수 있습니다.
  • 말을 기다리는 동안 마이크 입력 막대 가 움직여, 시스템이 듣고 있음을 확인시켜 줍니다.
  • 상태 문구(“진행 중 / 번역 중… / 음성을 기다리는 중…”)는 보는 사람의 언어로 표시됩니다 — 일본어 자막이면 「翻訳中…」, 중국어 자막이면 「翻译中…」.

직원 자막 + 환자 자막 (이중 화면)

진료실 대면 통역을 위해 자막을 두 개 로 나눌 수 있습니다.

  • 직원 자막 — 주 화면에 작게. 직원이 보는 언어.
  • 환자 자막 — 외장 모니터에 크게(원거리 판독용). 환자 언어로 표시.

설정(⌘,) → 녹음 → 자막 오버레이 (진료실) 에서 켭니다. 직원 글씨(14–48pt)·환자 글씨(24–96pt)·환자 화면·환자 언어를 각각 지정할 수 있습니다. 진료 의자와 디스플레이 사이 1.5–2.5 m 거리에서 읽기 좋게 큰 글씨를 씁니다.

05

AI 요약과 질의응답

전사가 끝나면 온디바이스 LLM이 회의록을 구조화된 요약으로 정리하고, 회의 내용에 대해 자연어로 질문할 수 있습니다. 요약과 질의응답은 번역과 같은 모델(DNA3.0-4B)을 쓰며, 전사 내용도 요약도 이 Mac을 떠나지 않습니다.

먼저: 번역·요약 모델

요약과 질의응답은 번역과 같은 온디바이스 모델(DNA3.0-4B, 약 2.6 GB)을 씁니다. 모델이 없으면 요약 버튼이 나타나지 않습니다. 받는 법은 실시간 번역·통역 또는 설정 페이지를 참고하세요.

회의 요약 만들기

  1. 전사가 끝난 뒤(녹음 중에는 안 됩니다), 상단 도구 막대의 ✦(반짝이) 버튼을 누릅니다. 또는 ⌘K 명령 팔레트에서 요약 생성을 고릅니다.
  2. 회의 요약 시트가 열리고 로컬 LLM이 요약을 생성합니다. "전사 내용은 이 Mac을 떠나지 않습니다"라는 안내가 함께 표시됩니다.
  3. 시트 위쪽의 전체 / 화자별 토글로 보기를 바꿉니다.
    • 전체 — 회의 전체의 요약·액션·결정
    • 화자별 — 화자마다 무슨 이야기를 했는지 정리 (처음 선택하면 그 자리에서 생성합니다)

참고

  • ✦ 버튼은 전사문이 있고 녹음 중이 아닐 때만 활성화됩니다. 전사가 비어 있으면 흐려집니다.

요약 시트의 버튼

  • 복사 — 요약 텍스트를 클립보드로 복사
  • 다시 생성 — 같은 회의록으로 요약을 새로 생성
  • 슬라이드(HTML) — 오프라인에서 열리는 HTML 슬라이드 덱으로 내보내고 Finder에서 보여 줍니다
  • 리캡 카드 — 공유용 한 장 요약 카드를 엽니다 (아래 참고)
  • 내보내기… — 요약을 .md 파일로 저장

리캡 카드

회의 한 장 요약 카드입니다. 요약 시트의 리캡 카드 버튼으로 엽니다. 다음이 담긴 공유용 카드입니다.

  • 제목 + 날짜
  • TL;DR (핵심 요약)
  • 결정 목록
  • 담당자별 액션
  • 화자별 발화 시간
  • 한 줄 인용

복사로 카드를 Markdown으로 복사하거나, 내보내기…로 파일로 저장할 수 있습니다.

회의록에 물어보기 (질의응답)

회의 내용을 자연어로 질문하면, 로컬 LLM이 회의록을 근거로 답합니다. 요약 시트 아래쪽에 있습니다.

  1. 회의록에 물어보기 입력란에 질문을 입력합니다. 예: "무엇을 결정했나요?", "김부장이 맡은 일은?"
  2. 종이비행기 버튼을 누르거나 Enter를 칩니다.
  3. 이 회의 / 전체 워크스페이스 토글로 검색 범위를 정합니다.
    • 이 회의 — 지금 열려 있는 회의록에서만 답변
    • 전체 워크스페이스 — 저장된 모든 회의록을 가로질러 검색. 예: "지난달 보안 결정은?"

참고

  • 답하는 동안 "로컬 LLM이 답하는 중…"이 표시됩니다.

개인정보 보호

요약도, 질의응답도 이 Mac 안에서 동작합니다. 전사 내용도 요약도 이 기기를 떠나지 않습니다.

06

검토와 교정

전사가 끝나면 깔끔하게 읽거나, 자세히 들여다보며 고칠 수 있습니다. Madi는 여러분이 고친 내용을 기억해 다음 회의에서 같은 실수를 자동으로 바로잡습니다.

내용 보기 vs 상세 보기

화면 상단의 전환 스위치로 두 가지 보기를 오갑니다.

  • 내용 — 시각·표시 없이 깨끗하게 읽는 기본 보기.
  • 상세 — 타임코드, 저신뢰 단어(호박색 강조), 화자 겹침 표시(⟨+이름 겹침⟩)를 함께 보여 줍니다.

검토와 편집은 상세 보기에서 합니다.

줄 직접 편집

  1. 고치고 싶은 줄을 더블 클릭합니다(또는 상세 보기에서 연필 버튼, 도움말 “이 문장 편집”).
  2. 내용 보기에서 더블 클릭하면 자동으로 상세 보기로 넘어가 편집창이 열립니다.
  3. 텍스트를 고치고 저장(⌘↩)을 누릅니다. 되돌리려면 취소(Esc).
  4. 고친 줄에는 편집됨 표시가 붙습니다.

원문을 고치면 이전 원문으로 생성 중이던 번역은 자동으로 폐기되고, 고친 원문을 기준으로 다시 번역됩니다. 늦게 도착한 예전 AI 결과가 사용자 교정을 덮어쓰지 않습니다.

번역문 직접 교정

확정된 번역문을 더블 클릭하면 번역 교정 입력란이 열려 언어별 번역을 직접 고칠 수 있습니다.

  • 저장한 번역에는 연필 표시가 붙고, 다중 번역의 다른 언어는 그대로 유지됩니다.
  • 교정된 원문·번역·화자 이름은 Markdown과 JSON에 함께 저장되며, Markdown 회의록을 다시 열어도 번역이 보존됩니다.
  • SRT/VTT는 항상 최종 교정 원문을 사용합니다.

검토 필요 — 저신뢰 단어 빠르게 확인

상세 보기는 신뢰도가 낮게 인식된 단어(기준값 미만, 기본 0.55)를 호박색으로 표시합니다.

  1. 상단에 검토 필요 N개와 현재 위치(N/전체)가 표시됩니다.
  2. ∧(이전 검토 단어) / ∨(다음 검토 단어) 버튼으로 표시된 단어들 사이를 건너뛰며 이동합니다.
  3. 각 단어를 확인하고, 필요하면 그 자리에서 고칩니다.

기준값은 설정(⌘,) → 저장 → 음성 인식의 저신뢰 표시 기준 (VAD) 에서 조정합니다. 값을 올리면 더 많은 단어가 검토 대상이 됩니다.

귀로 검토 — 들으며 확인

파일을 불러와 전사한 세션에서는, 저신뢰 단어의 오디오 구간을 하나씩 자동으로 재생해 귀로 확인할 수 있습니다.

  1. 검토바의 재생 버튼(도움말 “저신뢰 단어 귀로 검토”)을 누릅니다.
  2. 표시된 단어들의 오디오가 순서대로 자동 재생되고, 한 단어가 끝나면 다음으로 넘어갑니다(핸즈프리). 진행 상황은 재생 N/전체 로 표시됩니다.
  3. 멈추려면 같은 버튼(도움말 “귀로 검토 멈춤”)을 다시 누릅니다.
참고: 귀로 검토는 원본 미디어가 있는 파일 전사 세션에서만 켜집니다. 실시간 마이크 녹음에는 원본 파일이 없어 나타나지 않습니다.

AI 교정 (녹음이 끝난 뒤)

녹음이 끝나면 온디바이스 LLM이 대화 전체를 읽고 명백한 화자 오분리와 잘못된 언어로 받아쓴 줄을 보수적으로 바로잡습니다.

  • 켜는 법: 설정(⌘,) → 번역 → AI 교정 (세션 종료 후) 의 화자·언어 자동 교정.
  • 교정이 적용되면 전사문 위에 안내가 뜨고, 화자 교정 되돌리기 버튼으로 한 번에 되돌릴 수 있습니다.
  • 번역 모델(DNA3.0-4B)이 있어야 씁니다.

개인 단어장 — 교정을 기억하는 학습

전사문의 한 줄을 고치면 Madi가 그 교정을 학습합니다. 단어장 을 켜 두면, 다음 회의에서 같은 도메인 용어·이름의 오인식을 자동으로 바로잡습니다.

켜는 법: 설정(⌘,) → 단어장 탭에서 학습한 교정 자동 적용을 켭니다.

참고: 학습은 스위치와 상관없이 항상 동작하며, 이 스위치는 “적용”만 켭니다. 그래서 켜는 즉시 그동안 쌓인 교정이 적용됩니다.

적용 기준 (최소 확인 횟수)

  • 최소 확인 횟수 슬라이더로, 같은 교정을 몇 번 확인해야 믿고 자동 적용할지 정합니다(1~5회).
  • 값이 클수록 보수적입니다 — 우발적인 편집 한 번이 이후 전사를 덮어쓰지 않도록 막아 줍니다.

학습한 교정 관리·삭제

설정 → 단어장 탭의 목록에서 학습한 규칙을 관리합니다.

  • 각 규칙은 잘못된 단어 → 올바른 단어와 확인 횟수로 표시됩니다.
  • 규칙 옆 휴지통 버튼으로 하나씩 잊게 합니다.
  • 모두 지우려면 전체 지우기를 누릅니다.

텍스트 선택과 복사

전사문 전체에서 텍스트를 드래그로 선택하고 ⌘C로 복사할 수 있습니다.

07

작업 폴더와 내보내기

Madi는 저장 폴더를 통째로 하나의 작업 공간으로 보여 줍니다. 창 오른쪽의 작업 폴더 탐색기에서 지난 회의록을 다시 열고, 저장 위치를 바꾸고, 원하는 형식으로 내보냅니다.

작업 폴더 탐색기

탐색기는 창 오른쪽에 항상 표시됩니다. 위쪽은 회의 목록, 아래쪽은 자동저장·폴더·내보내기 조작부입니다.

파일 목록

  • 파일 탭에 저장 폴더의 회의록이 최근 순으로 쌓입니다.
  • 회의록을 클릭하면 그 회의가 화면에 다시 열립니다.

자동 저장

  • 자동저장 스위치를 켜 두면 전사가 끝날 때 회의록이 Markdown(.md) 으로 자동 저장됩니다.
  • 폴더 줄에 현재 저장 위치가 표시됩니다. 변경을 눌러 다른 폴더를 고를 수 있습니다.
  • 고른 폴더는 저장과 내보내기의 기본 위치가 됩니다.
같은 설정이 설정(⌘,) → 저장 탭에도 있습니다. 편한 쪽에서 바꾸면 됩니다.

팁 — ⌘K를 눌러 작업 폴더 변경을 입력해도 폴더를 바로 고를 수 있습니다.

내보내기

탐색기 아래쪽의 내보내기 버튼을 누르면 내보내기 형식을 묻습니다. 형식을 고르면 저장 위치를 정할 수 있습니다.

형식쓰임
Markdown (.md)마크다운 회의록. 화자 이름·번역·교정이 함께 저장됩니다
Subtitles (.srt)SRT 자막
Subtitles (.vtt)VTT 자막
Plain text (.txt)일반 텍스트
JSON (.json)JSON 데이터

참고

  • 전사문이 비어 있으면 내보내기 버튼이 흐려집니다.
  • SRT/VTT는 항상 최종 교정 원문을 사용합니다. (검토와 교정 참고.)

클릭해서 그 순간 듣기

오디오·영상 파일을 불러와 전사한 세션(원본 파일이 디스크에 있는 경우)에서는, 각 줄에 재생 버튼이 표시됩니다.

  1. 듣고 싶은 줄의 재생 버튼(도움말 “이 구간 오디오 재생”)을 누릅니다.
  2. 그 줄이 말해진 정확한 순간이 원본 미디어에서 재생됩니다.
참고: 실시간 마이크 녹음 세션에는 원본 파일이 없으므로 줄별 재생 버튼이 나타나지 않습니다.

지난 회의 빨리 찾기

⌘K 명령 팔레트에 회의 이름을 입력하면 저장된 회의록으로 바로 이동합니다. 화자 이름으로도 찾을 수 있습니다.

08

시스템 받아쓰기

받아쓰기는 macOS 어디서나 쓸 수 있는 Madi의 음성 입력 기능입니다. 전역 단축키를 누른 채 말하고 떼면, 말한 내용이 기기 안에서 글자로 바뀌어 지금 맨 앞에 있는 앱(메모, 메일, Slack, 코드 편집기 등)의 입력란에 그대로 들어갑니다. 100% 온디바이스 — 클라우드도, 계정도 없습니다.

사용법

  1. 설정(⌘,) → 받아쓰기 에서 어디서나 받아쓰기 사용 을 켭니다.
  2. 처음 켜면 손쉬운 사용 권한을 요청합니다(아래 참고).
  3. 텍스트를 넣고 싶은 곳에 커서를 둡니다 — 어떤 앱이든 상관없습니다.
  4. 오른쪽 ⌥(Option) 키를 누른 채 말합니다(누르고 있는 동안만 녹음).
  5. 키에서 손을 떼면 받아쓴 텍스트가 들어갑니다.

단축키: 오른쪽 ⌥ Option

단축키는 오른쪽 Option 키입니다. 누르고 있는 동안만 녹음하는 푸시투토크 방식이라, 떼는 순간 입력이 완료됩니다. 오른쪽 Option은 단독으로 쓰는 일이 거의 없고 ⌘K(명령 팔레트)와도 겹치지 않아 기본값으로 쓰입니다.

단축키는 지금 버전에서는 바꿀 수 없습니다.

클립보드는 그대로 유지됩니다

Madi는 텍스트를 넣을 때 먼저 현재 클립보드 내용을 저장하고, 받아쓴 텍스트를 붙여넣은 뒤, 원래 클립보드를 곧바로 되돌립니다. 따라서 복사해 둔 내용은 그대로 남아 있습니다. (붙여넣는 사이에 다른 앱이 클립보드를 바꿨다면, 그 내용을 덮어쓰지 않고 그대로 둡니다.)

필수 권한 — 손쉬운 사용

받아쓰기가 다른 앱에 텍스트를 붙여넣으려면 macOS 손쉬운 사용 권한이 필요합니다.

  1. 설정(⌘,) → 받아쓰기 에서 받아쓰기를 켭니다.
  2. 손쉬운 사용 권한 항목에서 상태를 확인합니다.
    • 허용됨: 바로 쓸 수 있습니다.
    • 권한 필요: 시스템 설정에서 허용 버튼을 누릅니다.
  3. 버튼을 누르면 시스템 설정의 개인정보 보호 및 보안 → 손쉬운 사용 으로 이동합니다. 거기서 Madi를 허용합니다.
  4. 허용 후 이 창으로 돌아오면 상태가 자동으로 허용됨 으로 바뀝니다.

권한이 없으면 받아쓰기는 동작하지 않습니다. 다만 조용히 실패하지 않고 “손쉬운 사용 권한이 필요합니다”라고 알려 줍니다.

회의 녹음 중에는 비활성화

회의를 녹음하는 동안에는 받아쓰기 단축키가 꺼집니다. 받아쓰기와 회의 녹음이 같은 물리 마이크를 쓰기 때문에 충돌을 막기 위함입니다. 이때 오른쪽 Option을 눌러도 “회의 녹음 중에는 받아쓰기를 사용할 수 없습니다”라는 짧은 안내가 표시되고, 녹음을 멈추면 다시 쓸 수 있습니다.

빠르고 가벼운 받아쓰기

받아쓰기는 받아쓴 말을 가공 없이 그대로 입력합니다. 큰 언어 모델을 메모리에 올리지 않고, 받아쓰기 전용 음성 인식만 짧게 돌렸다가 끝나면 종료합니다. 그래서 번역 모델을 받지 않았더라도, 메모리가 적은 Mac에서도 가볍고 빠르게 동작합니다.

받아쓰기 언어는 설정 → 녹음 → 언어 에서 고른 회의 언어 설정을 따릅니다(기본값 한국어). 짧은 음성은 자동 감지가 빗나갈 수 있어, 자동을 고르지 않은 경우 지정한 언어로 고정해 인식합니다.

설정 항목 정리 (설정 → 받아쓰기)

  • 어디서나 받아쓰기 사용 — 받아쓰기 켜기/끄기.
  • 누르고 있는 동안 녹음 — 단축키 안내(오른쪽 ⌥ Option). 읽기 전용입니다.
  • 손쉬운 사용 권한 — 현재 상태(허용됨 / 권한 필요)와 시스템 설정에서 허용 버튼.
  • 현재 — 지금 받아쓰기 상태: 꺼짐 / 대기 중 / 듣는 중… / 변환 중… / 입력 중…
09

설정

설정 창은 ⌘,(Command + 쉼표) 로 엽니다(왼쪽 패널의 톱니 버튼도 같습니다). 매 회의마다 만지는 것이 아니라 “한 번 정해 두는” 항목들이 여기에 모여 있습니다. 창 위쪽 탭으로 녹음 · 저장 · 번역 · 단어장 · 모델 · 받아쓰기 를 오갑니다.

회의마다 바뀌는 것(입력·출력 언어, 회의 모드, 화자 수)은 설정이 아니라 첫 화면의 회의 정보에 있습니다. (녹음과 전사 참고.)
참고: 녹음 탭의 설정은 녹음 중·일시정지 중에는 잠깁니다. 바꾸려면 녹음을 멈춘 뒤 조정하세요.

녹음

음원 캡처 방식과 실시간 동작, 화면 표시를 정합니다.

입력

  • 음원 — 무엇을 들을지 고릅니다.
    • 마이크 — 내 목소리 / 대면 회의.
    • 시스템 오디오 — Mac에서 재생되는 소리(Zoom·Teams·Slack·YouTube 등). 첫 사용 시 ‘화면 기록’ 권한을 요청합니다(오디오 전용, 화면은 저장하지 않음).
    • 마이크+시스템 — 온라인 회의(내 목소리 + 상대방 소리)에 적합합니다.
  • 마이크 — (마이크 / 마이크+시스템일 때) 사용할 입력 장치. 기본은 “시스템 기본”.
  • 언어 — 자동 감지 / 한국어 / English 중에서 받아쓰기 언어를 고정하거나 자동으로 둡니다. 시스템 받아쓰기도 이 설정을 따릅니다.

화자

  • 화자 분리 — 누가 말했는지 화자별로 구분합니다.
  • 중첩 발화 감지 — 두 사람이 동시에 말하는 구간을 감지합니다(상세 보기의 겹침 표시).

실시간

  • 반응 속도 — 빠름(5초) / 보통(7초) / 정확(10초). 빠름은 텍스트가 더 자주 떠 체감 속도가 좋고, 정확은 문맥을 길게 봐 품질이 좋습니다.
    • 출력 언어가 2개 이상이면 최소 보통(7초) 으로 내려앉습니다 — 빠름을 골라 두었어도 자동으로 7초가 됩니다. 단, 한국어+다른 언어 하나만 켠 양방향 통역은 예외입니다.
  • 실시간 프리뷰 — 한 구간이 확정되기 전, 중간 텍스트를 회색으로 미리 보여 줍니다(정확도 손해 없음, 메모리 약 830 MB 추가).

표시

  • 외관 — 시스템 / 라이트 / 다크 테마를 고릅니다.

자막 오버레이 (진료실)

대면 통역용 자막 창의 크기와 두 번째(환자용) 화면을 설정합니다. (실시간 번역·통역 참고.)

  • 직원 자막 크기 — 주 화면 자막 글씨(14–48pt).
  • 환자용 대형 자막 (별도 화면) — 두 번째 패널을 환자 언어로, 원거리 판독용 큰 글씨로 띄웁니다. 켜면 아래 항목이 나타납니다.
    • 환자 자막 크기 — 24–96pt.
    • 환자 화면 — 모니터가 둘 이상일 때, 어느 화면에 띄울지 고릅니다.
    • 환자 언어 — 자동(상대 언어) 또는 특정 언어로 고정.

저장

파일 저장과 인식 기준을 정합니다.

자동 저장

  • 완료 시 .md 자동저장 — 전사가 끝나면 Markdown 파일로 자동 저장합니다.
  • 폴더 / 변경… — 저장 폴더를 지정합니다. 이 폴더가 작업 폴더 탐색기에 보이는 작업 공간입니다.
같은 설정이 작업 폴더 탐색기 아래쪽에도 있습니다.

음성 인식

  • 저신뢰 표시 기준 (VAD) — 이 신뢰도(기본 0.55) 미만으로 인식된 단어를 검토 필요로 표시합니다. 범위 0.35–0.9. 값을 올리면 더 많은 단어가 검토 대상이 됩니다. (검토와 교정 참고.)

번역

온디바이스 번역(한국어·영어·일본어·중국어)을 켜고 끄는 곳입니다.

번역 엔진이 포함되지 않은 빌드에서는 이 탭이 아예 보이지 않습니다.

번역 모델 (DNA3.0-4B · 약 2.6 GB)

  • 상태 — 설치됨 / 검증 중 / 다운로드 진행률 / 미설치를 보여 줍니다.
  • 번역 모델 다운로드 — 모델을 받습니다. 앱에 동봉되어 있지 않고, 켤 때 받습니다(메모리 약 3 GB 추가). 받는 중에는 취소, 설치 후에는 Finder에서 보기 로 파일 위치를 열 수 있습니다.

실시간 번역 (다중 대상)

  • 한국어 / English / 日本語 / 中文 — 토글로 대상 언어를 고릅니다(최대 3개). 선택한 모든 언어로 각 줄을 동시에 번역해 원문 아래에 표시합니다(원문 언어는 자동 제외).
  • 모델을 먼저 받아야 쓸 수 있습니다. 대상이 2개 이상이면 반응 속도가 최소 ‘보통(7초)’ 이 됩니다(녹음 탭 참고).

번역 반응 (실시간)

  • 마지막 줄 대기 (초) — 말이 끝난 마지막 줄을 이 시간(0.5–5.0초, 기본 3초)만큼 기다렸다 번역합니다. 짧을수록 자막이 빨리 뜨지만 미완성 문장을 번역할 수 있습니다. 확정된(다음 줄이 시작된) 줄은 이 값과 무관하게 즉시 번역되며, 전사(STT) 반응 속도와는 별개입니다.

AI 교정 (세션 종료 후)

  • 화자·언어 자동 교정 — 녹음이 끝나면 온디바이스 LLM이 대화를 읽고 명백한 화자 오분리·잘못된 언어 줄을 보수적으로 바로잡습니다. 화자 교정은 한 번에 되돌릴 수 있습니다.
  • 번역·요약 모델(DNA3.0-4B)이 있어야 씁니다.

단어장 (개인 단어장)

자주 틀리는 도메인 용어·이름을 직접 고친 내용을 Madi가 학습해, 이후 회의에서 비슷한 오인식을 자동으로 바로잡습니다. (검토와 교정 참고.)

  • 학습한 교정 자동 적용 — 학습한 교정을 실제로 적용할지 켜는 스위치입니다. 학습은 항상 동작하며, 이 스위치는 ‘적용’만 켭니다. (기본 꺼짐 — 직접 켜세요.)
  • 최소 확인 횟수 — 같은 교정을 이 횟수(1~5회) 이상 확인해야 자동 적용합니다. 값이 클수록 보수적이라, 우발적 편집 한 번이 이후 전사를 덮어쓰지 않습니다.
  • 학습한 교정 목록 — 학습된 규칙(틀린 단어 → 맞는 단어, 확인 횟수)을 보여 줍니다. 각 줄의 휴지통 버튼으로 한 규칙만 잊게 하거나, 전체 지우기 로 모두 비웁니다.

모델

받아쓰기(Whisper) 모델의 상태를 확인하고 관리합니다.

  • 상태 / 위치 — 모델 설치 여부와 파일 경로를 보여 줍니다.
  • 모델 재다운로드 — 모델을 다시 받습니다.
  • Finder에서 보기 — 모델 파일 위치를 엽니다.
번역 모델(DNA3.0-4B)은 번역 탭에서 관리합니다.

Getting started

Welcome to Madi. Madi transcribes and translates your meetings entirely on this Mac. Live transcription, audio and video file transcription, speaker separation, on-device translation — every step happens inside your own machine.

What Madi does

  • Live transcription — listens to your mic or meeting audio and puts text on screen almost as fast as you speak.
  • File and video transcription — drop in a recording and Madi writes out the whole conversation.
  • Speaker separation — tells apart who spoke when, and lets you name them.
  • On-device translation — renders Korean, English, Japanese and Chinese in real time, and can float them as captions over any window.
  • AI summary and Q&A — distills the summary, decisions and actions when the meeting ends, and lets you ask about it in natural language.
  • Review and correction — finds words it wasn't sure about, lets you fix them, and remembers your fixes for next time.
  • System-wide dictation — hold a key in any app, speak, and your words land in the text field.

100% on-device — your data never leaves this Mac

Madi's core promise is sovereignty. No audio, no transcript, no translation is ever sent to the cloud. Once the models are downloaded it works with the internet unplugged. Your meetings exist only on your device.

About the models

Madi uses two kinds of AI model.

  • Whisper speech model — handles transcription. Bundled with the app, nothing to download.
  • DNA3.0-4B language model (~2.6 GB) — powers translation, AI correction, and summary / Q&A. To keep the app small, it is downloaded the first time you use it.
    • Where: Settings (⌘,) → Translation, the "Download translation model" button.
    • About 2.6 GB to download, and the same in disk space.

If you don't use translation, summary or Q&A you never need this model. Transcription and speaker separation run entirely on the bundled Whisper model.

About memory (honestly)

  • 8 GB Mac (e.g. M1 MacBook Air) — transcription and speaker separation run comfortably.
  • Translation adds about 3 GB. It works on an 8 GB Mac, but memory gets tight.
  • Live preview adds roughly another 830 MB.

Permissions Madi may ask for

Madi doesn't ask for everything up front — it requests each permission the first time you use that feature.

  • Microphone — to record. Asked when you first start a recording.
  • Screen Recording — only to capture system audio (sound playing on your Mac, e.g. Zoom, Teams, YouTube). macOS bundles audio capture into the Screen Recording permission; Madi never records your screen.
  • Accessibility — only for system-wide dictation, so Madi can insert text into other apps. (See System dictation.)

If you deny a permission and want it later, open System Settings → Privacy & Security, find the item (Microphone / Screen Recording / Accessibility) and enable Madi.

First-run quick start

  1. Open Madi. The first screen has two columns: Meeting info and Get started.
  2. Under Meeting info, set up this meeting — input language, output language (if you translate), meeting mode, speaker count.
  3. Under Get started, pick a mic and press Start recording now, or drop in an audio/video file.
  4. Watch the live transcript appear in the middle of the window.
  5. Press Stop to wrap up. If auto-save is on, the transcript is written to a file.
To translate, first download the translation model (~2.6 GB) in Settings (⌘,) → Translation.

The window

Once recording starts, the window splits into three columns.

  • Left — session panel: transport buttons (pause / stop), total time, the speaker bar, and the energy-flow graph. The Settings gear lives here too.
  • Center — transcript: what was said. You read and edit here.
  • Right — workspace explorer: past meetings, the auto-save switch, save folder, and export.

Recording and transcription

Madi transcribes meetings live as people speak, and it can also transcribe audio and video files you already have. Everything runs on this Mac — your transcript never leaves the device.

The app interface is in Korean. Korean UI labels are shown below with an English gloss in parentheses.

The first screen — meeting info and getting started

When you open the app the first screen splits in two. On the left you tell Madi what kind of meeting this is; on the right you start it.

회의 정보 (Meeting info) — left

Setting these before you record improves the result. They lock while recording.

  • 입력 언어 (Input language) — the language being spoken. Auto-detect, or pin a specific language.
  • 출력 언어 (Output language) — the languages to translate into (you can pick several). Requires the translation model. See Live translation.
  • 회의 모드 (Meeting mode) — the shape of the meeting. See below.
  • 화자 (Speakers) — how many people are in the room. See below.

시작하기 (Get started) — right

  • 파일로 시작하기 (Start from file) — press after picking or dropping a file.
  • 지금 녹음 시작 (Start recording now) — pick a mic and record immediately.

Live mic recording

  1. In 시작하기 (Get started), choose your mic (default is "시스템 기본" / System default).
  2. Press 지금 녹음 시작 (Start recording now). A short countdown runs before recording begins — you can cancel during it.
  3. As people speak, the transcript streams live in the center of the window.
  4. In the left panel, press 일시 정지 (Pause, ⌘P) to pause, or 정지 (Stop, ⌘R) to end.

Note

  • Stopping wraps up everything captured so far. If auto-save is on, it's written to a file.
  • If auto-save is off, Madi warns you before you leave — you can save first with 내보내기 (Export).

에너지 흐름 (Energy flow)

The 에너지 흐름 graph at the bottom of the left panel shows the meeting's texture in a single line — a composite of speaking pace, overlap and silence.

  • Click a point on the graph to jump to that moment. Handy for finding the liveliest stretch of a meeting.
  • Before enough speech accumulates it says "발언이 쌓이면 흐름이 표시됩니다" (the flow appears once speech accumulates).

Swapping mics mid-recording

During a live recording, the 입력 마이크 (Input mic) row in the left panel lets you switch microphones without interrupting the recording — handy when you plug in a headset mid-meeting.

Captions appear as soon as you stop talking

Madi doesn't wait for a window to fill up. When you pause and go quiet for a moment, it closes that window early and emits the transcript right away — cutting the wait noticeably in short back-and-forth conversations (like a consultation). Quiet, far-field voices aren't clipped: the threshold adapts automatically.

System audio capture (Zoom / Teams / video)

You can transcribe whatever is playing through your Mac — online meetings, videos, and so on.

  1. Go to 설정 → 녹음 → 입력 (Settings → Recording → Input).
  2. Under 음원 (Audio source), pick how to capture sound:
    • 마이크 (Microphone) — only the sound in front of you
    • 시스템 오디오 (System audio) — what's playing on the Mac: Zoom, Teams, Slack, YouTube, etc.
    • 마이크+시스템 (Mic + system) — for online meetings: your voice plus the other side
  3. Start recording as usual.

Note

  • The first time you use system audio, macOS asks for Screen Recording permission. Only audio is used; the screen is never saved.

File and video transcription

  1. Drop a file onto the window, or click the 파일 선택 or 드래그 앤 드롭 (Choose file or drag and drop) area to pick one. While dragging, 드롭하여 전사 (Drop to transcribe) appears.
  2. Press 파일로 시작하기 (Start from file).
  3. Progress shows as 전사 중 · N% (Transcribing · N%).
  4. When it finishes, the result appears on screen.

Note

  • Dropping a file does not start transcription by itself — you must press 파일로 시작하기. That gap is your chance to adjust the meeting info first.
  • Audio is extracted from video (mp4, mov, m4v, mkv, webm, avi …) automatically. No conversion needed.
  • Two features work only on file transcriptions: per-line audio playback and review by ear. See Review and correction and Workspace and export.

Speakers

Madi automatically works out who spoke during a meeting. All of this runs on this Mac.

The app interface is in Korean. Korean UI labels are shown below with an English gloss in parentheses.

Automatic speaker separation

While recording and transcribing, Madi splits speech by speaker automatically.

  • Each speaker gets a distinct color and a 화자 N (Speaker N) label.
  • The speaker bar in the left panel shows, in one line, who spoke when across the meeting.

Note

  • You can turn this off with the 화자 분리 (Speaker separation) switch in 설정 (⌘,) → 녹음 → 화자 (Settings → Recording → Speakers).

Pinning the speaker count

If you know how many people are in the room, set it to improve accuracy.

  1. On the first screen, go to 회의 정보 → 화자 (Meeting info → Speakers).
  2. Choose 자동 (Auto) / 1명 / 2명 / 3명 / 4명 이상 (1 / 2 / 3 / 4+ people).

Note

  • Pinning the count when you're sure gives cleaner speaker splits. If you're not sure, leave it on 자동 (Auto).
  • Choose it before recording — it locks once recording starts.

미확인 (Unknown) speakers

When you pin the speaker count, any voice that clearly doesn't match one of the people you specified gets collected under 미확인 (Unknown). This stops a passer-by's one-liner or a burst of noise from being misattributed to one of your real speakers.

  • 미확인 is not a person — it means "there's nowhere to put this." You cannot name it.
  • It never appears when the count is left on Auto.

Naming speakers

  1. In the transcript, click a speaker label (e.g. 화자 1 / Speaker 1) or the speaker chip.
  2. Type the real name into the 이름 (예: 김부장) (Name, e.g. Manager Kim) field.
  3. Press 저장 (Save). The name applies to all of that speaker's lines and to exports.

Note

  • Names apply to this transcript only. Madi will not recognize the same person automatically in your next meeting — you name them again each time.
  • 미확인 (Unknown) cannot be named.

AI speaker correction (after recording)

When recording ends, the on-device LLM reads the conversation and conservatively fixes obvious speaker mis-splits — one person's speech broken across two speakers, or a line attributed to the wrong person.

  • Toggle it under 설정 (⌘,) → 번역 → AI 교정 (세션 종료 후) (Settings → Translation → AI correction (after session)), switch 화자·언어 자동 교정 (Auto-correct speakers and language).
  • When a correction is applied, a note appears above the transcript with a 화자 교정 되돌리기 (Undo speaker correction) button — one click reverts all of it.
  • Requires the translation model (DNA3.0-4B).

Overlap markers

When two people talk at once, the 상세 (Detail) view shows a ⟨+name 겹침⟩ (overlap) marker naming the second speaker who cut in.

Note

  • Overlap markers appear only in the 상세 (Detail) view. Switch from 내용 → 상세 at the top of the window.
  • Requires 중첩 발화 감지 (Overlapping speech detection) in 설정 (⌘,) → 녹음 → 화자.

Live translation and interpreting

Madi's translation runs 100% on your device — no cloud, no account. While a meeting is in progress, each spoken line is translated into Korean, English, Japanese and/or Chinese and shown right beneath the original. Everything is handled by the on-device LLM (DNA3.0-4B).

The app interface is in Korean. Korean UI labels are shown below with an English gloss in parentheses.

First: download the translation model

Translation needs a separate model (DNA3.0-4B, ~2.6 GB) that isn't bundled with the app. You download it once.

  1. Open 설정 (⌘,) → 번역 (Settings → Translation).
  2. Press 번역 모델 다운로드 (Download translation model).
  3. When it finishes, the translation options become available.

It needs about 3 GB of additional memory while in use. Before the model is installed the toggles are disabled and you'll see "번역 모델을 먼저 다운로드하세요." (Download the translation model first.)

If you don't see the 번역 tab — your build doesn't include the translation engine, and translation isn't available at all.

Choosing output languages

Two places, same setting — use whichever is handy.

  • First screen → 회의 정보 → 출력 언어 (Meeting info → Output language) — as you start a meeting.
  • 설정 (⌘,) → 번역 → 실시간 번역 (다중 대상) (Settings → Translation → Live translation, multi-target) — toggles for 한국어 / English / 日本語 / 中文.

Every line is translated into all the languages you pick and shown directly under the original, each tagged with its language. The source language is excluded automatically.

Note

  • You can pick up to 3 output languages.
  • Without the translation model you can't pick output languages at all.

Translations type themselves out

Madi doesn't wait for a translation to be finished. Words fill in on screen as they're generated. A cursor ▍ blinks at the end of a line still being written, so you know it's continuing rather than truncated.

While someone is still speaking, an interim translation appears first, marked 진행 중 (in progress). When the line is finalized the interim smoothly becomes the final translation — and the interim stays on screen until the final arrives, so translations never blink out.

Face-to-face interpreting — bidirectional

Madi is designed for two people speaking different languages in the same room (for example, a Korean staff member and a Japanese or Chinese visitor).

Turn on only 한국어 plus one other language (e.g. 한국어 + 일본어) and it becomes a bidirectional interpreting mode.

  • Direction is detected per line. A Japanese line is translated only into Korean; a Korean line only into Japanese. No wasted work, so it's faster.
  • Both sides transcribe correctly even when you alternate languages. The language is re-checked per segment, so one person speaking Korean and the other Japanese both get accurate transcripts.
  • This combination is exempt from the latency floor below.

Frequent-phrase dictionary (instant translation)

For places that repeat the same guidance (say, post-procedure instructions in a clinic), you can pre-store translations of common phrases. When a stored phrase comes up, the translation appears instantly (0 s) without going through the model.

A few phrases ship by default, and you can add or edit your own.

  • File: ~/Library/Application Support/Sovereign/faq_translations.json
  • For safety it only fires on an exact match.

Latency and translation quality

With 2 or more output languages, boundary errors in the source line would propagate into every language — so the response speed drops to a floor of 보통 (7초) (Normal, 7 s). If you had picked 빠름 (5초) (Fast, 5 s), it automatically becomes 7 s. 정확 (10초) (Accurate, 10 s) still works.

Exception: the bidirectional mode (한국어 + exactly one other language) is not forced, because each line's effective target count drops to one. Captions appear faster in face-to-face interpreting.

When translation falls behind you'll see "번역 중 · N줄 대기" (Translating · N lines queued). It isn't stuck — it's working through them in order (the model translates one line at a time).

AI language correction (after recording)

Caption overlay

The caption overlay is a floating window of live translated captions that sits on top of everything. Park it over a Zoom or Teams call, or on a clinic display, and follow what the other person is saying in real time.

Toggle it with the speech-bubble icon in the top toolbar. The button only appears once you've picked at least one output language.

  • The window always stays in front but never takes focus, so you can keep clicking and typing in your call app.
  • It floats above full-screen apps, and you can drag it anywhere by its background.
  • The largest text is the translation; the smaller text beneath it is the original.
  • With multiple people, captions carry the speaker's color and name so you know who's talking.
  • While waiting for speech, a mic level bar moves to confirm the system is listening.

For clinic interpreting you can split captions into two panels.

  • Patient captions — large, on an external monitor, for reading at a distance, in the patient's language.

The large sizes are meant to read well across the 1.5–2.5 m between a treatment chair and the display.

Review and correction

Once a transcript is done you can read it clean, or go in close and fix it. Madi remembers the fixes you make and applies them automatically in later meetings.

The app interface is in Korean. Korean UI labels are shown below with an English gloss in parentheses.

내용 (Content) vs 상세 (Detail) view

The toggle at the top of the window switches between two views.

  • 내용 (Content) — a clean read, no timecodes or markers.
  • 상세 (Detail) — adds timecodes, low-confidence words (amber), and speaker-overlap markers (⟨+name 겹침⟩).

Reviewing and editing happen in the 상세 (Detail) view.

Editing a line

  1. Double-click the line you want to fix (or press the pencil button in 상세 view, tooltip "이 문장 편집" / Edit this line).
  2. Double-clicking from 내용 view switches to 상세 automatically and opens the editor.
  3. Fix the text and press 저장 (Save, ⌘↩). To back out, press 취소 (Cancel, Esc).
  4. Edited lines are marked 편집됨 (Edited).

When you edit the source, any translation still being generated from the old text is discarded and re-run against your corrected text. Late-arriving AI results never overwrite your correction.

Correcting translations

Double-click a finalized translation to open a 번역 교정 (Translation correction) field and fix that language's translation directly.

  • Saved translations get a pencil mark, and the other languages in a multi-target translation are left alone.
  • Corrected source text, translations and speaker names are saved into Markdown and JSON, and translations survive reopening a Markdown transcript.
  • SRT/VTT always use the final corrected source text.

검토 필요 (Needs review) — sweep low-confidence words

The 상세 view highlights words recognized below the confidence threshold (default 0.55) in amber.

  1. The bar at the top shows 검토 필요 N개 (N words need review) and your position (N/total).
  2. Use ∧ (previous flagged word) and ∨ (next flagged word) to jump between them.
  3. Check each one and fix it in place if needed.

Adjust the threshold under 설정 (⌘,) → 저장 → 음성 인식 (Settings → Save → Speech recognition), 저신뢰 표시 기준 (VAD). Raising it flags more words.

Review by ear

On file transcriptions, Madi can play back the audio for each flagged word so you can check it by ear.

  1. Press the play button in the review bar (tooltip "저신뢰 단어 귀로 검토" / Review low-confidence words by ear).
  2. The flagged words play in order, advancing automatically — hands-free. Progress shows as 재생 N/total (Playing N/total).
  3. Press the same button again to stop (tooltip "귀로 검토 멈춤" / Stop review by ear).
Note: Review by ear works only on file transcriptions, where the original media exists. Live mic recordings have no source file, so it doesn't appear.

AI correction (after recording)

When recording ends, the on-device LLM reads the whole conversation and conservatively fixes obvious speaker mis-splits and lines transcribed in the wrong language.

  • Turn it on: 설정 (⌘,) → 번역 → AI 교정 (세션 종료 후) → 화자·언어 자동 교정.
  • When applied, a note appears above the transcript with a 화자 교정 되돌리기 (Undo speaker correction) button — one click reverts all of it.
  • Requires the translation model (DNA3.0-4B).

Personal glossary — learning from your corrections

When you fix a line, Madi learns that correction. With the 단어장 (Glossary) switch on, it automatically fixes the same domain term or name in later meetings.

Turn it on: 설정 (⌘,) → 단어장 (Settings → Glossary), switch 학습한 교정 자동 적용 (Auto-apply learned corrections).

Note: Learning happens always, regardless of the switch — the switch only controls applying. So turning it on immediately applies everything learned so far.

Confidence threshold (minimum hits)

  • The 최소 확인 횟수 (Minimum hits) slider sets how many times the same correction must be seen before it's trusted and auto-applied (1–5).
  • Higher is more conservative — it stops one accidental edit from overwriting later transcripts.

Managing learned corrections

Manage the learned rules in the list under 설정 → 단어장.

  • Each rule shows as wrong word → right word with its hit count.
  • The trash button next to a rule forgets just that one.
  • 전체 지우기 (Clear all) wipes them all.

Selecting and copying text

You can drag-select across the whole transcript and copy with ⌘C.

System dictation

Dictation is Madi's voice input for anywhere in macOS. Hold a global hotkey, speak, release — and what you said is turned into text on-device and inserted into whatever app is frontmost (Notes, Mail, Slack, your code editor). 100% on-device — no cloud, no account.

The app interface is in Korean. Korean UI labels are shown below with an English gloss in parentheses.

How to use it

  1. Turn on 어디서나 받아쓰기 사용 (Enable dictation anywhere) in 설정 (⌘,) → 받아쓰기 (Settings → Dictation).
  2. The first time, it asks for Accessibility permission (see below).
  3. Put your cursor wherever you want the text — any app.
  4. Hold the right ⌥ (Option) key and speak (it only records while held).
  5. Release the key and the dictated text is inserted.

The hotkey: right ⌥ Option

The hotkey is the right Option key. It's push-to-talk — recording only while held, so releasing completes the insert. Right Option is rarely used on its own and doesn't collide with ⌘K (the command palette), which is why it's the default.

The hotkey can't be changed in this version.

Your clipboard is preserved

Madi saves your current clipboard, pastes the dictated text, then immediately restores what was there. Anything you had copied is still there afterwards. (If another app changed the clipboard mid-paste, Madi leaves that content alone rather than clobbering it.)

Required permission — Accessibility

To paste text into other apps, dictation needs the macOS Accessibility permission.

  1. Turn on dictation in 설정 (⌘,) → 받아쓰기.
  2. Check the 손쉬운 사용 권한 (Accessibility permission) row.
    • 허용됨 (Granted): ready to use.
    • 권한 필요 (Permission needed): press 시스템 설정에서 허용 (Allow in System Settings).
  3. That button opens System Settings → Privacy & Security → Accessibility. Enable Madi there.
  4. Come back to this window and the status flips to 허용됨 automatically.

Without the permission dictation won't work — but it won't fail silently either: it tells you "손쉬운 사용 권한이 필요합니다" (Accessibility permission required).

Disabled while recording a meeting

The dictation hotkey is disabled while a meeting is recording, because dictation and meeting recording use the same physical microphone. Pressing right Option then shows a brief "회의 녹음 중에는 받아쓰기를 사용할 수 없습니다" (Dictation is unavailable while recording a meeting). Stop the recording and it works again.

Fast and light

Dictation inserts what you said verbatim, with no rewriting. It never loads a large language model — it runs a short, dictation-only speech pass and shuts down when you're done. So it stays light and fast even on a Mac with little memory, and even if you never downloaded the translation model.

Dictation language follows the meeting language you picked in 설정 → 녹음 → 언어 (Settings → Recording → Language); the default is Korean. Auto-detect can miss on very short utterances, so unless you chose Auto, Madi pins recognition to the language you selected.

Settings reference (설정 → 받아쓰기)

  • 어디서나 받아쓰기 사용 (Enable dictation anywhere) — turn dictation on/off.
  • 누르고 있는 동안 녹음 (Hold to record) — shows the hotkey (right ⌥ Option). Read-only.
  • 손쉬운 사용 권한 (Accessibility permission) — current status (허용됨 / 권한 필요) and the 시스템 설정에서 허용 button.
  • 현재 (Current) — current dictation state: 꺼짐 (Off) / 대기 중 (Idle) / 듣는 중… (Listening) / 변환 중… (Transcribing) / 입력 중… (Inserting).
