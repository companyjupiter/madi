01

시작하기

Madi(마디)에 오신 것을 환영합니다. Madi는 회의를 전부 기기 안에서 받아쓰고 이해하는 한국어 회의 인텔리전스 앱입니다. 실시간 받아쓰기, 오디오·영상 파일 전사, 화자 분리, 온디바이스 번역, 요약, 질의응답까지 — 모든 처리가 여러분의 Mac 안에서 일어납니다.

Madi가 하는 일

  • 실시간 전사 — 마이크나 회의 음성을 들으며 말이 끝나기 전에 텍스트가 화면에 나타납니다.
  • 파일·영상 전사 — 녹음 파일이나 영상을 끌어다 놓으면 전체 대화를 받아씁니다.
  • 화자 분리 — 누가 언제 말했는지 화자별로 구분합니다.
  • 온디바이스 번역 — 한국어·영어·중국어·일본어를 서로 번역합니다.
  • 요약 · 질의응답 — 회의 핵심, 결정 사항, 할 일을 정리하고 내용에 대해 질문할 수 있습니다.

100% 온디바이스 — 내 데이터는 Mac을 떠나지 않습니다

Madi의 핵심 약속은 주권(sovereign) 입니다. 음성, 전사문, 번역, 요약 어느 것도 클라우드로 전송되지 않습니다. 인터넷이 끊겨 있어도(모델을 이미 받았다면) 동작합니다. 회의 내용은 오로지 여러분의 기기 안에만 존재합니다.

모델 안내

Madi는 두 종류의 AI 모델을 씁니다.

  • Whisper 음성 모델 — 받아쓰기를 담당합니다. 앱에 기본 동봉되어 있어 따로 받을 필요가 없습니다.
  • DNA3.0-4B 언어 모델 (약 2.6 GB) — 번역, 요약, 질의응답, 제목 생성에 쓰입니다. 앱 용량을 줄이기 위해 처음 쓸 때 다운로드합니다.
    • 받는 곳: 설정 → 모델 또는 설정 → 번역의 “번역 모델 다운로드” 버튼.
    • 다운로드 약 2.6 GB, 디스크 공간도 그만큼 필요합니다. (자세한 내용은 번역, 설정 참고.)

메모리 안내 (솔직하게)

  • 8 GB Mac (예: M1 MacBook Air) — 받아쓰기와 화자 분리는 원활히 돌아갑니다.
  • 16 GB 이상 권장 — 언어 모델을 전사와 동시에 돌리는 기능에서 필요합니다. 예를 들어 라이브 액션 추출(녹음 중 결정·할 일·질문 실시간 추출)이나 실시간 번역·요약을 전사와 함께 쓸 때입니다. 8 GB에서도 이런 기능을 켤 수는 있지만 메모리가 빠듯해질 수 있습니다.

Madi가 요청할 수 있는 권한

권한은 미리 한꺼번에 묻지 않고, 그 기능을 처음 쓸 때 필요한 것만 요청합니다.

  • 마이크 — 녹음할 때. 녹음을 처음 시작할 때 요청합니다.
  • 화면 기록 — 시스템 오디오(Mac에서 재생되는 소리, 예: Zoom·Teams·YouTube)를 녹음할 때만. macOS가 오디오 캡처를 화면 기록 권한으로 묶어두기 때문이며, 화면은 저장하지 않습니다.
  • 캘린더 — 선택 사항입니다. 회의 준비나 참석자 매칭에 쓰며, 쓰지 않아도 됩니다.
  • 손쉬운 사용(Accessibility) — 시스템 받아쓰기(어느 앱에서나 받아쓰기) 기능을 쓸 때만 필요합니다. 받아쓴 텍스트를 다른 앱에 넣으려면 이 권한이 필요합니다. (받아쓰기 참고.)

권한을 거부했다가 나중에 켜고 싶으면 시스템 설정 → 개인정보 보호 및 보안에서 해당 항목(마이크 / 화면 기록 / 손쉬운 사용 / 캘린더)을 찾아 Madi를 켜면 됩니다.

처음 실행 빠른 시작

  1. Madi를 엽니다.
  2. (선택) 번역·요약·질의응답을 쓰려면 설정(⌘,) → 모델 또는 번역에서 번역 모델(DNA3.0-4B, 약 2.6 GB)을 다운로드합니다.
  3. 녹음 시작 버튼을 누르거나, 오디오·영상 파일을 창에 끌어다 놓습니다.
  4. 화면에 실시간 전사문이 나타나는 것을 지켜봅니다.
  5. 회의가 끝나면 요약 버튼을 눌러 AI 요약을 받습니다. (요약은 번역 모델이 설치되어 있어야 합니다.)

준비 완료입니다. 더 자세한 내용은 녹음, 번역, 받아쓰기, 설정 등 다른 매뉴얼 페이지를 참고하세요.

02

녹음 및 전사

마디는 회의 음성을 실시간으로 받아 적고, 이미 녹음된 오디오·영상 파일도 전사합니다. 모든 처리는 이 Mac 안에서만 이루어지며, 전사 내용은 기기를 떠나지 않습니다.

실시간 마이크 녹음

  1. 화면 하단의 녹음 시작 버튼을 누릅니다.
  2. 말하기 시작하면 가운데 영역에 전사가 실시간으로 흘러나옵니다.
  3. 잠시 멈추려면 일시정지, 끝내려면 정지를 누릅니다.

참고

  • 녹음을 시작하기 전, 아래의 회의 모드와 화자 수를 먼저 설정해 두면 결과 품질이 좋아집니다. 녹음 중에는 이 항목들이 잠깁니다.
  • 상단의 입력 레벨 막대가 마이크 소리 크기를 보여 줍니다. 일시정지 중에는 0으로 내려갑니다.

말을 끝내면 자막이 바로 뜹니다

한 구간(윈도)이 다 차기를 기다리지 않고, 말을 멈추고 잠깐 조용해지면 Madi가 그 구간을 앞당겨 마감해 전사를 바로 내보냅니다. 짧게 주고받는 대화(예: 진료 상담)에서 대기 시간이 크게 줄어듭니다. 멀리서 들어오는 작은 목소리는 잘리지 않도록 자동으로 기준을 맞춥니다.

시스템 오디오 캡처 (Zoom·Teams·영상)

Mac에서 재생되는 소리(온라인 회의, 영상 등)를 그대로 전사할 수 있습니다.

  1. 설정 → 녹음 → 입력으로 이동합니다.
  2. 음원(Audio source)에서 입력 방식을 고릅니다.
    • 마이크 — 내 앞의 소리만
    • 시스템 오디오 — Zoom·Teams·Slack·YouTube 등 Mac에서 재생되는 소리
    • 마이크+시스템 — 온라인 회의용. 내 목소리와 상대 목소리를 함께
  3. 평소처럼 녹음 시작을 누릅니다.

참고

  • 시스템 오디오를 처음 쓸 때 macOS가 ‘화면 기록’ 권한을 요청합니다. 오디오만 사용하며 화면은 저장하지 않습니다. 권한을 허용해 주세요.

파일 및 영상 전사

이미 가지고 있는 오디오 또는 영상 파일을 끌어다 놓으면 전사됩니다.

  1. 오디오 또는 영상 파일(mp4·mov·m4v·mkv·webm·avi 등)을 마디 창 위로 끌어다 놓습니다. 드롭 영역에 드롭하여 전사가 표시됩니다.
  2. 진행률이 (N/전체 청크 · %) 형태로 표시됩니다.
  3. 전사가 끝나면 화면에 결과가 나타납니다.

참고

  • 영상 파일의 음성은 자동으로 추출되어 전사됩니다. 별도 변환이 필요 없습니다.

화자 수 고정

방 안의 인원수를 알고 있다면 미리 지정해 화자 분리(diarization) 정확도를 높일 수 있습니다.

  1. 설정 → 녹음 → 화자 수로 이동합니다.
  2. 자동(자동 감지) / 1 / 2 / 3 / 4명 이상 중에서 고릅니다.

참고

  • 인원수가 분명할 때 고정하면 화자가 더 정확하게 나뉩니다. 확실하지 않다면 자동 감지를 두세요.

회의 모드

회의의 성격에 맞춰 화자 수 · 요약 방식 · 강조 항목을 한 번에 맞춰 주는 프리셋입니다. 설정 → 녹음 → 회의 모드에서 고릅니다.

  • 일반 — 기본 설정 · 발화자 자동 감지
  • 1:1 — 발화자 2명 · 결정과 후속 조치 강조
  • 스탠드업 — 발화자 자동 · 액션과 블로커 강조
  • 인터뷰 — 발화자 2명 · 질문·답변 흐름 보존
  • 강의 — 발화자 1명 · 핵심 요점 위주 정리

참고

  • 회의 모드는 녹음을 시작하기 전에 골라야 합니다. 녹음 중에는 잠깁니다.

전사 보기 전환

화면 상단의 토글로 두 가지 보기를 오갈 수 있습니다.

  • 내용 — 깨끗한 회의록 읽기 보기 (기본값). 읽기에 집중할 때 좋습니다.
  • 상세 — 시각(타임코드), 신뢰도가 낮은 단어(노란색 강조), 발언 겹침 표시까지 보여 줍니다. 내용을 검토·수정할 때 좋습니다.
  • 대화 — 정확히 두 사람이 있을 때만 나타납니다. 첫 화자를 왼쪽, 상대를 오른쪽 말풍선에 놓는 메신저식 보기로, 통역·상담처럼 번갈아 읽을 때 좋습니다.

글자 크기는 + / − 버튼으로 조절합니다.

개인정보

마디의 모든 전사는 이 Mac 안에서만 처리됩니다. 전사 내용은 절대 기기를 떠나지 않습니다.

03

화자 및 화자 분리

마디는 회의에서 누가 말했는지를 자동으로 구분하고, 한 번 이름을 지정한 목소리는 다음 회의에서도 알아봅니다. 이 모든 처리는 이 Mac 안에서만 이루어집니다.

자동 화자 분리

녹음·전사가 진행되는 동안 마디는 발언을 화자별로 자동으로 나눕니다.

  • 각 화자에게 고유한 색 점과 화자 N 라벨이 붙습니다.
  • 인원수를 미리 알고 있다면 설정 → 녹음 → 화자 수에서 고정해 분리 정확도를 높일 수 있습니다.

화자 이름 지정

  1. 전사에서 화자 이름(예: 화자 1)이나 화자 칩을 클릭합니다.
  2. 화자 이름 입력란에 실제 이름을 입력합니다 (예: 김부장).
  3. 입력한 이름이 그 화자의 모든 발언과 내보내기에 적용됩니다.

음성 지문 (목소리로 자동 인식)

화자에게 이름을 지정하면 마디가 그 사람의 음성 지문을 등록합니다. 그러면 다음 회의에서 같은 목소리를 자동으로 알아보고 같은 이름을 붙여 줍니다. 모든 처리는 이 Mac 안에서만 이루어집니다.

  • 목소리로 자동 인식된 화자에게는 ✓ 음성 인식됨 배지가 표시됩니다 (등록된 목소리와 일치한다는 뜻).
  • 음성 지문 인식은 실시간 녹음에서만 동작합니다. 파일 전사에는 적용되지 않습니다.

등록된 음성 관리

  1. 워크스페이스 탐색기에서 사람 영역으로 이동합니다 (또는 설정에서 접근).
  2. 등록된 음성 목록에서 이름을 확인합니다.
  3. 더 이상 필요 없는 음성은 삭제 버튼으로 지웁니다.

참고

  • 등록된 음성이 하나도 없으면 “등록된 음성이 없습니다”라고 표시됩니다. 회의 중 화자 이름을 지정하면 그 목소리가 등록되어, 다음 회의에서 자동으로 인식됩니다.

발언 시간 · 사람 대시보드

누가 얼마나 말했는지를 한눈에 볼 수 있습니다.

  • 전사 화면에서 발언 시간으로 화자별 발화량을 확인합니다.
  • 워크스페이스 탐색기의 사람 탭은 한 사람의 발화량을 여러 회의에 걸쳐 모아서 보여 줍니다. 등록된 음성마다 카드 한 개가 생깁니다.

참고

  • 등록된 화자가 없으면 “등록된 화자가 없습니다”라고 표시됩니다. 화자 이름을 지정하면 목소리가 등록되어, 여기에 회의별 발화량이 모입니다.

발언 겹침 표시

두 사람이 동시에 말하면, 상세 보기에서 겹침 표시가 나타나 그 구간에 끼어든 두 번째 화자를 알려 줍니다.

참고

  • 겹침 표시는 상세 보기에서만 나타납니다. 화면 상단에서 내용 → 상세로 전환하세요.
04

실시간 번역·통역

Madi의 번역은 100% 기기 안에서 동작합니다. 클라우드도, 계정도 필요 없습니다. 회의가 진행되는 동안 각 발화를 한국어·English·日本語·中文로 즉시 옮겨 원문 아래에 함께 보여 줍니다. 모든 번역은 동봉된 온디바이스 LLM(DNA3.0-4B)이 처리합니다.

먼저: 번역 모델 받기

번역은 별도의 모델(DNA3.0-4B, 약 2.6 GB)이 필요하며 앱에 동봉되어 있지 않습니다. 켤 때 한 번 내려받습니다.

  1. 설정 → 번역(또는 모델) 탭을 엽니다.
  2. 번역 모델 다운로드 버튼을 누릅니다.
  3. 다운로드가 끝나면 실시간 번역 항목이 활성화됩니다.

메모리는 사용 중에 약 3 GB가 추가로 필요합니다. 모델을 받기 전에는 번역 토글이 비활성 상태이고, "번역 모델을 먼저 다운로드하세요."라는 안내가 표시됩니다.

실시간 번역 켜기 (다중 대상)

설정 → 번역 → 실시간 번역 (다중 대상) 에서 원하는 언어를 하나 이상 선택합니다.

  • 한국어
  • English
  • 日本語
  • 中文

여러 언어를 동시에 켤 수 있습니다. 선택한 모든 언어로 각 줄을 한꺼번에 번역해 원문 바로 아래에 표시하며, 각 번역에는 언어 태그(한 / EN / 日 / 中)가 붙습니다. 원문과 같은 언어는 자동으로 제외됩니다.

번역이 타이핑되듯 나타납니다

번역이 다 만들어질 때까지 기다리지 않습니다. Madi는 단어가 생성되는 대로 화면에 바로바로 채워 넣습니다(약 19밀리초에 한 글자꼴). 아직 쓰는 중인 줄 끝에는 커서 ▍ 가 깜빡여, 잘린 문장이 아니라 계속 이어지는 중임을 알려 줍니다.

말하는 도중에도 임시 번역이 먼저 뜨고 진행 중 으로 표시됩니다. 그 줄이 확정되면 임시 번역이 정식 번역으로 자연스럽게 바뀌며, 확정 번역이 도착할 때까지 임시 번역이 화면에 그대로 남아 있어 "번역이 잠깐 사라지는" 공백이 없습니다.

대면 통역 — 양방향 언어

Madi는 서로 다른 언어를 쓰는 두 사람의 대면 대화(예: 한국인 직원과 일본인·중국인 손님)를 위해 설계되었습니다.

번역 대상으로 한국어와 다른 언어 하나만 켜면 (예: 한국어 + 日本語) 양방향 통역 모드가 됩니다.

  • 줄마다 방향을 자동으로 판별합니다. 일본어로 말한 줄은 한국어로만, 한국어로 말한 줄은 일본어로만 번역합니다. 불필요한 번역이 없어 더 빠릅니다.
  • 두 언어를 번갈아 말해도 양쪽 전사가 모두 정확합니다. 세그먼트마다 어느 언어인지 다시 확인하기 때문에, 한 사람은 한국어·다른 사람은 일본어로 대화해도 각자의 말이 제대로 받아쓰기됩니다.
  • 이 경우에는 반응 속도가 자동으로 느려지지 않습니다(아래 참고).

자주 쓰는 문구 사전 (즉시 번역)

같은 안내를 반복하는 현장(예: 진료실의 시술 후 주의사항)을 위해, 자주 쓰는 문구의 번역을 미리 저장해 둘 수 있습니다. 저장된 문구와 같은 말이 나오면 모델을 거치지 않고 즉시(0초) 번역이 표시됩니다.

기본으로 몇 가지 문구가 들어 있으며, 직접 문구를 추가·수정할 수 있습니다(저장 위치: ~/Library/Application Support/Sovereign/faq_translations.json). 안전을 위해 정확히 일치하는 문구에서만 동작합니다.

반응 속도와 번역 품질

번역 대상을 2개 이상(예: 日本語 + 中文 + English) 선택하면, 원문 줄 경계 오류가 여러 언어로 번지지 않도록 반응 속도가 정확(10초) 으로 고정됩니다.

예외: 한국어 + 다른 언어 하나만 켠 양방향 통역 모드에서는 줄마다 실제 번역 대상이 한 개로 줄어들기 때문에 10초로 고정하지 않습니다. 대면 통역에서 자막이 더 빨리 뜹니다.

번역이 밀릴 때는 상단에 "N줄 번역 대기" 가 표시됩니다. 멈춘 것이 아니라 순서대로 처리 중이라는 뜻입니다(모델은 한 번에 한 줄씩 번역합니다).

자막 오버레이

자막 오버레이 는 화면 맨 위에 떠 있는 실시간 번역 자막 창입니다. Zoom·Teams 같은 통화 화면 위에, 또는 진료실 디스플레이에 올려 두고 상대의 말을 실시간 번역으로 따라갈 수 있습니다.

  • 사이드 패널의 자막 오버레이 버튼으로 켜고 끕니다.
  • 창은 항상 맨 앞에 머물지만 포커스를 빼앗지 않으므로, 통화 앱에서 계속 클릭·입력할 수 있습니다.
  • 전체 화면 위에서도 떠 있고, 배경을 잡아 원하는 위치로 끌어다 놓을 수 있습니다.
  • 가장 큰 글씨는 번역문, 그 아래 작은 글씨는 원문입니다.
  • 여러 명이 있을 때는 자막에도 화자 색점과 이름 이 붙어 누구 말인지 알 수 있습니다.
  • 말을 기다리는 동안 마이크 입력 막대 가 움직여, 시스템이 듣고 있음을 확인시켜 줍니다.
  • 아직 번역 중일 때 상태 문구("진행 중 / 번역 중… / 음성 대기")는 보는 사람의 언어로 표시됩니다 — 일본어 자막이면 「翻訳中…」, 중국어 자막이면 「翻译中…」.

직원 자막 + 환자 자막 (이중 화면)

진료실 대면 통역을 위해 자막을 두 개 로 나눌 수 있습니다.

  • 직원 자막 — 주 화면에 작게. 직원이 보는 언어(첫 번째 번역 대상).
  • 환자 자막 — 외장 모니터에 크게(원거리 판독용). 환자 언어로 표시.

설정 → 자막 오버레이(진료실) 에서 켭니다. 직원 글씨(14–48pt)·환자 글씨(24–96pt)·패널 폭·환자 화면·환자 언어를 각각 지정할 수 있습니다. 진료 의자와 디스플레이 사이 1.5–2.5m 거리에서 읽기 좋게 큰 글씨를 씁니다.

대화(채팅) 보기

정확히 두 사람이 대화할 때, 전사를 메신저처럼 좌우로 나눠 볼 수 있습니다. 첫 화자는 왼쪽, 상대는 오른쪽 말풍선에 놓여 번갈아 읽는 통역에 적합합니다. 제어 바에 두 명이 감지되면 대화 보기 버튼이 나타납니다.

성능 참고 — 메모리에 따라 달라집니다

실시간 번역과 회의 요약은 같은 LLM을 공유합니다. 그래서 동작 방식이 Mac의 메모리에 따라 달라집니다.

  • 16 GB 이상 Mac: 실시간 번역과 라이브 액션 추출 같은 기능이 함께 돌아갑니다. 번역 자막이 끊기지 않습니다.
  • 16 GB 미만 Mac: 한 번에 모델 하나만 메모리에 올릴 수 있습니다. 라이브 액션 추출 같은 기능을 켜면 그동안 실시간 번역이 잠시 멈춥니다.

번역 자막을 끊김 없이 쓰고 싶다면 16 GB 미만 Mac에서는 라이브 액션 추출 같은 추가 기능을 끄는 것이 좋습니다.

05

회의 인텔리전스

Madi의 회의 인텔리전스는 회의록을 단순한 받아쓰기에서 "정리된 회의 자산"으로 바꿔 줍니다. 요약, 액션 아이템, 질의응답, 실시간 코칭, 후속 추적까지 모두 이 Mac 안의 로컬 LLM(DNA3.0-4B)이 처리합니다. 전사 내용과 요약은 절대 이 기기를 떠나지 않습니다.

기능별로 필요한 조건이 다릅니다. 일부 기능은 요약 모델(LLM)이 설치되어 있어야 하고, 일부는 16GB 이상 메모리가 필요합니다. 각 항목에 표시해 두었습니다.

A.I 요약

회의록을 구조화된 요약 + 액션 아이템 + 결정 사항으로 정리합니다.

  1. 회의록 상단의 요약 버튼을 누릅니다 (반짝이 아이콘).
  2. 로컬 LLM이 회의 요약 시트를 열고 요약을 생성합니다. "전사 내용은 이 Mac을 떠나지 않습니다"라는 안내가 함께 표시됩니다.
  3. 시트 상단의 전체 / 화자별 토글로 보기를 바꿀 수 있습니다.
    • 전체 — 회의 전체의 요약·액션·결정
    • 화자별 — 화자마다 무슨 이야기를 했는지 정리 (처음 선택하면 그 자리에서 생성합니다)

요약 시트 아래쪽 버튼:

  • 복사 — 요약 텍스트를 클립보드로 복사
  • 다시 생성 — 같은 회의록으로 요약을 새로 생성
  • 슬라이드(HTML) — 오프라인에서 열리는 HTML 슬라이드 덱으로 내보내고 Finder에서 보여 줍니다
  • 리캡 카드 — 공유용 요약 카드를 엽니다 (아래 "리캡 카드" 참고)
  • 내보내기… — 요약을 .md 파일로 저장

필요 조건

  • 요약 모델(LLM)이 설치되어 있어야 합니다. 모델이 없으면 요약 버튼이 나타나지 않습니다.

A.I 요약을 별도 파일로 저장

회의가 끝날 때 요약을 전사문과 별개의 파일로 자동 저장합니다.

  1. 오른쪽 사이드 패널에서 A.I 요약 체크박스를 켭니다.
  2. 회의가 완료되면, 전사문 옆에 …요약.md 파일이 함께 저장됩니다 (예: 회의록.md → 회의록 요약.md).

필요 조건

  • 요약 모델(LLM)이 필요합니다.
  • 전사문 자동 저장이 켜져 있어야 합니다.

회의록에 물어보기 (질의응답)

회의 내용을 자연어로 질문하면, 로컬 LLM이 회의록을 근거로 답합니다. 요약 시트 아래쪽에 있습니다.

  1. 회의록에 물어보기 입력란에 질문을 입력합니다. 예: "무엇을 결정했나요?", "김부장이 맡은 일은?"
  2. 종이비행기 버튼을 누르거나 Enter를 칩니다.
  3. 이 회의 / 전체 워크스페이스 토글로 검색 범위를 정합니다.
    • 이 회의 — 지금 열려 있는 회의록에서만 답변
    • 전체 워크스페이스 — 저장된 모든 회의록을 가로질러 검색. 예: "지난달 보안 결정은?", "지난 분기 가격 결정 찾아줘"

필요 조건

  • 요약 모델(LLM)이 필요합니다.

라이브 액션 추출

녹음 중에 결정·할 일·질문을 실시간으로 뽑아내, 회의가 끝나는 순간 이미 정리되어 있도록 합니다. 추출된 항목은 사이드의 라이브 인텔리전스 영역에 [결정]·[액션]·[질문] 카드로 (담당자와 함께) 쌓입니다.

  1. 녹음을 시작하기 전에, 사이드 패널에서 라이브 액션 추출 체크박스를 켭니다.
  2. 녹음을 시작하면 카드가 실시간으로 채워집니다.

필요 조건

  • 16GB 이상 메모리가 필요합니다. 메모리가 부족하면 토글이 비활성화되고 "16GB 이상 메모리 필요" 안내가 표시됩니다.
  • 요약 모델(DNA3)을 전사와 동시에 구동하므로 메모리 사용이 큽니다.

참고

  • 같은 모델을 쓰는 실시간 번역은 라이브 액션 추출이 켜진 동안 일시 중지됩니다.
  • 녹음이 시작된 뒤에는 켜고 끌 수 없습니다. 반드시 녹음 전에 설정하세요.

라이브 코치 (텔레프롬프터)

녹음 중에 회의 진행을 도와주는 사이드 패널입니다. 어떤 Mac에서도 동작하며, 모델이 필요 없습니다.

  1. 사이드 패널에서 라이브 코치 체크박스를 켭니다 (기본값은 꺼짐).
  2. 녹음 중에 코치 패널이 다음을 실시간으로 보여 줍니다.
    • 안건 체크리스트 — 지난 결정·미해결 액션을 안건으로 띄우고, 라이브 전사가 그 내용을 다루면 자동으로 체크 표시(취소선)합니다. 상단에 "N / M 다룸" 진행도가 표시됩니다.
    • 미답변 질문 — 회의에서 나온 질문 중 아직 답이 안 된 항목
    • 지금 흐름 — 최근 발언 속도·겹침·침묵으로 추정한 회의 분위기를 가열 / 안정 / 저조로 표시 (작은 막대 그래프 포함)

필요 조건

  • 없음 — 모델이 필요 없으며 모든 Mac에서 동작합니다.

참고

  • 안건은 캘린더 일정이 잡혀 있을 때(지난 결정·액션이 모일 때) 더 풍부해집니다. 준비된 안건이 없으면 그 안내가 표시됩니다.

열린 항목 (후속 추적)

저장된 모든 회의에 걸쳐, 아직 마무리되지 않은 액션 아이템·열린 질문을 한곳에 모아 보여 줍니다. 워크스페이스 탐색기의 열린 항목 탭(파일 / 사람 옆)에서 볼 수 있습니다.

각 항목에는 다음이 표시됩니다.

  • 종류 배지 — [결정] / [액션] / [질문]
  • 담당자 (액션 아이템의 경우)
  • 출처 회의 이름
  • 경과 일수 — 미해결이면 "12일째 후속 없음", 해결됐으면 "12일 경과"
  • 후속 여부 — 이후 회의에서 다시 언급되었으면 "5일 후 ○○회의에서 언급됨"

항목은 후속 필요(오래된 순)와 후속됨 두 그룹으로 나뉩니다. 항목을 누르면 출처 회의록이 열립니다.

필요 조건

  • 회의 요약에 [결정]·[액션]·[질문]이 기록되어 있어야 추적됩니다 (즉, 요약 모델로 정리된 회의록).

회의 준비 브리핑

회의를 시작하기 전(또는 캘린더 일정이 감지될 때), 이 참석자들과 관련된 지난 맥락을 한 장으로 정리해 보여 줍니다. 캘린더 + 사람 + 지난 회의 검색을 결합합니다.

브리핑에 담기는 내용:

  • 회의 참석자 — 참석자별 지난 회의 이력
  • 지난 결정 — 이 참석자들과 관련해 과거에 내려진 결정
  • 미해결 액션 — 아직 끝나지 않은 액션 아이템
  • 관련 논의 — 관련된 지난 회의 목록

하단의 복사 / 내보내기… 버튼으로 브리핑을 클립보드나 .md 파일로 저장할 수 있습니다.

참고

  • 기본 브리핑(참석자·지난 결정·미해결 액션)은 워크스페이스에 저장된 회의록만으로 구성되며 요약 모델이 필요 없습니다.
  • 워크스페이스에서 더 찾기 토글을 켜면, 로컬 LLM이 워크스페이스 전체를 검색해 "관련 논의"에 추가 맥락을 보여 줍니다. 이 검색은 요약 모델이 필요하며, 기본값은 꺼짐입니다(요약 모델을 띄우면 번역 엔진이 잠시 내려갑니다).

제목 자동 생성 · 리캡 카드

제목 자동 생성 — A.I 요약 자동 저장이 켜진 라이브 세션에서는, 회의가 끝날 때 로컬 LLM이 회의 제목을 직접 지어 파일 이름을 그 제목으로 바꿔 줍니다(요약본과 같은 이름으로 묶입니다). 파일 이름을 직접 입력하지 않았을 때만 동작합니다.

리캡 카드 — 회의 한 장 요약 카드입니다. 요약 시트의 리캡 카드 버튼으로 엽니다. 다음이 담긴 공유용 카드입니다.

  • 제목 + 날짜
  • TL;DR (핵심 요약)
  • 결정 목록
  • 담당자별 액션
  • 화자별 발화 시간(막대)
  • 한 줄 인용

복사로 카드 한 페이지를 Markdown으로 복사하거나, 내보내기…로 같은 내용을 파일로 저장할 수 있습니다.

필요 조건

  • 제목 자동 생성과 리캡 카드의 요약 내용은 모두 요약 모델(LLM)이 필요합니다.

개인정보 보호

이 모든 기능은 이 Mac 안에서 동작합니다. 전사 내용도, 요약도, 질의응답도 이 기기를 떠나지 않습니다.

06

작업 폴더와 파일 관리

Madi는 저장 폴더를 통째로 하나의 작업 공간(워크스페이스)으로 보여줍니다. 화면 옆의 IDE 스타일 파일 트리에서 지난 회의록을 다시 열고, 새 폴더로 전환하고, 다양한 형식으로 내보낼 수 있습니다.

작업 폴더 탐색기 열고 닫기

회의록 옆에 파일 트리(탐색기)가 나타나, 저장 폴더가 하나의 작업 공간처럼 보입니다.

  1. 상단의 폴더 버튼(사이드바 아이콘, 도움말 "작업 폴더 탐색기")을 눌러 탐색기를 켜거나 끕니다.
  2. 탐색기 안의 탐색기 닫기 버튼으로도 닫을 수 있습니다.

팁 — 너비 조절: 탐색기의 가장자리를 끌어 너비를 조절할 수 있습니다. 조절한 너비는 다음 실행 때도 기억됩니다.

탭 전환

탐색기 위쪽의 탭으로 보기를 바꿉니다.

  • 파일 — 저장 폴더의 회의록과 하위 폴더를 트리로 보여줍니다.
  • 사람 — 회의에 참여한 화자 분석을 보여줍니다.
  • 열린 항목 — 아직 마무리되지 않은 결정·할 일 등 "열린 고리"를 모아 보여줍니다.

저장된 회의 다시 열기

  1. 파일 탭에서 회의록 파일(.md)을 클릭합니다.
  2. 해당 회의록이 화면에 다시 열립니다.

회의록 미리보기(요지)

각 회의록 파일 이름 아래에는 한 줄짜리 요지(그 회의의 첫 결정·요약 줄)가 표시됩니다. 덕분에 트리가 회의 기록 피드처럼 한눈에 읽힙니다.

작업 폴더 선택·전환

선택한 폴더는 저장과 내보내기의 기본 위치가 됩니다(둘 다 같은 폴더).

  1. 트리에서 폴더를 클릭하면, 그 폴더가 작업 공간이자 저장·내보내기 폴더가 됩니다.
  2. 상위로 올라가려면 상단의 상위 폴더로(↑) 버튼을 누릅니다.
  3. 완전히 다른 폴더를 고르려면 폴더-기어 버튼(도움말 "작업 폴더 변경…")을 눌러 새 폴더를 선택합니다.
  4. 폴더를 마우스 오른쪽 버튼으로 눌러 이 폴더 열기 (작업 폴더로) 를 선택해도 됩니다.
참고: 새로 선택한 폴더가 곧바로 기본 저장 위치이자 기본 내보내기 위치가 됩니다.

저장 방식

  • 회의는 작업 폴더에 자동 저장됩니다.
  • A.I 요약을 켜 두면, 전사문과 별개로 "…요약.md" 파일이 함께 저장됩니다.

내보내기

상단의 내보내기 메뉴에서 형식을 고릅니다. 내보낸 파일은 기본적으로 작업 폴더에 저장됩니다.

  • Markdown (.md) — 마크다운 회의록
  • Subtitles (.srt) — SRT 자막
  • Subtitles (.vtt) — VTT 자막
  • Plain text (.txt) — 일반 텍스트
  • JSON (.json) — JSON 데이터
  • 슬라이드(HTML) — HTML 슬라이드 덱
  • 타이튼 컷 목록 (.csv) — 잘라낼 필러·무음 컷 목록(CSV)
  • 유튜브 챕터 (.txt) — 챕터 목록 텍스트

클릭해서 그 순간 듣기

오디오·영상 파일을 불러와 전사한 세션(원본 파일이 디스크에 있는 경우)에서는, 각 줄에 재생 버튼이 표시됩니다.

  1. 듣고 싶은 줄의 재생 버튼(도움말 "이 구간 오디오 재생")을 누릅니다.
  2. 그 줄이 말해진 정확한 순간이 원본 미디어에서 재생됩니다.
참고: 실시간 마이크 녹음 세션에는 원본 파일이 없으므로 줄별 재생 버튼이 나타나지 않습니다.
07

편집과 검토

전사가 끝나면 깔끔하게 읽거나, 자세히 들여다보며 고칠 수 있습니다. Madi는 여러분이 고친 내용을 기억해 다음 회의에서 같은 실수를 자동으로 바로잡고, 잘라낼 부분까지 짚어 줍니다.

내용 보기 vs 상세 보기

화면 상단의 전환 스위치(도움말 "내용: 깨끗한 회의록 보기 · 상세: 시각·신뢰도·겹침 표시")로 두 가지 보기를 오갑니다.

  • 내용 — 시각·표시 없이 깨끗하게 읽는 기본 보기.
  • 상세 — 타임코드, 저신뢰 단어(호박색 강조), 화자 겹침 표시(⟨+이름 겹침⟩)를 함께 보여줍니다.

줄 직접 편집(인라인 편집)

  1. 고치고 싶은 줄을 더블 클릭합니다(또는 상세 보기에서 연필 버튼, 도움말 "이 문장 편집"을 누릅니다).
  2. 내용 보기에서 더블 클릭하면 자동으로 상세 보기로 넘어가 편집창이 열립니다.
  3. 텍스트를 고치고 입력을 마칩니다.
  4. 고친 줄에는 편집됨 표시가 붙습니다.

검토 필요 — 저신뢰 단어 빠르게 확인

상세 보기는 신뢰도가 낮은 단어(설정의 기준값 미만, 기본 0.55)를 호박색으로 표시합니다.

  1. 상단에 검토 필요 N개가 표시됩니다.
  2. 이전(이전 검토 단어) / 다음(다음 검토 단어) 버튼으로 표시된 단어들 사이를 건너뛰며 이동합니다.
  3. 각 단어를 확인하고, 필요하면 그 자리에서 고칩니다.

귀로 검토 — 들으며 확인

파일을 불러와 전사한 세션에서는, 저신뢰 단어의 오디오 구간을 하나씩 자동으로 재생해 귀로 확인할 수 있습니다(클릭 재생 기능을 그대로 활용).

  1. 검토바의 재생 버튼(도움말 "저신뢰 단어 귀로 검토")을 누릅니다.
  2. 표시된 단어들의 오디오가 순서대로 자동 재생되고, 한 단어가 끝나면 다음으로 넘어갑니다(핸즈프리).
  3. 멈추려면 같은 버튼(도움말 "귀로 검토 멈춤")을 다시 누릅니다.
참고: 귀로 검토는 원본 미디어가 있는 파일 전사 세션에서만 켜집니다.

개인 단어장 — 교정을 기억하는 학습

전사문의 한 줄을 고치면 Madi가 그 교정을 학습합니다. 단어장 기능을 켜 두면, 다음 회의에서 같은 도메인 용어·이름의 오인식을 자동으로 바로잡습니다.

켜는 법: 설정(⌘,) → 단어장 탭에서 학습한 교정 자동 적용을 켭니다.

참고: 학습은 스위치와 상관없이 항상 동작하며, 이 스위치는 "적용"만 켭니다. 그래서 켜는 즉시 그동안 쌓인 교정이 적용됩니다.

적용 기준(최소 확인 횟수)

  • 최소 확인 횟수(minHits) 슬라이더로, 같은 교정을 몇 번 확인해야 믿고 자동 적용할지 정합니다(1~5회).
  • 값이 클수록 보수적입니다 — 우발적인 편집 한 번이 이후 전사를 덮어쓰지 않도록 막아 줍니다.

학습한 교정 관리·삭제

설정 → 단어장 탭의 목록에서 학습한 규칙을 관리합니다.

  • 각 규칙은 잘못된 단어 → 올바른 단어와 확인 횟수로 표시됩니다.
  • 규칙 옆 휴지통 버튼(도움말 "이 교정을 잊기")으로 하나씩 잊게 합니다.
  • 모두 지우려면 전체 지우기를 누릅니다.

타이튼 — 잘라낼 부분 찾기

타이튼은 잘라내도 되는 필러(말버릇)와 무음 구간을 찾아냅니다.

  1. 컨트롤 패널에 타이튼: N컷 · N초 절감 가능이 표시됩니다.
  2. 잘라낼 목록을 파일로 받으려면 내보내기 → 타이튼 컷 목록 (.csv) 를 선택합니다.
참고: 타이튼은 깨끗한 회의록 본문은 건드리지 않습니다 — 잘라낼 후보만 알려 줍니다.

편집 보조 기능

설정 → 편집·저장 탭에서 다음 분석을 켜고 끕니다(기본은 꺼짐, 필요할 때만 켜세요).

  • 챕터 — 자동 챕터 나누기.
  • 리테이크 · 하이라이트 — 다시 말한 부분 감지, 하이라이트 표시.

텍스트 선택과 복사

전사문 전체에서 텍스트를 드래그로 선택하고 ⌘C로 복사할 수 있습니다.

08

시스템 받아쓰기

받아쓰기는 macOS 어디서나 쓸 수 있는 Madi의 음성 입력 기능입니다. 전역 단축키를 누른 채 말하고 떼면, 말한 내용이 기기 안에서 글자로 바뀌어 지금 맨 앞에 있는 앱(메모, 메일, Slack, 코드 편집기 등)의 입력란에 그대로 들어갑니다. 100% 온디바이스 — 클라우드도, 계정도 없습니다.

사용법

  1. 설정 → 받아쓰기 에서 어디서나 받아쓰기 사용 을 켭니다.
  2. 처음 켜면 손쉬운 사용 권한을 요청합니다(아래 참고).
  3. 텍스트를 넣고 싶은 곳에 커서를 둡니다 — 어떤 앱이든 상관없습니다.
  4. 오른쪽 ⌥(Option) 키를 누른 채 말합니다(누르고 있는 동안만 녹음).
  5. 키에서 손을 떼면 받아쓴 텍스트가 들어갑니다.

기본 단축키: 오른쪽 ⌥ Option

기본 단축키는 오른쪽 Option 키입니다. 누르고 있는 동안만 녹음하는 푸시투토크 방식이라, 떼는 순간 입력이 완료됩니다. 오른쪽 Option은 단독으로 쓰는 일이 거의 없고 ⌘K(명령 팔레트)와도 겹치지 않아 기본값으로 쓰입니다.

클립보드는 그대로 유지됩니다

Madi는 텍스트를 넣을 때 먼저 현재 클립보드 내용을 저장하고, 받아쓴 텍스트를 붙여넣은 뒤, 원래 클립보드를 곧바로 되돌립니다. 따라서 복사해 둔 내용은 그대로 남아 있습니다.

필수 권한 — 손쉬운 사용

받아쓰기가 다른 앱에 텍스트를 붙여넣으려면 macOS 손쉬운 사용 권한이 필요합니다.

  1. 설정 → 받아쓰기 에서 받아쓰기를 켭니다.
  2. 손쉬운 사용 권한 항목에서 상태를 확인합니다.
    • 허용됨: 바로 쓸 수 있습니다.
    • 권한 필요: 시스템 설정에서 허용 버튼을 누릅니다.
  3. 버튼을 누르면 시스템 설정의 개인정보 보호 및 보안 → 손쉬운 사용 으로 이동합니다. 거기서 Madi를 허용합니다.
  4. 허용 후 이 창으로 돌아오면 상태가 자동으로 허용됨 으로 바뀝니다.

권한이 없으면 받아쓰기는 동작하지 않습니다. 다만 조용히 실패하지 않고 "손쉬운 사용 권한이 필요합니다"라고 알려 줍니다.

회의 녹음 중에는 비활성화

회의를 녹음하는 동안에는 받아쓰기 단축키가 꺼집니다. 받아쓰기와 회의 녹음이 같은 물리 마이크를 쓰기 때문에 충돌을 막기 위함입니다. 이때 오른쪽 Option을 눌러도 "회의 녹음 중에는 받아쓰기를 사용할 수 없습니다"라는 짧은 안내가 표시되고, 녹음을 멈추면 다시 쓸 수 있습니다.

빠르고 가벼운 받아쓰기

받아쓰기는 받아쓴 말을 가공 없이 그대로 입력합니다. 큰 LLM을 메모리에 올리지 않고, 받아쓰기 전용 음성 인식만 짧게 돌렸다가 끝나면 종료합니다. 그래서 회의 요약/번역 모델을 켜지 않았더라도, 메모리가 적은 Mac에서도 가볍고 빠르게 동작합니다.

받아쓰기 언어는 회의 녹음에서 고른 언어 설정을 따릅니다(기본값 한국어). 짧은 음성은 자동 감지가 빗나갈 수 있어, 자동을 선택하지 않은 경우 고른 언어로 고정해 인식합니다.

설정 항목 정리 (설정 → 받아쓰기)

  • 어디서나 받아쓰기 사용 — 받아쓰기 켜기/끄기.
  • 단축키 — 기본값 안내(오른쪽 ⌥ Option, 누르고 있는 동안 녹음).
  • 손쉬운 사용 권한 — 현재 상태와 시스템 설정에서 허용 버튼.
  • 상태 — 현재 받아쓰기 상태(대기 중 / 듣는 중 / 변환 중 / 입력 중).
09

설정

설정 창은 ⌘,(Command + 쉼표) 로 엽니다. 매 회의마다 만지는 것이 아니라 “한 번 정해 두는” 항목들이 여기에 모여 있습니다. 창 위쪽 탭으로 녹음 · 편집·저장 · 번역 · 단어장 · 모델 · 받아쓰기 를 오갑니다.

참고: 녹음 탭의 설정은 녹음 중·일시정지 중에는 잠깁니다. 바꾸려면 녹음을 멈춘 뒤 조정하세요.

녹음

음원 캡처 방식과 실시간 동작, 화면 표시를 정합니다.

입력

  • 음원 — 무엇을 들을지 고릅니다.
    • 마이크 — 내 목소리/대면 회의.
    • 시스템 오디오 — Mac에서 재생되는 소리(Zoom·Teams·Slack·YouTube 등). 첫 사용 시 ‘화면 기록’ 권한을 요청합니다(오디오 전용, 화면은 저장하지 않음).
    • 마이크+시스템 — 온라인 회의(내 목소리 + 상대방 소리)에 적합합니다.
  • 마이크 — (마이크/마이크+시스템일 때) 사용할 입력 장치를 고릅니다. 기본은 “시스템 기본”.
  • 언어 — 자동 감지 / 한국어 / English 중에서 받아쓰기 언어를 고정하거나 자동으로 둡니다.

화자

  • 화자 분리 — 누가 말했는지 화자별로 구분합니다.
  • 중첩 발화 감지 — 두 사람이 동시에 말하는 구간을 감지합니다.

실시간

  • 반응 속도 — 빠름(5초) / 보통(7초) / 정확(10초). 빠름은 텍스트가 더 자주 떠 체감 속도가 좋고, 정확은 문맥을 길게 봐 품질이 좋습니다. 번역 대상이 2개 이상이면 자동으로 ‘정확(10초)’ 으로 고정됩니다.
  • 실시간 프리뷰 — 한 구간이 확정되기 전, 중간 텍스트를 회색으로 미리 보여 줍니다(정확도 손해 없음, 메모리 약 830 MB 추가).

표시

  • 외관 — 시스템 / 라이트 / 다크 테마를 고릅니다.

자막 오버레이 (진료실)

대면 통역용 자막 창의 크기와 두 번째(환자용) 화면을 설정합니다.

  • 직원 자막 크기 — 주 화면 자막 글씨(14–48pt).
  • 환자용 대형 자막 (별도 화면) — 두 번째 패널을 환자 언어로, 원거리 판독용 큰 글씨로 띄웁니다. 켜면 아래 항목이 나타납니다.
    • 환자 자막 크기 — 24–96pt.
    • 환자 화면 — 모니터가 둘 이상이면 어느 화면에 띄울지 고릅니다.
    • 환자 언어 — 자동(상대 언어) 또는 특정 언어로 고정.

자동 저장 관련

자동 저장 폴더 설정은 편집·저장 탭에 있습니다(아래 참고).

편집·저장

자동 저장

  • 완료 시 .md 자동저장 — 전사가 끝나면 Markdown 파일로 자동 저장합니다.
  • 폴더 / 변경… — 저장 폴더를 지정합니다.

음성 인식

  • 저신뢰 표시 기준 (VAD) — 이 신뢰도(기본 0.55) 미만으로 인식된 단어를 ‘검토 필요’로 표시합니다.

편집 기능

  • 편집 기능 사용 — 필러·무음 타이튼, 챕터, 리테이크, 하이라이트 분석을 켭니다. 기본은 꺼짐 — 필요할 때만 켜세요. (꺼져 있으면 아래 항목들은 비활성화됩니다.)

필러 · 무음 (타이튼)

  • 무음 컷 — 긴 무음 구간을 감지합니다.
  • 무음 최소초 — 무음으로 간주할 최소 길이.

챕터

리테이크 · 하이라이트

  • 리테이크 감지 — 같은 말을 다시 한 “다시 찍기” 구간을 찾습니다. 유사도 슬라이더로 민감도를 조정합니다.

01

Getting Started

Welcome to Madi. Madi is a Korean meeting-intelligence app that transcribes and understands your meetings entirely on your Mac. Live dictation, audio and video file transcription, speaker diarization, on-device translation, summaries, and Q&A — every bit of processing happens locally on your machine.

What Madi does

  • Live transcription — listens to your microphone or meeting audio and shows text on screen before you even finish speaking.
  • File and video transcription — drag in a recording or video and Madi transcribes the whole conversation.
  • Speaker diarization — separates who said what, and when.
  • On-device translation — translates between Korean, English, Chinese, and Japanese.
  • Summary and Q&A — distills key points, decisions, and action items, and lets you ask questions about the content.

100% on-device — your data never leaves the Mac

Madi's core promise is sovereignty. None of your audio, transcripts, translations, or summaries are ever sent to the cloud. It works even with the internet disconnected (once the models are downloaded). Your meeting content lives only on your device.

About the models

Madi uses two kinds of AI model.

  • Whisper speech model — handles transcription. It is bundled with the app, so there is nothing to download.
  • DNA3.0-4B language model (~2.6 GB) — powers translation, summaries, Q&A, and title generation. To keep the app small, it is downloaded the first time you use it.
    • Where to get it: the “번역 모델 다운로드 (Download translation model)” button under 설정 → 모델 (Settings → Models) or 설정 → 번역 (Settings → Translation).
    • The download is about 2.6 GB, and it needs roughly that much disk space. (See 번역 / Translation and 설정 / Settings for details.)

Memory guidance (the honest version)

  • 8 GB Macs (e.g. the M1 MacBook Air) — transcription and speaker diarization run smoothly.
  • 16 GB or more recommended — needed for features that run the language model alongside transcription. Examples: 라이브 액션 추출 (live action extraction) — pulling out decisions, to-dos, and questions live while recording — or running live translation and summary together with transcription. You can still enable these on 8 GB, but memory will be tight.

Permissions Madi may ask for

Madi does not ask for everything up front. It requests each permission the first time the relevant feature needs it.

  • Microphone — for recording. Requested the first time you start a recording.
  • Screen Recording — only when capturing system audio (sound playing on your Mac, e.g. Zoom, Teams, YouTube). macOS bundles audio capture under the Screen Recording permission; Madi does not save the screen.
  • Calendar — optional. Used for meeting prep and attendee matching. You can skip it entirely.
  • Accessibility (손쉬운 사용) — only needed for system-wide dictation (dictating into any app). It is required to insert dictated text into other apps. (See 받아쓰기 / Dictation.)

If you declined a permission and want to grant it later, open System Settings → Privacy & Security, find the relevant item (Microphone / Screen Recording / Accessibility / Calendar), and switch Madi on.

First-run quickstart

  1. Open Madi.
  2. (Optional) To use translation, summary, or Q&A, download the translation model (DNA3.0-4B, ~2.6 GB) from 설정 (Settings, ⌘,) → 모델 (Models) or 번역 (Translation).
  3. Press 녹음 시작 (Start recording), or drag an audio or video file into the window.
  4. Watch the live transcript appear on screen.
  5. When the meeting ends, press 요약 (Summary) for an AI summary. (Summaries require the translation model to be installed.)

That's it. For more detail, see the other manual pages on recording, translation, dictation, and settings.

Recording & Transcription

Madi transcribes meetings live as people speak, and it can also transcribe audio and video files you already have. Everything runs on this Mac — your transcript never leaves the device.

The app interface is in Korean. Korean UI labels are shown below with an English gloss in parentheses.

Live mic recording

  1. Press 녹음 시작 (Start recording) at the bottom of the window.
  2. As people speak, the transcript streams live in the center of the window.
  3. Press 일시정지 (Pause) to pause, or 정지 (Stop) to end the recording.

Note

  • Set 회의 모드 (Meeting mode) and 화자 수 (Speaker count) before you start — see below. They lock while recording is in progress.
  • The input level bar at the top shows your mic level; it drops to 0 while paused.

Captions appear as soon as you stop talking

Madi doesn't wait for a window to fill up. When you pause and go quiet for a moment, it closes that window early and emits the transcript right away — cutting the wait noticeably in short back-and-forth conversations (like a consultation). Quiet, far-field voices aren't clipped: the threshold adapts automatically.

System audio capture (Zoom / Teams / video)

You can transcribe whatever is playing through your Mac — online meetings, videos, and so on.

  1. Go to 설정 → 녹음 → 입력 (Settings → Recording → Input).
  2. Under 음원 (Audio source), pick how to capture sound:
    • 마이크 (Microphone) — only the sound in front of you
    • 시스템 오디오 (System audio) — what's playing on the Mac: Zoom, Teams, Slack, YouTube, etc.
    • 마이크+시스템 (Mic + system) — for online meetings: your voice plus the other side
  3. Press 녹음 시작 (Start recording) as usual.

Note

  • The first time you use system audio, macOS asks for Screen Recording permission. Madi uses audio only and never saves your screen. Please allow it.

File & video transcription

Drop an audio or video file you already have to transcribe it.

  1. Drag an audio or video file (mp4, mov, m4v, mkv, webm, avi, and more) onto the Madi window. The drop area shows 드롭하여 전사 (Drop to transcribe).
  2. Progress appears as (N / total chunks · %).
  3. When transcription finishes, the result appears on screen.

Note

  • Audio from video files is decoded automatically — no conversion needed.

Fixed speaker count

If you know how many people are in the room, set it in advance to improve speaker separation (diarization).

  1. Go to 설정 → 녹음 → 화자 수 (Settings → Recording → Speaker count).
  2. Choose 자동 (자동 감지 / Auto-detect) / 1 / 2 / 3 / 4명 이상 (4 or more).

Note

  • Fixing the count when you're sure of it produces cleaner speaker separation. If you're unsure, leave it on 자동 감지 (Auto-detect).

Meeting modes (회의 모드)

A one-pick preset that sets speaker count, summary style, and emphasis to match the shape of your meeting. Choose it in 설정 → 녹음 → 회의 모드 (Settings → Recording → Meeting mode).

  • 일반 (General) — Default settings, automatic speaker detection
  • 1:1 (One-on-one) — 2 speakers, emphasizes decisions and follow-ups
  • 스탠드업 (Standup) — Automatic speakers, emphasizes actions and blockers
  • 인터뷰 (Interview) — 2 speakers, preserves the question-and-answer flow
  • 강의 (Lecture) — 1 speaker, organizes around key points

Note

  • Pick a meeting mode before you start recording. It locks while recording is in progress.

Transcript views

Use the toggle at the top of the window to switch between two views.

  • 내용 (Content) — A clean, minutes-style reading view (the default). Best for reading.
  • 상세 (Detailed) — Shows timecodes, low-confidence words (highlighted in amber), and overlap markers when two people talk at once. Best for reviewing and editing.
  • 대화 (Chat) — Appears only when exactly two people are present. Puts the first speaker on the left and the other on the right in message bubbles — good for reading back-and-forth interpreting or a consultation.

Adjust the font size with the + / − buttons.

Privacy

All of Madi's transcription happens on this Mac. Your transcript never leaves the device.

Speakers & Diarization

Madi automatically figures out who spoke during a meeting, and once you name a voice, it recognizes that same voice in future meetings. All of this runs on this Mac.

The app interface is in Korean. Korean UI labels are shown below with an English gloss in parentheses.

Automatic speaker separation

While recording and transcribing, Madi splits speech by speaker automatically.

  • Each speaker gets a colored dot and a 화자 N (Speaker N) label.
  • If you know how many people are present, fix the count in 설정 → 녹음 → 화자 수 (Settings → Recording → Speaker count) to improve separation.

Naming speakers

  1. In the transcript, click a speaker name (e.g. 화자 1 / Speaker 1) or speaker chip.
  2. Type the real name in the 화자 이름 (Speaker name) field — for example, 김부장.
  3. The name applies to all of that speaker's lines and to exports.

Voiceprints (recognized by voice)

When you name a speaker, Madi enrolls that person's voiceprint. From then on, it auto-recognizes the same voice in future meetings and labels it with the same name. All of this happens on this Mac.

  • A speaker recognized by voice shows a ✓ 음성 인식됨 (recognized by voice) badge, meaning the voice matched an enrolled one.
  • Voiceprint recognition works for live recording only — it does not apply to file transcription.

Managing enrolled voiceprints

  1. In the workspace explorer, go to the 사람 (People) area (or reach it from Settings).
  2. Review the list of enrolled voices by name.
  3. Use the 삭제 (Delete) button to remove a voice you no longer need.

Note

  • If nothing is enrolled yet, you'll see "등록된 음성이 없습니다" (No enrolled voices). Naming a speaker during a meeting enrolls that voice, so it's recognized automatically next time.

Talk time & People dashboard

See at a glance who spoke how much.

  • In the transcript, 발언 시간 (Talk time) shows how much each speaker spoke.
  • The 사람 (People) tab in the workspace explorer aggregates one person's talk time across multiple meetings. Each enrolled voice gets its own card.

Note

  • If no speakers are enrolled, you'll see "등록된 화자가 없습니다" (No enrolled speakers). Naming a speaker enrolls the voice, and per-meeting talk time accumulates here.

Overlap markers

When two people talk at the same time, an overlap marker appears in the 상세 (Detailed) view to flag the second speaker in that stretch.

Note

  • Overlap markers appear only in the 상세 (Detailed) view. Switch from 내용 → 상세 (Content → Detailed) at the top of the window.

Real-time translation & interpreting

Madi's translation runs 100% on your device — no cloud, no account. While a meeting is in progress, each spoken line is translated into Korean, English, Japanese, and/or Chinese and shown right beneath the original. Everything is handled by the bundled on-device LLM (DNA3.0-4B).

First: download the translation model

Translation needs a separate model (DNA3.0-4B, ~2.6 GB) that is not bundled with the app. You download it once, on demand.

  1. Open 설정 → 번역 (Settings → Translation) — or the 모델 (Model) tab.
  2. Click 번역 모델 다운로드 (Download translation model).
  3. When the download finishes, the real-time translation toggles become active.

While in use it needs roughly 3 GB of extra memory. Until the model is downloaded the translation toggles are disabled and you'll see the note "번역 모델을 먼저 다운로드하세요." (Download the translation model first).

Turn on real-time translation (multi-target)

In 설정 → 번역 → 실시간 번역 (다중 대상) (Settings → Translation → Real-time translation, multi-target), pick one or more target languages:

  • 한국어 (Korean)
  • English
  • 日本語 (Japanese)
  • 中文 (Chinese)

You can enable several at once. Madi translates each line into all chosen languages simultaneously and shows them directly below the original, each tagged with its language (한 / EN / 日 / 中). The original's own language is excluded automatically.

Translation types itself out

You don't wait for the whole translation to be built. Madi fills it in word by word as it's generated (about one character every 19 milliseconds). A caret ▍ blinks at the end of a line that's still being written, so a half-arrived translation reads as "still typing," not a truncated sentence.

While you're still speaking, a provisional translation appears first, marked 진행 중 (in-progress). When the line commits, the provisional translation is smoothly replaced by the final one — and it stays on screen until the final translation arrives, so the translation never briefly disappears.

Face-to-face interpreting — bidirectional languages

Madi is designed for a face-to-face conversation between two people who speak different languages (for example, Korean staff and a Japanese or Chinese patient).

Turn on 한국어 plus exactly one other language (e.g. Korean + 日本語) and you get bidirectional interpreting mode:

  • Direction is detected per line. A line spoken in Japanese is translated only to Korean; a Korean line only to Japanese. No wasted translations, so it's faster.
  • Both sides transcribe correctly even when the two languages alternate. Madi re-checks the language every segment, so one person speaking Korean and another speaking Japanese are both transcribed accurately.
  • In this mode the response speed is not forced to slow down (see below).

Frequent-phrase dictionary (instant translation)

For settings that repeat the same guidance (e.g. after-care instructions in a clinic), you can pre-save the translation of your common phrases. When a saved phrase is spoken, its translation appears instantly (0 s), without going through the model.

A few phrases are included by default, and you can add or edit your own (stored at ~/Library/Application Support/Sovereign/faq_translations.json). For safety it only matches exact phrases.

Response speed & translation quality

Choosing two or more target languages (e.g. 日本語 + 中文 + English) locks the response speed to 정확 (10초) — Accurate (10s), so an error in the original line boundary doesn't propagate into every translation.

Exception: in bidirectional interpreting mode (한국어 + one other language), each line has only a single real target, so it is not locked to 10 s — captions appear faster in face-to-face interpreting.

When translation falls behind, "N줄 번역 대기" (N lines waiting to translate) appears at the top. It means the work is queued, not stuck (the model translates one line at a time).

Caption overlay (자막 오버레이)

The 자막 오버레이 (caption overlay) is a floating, always-on-top live-translation caption window. Place it over a Zoom/Teams call, or on a clinic display, to follow the other side's speech in real-time translation.

  • Toggle it with the 자막 오버레이 button in the side panel.
  • The window stays on top but never takes focus, so your clicks and typing keep going to the call app.
  • It floats even over fullscreen apps, and you can drag it anywhere by its background.
  • The large text is the translation; the small text below is the original.
  • With more than one speaker, the caption shows a speaker color dot and name so you know who said it.
  • While waiting for speech, a mic level bar moves to confirm the system is listening.
  • The status text ("in-progress / translating… / waiting for speech") is shown in the viewer's own language — 「翻訳中…」 for a Japanese caption, 「翻译中…」 for a Chinese one.

Staff caption + patient caption (dual screen)

For face-to-face clinic interpreting you can split the caption into two panels.

  • Staff caption — small, on the main screen, in the staff's language (first translate target).
  • Patient caption — large (for distance reading), on an external monitor, in the patient's language.

Turn it on in 설정 → 자막 오버레이(진료실) (Settings → Caption overlay (Clinic)). You can set staff font (14–48pt), patient font (24–96pt), panel width, patient screen, and patient language separately — large type for a 1.5–2.5 m viewing distance between the chair and the display.

Chat view

When exactly two people are talking, you can view the transcript like a messenger, left and right. The first speaker sits on the left, the other on the right — good for reading back-and-forth interpreting. The chat-view button appears in the control bar when two speakers are detected.

Performance note — it depends on your memory

Live translation and the meeting-summary model share the same LLM, so behavior depends on how much memory your Mac has.

  • 16 GB+ Macs: live translation and features like 라이브 액션 추출 (live action extraction) run together. Translation captions never stall.
  • Under-16 GB Macs: only one model fits in memory at a time. Turning on a feature like 라이브 액션 추출 pauses live translation while it runs.

If you want uninterrupted translation captions on an under-16 GB Mac, leave extra features like live action extraction off.

Meeting Intelligence

Madi's meeting intelligence turns a raw transcript into an organized meeting asset. Summaries, action items, Q&A, live coaching, and follow-up tracking are all produced by the local LLM (DNA3.0-4B) running on this Mac. Your transcript and summaries never leave the device.

Different features have different requirements. Some need the summary model (LLM) installed; some need 16 GB or more of memory. Each section notes which.
The app interface is in Korean. Korean UI labels are shown below with an English gloss in parentheses.

A.I 요약 (AI Summary)

Turns the transcript into a structured summary plus action items and decisions.

  1. Press 요약 (Summarize) at the top of the transcript (the sparkles button).
  2. The local LLM opens the 회의 요약 (Meeting summary) sheet and generates the summary. A note reads "전사 내용은 이 Mac을 떠나지 않습니다" (Your transcript never leaves this Mac).
  3. Use the 전체 / 화자별 (Whole / By speaker) toggle at the top of the sheet to switch views.
    • 전체 (Whole) — Summary, actions, and decisions for the entire meeting
    • 화자별 (By speaker) — What each speaker said, broken down per person (generated on the spot the first time you pick it)

Buttons at the bottom of the summary sheet:

  • 복사 (Copy) — Copies the summary text to the clipboard
  • 다시 생성 (Regenerate) — Generates a fresh summary from the same transcript
  • 슬라이드(HTML) (Slides — HTML) — Exports an offline HTML slide deck and reveals it in Finder
  • 리캡 카드 (Recap card) — Opens a shareable summary card (see "Recap card" below)
  • 내보내기… (Export…) — Saves the summary as a .md file

Requirements

  • The summary model (LLM) must be installed. If it isn't, the 요약 (Summarize) button does not appear.

A.I 요약 as a separate file

Saves the summary as a separate file alongside the transcript when a session finishes.

  1. In the right side panel, turn on the A.I 요약 (AI Summary) checkbox.
  2. When the meeting finishes, a …요약.md file is saved next to the transcript (e.g. 회의록.md → 회의록 요약.md).

Requirements

  • The summary model (LLM) is required.
  • Transcript auto-save must be on.

회의록에 물어보기 (Ask your meeting — Q&A)

Ask about the meeting in plain language, and the local LLM answers from the transcript. It lives at the bottom of the summary sheet.

  1. Type a question in the 회의록에 물어보기 (Ask your meeting) field. For example: "무엇을 결정했나요?" (What did we decide?), "김부장이 맡은 일은?" (What is Manager Kim responsible for?)
  2. Press the paper-plane button or hit Enter.
  3. Use the 이 회의 / 전체 워크스페이스 (This meeting / Entire workspace) toggle to set the scope.
    • 이 회의 (This meeting) — Answers from the currently open transcript only
    • 전체 워크스페이스 (Entire workspace) — Searches across all your saved meetings. For example: "지난달 보안 결정은?" (What were last month's security decisions?), "지난 분기 가격 결정 찾아줘" (Find last quarter's pricing decision)

Requirements

  • The summary model (LLM) is required.

라이브 액션 추출 (Live action extraction)

Pulls out decisions, to-dos, and questions in real time while you record, so the meeting is already organized the moment it ends. Extracted items stack up in the side 라이브 인텔리전스 (Live intelligence) area as [결정] (Decision) / [액션] (Action) / [질문] (Question) cards, each with an owner.

  1. Before you start recording, turn on the 라이브 액션 추출 (Live action extraction) checkbox in the side panel.
  2. Start recording, and the cards fill in live.

Requirements

  • 16 GB or more of memory is required. On machines with less, the toggle is disabled and shows "16GB 이상 메모리 필요" (16 GB or more of memory required).
  • It runs the summary model (DNA3) alongside transcription, so memory use is high.

Note

  • Live translation, which uses the same model, is paused while live action extraction is on.
  • You cannot turn it on or off once recording has started. Always set it before recording.

라이브 코치 (Live coach / teleprompter)

A side panel that helps you run the meeting while recording. It works on any Mac and needs no model.

  1. Turn on the 라이브 코치 (Live coach) checkbox in the side panel (off by default).
  2. While recording, the coach panel shows the following in real time.
    • Agenda checklist — Surfaces prior decisions and open action items as agenda items, and ticks them off (with a strikethrough) when the live transcript covers them. A "N / M 다룸" (N / M covered) progress count appears at the top.
    • 미답변 질문 (Unanswered questions) — Questions raised in the meeting that haven't been answered yet
    • 지금 흐름 (Current pace) — The meeting's momentum, estimated from recent speaking speed, overlap, and silence, shown as 가열 / 안정 / 저조 (Heating up / Steady / Quiet), with a small bar sparkline

Requirements

  • None — no model required, works on every Mac.

Note

  • The agenda is richer when a calendar event is detected (prior decisions and actions are gathered). If there's no prepared agenda, the panel says so.

열린 항목 (Open loops — follow-up tracking)

Aggregates every unresolved action item and open question across all your saved meetings in one place. Find it in the 열린 항목 (Open loops) tab of the workspace explorer (next to 파일 / Files and 사람 / People).

Each row shows:

  • Kind badge — [결정] (Decision) / [액션] (Action) / [질문] (Question)
  • Owner (for action items)
  • Source meeting name
  • Age — "12일째 후속 없음" (12 days with no follow-up) if unresolved, or "12일 경과" (12 days elapsed) if resolved
  • Follow-up — if a later meeting re-mentioned it, "5일 후 ○○회의에서 언급됨" (mentioned in meeting ○○ 5 days later)

Rows are split into two groups: 후속 필요 (Needs follow-up, oldest first) and 후속됨 (Followed up). Tapping a row opens the source transcript.

Requirements

  • An item is tracked only if [결정]/[액션]/[질문] were recorded in the meeting summary — that is, transcripts organized by the summary model.

회의 준비 브리핑 (Meeting prep brief)

Before a meeting (or when a calendar event is detected), it surfaces prior context for these attendees on a single page. It combines calendar + people + past-meeting search.

The brief includes:

  • 회의 참석자 (Attendees) — Each attendee's past-meeting history
  • 지난 결정 (Prior decisions) — Decisions made previously involving these attendees
  • 미해결 액션 (Open action items) — Action items that aren't finished yet
  • 관련 논의 (Related discussions) — A list of related past meetings

Use the 복사 (Copy) / 내보내기… (Export…) buttons at the bottom to save the brief to the clipboard or a .md file.

Note

  • The base brief (attendees, prior decisions, open items) is built from saved transcripts alone and needs no summary model.
  • Turning on the 워크스페이스에서 더 찾기 (Search the workspace for more) toggle has the local LLM search the entire workspace and add extra context under "관련 논의" (Related discussions). 제목 자동 생성 (Auto title) · 리캡 카드 (Recap card)

Auto title — In a live session with A.I 요약 (AI Summary) auto-save on, the local LLM names the meeting when it ends and renames the file to that title (so it matches the summary file's name). This only happens when you didn't type a file name yourself.

Recap card — A one-page summary card for the meeting. Open it with the 리캡 카드 (Recap card) button in the summary sheet. The shareable card includes:

  • Title and date
  • TL;DR (the key takeaways)
  • A list of decisions
  • Actions by owner
  • Talk time per speaker (bars)
  • A one-line quote

Use 복사 (Copy) to copy the one-page card as Markdown, or 내보내기… (Export…) to save the same content to a file.

Requirements

  • Both the auto title and the recap card's summary content require the summary model (LLM).

Privacy

All of this runs on this Mac. Your transcript, your summaries, and your Q&A answers never leave the device.

Inline editing

  1. Double-click the line you want to fix (or, in 상세 (Detailed) view, press the pencil button — tooltip 이 문장 편집 / "Edit this line").
  2. Double-clicking in 내용 (Content) view automatically flips to 상세 (Detailed) view and opens the edit field.

  4. Edited lines are marked 편집됨 (Edited).

  1. A count appears at the top: 검토 필요 N개 ("N to review").
  2. Use the 이전 (Previous — previous review word) / 다음 (Next — next review word) buttons to jump between the flagged words.
  3. Confirm each word and fix it on the spot if needed.

  1. Press the play button in the review bar (tooltip 저신뢰 단어 귀로 검토 / "Review low-confidence words by ear").
  2. The flagged words' audio plays in order, advancing to the next word automatically when one finishes (hands-free).

  • The 최소 확인 횟수 (minHits, "minimum confirmations") slider sets how many times a correction must be confirmed before Madi trusts it enough to auto-apply (1–5).

  • Forget a single rule with the trash button beside it (tooltip 이 교정을 잊기 / "Forget this correction").

System dictation (받아쓰기)

Dictation (받아쓰기) is Madi's system-wide voice-to-text. Hold a global hotkey anywhere in macOS, speak, then release — your speech is transcribed on-device and inserted into whatever app is frontmost (Notes, Mail, Slack, a code editor, and so on). It's 100% on-device: no cloud, no account.

How to use it

  1. In 설정 → 받아쓰기 (Settings → Dictation), turn on 어디서나 받아쓰기 사용 (Use dictation anywhere).
  2. The first time you enable it, macOS asks for 손쉬운 사용 (Accessibility) permission — see below.
  3. Put your cursor wherever you want the text — in any app.
  4. Hold Right-Option (오른쪽 ⌥) and speak (it records only while held).
  5. Release the key, and the transcribed text is inserted.

Default hotkey: Right-Option

The default hotkey is the Right-Option key. It's push-to-talk — recording happens only while you hold it, and releasing completes the insert. Right-Option is the default because you almost never press it alone and it never collides with ⌘K (the command palette).

Your clipboard is preserved

When inserting text, Madi first saves your current clipboard, pastes the transcribed text, then immediately restores your original clipboard. So anything you'd copied is left intact.

Required permission — Accessibility

To paste text into other apps, dictation needs macOS 손쉬운 사용 (Accessibility) permission.

  1. Turn on dictation in 설정 → 받아쓰기 (Settings → Dictation).
  2. Check the status under 손쉬운 사용 권한 (Accessibility permission):
    • 허용됨 (Granted): you're ready to go.
    • 권한 필요 (Permission needed): click 시스템 설정에서 허용 (Allow in System Settings).
  3. That button opens System Settings → Privacy & Security → Accessibility. Allow Madi there.
  4. When you return to this window, the status updates to 허용됨 (Granted) automatically.

Without this permission dictation won't work — but it won't fail silently. Madi tells you with "손쉬운 사용 권한이 필요합니다" (Accessibility permission is required).

Disabled while a meeting is recording

While a meeting is being recorded, the dictation hotkey is turned off. Dictation and meeting recording share the same physical microphone, so this guards against a conflict. If you press Right-Option during recording you'll see a brief notice — "회의 녹음 중에는 받아쓰기를 사용할 수 없습니다" (Dictation isn't available while a meeting is recording) — and it works again once you stop recording.

Fast, lightweight dictation

Dictation inserts your words as-is, with no rewriting. It does not keep a large LLM in memory: it runs a short, dictation-only speech recognizer and shuts it down when done. So it stays light and fast even on Macs with little memory, and even when the meeting summary/translation model isn't loaded.

The dictation language follows the language setting you chose for meeting recording (Korean by default). Auto-detect can misfire on short clips, so unless you picked auto, dictation is locked to your chosen language.

Settings reference (설정 → 받아쓰기)

  • 어디서나 받아쓰기 사용 (Use dictation anywhere) — turn dictation on/off.
  • 단축키 (Hotkey) — shows the default (Right-Option, hold to record).
  • 손쉬운 사용 권한 (Accessibility permission) — current status plus the 시스템 설정에서 허용 (Allow in System Settings) button.
  • 상태 (Status) — the current dictation state (idle / listening / transcribing / inserting).

음성 인식 (Speech recognition)

  • 저신뢰 표시 기준 (VAD) (Low-confidence threshold) — words recognized below this confidence (default 0.55) are flagged as "needs review".

편집 기능 (Editing features)

  • 편집 기능 사용 (Enable editing features) — turns on filler/silence tighten, chapters, retakes, and highlight analysis. Off by default — turn it on only when needed. (When off, the sections below are disabled.)

필러 · 무음 (타이튼) (Fillers · Silence — Tighten)

  • 필러 컷 (Filler cut) — detects filler words ("um…", "uh…").
  • 무음 컷 (Silence cut) — detects long silent gaps.
  • 무음 최소초 (Min silence seconds) — the minimum length to count as silence.

챕터 (Chapters)

  • 자동 챕터 (Auto chapters) — splits the conversation into chapters automatically.
  • 휴지 경계초 / 최소 간격초 (Pause boundary / Min gap seconds) — tune the pause length that triggers a chapter break and the minimum chapter spacing.

리테이크 · 하이라이트 (Retakes · Highlights)

  • 리테이크 감지 (Retake detection) — finds "second take" passages where something was re-said. The 유사도 (Similarity) slider tunes sensitivity.
  • 하이라이트 (Highlights) — emphasizes important passages. 최소 신뢰도 (Min confidence) sets the bar.

번역 (Translation)

Where you turn on-device translation (Korean, Chinese, Japanese, English) on and off.

번역 모델 (DNA3.0-4B · ~2.6 GB) (Translation model)

  • 상태 (Status) — shows Installed / download progress / Not installed.
  • 번역 모델 다운로드 (Download translation model) — fetches the model. It is not bundled with the app and is downloaded when you enable it (~3 GB extra memory). Once installed, Finder에서 보기 (Reveal in Finder) opens the file location.

실시간 번역 (다중 대상) (Live translation — multi-target)

  • 한국어 (Korean) / English / 日本語 (Japanese) / 中文 (Chinese) — toggle the target languages. Each line is translated into every selected language simultaneously and shown under the original (the source language is excluded automatically).
  • The model must be downloaded first. With two or more targets, recording responsiveness is pinned to 정확 (Accurate, 10s) — see the Recording tab.

단어장 (Personal Vocabulary)

Madi learns the corrections you make to frequently-misheard domain terms and names, then fixes similar mis-recognitions automatically in later meetings.

개인 단어장 (Personal vocabulary)

  • 학습한 교정 자동 적용 (Auto-apply learned corrections) — the switch that decides whether learned corrections are actually applied. Learning always runs; this switch only enables "apply". (Off by default — turn it on yourself.)

적용 기준 (Application threshold)

  • 최소 확인 횟수 (Minimum confirmations) — a correction must be confirmed at least this many times (1–5) before it auto-applies. Higher is more conservative, so a single accidental edit won't overwrite later transcripts.

Learned corrections list

  • Shows each learned rule (wrong word → right word, with a hit count). Use the trash button on a row to "잊기 (Forget)" a single rule, or 전체 지우기 (Clear all) to empty the list.

모델 (Models)

Check and manage the status of the speech and language models.

  • 상태 / 위치 (Status / Location) — whether the model is installed and its file path.
  • 모델 재다운로드 (Re-download model) — fetches the model again.
  • Finder에서 보기 (Reveal in Finder) — opens the model file location.

You can also download the translation model (DNA3.0-4B) from the 번역 (Translation) tab.

받아쓰기 (Dictation)

System-wide push-to-talk dictation settings that work in any app. For full usage, see the 받아쓰기 / Dictation manual page.

시스템 받아쓰기 (System dictation)

  • 어디서나 받아쓰기 사용 (Enable dictation everywhere) — hold the right ⌥ (Option) key while you speak, then release, and the dictated text lands in the frontmost input field of any app. All processing happens on-device.

단축키 (Hotkey)

  • 누르고 있는 동안 녹음 (Hold to record) — the default is the right ⌥ Option key (chosen so it doesn't clash with the command palette, ⌘K).

손쉬운 사용 권한 (Accessibility permission)

  • 상태 (Status) — shows whether Accessibility (손쉬운 사용) permission is granted.
  • 시스템 설정에서 허용 (Grant in System Settings) — if it isn't granted, this button opens System Settings. The permission is required to insert text into other apps; once granted, returning to this window recognizes it automatically.

상태 (Status)

  • 현재 (Current) — shows dictation's current state (idle / listening / transcribing / inserting, etc.).
