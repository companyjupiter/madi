01

시작하기

Madi(마디)에 오신 것을 환영합니다. Madi는 회의를 전부 이 Mac 안에서 받아쓰고 옮기는 앱입니다. 실시간 받아쓰기, 오디오·영상 파일 전사, 화자 분리, 온디바이스 번역까지 — 모든 처리가 여러분의 Mac 안에서 일어납니다.

Madi가 하는 일

  • 실시간 전사 — 마이크나 회의 음성을 들으며 말이 끝나기 무섭게 텍스트가 나타납니다.
  • 파일·영상 전사 — 녹음 파일이나 영상을 끌어다 놓으면 전체 대화를 받아씁니다.
  • 화자 분리 — 누가 언제 말했는지 구분하고, 이름을 붙일 수 있습니다.
  • 온디바이스 번역·통역 — 한국어·English·日本語·中文을 실시간으로 옮기고, 화면 위 자막으로 띄웁니다.
  • AI 요약·질의응답 — 회의가 끝나면 요약·결정·액션을 정리하고, 회의 내용에 대해 자연어로 질문할 수 있습니다.
  • 검토와 교정 — 잘못 들은 단어를 찾아 고치고, 고친 내용을 기억해 다음 회의에 적용합니다.
  • 시스템 받아쓰기 (추후 제공) — 어느 앱에서나 단축키를 누르고 말하면 그 자리에 글로 들어가는 기능을 준비 중입니다.

100% 온디바이스 — 내 데이터는 Mac을 떠나지 않습니다

Madi의 핵심 약속은 주권(sovereign) 입니다. 음성도, 전사문도, 번역도 클라우드로 전송되지 않습니다. 모델을 받아 둔 뒤에는 인터넷이 끊겨 있어도 동작합니다. 회의 내용은 오로지 여러분의 기기 안에만 존재합니다.

모델 안내

Madi는 두 종류의 AI 모델을 씁니다.

  • Whisper 음성 모델 (약 867 MB) — 받아쓰기를 담당합니다. 표준 DMG에서는 첫 실행에 한 번 받습니다.
  • DNA3.0 언어 모델 — 번역, AI 교정, 요약·질의응답에 쓰입니다. 8GB Mac은 2B(약 1.31 GB), 16GB 이상은 품질 우선 4B(약 2.78 GB)를 자동 선택하며 처음 쓸 때 다운로드합니다.
    • 받는 곳: 설정(⌘,) → 번역의 “번역 모델 다운로드” 버튼.
    • 선택된 모델만 받으며 디스크 공간도 그만큼 필요합니다.

번역·요약·질의응답을 쓰지 않는다면 이 모델은 받지 않아도 됩니다. 전사와 화자 분리는 동봉된 Whisper만으로 완전히 동작합니다.

메모리 안내 (솔직하게)

  • 8 GB Mac (예: M1 MacBook Air) — DNA3.0-2B와 4턴 번역 대기열을 자동 적용합니다. 번역 엔진의 실측 물리 메모리는 약 2.4 GB입니다.
  • 16 GB 이상 — 번역 품질을 우선해 DNA3.0-4B를 사용합니다(실측 약 5.1 GB).
  • 실시간 프리뷰는 확정 전사와 같은 Whisper 프로세스를 공유하므로 두 번째 830 MB 모델을 띄우지 않습니다.

Madi가 요청할 수 있는 권한

권한은 미리 한꺼번에 묻지 않고, 그 기능을 처음 쓸 때 필요한 것만 요청합니다.

  • 마이크 — 녹음할 때. 녹음을 처음 시작할 때 요청합니다.
  • 화면 기록 — 시스템 오디오(Mac에서 재생되는 소리, 예: Zoom·Teams·YouTube)를 녹음할 때만. macOS가 오디오 캡처를 화면 기록 권한으로 묶어두기 때문이며, 화면은 저장하지 않습니다.

    • (손쉬운 사용(Accessibility) 권한은 시스템 받아쓰기(추후 제공)에만 필요하며, 현재 베타에서는 요청하지 않습니다.)

권한을 거부했다가 나중에 켜고 싶으면 시스템 설정 → 개인정보 보호 및 보안에서 해당 항목(마이크 / 화면 기록)을 찾아 Madi를 켜면 됩니다.

처음 실행 빠른 시작

  1. Madi를 엽니다. 첫 화면에 회의 정보와 시작하기 두 칸이 보입니다.
  2. 회의 정보에서 이번 회의에 맞게 골라 둡니다 — 입력 언어, (번역을 쓴다면) 출력 언어, 회의 모드, 화자 수.
  3. 시작하기에서 마이크를 고르고 지금 녹음 시작을 누르거나, 오디오·영상 파일을 끌어다 놓습니다.
  4. 화면 가운데에 실시간 전사문이 나타나는 것을 지켜봅니다.
  5. 정지를 누르면 거기까지의 기록이 정리됩니다. 자동저장이 켜져 있으면 파일로 저장됩니다.
번역을 쓰려면 먼저 설정(⌘,) → 번역에서 Mac 메모리에 맞게 선택된 번역 모델을 받아야 합니다. 8GB Mac에서는 전용 가이드가 최초 한 번 자동으로 열립니다.

창 구조

녹음이 시작되면 창은 세 칸으로 나뉩니다.

  • 왼쪽 — 세션 패널: 녹음 버튼(일시 정지·정지), 총 시간, 화자 막대, 에너지 흐름 그래프. 설정(톱니)도 여기 있습니다.
  • 가운데 — 전사문: 받아쓴 내용. 여기서 읽고 고칩니다.
  • 오른쪽 — 작업 폴더 탐색기: 지난 회의 목록, 자동저장 스위치, 저장 폴더, 내보내기.

단축키

단축키하는 일
⌘,설정 열기
⌘K명령 팔레트 (아래 참고)

명령 팔레트 (⌘K)

⌘K를 누르면 검색창이 뜹니다. 메뉴를 뒤지지 않고 이름으로 바로 실행합니다. (View 메뉴의 명령 팔레트로도 열 수 있습니다.)

  • 요약 생성 / 화자별 요약 — 회의 요약 시트 열기 (전사문이 있을 때).
  • 새 세션 — 현재 전사를 비웁니다.
  • 작업 폴더 변경 — 저장 위치를 고릅니다.
  • 화자 이름 — 이 회의의 화자로 바로 이동합니다.
  • 지난 회의 이름 — 저장된 회의록을 열어 줍니다.

도움말 메뉴

  • Madi 사용자 매뉴얼 (⌘?) — 이 문서를 엽니다. 인터넷 없이 열립니다.
  • 업데이트 설치… — 새 버전이 있는지 확인하고 설치합니다.
  • 정보 — 버전과 라이선스를 보여 줍니다.

준비 완료입니다. 더 자세한 내용은 녹음, 화자, 번역, 받아쓰기, 설정 등 다른 페이지를 참고하세요.

02

녹음과 전사

Madi는 회의 음성을 실시간으로 받아 적고, 이미 녹음된 오디오·영상 파일도 전사합니다. 모든 처리는 이 Mac 안에서만 이루어지며, 전사 내용은 기기를 떠나지 않습니다.

첫 화면 — 회의 정보와 시작하기

앱을 열면 첫 화면이 두 칸으로 나뉩니다. 왼쪽에서 이번 회의가 어떤 회의인지 알려 주고, 오른쪽에서 시작합니다.

회의 정보 (왼쪽)

녹음을 시작하기 전에 골라 두면 결과 품질이 좋아집니다. 녹음 중에는 잠깁니다.

  • 입력 언어 — 말하는 언어. 자동 감지 또는 특정 언어로 고정합니다.
  • 출력 언어 — 번역해서 보여 줄 언어(여러 개 선택 가능). 번역 모델이 있어야 쓸 수 있습니다. (실시간 번역·통역 참고.)
  • 회의 모드 — 회의의 성격. 아래 참고.
  • 화자 — 방 안의 인원수. 아래 참고.

시작하기 (오른쪽)

  • 파일로 시작하기 — 파일을 고르거나 끌어다 놓은 뒤 누릅니다.
  • 지금 녹음 시작 — 마이크를 골라 바로 녹음합니다.

실시간 마이크 녹음

  1. 시작하기 칸에서 마이크를 고릅니다(기본은 “시스템 기본”).
  2. 지금 녹음 시작을 누릅니다. 짧은 카운트다운이 지나면 녹음이 시작됩니다. 이때 취소할 수 있습니다.
  3. 말하기 시작하면 가운데에 전사가 실시간으로 흘러나옵니다.
  4. 왼쪽 패널의 일시 정지(⌘P)로 잠시 멈추고, 정지(⌘R)로 끝냅니다.

참고

  • 정지하면 거기까지의 기록이 정리됩니다. 자동저장이 켜져 있으면 파일로 저장됩니다.
  • 자동저장이 꺼져 있으면 나가기 전에 안내가 뜹니다 — 내보내기로 먼저 저장할 수 있습니다.

에너지 흐름

왼쪽 패널 아래의 에너지 흐름 그래프가 회의의 분위기를 한 줄로 보여 줍니다 — 발언 속도·겹침·침묵을 종합한 흐름입니다.

  • 그래프의 한 지점을 클릭하면 그 구간으로 이동합니다. 회의에서 가장 뜨거웠던 대목을 바로 찾아갈 때 좋습니다.
  • 발언이 쌓이기 전에는 “발언이 쌓이면 흐름이 표시됩니다”라고 안내합니다.

녹음 중 마이크 바꾸기

실시간 녹음 중에는 왼쪽 패널의 입력 마이크 줄에서 마이크를 녹음을 끊지 않고 바꿀 수 있습니다. 회의 도중 헤드셋을 연결했을 때 유용합니다.

말을 멈추면 자막이 바로 뜹니다

한 구간(윈도)이 다 차기를 기다리지 않고, 말을 멈추고 잠깐 조용해지면 Madi가 그 구간을 앞당겨 마감해 전사를 바로 내보냅니다. 짧게 주고받는 대화(예: 진료 상담)에서 대기 시간이 크게 줄어듭니다. 멀리서 들어오는 작은 목소리는 잘리지 않도록 자동으로 기준을 맞춥니다.

시스템 오디오 캡처 (Zoom·Teams·영상)

Mac에서 재생되는 소리(온라인 회의, 영상 등)를 그대로 전사할 수 있습니다.

  1. 설정(⌘,) → 녹음 → 입력으로 갑니다.
  2. 음원에서 입력 방식을 고릅니다.
    • 마이크 — 내 앞의 소리만
    • 시스템 오디오 — Zoom·Teams·Slack·YouTube 등 Mac에서 재생되는 소리
    • 마이크+시스템 — 온라인 회의용. 내 목소리와 상대 목소리를 함께
  3. 평소처럼 녹음을 시작합니다.

참고

  • 시스템 오디오를 처음 쓸 때 macOS가 ‘화면 기록’ 권한을 요청합니다. 오디오만 사용하며 화면은 저장하지 않습니다.

파일과 영상 전사

이미 가지고 있는 오디오 또는 영상 파일을 전사합니다.

  1. 파일을 창에 끌어다 놓거나, 파일 선택 or 드래그 앤 드롭 영역을 눌러 고릅니다. 드래그 중에는 드롭하여 전사가 표시됩니다.
  2. 파일로 시작하기를 누릅니다.
  3. 진행률이 전사 중 · N% 로 표시됩니다.
  4. 전사가 끝나면 결과가 화면에 나타납니다.

참고

  • 파일을 놓기만 해서는 전사가 시작되지 않습니다. 파일로 시작하기를 눌러야 시작합니다. 그 사이에 회의 정보를 고쳐도 됩니다.
  • 영상(mp4·mov·m4v·mkv·webm·avi 등)의 음성은 자동으로 추출됩니다. 별도 변환이 필요 없습니다.
  • 파일 전사에서만 쓸 수 있는 기능이 있습니다 — 줄별 오디오 재생과 귀로 검토. (검토와 교정, 작업 폴더와 내보내기 참고.)

회의 모드

회의의 성격에 맞춰 화자 수와 강조 항목을 한 번에 맞춰 주는 프리셋입니다. 첫 화면 회의 정보 → 회의 모드에서 고릅니다.

참고

  • 회의 모드는 녹음을 시작하기 전에 골라야 합니다. 녹음 중에는 잠깁니다.

화자 수

방 안의 인원수를 알고 있다면 미리 지정해 화자 분리 정확도를 높일 수 있습니다. 첫 화면 회의 정보 → 화자에서 자동 / 1명 / 2명 / 3명 / 4명 이상 중 고릅니다.

인원수가 분명할 때 고정하면 화자가 더 정확하게 나뉩니다. 확실하지 않다면 자동을 두세요. 자세한 내용은 화자 페이지를 참고하세요.

전사 보기 전환

화면 상단의 토글로 두 가지 보기를 오갑니다.

  • 내용 — 깨끗한 회의록 읽기 보기 (기본값). 읽기에 집중할 때 좋습니다.
  • 상세 — 시각(타임코드), 신뢰도가 낮은 단어(호박색 강조), 발언 겹침 표시까지 보여 줍니다. 검토·수정할 때 좋습니다.

글자 크기는 상단의 A− / A+ 버튼으로 조절합니다.

개인정보

Madi의 모든 전사는 이 Mac 안에서만 처리됩니다. 전사 내용은 절대 기기를 떠나지 않습니다.

03

화자

Madi는 회의에서 누가 말했는지를 자동으로 구분합니다. 이 모든 처리는 이 Mac 안에서만 이루어집니다.

자동 화자 분리

녹음·전사가 진행되는 동안 Madi는 발언을 화자별로 자동으로 나눕니다.

  • 각 화자에게 고유한 색과 화자 N 라벨이 붙습니다.
  • 왼쪽 패널의 화자 막대가 회의 흐름에서 누가 언제 말했는지를 한 줄로 보여 줍니다.

참고

  • 화자 분리는 설정(⌘,) → 녹음 → 화자의 화자 분리 스위치로 끌 수 있습니다.

화자 수 고정

방 안의 인원수를 알고 있다면 미리 지정해 정확도를 높일 수 있습니다.

  1. 첫 화면 회의 정보 → 화자에서 고릅니다.
  2. 자동 / 1명 / 2명 / 3명 / 4명 이상 중에서 선택합니다.

참고

  • 인원수가 분명할 때 고정하면 화자가 더 정확하게 나뉩니다. 확실하지 않다면 자동을 두세요.
  • 녹음을 시작하기 전에 골라야 합니다. 녹음 중에는 잠깁니다.

미확인 화자

화자 수를 고정했을 때, 고른 인원 중 누구와도 뚜렷하게 다른 목소리가 들어오면 Madi는 그 발언을 미확인으로 따로 모읍니다. 지나가는 사람의 한마디나 갑자기 섞인 잡음이 정해 둔 화자 중 한 명으로 잘못 붙는 것을 막아 줍니다.

  • 미확인은 사람이 아니라 “여기 넣을 곳이 없다”는 표시입니다. 이름을 붙일 수 없습니다.
  • 자동(화자 수 미고정)에서는 나타나지 않습니다.

화자 이름 지정

  1. 전사에서 화자 이름(예: 화자 1)이나 화자 칩을 클릭합니다.
  2. 이름 (예: 김부장) 입력란에 실제 이름을 입력합니다.
  3. 저장을 누릅니다. 입력한 이름이 그 화자의 모든 발언과 내보내기에 적용됩니다.

참고

  • 이름은 지금 이 회의록에만 적용됩니다. 다음 회의에서 같은 사람을 자동으로 알아보지는 않습니다 — 회의마다 다시 지정해야 합니다.
  • 미확인에는 이름을 붙일 수 없습니다.

AI 화자 교정 (녹음이 끝난 뒤)

녹음이 끝나면 온디바이스 LLM이 대화를 읽고 명백한 화자 오분리를 보수적으로 바로잡습니다. 한 사람의 말이 두 화자로 쪼개졌거나 한 줄이 엉뚱한 화자에게 붙은 경우를 정리합니다.

  • 설정(⌘,) → 번역 → AI 교정 (세션 종료 후) 의 화자·언어 자동 교정으로 켜고 끕니다.
  • 교정이 적용되면 전사문 위에 안내가 뜨고, 화자 교정 되돌리기 버튼으로 한 번에 되돌릴 수 있습니다.
  • 하드웨어에 맞게 선택된 DNA3.0 번역 모델이 있어야 씁니다.

발언 겹침 표시

두 사람이 동시에 말하면 상세 보기에 ⟨+이름 겹침⟩ 표시가 나타나, 그 구간에 끼어든 두 번째 화자를 알려 줍니다.

참고

  • 겹침 표시는 상세 보기에서만 나타납니다. 화면 상단에서 내용 → 상세로 전환하세요.
  • 설정(⌘,) → 녹음 → 화자의 중첩 발화 감지가 켜져 있어야 합니다.
04

실시간 번역·통역

Madi의 번역은 100% 기기 안에서 동작합니다. 클라우드도, 계정도 필요 없습니다. 회의가 진행되는 동안 각 발화를 한국어·영어·일본어·중국어로 즉시 옮겨 원문 아래에 함께 보여 줍니다. 8GB Mac은 DNA3.0-2B, 16GB 이상은 DNA3.0-4B를 자동으로 사용합니다.

먼저: 번역 모델 받기

번역은 별도 모델이 필요하며 앱에 동봉되어 있지 않습니다. 8GB Mac은 DNA3.0-2B(약 1.31 GB), 16GB 이상은 DNA3.0-4B(약 2.78 GB)를 켤 때 한 번 내려받습니다.

  1. 설정(⌘,) → 번역 탭을 엽니다.
  2. 번역 모델 다운로드 버튼을 누릅니다.
  3. 다운로드가 끝나면 번역 항목이 활성화됩니다.

엔진 프로세스의 실측 물리 메모리는 2B 약 2.4 GB, 4B 약 5.1 GB입니다. 모델을 받기 전에는 번역 토글이 비활성 상태이고 “번역 모델을 먼저 다운로드하세요.”라는 안내가 표시됩니다.

번역 탭이 안 보인다면 — 번역 엔진이 포함되지 않은 빌드입니다. 이 경우 번역 기능 자체를 쓸 수 없습니다.

번역할 언어 고르기 (출력 언어)

두 곳 중 편한 곳에서 고릅니다. 같은 설정입니다.

  • 첫 화면 → 회의 정보 → 출력 언어 — 회의를 시작하며 바로.
  • 설정(⌘,) → 번역 → 실시간 번역 (다중 대상) — 한국어 / English / 日本語 / 中文 토글.

선택한 모든 언어로 각 줄을 한꺼번에 번역해 원문 바로 아래에 표시하며, 각 번역에는 언어 태그가 붙습니다. 원문과 같은 언어는 자동으로 제외됩니다.

참고

  • 출력 언어는 최대 3개까지 고를 수 있습니다.
  • 번역 모델이 없으면 출력 언어를 고를 수 없습니다.

번역이 타이핑되듯 나타납니다

번역이 다 만들어질 때까지 기다리지 않습니다. Madi는 단어가 생성되는 대로 화면에 바로바로 채워 넣습니다. 아직 쓰는 중인 줄 끝에는 커서 ▍ 가 깜빡여, 잘린 문장이 아니라 계속 이어지는 중임을 알려 줍니다.

말하는 도중에도 임시 번역이 먼저 뜨고 진행 중 으로 표시됩니다. 그 줄이 확정되면 임시 번역이 정식 번역으로 자연스럽게 바뀌며, 확정 번역이 도착할 때까지 임시 번역이 화면에 그대로 남아 있어 “번역이 잠깐 사라지는” 공백이 없습니다.

대면 통역 — 양방향 언어

Madi는 서로 다른 언어를 쓰는 두 사람의 대면 대화(예: 한국인 직원과 일본인·중국인 손님)를 위해 설계되었습니다.

출력 언어로 한국어와 다른 언어 하나만 켜면 (예: 한국어 + 일본어) 양방향 통역 모드가 됩니다.

  • 줄마다 방향을 자동으로 판별합니다. 일본어로 말한 줄은 한국어로만, 한국어로 말한 줄은 일본어로만 번역합니다. 불필요한 번역이 없어 더 빠릅니다.
  • 두 언어를 번갈아 말해도 양쪽 전사가 모두 정확합니다. 세그먼트마다 어느 언어인지 다시 확인하기 때문에, 한 사람은 한국어·다른 사람은 일본어로 대화해도 각자의 말이 제대로 받아쓰기됩니다.
  • 이 조합에서는 반응 속도가 자동으로 느려지지 않습니다(아래 참고).

자주 쓰는 문구 사전 (즉시 번역)

같은 안내를 반복하는 현장(예: 진료실의 시술 후 주의사항)을 위해, 자주 쓰는 문구의 번역을 미리 저장해 둘 수 있습니다. 저장된 문구와 같은 말이 나오면 모델을 거치지 않고 즉시(0초) 번역이 표시됩니다.

기본으로 몇 가지 문구가 들어 있으며, 직접 문구를 추가·수정할 수 있습니다.

  • 저장 위치: ~/Library/Application Support/Sovereign/faq_translations.json
  • 안전을 위해 정확히 일치하는 문구에서만 동작합니다.

반응 속도와 번역 품질

출력 언어를 2개 이상 고르면 원문 줄 경계 오류가 여러 언어로 번지므로, 반응 속도가 최소 보통(7초) 으로 내려앉습니다. 빠름(5초) 을 골라 두었더라도 자동으로 7초가 됩니다. 정확(10초) 은 그대로 쓸 수 있습니다.

예외: 한국어 + 다른 언어 하나만 켠 양방향 통역 모드에서는 줄마다 실제 번역 대상이 한 개로 줄어들기 때문에 강제하지 않습니다. 대면 통역에서 자막이 더 빨리 뜹니다.

번역이 밀릴 때는 “번역 중 · N줄 대기” 가 표시됩니다. 멈춘 것이 아닙니다. 확정된 전사 줄을 임시 프리뷰보다 먼저 처리하고, 같은 줄의 오래된 요청은 최신 문장으로 합칩니다. 8GB 프로필은 실시간 대기를 4턴으로 제한하며 밀린 확정 줄은 녹음 종료 후 채웁니다.

AI 언어 교정 (녹음이 끝난 뒤)

녹음이 끝나면 온디바이스 LLM이 대화를 읽고 잘못된 언어로 받아쓴 줄을 보수적으로 바로잡습니다. 설정(⌘,) → 번역 → AI 교정 (세션 종료 후) 의 화자·언어 자동 교정으로 켜고 끕니다. (화자 참고.)

자막 오버레이

자막 오버레이 는 화면 맨 위에 떠 있는 실시간 번역 자막 창입니다. Zoom·Teams 같은 통화 화면 위에, 또는 진료실 디스플레이에 올려 두고 상대의 말을 실시간 번역으로 따라갈 수 있습니다.

상단 도구 막대의 말풍선 아이콘으로 켜고 끕니다. 출력 언어를 하나 이상 골랐을 때만 이 버튼이 나타납니다.

  • 창은 항상 맨 앞에 머물지만 포커스를 빼앗지 않으므로, 통화 앱에서 계속 클릭·입력할 수 있습니다.
  • 전체 화면 위에서도 떠 있고, 배경을 잡아 원하는 위치로 끌어다 놓을 수 있습니다.
  • 가장 큰 글씨는 번역문, 그 아래 작은 글씨는 원문입니다.
  • 여러 명이 있을 때는 자막에도 화자 색과 이름 이 붙어 누구 말인지 알 수 있습니다.
  • 말을 기다리는 동안 마이크 입력 막대 가 움직여, 시스템이 듣고 있음을 확인시켜 줍니다.
  • 상태 문구(“진행 중 / 번역 중… / 음성을 기다리는 중…”)는 보는 사람의 언어로 표시됩니다 — 일본어 자막이면 「翻訳中…」, 중국어 자막이면 「翻译中…」.

직원 자막 + 환자 자막 (이중 화면)

진료실 대면 통역을 위해 자막을 두 개 로 나눌 수 있습니다.

  • 직원 자막 — 주 화면에 작게. 직원이 보는 언어.
  • 환자 자막 — 외장 모니터에 크게(원거리 판독용). 환자 언어로 표시.

설정(⌘,) → 녹음 → 자막 오버레이 (진료실) 에서 켭니다. 직원 글씨(14–48pt)·환자 글씨(24–96pt)·환자 화면·환자 언어를 각각 지정할 수 있습니다. 진료 의자와 디스플레이 사이 1.5–2.5 m 거리에서 읽기 좋게 큰 글씨를 씁니다.

05

AI 요약과 질의응답

전사가 끝나면 온디바이스 LLM이 회의록을 구조화된 요약으로 정리하고, 회의 내용에 대해 자연어로 질문할 수 있습니다. 요약과 질의응답은 번역과 같은 하드웨어 맞춤 모델(8GB는 DNA3.0-2B, 16GB 이상은 4B)을 쓰며, 전사 내용도 요약도 이 Mac을 떠나지 않습니다.

먼저: 번역·요약 모델

요약과 질의응답은 번역과 같은 온디바이스 모델을 씁니다. 모델이 없으면 요약 버튼이 나타나지 않습니다. 받는 법은 실시간 번역·통역 또는 설정 페이지를 참고하세요.

회의 요약 만들기

  1. 전사가 끝난 뒤(녹음 중에는 안 됩니다), 상단 도구 막대의 ✦(반짝이) 버튼을 누릅니다. 또는 ⌘K 명령 팔레트에서 요약 생성을 고릅니다.
  2. 회의 요약 시트가 열리고 로컬 LLM이 요약을 생성합니다. "전사 내용은 이 Mac을 떠나지 않습니다"라는 안내가 함께 표시됩니다.
  3. 시트 위쪽의 전체 / 화자별 토글로 보기를 바꿉니다.
    • 전체 — 회의 전체의 요약·액션·결정
    • 화자별 — 화자마다 무슨 이야기를 했는지 정리 (처음 선택하면 그 자리에서 생성합니다)

참고

  • ✦ 버튼은 전사문이 있고 녹음 중이 아닐 때만 활성화됩니다. 전사가 비어 있으면 흐려집니다.

요약 시트의 버튼

  • 복사 — 요약 텍스트를 클립보드로 복사
  • 다시 생성 — 같은 회의록으로 요약을 새로 생성
  • 슬라이드(HTML) — 오프라인에서 열리는 HTML 슬라이드 덱으로 내보내고 Finder에서 보여 줍니다
  • 리캡 카드 — 공유용 한 장 요약 카드를 엽니다 (아래 참고)
  • 내보내기… — 요약을 .md 파일로 저장

리캡 카드

회의 한 장 요약 카드입니다. 요약 시트의 리캡 카드 버튼으로 엽니다. 다음이 담긴 공유용 카드입니다.

  • 제목 + 날짜
  • TL;DR (핵심 요약)
  • 결정 목록
  • 담당자별 액션
  • 화자별 발화 시간
  • 한 줄 인용

복사로 카드를 Markdown으로 복사하거나, 내보내기…로 파일로 저장할 수 있습니다.

회의록에 물어보기 (질의응답)

회의 내용을 자연어로 질문하면, 로컬 LLM이 회의록을 근거로 답합니다. 요약 시트 아래쪽에 있습니다.

  1. 회의록에 물어보기 입력란에 질문을 입력합니다. 예: "무엇을 결정했나요?", "김부장이 맡은 일은?"
  2. 종이비행기 버튼을 누르거나 Enter를 칩니다.
  3. 이 회의 / 전체 워크스페이스 토글로 검색 범위를 정합니다.
    • 이 회의 — 지금 열려 있는 회의록에서만 답변
    • 전체 워크스페이스 — 저장된 모든 회의록을 가로질러 검색. 예: "지난달 보안 결정은?"

참고

  • 답하는 동안 "로컬 LLM이 답하는 중…"이 표시됩니다.

개인정보 보호

요약도, 질의응답도 이 Mac 안에서 동작합니다. 전사 내용도 요약도 이 기기를 떠나지 않습니다.

06

검토와 교정

전사가 끝나면 깔끔하게 읽거나, 자세히 들여다보며 고칠 수 있습니다. Madi는 여러분이 고친 내용을 기억해 다음 회의에서 같은 실수를 자동으로 바로잡습니다.

내용 보기 vs 상세 보기

화면 상단의 전환 스위치로 두 가지 보기를 오갑니다.

  • 내용 — 시각·표시 없이 깨끗하게 읽는 기본 보기.
  • 상세 — 타임코드, 저신뢰 단어(호박색 강조), 화자 겹침 표시(⟨+이름 겹침⟩)를 함께 보여 줍니다.

검토와 편집은 상세 보기에서 합니다.

줄 직접 편집

  1. 고치고 싶은 줄을 더블 클릭합니다(또는 상세 보기에서 연필 버튼, 도움말 “이 문장 편집”).
  2. 내용 보기에서 더블 클릭하면 자동으로 상세 보기로 넘어가 편집창이 열립니다.
  3. 텍스트를 고치고 저장(⌘↩)을 누릅니다. 되돌리려면 취소(Esc).
  4. 고친 줄에는 편집됨 표시가 붙습니다.

원문을 고치면 이전 원문으로 생성 중이던 번역은 자동으로 폐기되고, 고친 원문을 기준으로 다시 번역됩니다. 늦게 도착한 예전 AI 결과가 사용자 교정을 덮어쓰지 않습니다.

번역문 직접 교정

확정된 번역문을 더블 클릭하면 번역 교정 입력란이 열려 언어별 번역을 직접 고칠 수 있습니다.

  • 저장한 번역에는 연필 표시가 붙고, 다중 번역의 다른 언어는 그대로 유지됩니다.
  • 교정된 원문·번역·화자 이름은 Markdown과 JSON에 함께 저장되며, Markdown 회의록을 다시 열어도 번역이 보존됩니다.
  • SRT/VTT는 항상 최종 교정 원문을 사용합니다.

검토 필요 — 저신뢰 단어 빠르게 확인

상세 보기는 신뢰도가 낮게 인식된 단어(기준값 미만, 기본 0.55)를 호박색으로 표시합니다.

  1. 상단에 검토 필요 N개와 현재 위치(N/전체)가 표시됩니다.
  2. ∧(이전 검토 단어) / ∨(다음 검토 단어) 버튼으로 표시된 단어들 사이를 건너뛰며 이동합니다.
  3. 각 단어를 확인하고, 필요하면 그 자리에서 고칩니다.

기준값은 설정(⌘,) → 저장 → 음성 인식의 저신뢰 표시 기준 (VAD) 에서 조정합니다. 값을 올리면 더 많은 단어가 검토 대상이 됩니다.

귀로 검토 — 들으며 확인

파일을 불러와 전사한 세션에서는, 저신뢰 단어의 오디오 구간을 하나씩 자동으로 재생해 귀로 확인할 수 있습니다.

  1. 검토바의 재생 버튼(도움말 “저신뢰 단어 귀로 검토”)을 누릅니다.
  2. 표시된 단어들의 오디오가 순서대로 자동 재생되고, 한 단어가 끝나면 다음으로 넘어갑니다(핸즈프리). 진행 상황은 재생 N/전체 로 표시됩니다.
  3. 멈추려면 같은 버튼(도움말 “귀로 검토 멈춤”)을 다시 누릅니다.
참고: 귀로 검토는 원본 미디어가 있는 파일 전사 세션에서만 켜집니다. 실시간 마이크 녹음에는 원본 파일이 없어 나타나지 않습니다.

AI 교정 (녹음이 끝난 뒤)

녹음이 끝나면 온디바이스 LLM이 대화 전체를 읽고 명백한 화자 오분리와 잘못된 언어로 받아쓴 줄을 보수적으로 바로잡습니다.

  • 켜는 법: 설정(⌘,) → 번역 → AI 교정 (세션 종료 후) 의 화자·언어 자동 교정.
  • 교정이 적용되면 전사문 위에 안내가 뜨고, 화자 교정 되돌리기 버튼으로 한 번에 되돌릴 수 있습니다.
  • 하드웨어에 맞게 선택된 DNA3.0 번역 모델이 있어야 씁니다.

개인 단어장 — 교정을 기억하는 학습

전사문의 한 줄을 고치면 Madi가 그 교정을 학습합니다. 단어장 을 켜 두면, 다음 회의에서 같은 도메인 용어·이름의 오인식을 자동으로 바로잡습니다.

켜는 법: 설정(⌘,) → 단어장 탭에서 학습한 교정 자동 적용을 켭니다.

참고: 학습은 스위치와 상관없이 항상 동작하며, 이 스위치는 “적용”만 켭니다. 그래서 켜는 즉시 그동안 쌓인 교정이 적용됩니다.

적용 기준 (최소 확인 횟수)

  • 최소 확인 횟수 슬라이더로, 같은 교정을 몇 번 확인해야 믿고 자동 적용할지 정합니다(1~5회).
  • 값이 클수록 보수적입니다 — 우발적인 편집 한 번이 이후 전사를 덮어쓰지 않도록 막아 줍니다.

학습한 교정 관리·삭제

설정 → 단어장 탭의 목록에서 학습한 규칙을 관리합니다.

  • 각 규칙은 잘못된 단어 → 올바른 단어와 확인 횟수로 표시됩니다.
  • 규칙 옆 휴지통 버튼으로 하나씩 잊게 합니다.
  • 모두 지우려면 전체 지우기를 누릅니다.

텍스트 선택과 복사

전사문 전체에서 텍스트를 드래그로 선택하고 ⌘C로 복사할 수 있습니다.

07

작업 폴더와 내보내기

Madi는 저장 폴더를 통째로 하나의 작업 공간으로 보여 줍니다. 창 오른쪽의 작업 폴더 탐색기에서 지난 회의록을 다시 열고, 저장 위치를 바꾸고, 원하는 형식으로 내보냅니다.

작업 폴더 탐색기

탐색기는 창 오른쪽에 항상 표시됩니다. 위쪽은 회의 목록, 아래쪽은 자동저장·폴더·내보내기 조작부입니다.

파일 목록

  • 파일 탭에 저장 폴더의 회의록이 최근 순으로 쌓입니다.
  • 회의록을 클릭하면 그 회의가 화면에 다시 열립니다.

자동 저장

  • 자동저장 스위치를 켜 두면 전사가 끝날 때 회의록이 Markdown(.md) 으로 자동 저장됩니다.
  • 폴더 줄에 현재 저장 위치가 표시됩니다. 변경을 눌러 다른 폴더를 고를 수 있습니다.
  • 고른 폴더는 저장과 내보내기의 기본 위치가 됩니다.
같은 설정이 설정(⌘,) → 저장 탭에도 있습니다. 편한 쪽에서 바꾸면 됩니다.

팁 — ⌘K를 눌러 작업 폴더 변경을 입력해도 폴더를 바로 고를 수 있습니다.

내보내기

탐색기 아래쪽의 내보내기 버튼을 누르면 내보내기 형식을 묻습니다. 형식을 고르면 저장 위치를 정할 수 있습니다.

형식쓰임
Markdown (.md)마크다운 회의록. 화자 이름·번역·교정이 함께 저장됩니다
Subtitles (.srt)SRT 자막
Subtitles (.vtt)VTT 자막
Plain text (.txt)일반 텍스트
JSON (.json)JSON 데이터

참고

  • 전사문이 비어 있으면 내보내기 버튼이 흐려집니다.
  • SRT/VTT는 항상 최종 교정 원문을 사용합니다. (검토와 교정 참고.)

클릭해서 그 순간 듣기

오디오·영상 파일을 불러와 전사한 세션(원본 파일이 디스크에 있는 경우)에서는, 각 줄에 재생 버튼이 표시됩니다.

  1. 듣고 싶은 줄의 재생 버튼(도움말 “이 구간 오디오 재생”)을 누릅니다.
  2. 그 줄이 말해진 정확한 순간이 원본 미디어에서 재생됩니다.
참고: 실시간 마이크 녹음 세션에는 원본 파일이 없으므로 줄별 재생 버튼이 나타나지 않습니다.

지난 회의 빨리 찾기

⌘K 명령 팔레트에 회의 이름을 입력하면 저장된 회의록으로 바로 이동합니다. 화자 이름으로도 찾을 수 있습니다.

08

시스템 받아쓰기 (추후 제공)

준비 중 — 현재 베타에는 포함되지 않았습니다. 아래는 앞으로 제공될 기능 소개이며, 지금 버전에서는 설정에 받아쓰기 탭이 없고 단축키도 동작하지 않습니다.

시스템 받아쓰기는 macOS 어디서나 쓸 수 있는 음성 입력 기능으로 준비하고 있습니다. 전역 단축키를 누른 채 말하고 떼면, 말한 내용이 기기 안에서 글자로 바뀌어 지금 맨 앞에 있는 앱(메모, 메일, Slack, 코드 편집기 등)의 입력란에 그대로 들어가도록 하는 것이 목표입니다. 회의 전사·번역과 마찬가지로 100% 온디바이스로 동작하도록 설계하고 있습니다.

계획된 동작

  • 푸시투토크 — 전역 단축키를 누르는 동안만 녹음하고, 떼는 순간 받아쓴 텍스트가 입력됩니다.
  • 가볍고 빠르게 — 큰 언어 모델을 올리지 않고, 받아쓰기 전용 음성 인식만 짧게 돌렸다가 종료하는 방식이라 메모리가 적은 Mac에서도 부담이 적습니다.
  • 클립보드 보존 — 텍스트를 넣을 때 기존 클립보드를 저장했다 곧바로 되돌립니다.
  • 회의 녹음 중 비활성 — 받아쓰기와 회의 녹음이 같은 마이크를 쓰므로 충돌을 막기 위해 녹음 중에는 꺼집니다.

지금은?

지금 버전에서 쓸 수 있는 기능은 회의 전사·화자 분리·온디바이스 번역·검토와 교정·AI 요약입니다. 시스템 받아쓰기는 이후 업데이트에서 제공될 예정입니다. 업데이트 확인은 Madi 메뉴 → 업데이트 설치… 에서 할 수 있습니다.

09

설정

설정 창은 ⌘,(Command + 쉼표) 로 엽니다(왼쪽 패널의 톱니 버튼도 같습니다). 매 회의마다 만지는 것이 아니라 “한 번 정해 두는” 항목들이 여기에 모여 있습니다. 창 위쪽 탭으로 녹음 · 저장 · 번역 · 단어장 · 모델 을 오갑니다.

회의마다 바뀌는 것(입력·출력 언어, 회의 모드, 화자 수)은 설정이 아니라 첫 화면의 회의 정보에 있습니다. (녹음과 전사 참고.)
참고: 녹음 탭의 설정은 녹음 중·일시정지 중에는 잠깁니다. 바꾸려면 녹음을 멈춘 뒤 조정하세요.

녹음

음원 캡처 방식과 실시간 동작, 화면 표시를 정합니다.

입력

  • 음원 — 무엇을 들을지 고릅니다.
    • 마이크 — 내 목소리 / 대면 회의.
    • 시스템 오디오 — Mac에서 재생되는 소리(Zoom·Teams·Slack·YouTube 등). 첫 사용 시 ‘화면 기록’ 권한을 요청합니다(오디오 전용, 화면은 저장하지 않음).
    • 마이크+시스템 — 온라인 회의(내 목소리 + 상대방 소리)에 적합합니다.
  • 마이크 — (마이크 / 마이크+시스템일 때) 사용할 입력 장치. 기본은 “시스템 기본”.
  • 언어 — 자동 감지 / 한국어 / English 중에서 전사 언어를 고정하거나 자동으로 둡니다.

화자

  • 화자 분리 — 누가 말했는지 화자별로 구분합니다.
  • 중첩 발화 감지 — 두 사람이 동시에 말하는 구간을 감지합니다(상세 보기의 겹침 표시).

실시간

  • 반응 속도 — 빠름(5초) / 보통(7초) / 정확(10초). 빠름은 텍스트가 더 자주 떠 체감 속도가 좋고, 정확은 문맥을 길게 봐 품질이 좋습니다.
    • 출력 언어가 2개 이상이면 최소 보통(7초) 으로 내려앉습니다 — 빠름을 골라 두었어도 자동으로 7초가 됩니다. 단, 한국어+다른 언어 하나만 켠 양방향 통역은 예외입니다.
  • 실시간 프리뷰 — 한 구간이 확정되기 전, 중간 텍스트를 회색으로 미리 보여 줍니다. 확정 전사와 같은 Whisper 프로세스를 공유해 두 번째 모델을 띄우지 않습니다.

표시

  • 외관 — 시스템 / 라이트 / 다크 테마를 고릅니다.

자막 오버레이 (진료실)

대면 통역용 자막 창의 크기와 두 번째(환자용) 화면을 설정합니다. (실시간 번역·통역 참고.)

  • 직원 자막 크기 — 주 화면 자막 글씨(14–48pt).
  • 환자용 대형 자막 (별도 화면) — 두 번째 패널을 환자 언어로, 원거리 판독용 큰 글씨로 띄웁니다. 켜면 아래 항목이 나타납니다.
    • 환자 자막 크기 — 24–96pt.
    • 환자 화면 — 모니터가 둘 이상일 때, 어느 화면에 띄울지 고릅니다.
    • 환자 언어 — 자동(상대 언어) 또는 특정 언어로 고정.

저장

파일 저장과 인식 기준을 정합니다.

자동 저장

  • 완료 시 .md 자동저장 — 전사가 끝나면 Markdown 파일로 자동 저장합니다.
  • 폴더 / 변경… — 저장 폴더를 지정합니다. 이 폴더가 작업 폴더 탐색기에 보이는 작업 공간입니다.
같은 설정이 작업 폴더 탐색기 아래쪽에도 있습니다.

음성 인식

  • 저신뢰 표시 기준 (VAD) — 이 신뢰도(기본 0.55) 미만으로 인식된 단어를 검토 필요로 표시합니다. 범위 0.35–0.9. 값을 올리면 더 많은 단어가 검토 대상이 됩니다. (검토와 교정 참고.)

번역

온디바이스 번역(한국어·영어·일본어·중국어)을 켜고 끄는 곳입니다.

번역 엔진이 포함되지 않은 빌드에서는 이 탭이 아예 보이지 않습니다.

번역 모델 (8GB: DNA3.0-2B · 약 1.31 GB / 16GB+: DNA3.0-4B · 약 2.78 GB)

  • 상태 — 설치됨 / 검증 중 / 다운로드 진행률 / 미설치를 보여 줍니다.
  • 번역 모델 다운로드 — Mac 메모리에 맞게 자동 선택된 모델을 받습니다. 앱에 동봉되어 있지 않습니다. 엔진 실측 물리 메모리는 2B 약 2.4 GB, 4B 약 5.1 GB이며, 받는 중에는 취소, 설치 후에는 Finder에서 보기 로 파일 위치를 열 수 있습니다.

실시간 번역 (다중 대상)

  • 한국어 / English / 日本語 / 中文 — 토글로 대상 언어를 고릅니다(최대 3개). 선택한 모든 언어로 각 줄을 동시에 번역해 원문 아래에 표시합니다(원문 언어는 자동 제외).
  • 모델을 먼저 받아야 쓸 수 있습니다. 대상이 2개 이상이면 반응 속도가 최소 ‘보통(7초)’ 이 됩니다(녹음 탭 참고).

번역 반응 (실시간)

  • 마지막 줄 대기 (초) — 말이 끝난 마지막 줄을 이 시간(0.5–5.0초, 기본 3초)만큼 기다렸다 번역합니다. 짧을수록 자막이 빨리 뜨지만 미완성 문장을 번역할 수 있습니다. 확정된(다음 줄이 시작된) 줄은 이 값과 무관하게 즉시 번역되며, 전사(STT) 반응 속도와는 별개입니다.

AI 교정 (세션 종료 후)

  • 화자·언어 자동 교정 — 녹음이 끝나면 온디바이스 LLM이 대화를 읽고 명백한 화자 오분리·잘못된 언어 줄을 보수적으로 바로잡습니다. 화자 교정은 한 번에 되돌릴 수 있습니다.
  • 하드웨어에 맞게 선택된 DNA3.0 번역·요약 모델이 있어야 씁니다.

단어장 (개인 단어장)

자주 틀리는 도메인 용어·이름을 직접 고친 내용을 Madi가 학습해, 이후 회의에서 비슷한 오인식을 자동으로 바로잡습니다. (검토와 교정 참고.)

  • 학습한 교정 자동 적용 — 학습한 교정을 실제로 적용할지 켜는 스위치입니다. 학습은 항상 동작하며, 이 스위치는 ‘적용’만 켭니다. (기본 꺼짐 — 직접 켜세요.)
  • 최소 확인 횟수 — 같은 교정을 이 횟수(1~5회) 이상 확인해야 자동 적용합니다. 값이 클수록 보수적이라, 우발적 편집 한 번이 이후 전사를 덮어쓰지 않습니다.
  • 학습한 교정 목록 — 학습된 규칙(틀린 단어 → 맞는 단어, 확인 횟수)을 보여 줍니다. 각 줄의 휴지통 버튼으로 한 규칙만 잊게 하거나, 전체 지우기 로 모두 비웁니다.

모델

받아쓰기(Whisper) 모델의 상태를 확인하고 관리합니다.

  • 상태 / 위치 — 모델 설치 여부와 파일 경로를 보여 줍니다.
  • 모델 재다운로드 — 모델을 다시 받습니다.
  • Finder에서 보기 — 모델 파일 위치를 엽니다.
선택된 DNA3.0 번역 모델은 번역 탭에서 관리합니다.
시스템 받아쓰기는 추후 제공 예정이라, 현재 베타에는 받아쓰기 탭이 없습니다. (시스템 받아쓰기 (추후 제공) 참고.)

8GB Mac 사용 가이드

Madi가 8GB급 Mac을 감지하면 이 문서를 최초 한 번 자동으로 엽니다. 이후에는 도움말 → 8GB Mac 사용 가이드에서 언제든 다시 볼 수 있습니다.

자동으로 적용되는 저메모리 프로필

별도 설정 없이 다음 정책이 적용됩니다.

  • DNA3.0-2B 번역 모델 — 4B 대신 2B를 선택합니다. 다운로드는 약 1.31 GB, 엔진 프로세스의 실측 물리 메모리는 약 2.4 GB입니다(4B 실측 약 5.1 GB 대비 53% 감소).
  • 확정 자막 우선 — 말하는 중의 임시 번역보다 확정된 전사 줄을 먼저 번역합니다.
  • 대기열 합치기 — 같은 줄이 다시 인식되면 오래된 번역 요청을 버리고 최신 문장 하나만 남깁니다.
  • 4턴 대기 상한 — 실시간 화면은 최신 번역을 따라가며, 밀린 확정 줄은 녹음 종료 후 다시 채웁니다.
  • 저메모리 Whisper 경로 — 큰 encoder 캐시를 보존하지 않아 메모리 압박과 swap을 줄입니다.

이 정책은 품질을 숨기지 않습니다. 2B는 4B보다 작아 어려운 문장에서는 번역 표현이 덜 정확할 수 있습니다. Madi는 원문 반복, 잘못된 문자 체계, <think> 누출과 반복 폭주를 감지해 한 번 다시 생성하고, 그래도 잘못되면 틀린 번역을 표시하지 않습니다.

실시간 통역 권장 설정

  1. 출력 언어는 가능하면 하나만 고릅니다.
  2. 대면 통역이라면 한국어 + 상대 언어 하나만 켭니다. 줄마다 실제 번역 대상은 하나가 되어 가장 효율적입니다.
  3. 처음에는 보통(7초) 으로 시작합니다. 원문 경계가 더 중요하면 정확(10초) 을 씁니다.
  4. 장시간 통역 중에는 브라우저의 많은 탭, 대형 IDE, 다른 로컬 LLM처럼 메모리를 많이 쓰는 앱을 닫습니다.
  5. “번역 중 · N줄 대기”가 보이면 멈춘 것이 아닙니다. 확정 자막이 우선 처리되고 있으며 오래된 임시 요청은 자동으로 정리됩니다.

무엇을 기대하면 되나요?

  • 전사와 화자 분리만 사용하면 번역 모델을 내려받거나 실행하지 않습니다.
  • 번역·요약·AI 교정을 처음 켤 때 8GB용 2B 모델을 한 번 내려받습니다.
  • 실시간 번역 중 오래된 확정 줄이 화면에서 늦어질 수 있지만, 녹음을 끝내면 저장할 기록을 위해 다시 번역합니다.
  • 메모리 압박이 심하면 macOS의 swap 때문에 전사와 번역이 함께 느려질 수 있습니다. 이때는 출력 언어 수와 다른 앱의 메모리 사용량부터 줄이세요.

문제를 확인할 때

  • 설정(⌘,) → 번역에서 DNA3.0-2B · ~1.3 GB가 표시되는지 확인합니다.
  • 모델을 아직 받지 않았다면 같은 화면의 번역 모델 다운로드를 누릅니다.
  • 번역 없이도 전사·화자 분리는 정상 동작해야 합니다.
  • 문제가 계속되면 도움말의 사용자 매뉴얼과 업데이트 화면에서 현재 버전을 확인하세요.
모든 처리는 이 Mac에서 — 전사·번역·요약이 기기를 떠나지 않습니다.

Getting started

Welcome to Madi. Madi transcribes and translates your meetings entirely on this Mac. Live transcription, audio and video file transcription, speaker separation, on-device translation — every step happens inside your own machine.

What Madi does

  • Live transcription — listens to your mic or meeting audio and puts text on screen almost as fast as you speak.
  • File and video transcription — drop in a recording and Madi writes out the whole conversation.
  • Speaker separation — tells apart who spoke when, and lets you name them.
  • On-device translation — renders Korean, English, Japanese and Chinese in real time, and can float them as captions over any window.
  • AI summary and Q&A — distills the summary, decisions and actions when the meeting ends, and lets you ask about it in natural language.
  • Review and correction — finds words it wasn't sure about, lets you fix them, and remembers your fixes for next time.
  • System-wide dictation (coming later) — a planned feature: hold a key in any app, speak, and your words land in the text field.

100% on-device — your data never leaves this Mac

Madi's core promise is sovereignty. No audio, no transcript, no translation is ever sent to the cloud. Once the models are downloaded it works with the internet unplugged. Your meetings exist only on your device.

About the models

Madi uses two kinds of AI model.

  • Whisper speech model (~867 MB) — handles transcription. The standard DMG downloads it once on first launch.
  • DNA3.0 language model — powers translation, AI correction, and summary / Q&A. Madi automatically selects 2B (~1.31 GB) on an 8 GB Mac and quality-first 4B (~2.78 GB) on 16 GB or more; it is downloaded the first time you use it.
    • Where: Settings (⌘,) → Translation, the "Download translation model" button.
    • Only the selected model is downloaded, using the same amount of disk space.

If you don't use translation, summary or Q&A you never need this model. Transcription and speaker separation run entirely on the bundled Whisper model.

About memory (honestly)

  • 8 GB Mac (e.g. M1 MacBook Air) — Madi automatically uses DNA3.0-2B and a four-turn translation horizon. The measured translation-engine footprint is about 2.4 GB.
  • 16 GB and above — Madi uses quality-first DNA3.0-4B (measured at about 5.1 GB).
  • Live preview shares the committed Whisper process; it no longer launches a second 830 MB model.

Permissions Madi may ask for

Madi doesn't ask for everything up front — it requests each permission the first time you use that feature.

  • Microphone — to record. Asked when you first start a recording.
  • Screen Recording — only to capture system audio (sound playing on your Mac, e.g. Zoom, Teams, YouTube). macOS bundles audio capture into the Screen Recording permission; Madi never records your screen.

    • (The Accessibility permission is only for system-wide dictation (coming later), and the current beta doesn't request it.)

If you deny a permission and want it later, open System Settings → Privacy & Security, find the item (Microphone / Screen Recording) and enable Madi.

First-run quick start

  1. Open Madi. The first screen has two columns: Meeting info and Get started.
  2. Under Meeting info, set up this meeting — input language, output language (if you translate), meeting mode, speaker count.
  3. Under Get started, pick a mic and press Start recording now, or drop in an audio/video file.
  4. Watch the live transcript appear in the middle of the window.
  5. Press Stop to wrap up. If auto-save is on, the transcript is written to a file.
To translate, download the hardware-selected model in Settings (⌘,) → Translation. On an 8 GB Mac, Madi opens the dedicated guide once.

The window

Once recording starts, the window splits into three columns.

  • Left — session panel: transport buttons (pause / stop), total time, the speaker bar, and the energy-flow graph. The Settings gear lives here too.
  • Center — transcript: what was said. You read and edit here.
  • Right — workspace explorer: past meetings, the auto-save switch, save folder, and export.

Recording and transcription

Madi transcribes meetings live as people speak, and it can also transcribe audio and video files you already have. Everything runs on this Mac — your transcript never leaves the device.

The app interface is in Korean. Korean UI labels are shown below with an English gloss in parentheses.

The first screen — meeting info and getting started

When you open the app the first screen splits in two. On the left you tell Madi what kind of meeting this is; on the right you start it.

회의 정보 (Meeting info) — left

Setting these before you record improves the result. They lock while recording.

  • 입력 언어 (Input language) — the language being spoken. Auto-detect, or pin a specific language.
  • 출력 언어 (Output language) — the languages to translate into (you can pick several). Requires the translation model. See Live translation.
  • 회의 모드 (Meeting mode) — the shape of the meeting. See below.
  • 화자 (Speakers) — how many people are in the room. See below.

시작하기 (Get started) — right

  • 파일로 시작하기 (Start from file) — press after picking or dropping a file.
  • 지금 녹음 시작 (Start recording now) — pick a mic and record immediately.

Live mic recording

  1. In 시작하기 (Get started), choose your mic (default is "시스템 기본" / System default).
  2. Press 지금 녹음 시작 (Start recording now). A short countdown runs before recording begins — you can cancel during it.
  3. As people speak, the transcript streams live in the center of the window.
  4. In the left panel, press 일시 정지 (Pause, ⌘P) to pause, or 정지 (Stop, ⌘R) to end.

Note

  • Stopping wraps up everything captured so far. If auto-save is on, it's written to a file.
  • If auto-save is off, Madi warns you before you leave — you can save first with 내보내기 (Export).

에너지 흐름 (Energy flow)

The 에너지 흐름 graph at the bottom of the left panel shows the meeting's texture in a single line — a composite of speaking pace, overlap and silence.

  • Click a point on the graph to jump to that moment. Handy for finding the liveliest stretch of a meeting.
  • Before enough speech accumulates it says "발언이 쌓이면 흐름이 표시됩니다" (the flow appears once speech accumulates).

Swapping mics mid-recording

During a live recording, the 입력 마이크 (Input mic) row in the left panel lets you switch microphones without interrupting the recording — handy when you plug in a headset mid-meeting.

Captions appear as soon as you stop talking

Madi doesn't wait for a window to fill up. When you pause and go quiet for a moment, it closes that window early and emits the transcript right away — cutting the wait noticeably in short back-and-forth conversations (like a consultation). Quiet, far-field voices aren't clipped: the threshold adapts automatically.

System audio capture (Zoom / Teams / video)

You can transcribe whatever is playing through your Mac — online meetings, videos, and so on.

  1. Go to 설정 → 녹음 → 입력 (Settings → Recording → Input).
  2. Under 음원 (Audio source), pick how to capture sound:
    • 마이크 (Microphone) — only the sound in front of you
    • 시스템 오디오 (System audio) — what's playing on the Mac: Zoom, Teams, Slack, YouTube, etc.
    • 마이크+시스템 (Mic + system) — for online meetings: your voice plus the other side
  3. Start recording as usual.

Note

  • The first time you use system audio, macOS asks for Screen Recording permission. Only audio is used; the screen is never saved.

File and video transcription

  1. Drop a file onto the window, or click the 파일 선택 or 드래그 앤 드롭 (Choose file or drag and drop) area to pick one. While dragging, 드롭하여 전사 (Drop to transcribe) appears.
  2. Press 파일로 시작하기 (Start from file).
  3. Progress shows as 전사 중 · N% (Transcribing · N%).
  4. When it finishes, the result appears on screen.

Note

  • Dropping a file does not start transcription by itself — you must press 파일로 시작하기. That gap is your chance to adjust the meeting info first.
  • Audio is extracted from video (mp4, mov, m4v, mkv, webm, avi …) automatically. No conversion needed.
  • Two features work only on file transcriptions: per-line audio playback and review by ear. See Review and correction and Workspace and export.

회의 모드 (Meeting mode)

A preset that tunes speaker count and emphasis to the shape of the meeting. Pick it on the first screen under 회의 정보 → 회의 모드.

화자 (Speaker count)

Speakers

Madi automatically works out who spoke during a meeting. All of this runs on this Mac.

The app interface is in Korean. Korean UI labels are shown below with an English gloss in parentheses.

Automatic speaker separation

While recording and transcribing, Madi splits speech by speaker automatically.

  • Each speaker gets a distinct color and a 화자 N (Speaker N) label.
  • The speaker bar in the left panel shows, in one line, who spoke when across the meeting.

Note

  • You can turn this off with the 화자 분리 (Speaker separation) switch in 설정 (⌘,) → 녹음 → 화자 (Settings → Recording → Speakers).

Pinning the speaker count

If you know how many people are in the room, set it to improve accuracy.

  1. On the first screen, go to 회의 정보 → 화자 (Meeting info → Speakers).
  2. Choose 자동 (Auto) / 1명 / 2명 / 3명 / 4명 이상 (1 / 2 / 3 / 4+ people).

Note

  • Pinning the count when you're sure gives cleaner speaker splits. If you're not sure, leave it on 자동 (Auto).
  • Choose it before recording — it locks once recording starts.

미확인 (Unknown) speakers

When you pin the speaker count, any voice that clearly doesn't match one of the people you specified gets collected under 미확인 (Unknown). This stops a passer-by's one-liner or a burst of noise from being misattributed to one of your real speakers.

  • 미확인 is not a person — it means "there's nowhere to put this." You cannot name it.
  • It never appears when the count is left on Auto.

Naming speakers

  1. In the transcript, click a speaker label (e.g. 화자 1 / Speaker 1) or the speaker chip.
  2. Type the real name into the 이름 (예: 김부장) (Name, e.g. Manager Kim) field.
  3. Press 저장 (Save). The name applies to all of that speaker's lines and to exports.

Note

  • Names apply to this transcript only. Madi will not recognize the same person automatically in your next meeting — you name them again each time.
  • 미확인 (Unknown) cannot be named.

AI speaker correction (after recording)

When recording ends, the on-device LLM reads the conversation and conservatively fixes obvious speaker mis-splits — one person's speech broken across two speakers, or a line attributed to the wrong person.

  • Toggle it under 설정 (⌘,) → 번역 → AI 교정 (세션 종료 후) (Settings → Translation → AI correction (after session)), switch 화자·언어 자동 교정 (Auto-correct speakers and language).
  • When a correction is applied, a note appears above the transcript with a 화자 교정 되돌리기 (Undo speaker correction) button — one click reverts all of it.
  • Requires the hardware-selected DNA3.0 translation model.

Overlap markers

When two people talk at once, the 상세 (Detail) view shows a ⟨+name 겹침⟩ (overlap) marker naming the second speaker who cut in.

Note

Live translation and interpreting

Madi's translation runs 100% on your device — no cloud, no account. While a meeting is in progress, each spoken line is translated into Korean, English, Japanese and/or Chinese and shown right beneath the original. Madi automatically uses DNA3.0-2B on an 8 GB Mac and DNA3.0-4B on 16 GB or more.

The app interface is in Korean. Korean UI labels are shown below with an English gloss in parentheses.

First: download the translation model

Translation needs a separate model that isn't bundled with the app. You download DNA3.0-2B (~1.31 GB) once on an 8 GB Mac, or DNA3.0-4B (~2.78 GB) on 16 GB or more.

  1. Open 설정 (⌘,) → 번역 (Settings → Translation).
  2. Press 번역 모델 다운로드 (Download translation model).
  3. When it finishes, the translation options become available.

The measured engine-process footprint is about 2.4 GB for 2B and 5.1 GB for 4B. Before the model is installed the toggles are disabled and you'll see "번역 모델을 먼저 다운로드하세요." (Download the translation model first.)

If you don't see the 번역 tab — your build doesn't include the translation engine, and translation isn't available at all.

Choosing output languages

Two places, same setting — use whichever is handy.

  • First screen → 회의 정보 → 출력 언어 (Meeting info → Output language) — as you start a meeting.
  • 설정 (⌘,) → 번역 → 실시간 번역 (다중 대상) (Settings → Translation → Live translation, multi-target) — toggles for 한국어 / English / 日本語 / 中文.

Every line is translated into all the languages you pick and shown directly under the original, each tagged with its language. The source language is excluded automatically.

Note

  • You can pick up to 3 output languages.
  • Without the translation model you can't pick output languages at all.

Translations type themselves out

Madi doesn't wait for a translation to be finished. Words fill in on screen as they're generated. A cursor ▍ blinks at the end of a line still being written, so you know it's continuing rather than truncated.

While someone is still speaking, an interim translation appears first, marked 진행 중 (in progress). When the line is finalized the interim smoothly becomes the final translation — and the interim stays on screen until the final arrives, so translations never blink out.

Face-to-face interpreting — bidirectional

Madi is designed for two people speaking different languages in the same room (for example, a Korean staff member and a Japanese or Chinese visitor).

Turn on only 한국어 plus one other language (e.g. 한국어 + 일본어) and it becomes a bidirectional interpreting mode.

  • Direction is detected per line. A Japanese line is translated only into Korean; a Korean line only into Japanese. No wasted work, so it's faster.
  • Both sides transcribe correctly even when you alternate languages. The language is re-checked per segment, so one person speaking Korean and the other Japanese both get accurate transcripts.
  • This combination is exempt from the latency floor below.

Frequent-phrase dictionary (instant translation)

For places that repeat the same guidance (say, post-procedure instructions in a clinic), you can pre-store translations of common phrases. When a stored phrase comes up, the translation appears instantly (0 s) without going through the model.

A few phrases ship by default, and you can add or edit your own.

  • File: ~/Library/Application Support/Sovereign/faq_translations.json
  • For safety it only fires on an exact match.

Latency and translation quality

With 2 or more output languages, boundary errors in the source line would propagate into every language — so the response speed drops to a floor of 보통 (7초) (Normal, 7 s). If you had picked 빠름 (5초) (Fast, 5 s), it automatically becomes 7 s. 정확 (10초) (Accurate, 10 s) still works.

Exception: the bidirectional mode (한국어 + exactly one other language) is not forced, because each line's effective target count drops to one. Captions appear faster in face-to-face interpreting.

When translation falls behind you'll see "번역 중 · N줄 대기" (Translating · N lines queued). It is not stuck: committed transcript lines run before disposable previews, and stale revisions of the same line are coalesced. The 8 GB profile keeps a four-turn live horizon and fills deferred durable lines after recording stops.

AI language correction (after recording)

When recording ends, the on-device LLM reads the conversation and conservatively fixes lines transcribed in the wrong language. Toggle it under 설정 (⌘,) → 번역 → AI 교정 (세션 종료 후) → 화자·언어 자동 교정. See Speakers.

Caption overlay

The caption overlay is a floating window of live translated captions that sits on top of everything. Park it over a Zoom or Teams call, or on a clinic display, and follow what the other person is saying in real time.

Toggle it with the speech-bubble icon in the top toolbar. The button only appears once you've picked at least one output language.

  • The window always stays in front but never takes focus, so you can keep clicking and typing in your call app.
  • It floats above full-screen apps, and you can drag it anywhere by its background.
  • The largest text is the translation; the smaller text beneath it is the original.
  • With multiple people, captions carry the speaker's color and name so you know who's talking.
  • While waiting for speech, a mic level bar moves to confirm the system is listening.
  • Status text ("진행 중 / 번역 중… / 음성을 기다리는 중…") is shown in the viewer's language — 「翻訳中…」 on Japanese captions, 「翻译中…」 on Chinese.

Staff captions + patient captions (dual display)

For clinic interpreting you can split captions into two panels.

  • Staff captions — small, on the main display, in the staff member's language.
  • Patient captions — large, on an external monitor, for reading at a distance, in the patient's language.

Turn it on in 설정 (⌘,) → 녹음 → 자막 오버레이 (진료실) (Settings → Recording → Caption overlay (clinic)). You can set staff text size (14–48 pt), patient text size (24–96 pt), which display to use, and the patient's language. The large sizes are meant to read well across the 1.5–2.5 m between a treatment chair and the display.

AI summary and Q&A

When a transcript is done, the on-device LLM distills the meeting into a structured summary, and you can ask questions about it in natural language. Summary and Q&A use the same hardware-selected model as translation (DNA3.0-2B on 8 GB, 4B on 16 GB or more), and neither the transcript nor the summary ever leaves this Mac.

The app interface is in Korean. Korean UI labels are shown below with an English gloss in parentheses.

First: the translation/summary model

Summary and Q&A use the same on-device model as translation. Without it, the summary button doesn't appear. See Live translation or Settings for how to download it.

Generating a meeting summary

  1. After transcription finishes (not while recording), press the ✦ (sparkles) button in the top toolbar. Or pick 요약 생성 (Generate summary) from the ⌘K command palette.
  2. The 회의 요약 (Meeting summary) sheet opens and the local LLM generates the summary, with a note that "the transcript never leaves this Mac."
  3. The 전체 / 화자별 (Overall / By speaker) toggle at the top switches the view.
    • 전체 (Overall) — summary, actions and decisions for the whole meeting.
    • 화자별 (By speaker) — what each speaker talked about (generated on first selection).

Note

  • The ✦ button is only enabled when there's a transcript and you're not recording. It dims when the transcript is empty.

Buttons in the summary sheet

  • 복사 (Copy) — copy the summary text to the clipboard.
  • 다시 생성 (Regenerate) — generate a fresh summary from the same transcript.
  • 슬라이드(HTML) (Slides, HTML) — export an offline HTML slide deck and reveal it in Finder.
  • 리캡 카드 (Recap card) — open a shareable one-pager (see below).
  • 내보내기… (Export…) — save the summary as a .md file.

Recap card

A one-page shareable summary of the meeting. Open it with 리캡 카드 in the summary sheet. It carries:

  • Title + date
  • TL;DR
  • List of decisions
  • Actions by owner
  • Talk-time per speaker
  • A one-line quote

Use 복사 (Copy) to copy it as Markdown, or 내보내기… (Export…) to save it to a file.

Ask the meeting (Q&A)

Ask about the meeting in natural language and the local LLM answers, grounded in the transcript. It sits at the bottom of the summary sheet.

  1. Type your question into the 회의록에 물어보기 (Ask the transcript) field. E.g. "무엇을 결정했나요?" (What did we decide?), "김부장이 맡은 일은?" (What is Manager Kim responsible for?).
  2. Press the paper-plane button or Enter.
  3. The 이 회의 / 전체 워크스페이스 (This meeting / Whole workspace) toggle sets the scope.
    • 이 회의 (This meeting) — answer only from the currently open transcript.
    • 전체 워크스페이스 (Whole workspace) — search across all saved transcripts. E.g. "지난달 보안 결정은?" (What security decisions were made last month?).

Note

  • While answering, "로컬 LLM이 답하는 중…" (the local LLM is answering…) is shown.

Privacy

Both summary and Q&A run on this Mac. Neither the transcript nor the summary leaves the device.

Review and correction

Once a transcript is done you can read it clean, or go in close and fix it. Madi remembers the fixes you make and applies them automatically in later meetings.

The app interface is in Korean. Korean UI labels are shown below with an English gloss in parentheses.

내용 (Content) vs 상세 (Detail) view

The toggle at the top of the window switches between two views.

  • 내용 (Content) — a clean read, no timecodes or markers.
  • 상세 (Detail) — adds timecodes, low-confidence words (amber), and speaker-overlap markers (⟨+name 겹침⟩).

Reviewing and editing happen in the 상세 (Detail) view.

Editing a line

  1. Double-click the line you want to fix (or press the pencil button in 상세 view, tooltip "이 문장 편집" / Edit this line).
  2. Double-clicking from 내용 view switches to 상세 automatically and opens the editor.
  3. Fix the text and press 저장 (Save, ⌘↩). To back out, press 취소 (Cancel, Esc).
  4. Edited lines are marked 편집됨 (Edited).

When you edit the source, any translation still being generated from the old text is discarded and re-run against your corrected text. Late-arriving AI results never overwrite your correction.

Correcting translations

Double-click a finalized translation to open a 번역 교정 (Translation correction) field and fix that language's translation directly.

  • Saved translations get a pencil mark, and the other languages in a multi-target translation are left alone.
  • Corrected source text, translations and speaker names are saved into Markdown and JSON, and translations survive reopening a Markdown transcript.
  • SRT/VTT always use the final corrected source text.

검토 필요 (Needs review) — sweep low-confidence words

The 상세 view highlights words recognized below the confidence threshold (default 0.55) in amber.

  1. The bar at the top shows 검토 필요 N개 (N words need review) and your position (N/total).
  2. Use ∧ (previous flagged word) and ∨ (next flagged word) to jump between them.
  3. Check each one and fix it in place if needed.

Adjust the threshold under 설정 (⌘,) → 저장 → 음성 인식 (Settings → Save → Speech recognition), 저신뢰 표시 기준 (VAD). Raising it flags more words.

Review by ear

On file transcriptions, Madi can play back the audio for each flagged word so you can check it by ear.

  1. Press the play button in the review bar (tooltip "저신뢰 단어 귀로 검토" / Review low-confidence words by ear).
  2. The flagged words play in order, advancing automatically — hands-free. Progress shows as 재생 N/total (Playing N/total).
  3. Press the same button again to stop (tooltip "귀로 검토 멈춤" / Stop review by ear).
Note: Review by ear works only on file transcriptions, where the original media exists. Live mic recordings have no source file, so it doesn't appear.

AI correction (after recording)

When recording ends, the on-device LLM reads the whole conversation and conservatively fixes obvious speaker mis-splits and lines transcribed in the wrong language.

  • Turn it on: 설정 (⌘,) → 번역 → AI 교정 (세션 종료 후) → 화자·언어 자동 교정.
  • When applied, a note appears above the transcript with a 화자 교정 되돌리기 (Undo speaker correction) button — one click reverts all of it.
  • Requires the hardware-selected DNA3.0 translation model.

Personal glossary — learning from your corrections

When you fix a line, Madi learns that correction. With the 단어장 (Glossary) switch on, it automatically fixes the same domain term or name in later meetings.

Turn it on: 설정 (⌘,) → 단어장 (Settings → Glossary), switch 학습한 교정 자동 적용 (Auto-apply learned corrections).

Note: Learning happens always, regardless of the switch — the switch only controls applying. So turning it on immediately applies everything learned so far.

Confidence threshold (minimum hits)

  • The 최소 확인 횟수 (Minimum hits) slider sets how many times the same correction must be seen before it's trusted and auto-applied (1–5).
  • Higher is more conservative — it stops one accidental edit from overwriting later transcripts.

Managing learned corrections

Manage the learned rules in the list under 설정 → 단어장.

  • Each rule shows as wrong word → right word with its hit count.
  • The trash button next to a rule forgets just that one.
  • 전체 지우기 (Clear all) wipes them all.

Selecting and copying text

You can drag-select across the whole transcript and copy with ⌘C.

System dictation (coming later)

In the works — not included in the current beta. The following describes a planned feature. In this version there is no 받아쓰기 (Dictation) tab in Settings and the hotkey does nothing.

System dictation is a planned voice-input feature for anywhere in macOS. The goal: hold a global hotkey, speak, release — and what you said is turned into text on-device and inserted into whatever app is frontmost (Notes, Mail, Slack, your code editor). Like meeting transcription and translation, it's designed to run 100% on-device.

Planned behavior

  • Push-to-talk — records only while the global hotkey is held; releasing inserts the text.
  • Light and fast — no large language model; a short dictation-only recognition pass that shuts down when done, so it stays light even on low-memory Macs.
  • Clipboard preserved — saves your clipboard before inserting and restores it right after.
  • Disabled while recording a meeting — dictation and meeting recording share the mic, so it's off during recording to avoid conflicts.

For now

What you can use today is meeting transcription, speaker separation, on-device translation, review & correction, and AI summary. System dictation is planned for a later update. Check for updates via Madi menu → 업데이트 설치… (Install update…).

번역 반응 (실시간) — Live translation response

8 GB Mac guide

Madi opens this document once when it detects an 8 GB-class Mac. Reopen it any time from Help → 8 GB Mac Guide.

The low-memory profile Madi applies automatically

No manual tuning is required.

  • DNA3.0-2B translation model — Madi selects 2B instead of 4B. The download is about 1.31 GB and the measured engine process footprint is about 2.4 GB (53% below the measured 5.1 GB 4B process).
  • Committed captions first — finalized transcript lines translate before disposable in-progress previews.
  • Queue coalescing — when recognition revises a line, the stale translation request is replaced by the newest text.
  • Four-turn live horizon — the screen follows current speech; shed committed lines are translated again after recording stops.
  • Low-memory Whisper path — Madi does not retain the large encoder cache, reducing memory pressure and swap.

This profile does not hide the model tradeoff. The smaller 2B model can choose less accurate wording on difficult sentences. Madi detects source echoes, visibly wrong scripts, leaked <think> framing, and runaway repetition, retries once, and suppresses a still-invalid translation rather than displaying it as correct.

Recommended live-interpreting setup

  1. Select one output language whenever possible.
  2. For face-to-face interpreting, enable Korean plus one counterpart language. Each line then has only one effective target.
  3. Start with Normal (7 s). Use Accurate (10 s) when clean source boundaries matter more than immediacy.
  4. During long sessions, close memory-heavy browser tabs, large IDEs, and other local LLMs.
  5. “Translating · N lines queued” does not mean the engine is stuck. Final captions are running first and stale preview work is being discarded.

What to expect

  • Transcription and speaker separation alone never download or launch the translation model.
  • The first use of translation, summary, or AI correction downloads the 8 GB 2B model once.
  • An older finalized line can appear late during live translation, but Madi retries deferred durable lines after recording stops.
  • Under severe memory pressure, macOS swap can slow transcription and translation together. Reduce output languages and other apps' memory use first.

If something looks wrong

  • In Settings (⌘,) → Translation, confirm that DNA3.0-2B · ~1.3 GB is shown.
  • If it is not installed, use Download translation model on that screen.
  • Transcription and speaker separation should continue to work without translation.
  • Use the Help manual and update screen to confirm the installed Madi version.
Everything runs on this Mac — transcripts, translation and summaries never leave the device.

はじめに

Madi へようこそ。Madi は会議をすべてこの Mac の中で文字起こしし、翻訳するアプリです。リアルタイムの文字起こし、音声・動画ファイルの文字起こし、話者分離、オンデバイス翻訳まで — すべての処理があなた自身の Mac の中で行われます。

Madi でできること

  • リアルタイム文字起こし — マイクや会議の音声を聞き取り、話し終わるとほぼ同時に画面へ文字が表示されます。
  • ファイル・動画の文字起こし — 録音ファイルや動画をドロップすると、Madi が会話全体を書き起こします。
  • 話者分離 — 誰がいつ話したかを聞き分け、名前を付けられます。
  • オンデバイス翻訳 — 韓国語・英語・日本語・中国語をリアルタイムで翻訳し、任意のウィンドウの上に字幕として重ねて表示できます。
  • AI 要約・質疑応答 — 会議が終わると要約・決定事項・アクションを整理し、その内容について自然言語で質問できます。
  • レビューと修正 — 聞き取りに自信のない単語を見つけて修正でき、修正した内容を記憶して次回に活かします。
  • システムディクテーション（音声入力） (今後提供予定) — どのアプリでもキーを押しながら話すと、その言葉がテキスト欄に入力される機能を準備中です。

100% オンデバイス — データがこの Mac を離れることはありません

Madi の中心的な約束は主権（sovereignty）です。音声も、文字起こしも、翻訳も、クラウドへ送信されることは一切ありません。モデルをダウンロードした後は、インターネットに接続していなくても動作します。会議の内容はあなたのデバイスの中だけに存在します。

モデルについて

Madi は 2 種類の AI モデルを使用します。

  • Whisper 音声モデル（約 867 MB） — 文字起こしを担当します。標準 DMG では初回起動時に一度ダウンロードします。
  • DNA3.0 言語モデル — 翻訳、AI 修正、要約・質疑応答に使われます。8 GB Mac では 2B（約 1.31 GB）、16 GB 以上では品質優先の 4B（約 2.78 GB）を自動選択し、初めて使うときにダウンロードします。
    • 入手先: 設定（⌘,）→ 翻訳の「翻訳モデルをダウンロード」ボタン。
    • 選択されたモデルだけをダウンロードし、同じだけのディスク容量が必要です。

翻訳・要約・質疑応答を使わないのであれば、このモデルは不要です。文字起こしと話者分離は、同梱の Whisper モデルだけで完全に動作します。

メモリについて（正直なところ）

  • 8 GB の Mac（例: M1 MacBook Air） — DNA3.0-2B と最大 4 ターンの翻訳待機を自動適用します。翻訳エンジンの実測物理メモリは約 2.4 GB です。
  • 16 GB 以上 — 翻訳品質を優先して DNA3.0-4B を使います（実測約 5.1 GB）。
  • リアルタイムプレビューは確定文字起こしと同じ Whisper プロセスを共有し、2 個目の 830 MB モデルを起動しません。

Madi が求めることのある権限

Madi は必要な権限を最初にまとめて求めることはせず、その機能を初めて使うときに必要なものだけを要求します。

  • マイク — 録音のため。初めて録音を開始するときに要求します。
  • 画面収録の許可 — システム音声（Mac で再生される音、例: Zoom・Teams・YouTube）を取り込むときのみ。macOS が音声キャプチャを画面収録の許可に含めているためであり、Madi が画面を記録することはありません。

    • （アクセシビリティの権限はシステムディクテーション（音声入力）（今後提供予定）にのみ必要で、現在のベータ版では要求しません。）

権限を拒否した後で有効にしたい場合は、システム設定 → プライバシーとセキュリティを開き、該当項目（マイク / 画面収録）で Madi をオンにしてください。

初回起動クイックスタート

  1. Madi を開きます。最初の画面には会議情報とはじめるの 2 つの列があります。
  2. 会議情報で、この会議に合わせて設定しておきます — 入力言語、（翻訳する場合は）出力言語、会議モード、話者数。
  3. はじめるでマイクを選び、今すぐ録音を開始を押すか、音声・動画ファイルをドロップします。
  4. ウィンドウ中央にリアルタイムの文字起こしが表示されるのを確認します。
  5. 停止を押して終了します。自動保存がオンの場合、文字起こしはファイルに保存されます。
翻訳するには、まず設定（⌘,）→ 翻訳で Mac のメモリに合わせて選択されたモデルをダウンロードしてください。8 GB Mac では専用ガイドが最初の一度だけ自動的に開きます。

ウィンドウの構成

録音を開始すると、ウィンドウは 3 つの列に分かれます。

  • 左 — セッションパネル: 録音ボタン（一時停止・停止）、合計時間、話者バー、エネルギーフローのグラフ。設定（歯車）もここにあります。
  • 中央 — 文字起こし: 話された内容。ここで読んだり編集したりします。
  • 右 — ワークスペースエクスプローラー: 過去の会議、自動保存スイッチ、保存フォルダ、エクスポート。

02

録音と文字起こし

Madi は会議の音声を人が話すそばからリアルタイムで文字起こしし、すでにお持ちの音声・動画ファイルも文字起こしできます。すべての処理はこの Mac の中で行われ、文字起こしの内容がデバイスを離れることはありません。

アプリのインターフェースは韓国語です。韓国語の UI ラベルには、以下では日本語の訳を括弧で添えています。

最初の画面 — 会議情報とはじめる

アプリを開くと、最初の画面が 2 つに分かれます。左側で これがどんな会議なのか を Madi に伝え、右側で 開始 します。

회의 정보（会議情報）— 左

録音を始める前にこれらを設定しておくと、結果の品質が向上します。録音中はロックされます。

  • 입력 언어（入力言語）— 話されている言語。自動検出するか、特定の言語に固定します。
  • 출력 언어（出力言語）— 翻訳先の言語（複数選択可）。翻訳モデルが必要です。リアルタイム翻訳を参照してください。
  • 회의 모드（会議モード）— 会議の性格。下記を参照してください。
  • 화자（話者）— 部屋にいる人数。下記を参照してください。

시작하기（はじめる）— 右

  • 파일로 시작하기（ファイルから開始）— ファイルを選ぶかドロップした後に押します。
  • 지금 녹음 시작（今すぐ録音を開始）— マイクを選んですぐに録音します。

リアルタイムのマイク録音

  1. 시작하기（はじめる）でマイクを選びます（初期設定は「시스템 기본」/ システム標準）。
  2. 지금 녹음 시작（今すぐ録音を開始）を押します。録音が始まる前に短いカウントダウンが流れ、その間にキャンセルできます。
  3. 話し始めると、ウィンドウ中央に文字起こしがリアルタイムで流れます。
  4. 左パネルの 일시 정지（一時停止、⌘P）で一時停止し、정지（停止、⌘R）で終了します。

参考

  • 停止すると、そこまでに取り込んだ内容がまとめられます。自動保存がオンの場合、ファイルに保存されます。
  • 自動保存がオフの場合、終了する前に Madi が確認を表示します — 내보내기（エクスポート）で先に保存できます。

에너지 흐름（エネルギーフロー）

左パネル下部の 에너지 흐름 グラフは、会議の雰囲気を 1 本の線で示します — 発言の速さ・重なり・沈黙を総合した流れです。

  • グラフ上の一点をクリックすると、その箇所へ移動します。 会議で最も盛り上がった場面をすぐに探し出すのに便利です。
  • 十分な発言がたまる前は「발언이 쌓이면 흐름이 표시됩니다」（発言がたまると流れが表示されます）と案内されます。

録音中のマイク切り替え

録音中は、左パネルの 입력 마이크（入力マイク）の行で、録音を中断せずにマイクを切り替えられます — 会議の途中でヘッドセットを接続したときに便利です。

話し終わるとすぐに字幕が表示されます

Madi は 1 つの区間（ウィンドウ）がいっぱいになるのを待ちません。話を止めて少しの間静かになると、Madi はその区間を早めに区切り、文字起こしをすぐに送り出します — 短くやり取りする会話（例: 診療相談）では待ち時間が大きく減ります。遠くから入ってくる小さな声が途切れないよう、しきい値は自動で調整されます。

システム音声のキャプチャ（Zoom・Teams・動画）

Mac で再生されている音声（オンライン会議、動画など）をそのまま文字起こしできます。

  1. 설정 → 녹음 → 입력（設定 → 録音 → 入力）へ進みます。
  2. 음원（音源）で、音声の取り込み方法を選びます。
    • 마이크（マイク）— 目の前の音だけ
    • 시스템 오디오（システム音声）— Mac で再生されている音: Zoom・Teams・Slack・YouTube など
    • 마이크+시스템（マイク＋システム）— オンライン会議向け: 自分の声と相手の声を一緒に
  3. いつものように録音を開始します。

参考

  • システム音声を初めて使うとき、macOS が画面収録の許可を求めます。使用されるのは音声のみで、画面が保存されることはありません。

ファイルと動画の文字起こし

  1. ファイルをウィンドウにドロップするか、파일 선택 or 드래그 앤 드롭（ファイル選択 or ドラッグ＆ドロップ）の領域をクリックして選びます。ドラッグ中は 드롭하여 전사（ドロップして文字起こし）と表示されます。
  2. 파일로 시작하기（ファイルから開始）を押します。
  3. 進行状況が 전사 중 · N%（文字起こし中 · N%）と表示されます。
  4. 完了すると、結果が画面に表示されます。

参考

  • ファイルを置いただけでは文字起こしは始まりません — 파일로 시작하기 を押す必要があります。その間に会議情報を先に調整できます。
  • 動画（mp4・mov・m4v・mkv・webm・avi など）から音声は自動的に抽出されます。別途の変換は不要です。
  • ファイルの文字起こしでのみ使える機能が 2 つあります — 行単位の音声再生と耳で確認です。レビューと修正およびワークスペースとエクスポートを参照してください。

회의 모드（会議モード）

会議の性格に合わせて、話者数と強調する項目を一括で調整するプリセットです。最初の画面の 회의 정보 → 회의 모드（会議情報 → 会議モード）で選びます。

モード調整される項目
일반（一般）標準設定 · 話者を自動検出
1:1話者 2 名 · 決定事項とフォローアップを強調
스탠드업（スタンドアップ）話者は自動 · アクションとブロッカーを強調
인터뷰（面談）話者 2 名 · 質問と回答の流れを保持
강의（講義）話者 1 名 · 要点を中心に整理

参考

  • 会議モードは録音を始める前に選んでください。録音中はロックされます。

화자（話者数）

部屋にいる人数がわかっている場合は、設定すると話者分離が向上します。最初の画面の 회의 정보 → 화자（会議情報 → 話者）で、자동（自動）/ 1명 / 2명 / 3명 / 4명 이상（1 名 / 2 名 / 3 名 / 4 名以上）から選びます。

人数が確かなときに固定すると、話者の分かれ方がより正確になります。確信がない場合は 자동（自動）のままにしてください。詳しくは話者ページを参照してください。

文字起こし表示の切り替え

ウィンドウ上部のトグルで、2 つの表示を切り替えます。

  • 내용（内容）— すっきり読みやすい文字起こし。初期設定で、読むのに最適です。
  • 상세（詳細）— タイムコード、信頼度の低い単語（琥珀色でハイライト）、話者の重なり表示が加わります。確認・修正に最適です。

文字サイズは上部の A− / A+ ボタンで調整します。

プライバシー

Madi のすべての文字起こしは、この Mac の中で処理されます。文字起こしの内容がデバイスを離れることは決してありません。

03

話者

Madi は会議中に誰が話したかを自動的に判別します。これらの処理はすべてこの Mac の中で行われます。

アプリのインターフェースは韓国語です。韓国語の UI ラベルには、以下では日本語の訳を括弧で添えています。

自動話者分離

録音と文字起こしを行っている間、Madi は発言を話者ごとに自動的に分けます。

  • 各話者には固有の色と 화자 N（話者 N）ラベルが付きます。
  • 左パネルの話者バーが、会議全体で誰がいつ話したかを 1 行で示します。

参考

  • 話者分離は 설정 (⌘,) → 녹음 → 화자（設定 → 録音 → 話者）の 화자 분리（話者分離）スイッチでオフにできます。

話者数の固定

部屋にいる人数がわかっている場合は、設定すると精度が向上します。

  1. 最初の画面で 회의 정보 → 화자（会議情報 → 話者）へ進みます。
  2. 자동（自動）/ 1명 / 2명 / 3명 / 4명 이상（1 名 / 2 名 / 3 名 / 4 名以上）から選びます。

参考

  • 人数が確かなときに固定すると、話者の分かれ方がより正確になります。確信がない場合は 자동（自動）のままにしてください。
  • 録音を始める前に選んでください — 録音が始まるとロックされます。

미확인（未確認）話者

話者数を固定しているとき、指定した人物の誰とも明らかに一致しない声は、미확인（未確認）としてまとめられます。これにより、通りすがりの人の一言や突発的なノイズが、実際の話者の誰かに誤って割り当てられるのを防ぎます。

  • 미확인 は人物ではなく、「ここに入れる場所がない」ことを示します。名前を付けることはできません。
  • 人数を自動のままにしている場合は表示されません。

話者に名前を付ける

  1. 文字起こしで、話者ラベル（例: 화자 1 / 話者 1）または話者チップをクリックします。
  2. 이름 (예: 김부장)（名前、例: キム部長）の欄に実際の名前を入力します。
  3. 저장（保存）を押します。入力した名前は、その話者のすべての発言とエクスポートに適用されます。

参考

  • 名前はこの文字起こしにのみ適用されます。Madi が次の会議で同じ人物を自動的に認識することはありません — 会議ごとに付け直します。
  • 미확인（未確認）には名前を付けられません。

AI 話者修正（録音終了後）

録音が終わると、オンデバイスの LLM が会話を読み取り、明らかな話者の誤分離を控えめに修正します — 1 人の発言が 2 人の話者に分かれてしまった場合や、ある行が別の人物に割り当てられてしまった場合を整理します。

  • 설정 (⌘,) → 번역 → AI 교정 (세션 종료 후)（設定 → 翻訳 → AI 修正（セッション終了後））の 화자·언어 자동 교정（話者・言語の自動修正）でオン・オフを切り替えます。
  • 修正が適用されると、文字起こしの上に案内が表示され、화자 교정 되돌리기（話者修正を元に戻す）ボタンが付きます — 1 回のクリックですべて元に戻せます。
  • ハードウェアに合わせて選択された DNA3.0 翻訳モデルが必要です。

発言の重なりマーカー

2 人が同時に話すと、상세（詳細）表示に ⟨+name 겹침⟩（重なり）マーカーが現れ、割り込んだ 2 人目の話者を示します。

参考

  • 重なりマーカーは 상세（詳細）表示でのみ表示されます。ウィンドウ上部で 내용 → 상세（内容 → 詳細）に切り替えてください。
  • 설정 (⌘,) → 녹음 → 화자（設定 → 録音 → 話者）の 중첩 발화 감지（重なり発話の検出）が有効になっている必要があります。
04

リアルタイム翻訳・通訳

Madi の翻訳は 100% お使いのデバイス上で動作します — クラウドもアカウントも不要です。会議の進行中、話された各行を韓国語・英語・日本語・中国語に翻訳し、原文のすぐ下に表示します。8 GB Mac では DNA3.0-2B、16 GB 以上では DNA3.0-4B を自動的に使用します。

アプリのインターフェースは韓国語です。韓国語の UI ラベルには、以下では日本語の訳を括弧で添えています。

まず：翻訳モデルをダウンロード

翻訳には別途モデルが必要で、アプリには同梱されていません。8 GB Mac では DNA3.0-2B（約 1.31 GB）、16 GB 以上では DNA3.0-4B（約 2.78 GB）を最初に一度だけダウンロードします。

  1. 설정 (⌘,) → 번역（設定 → 翻訳）を開きます。
  2. 번역 모델 다운로드（翻訳モデルをダウンロード）を押します。
  3. 完了すると、翻訳のオプションが使えるようになります。

エンジンプロセスの実測物理メモリは、2B が約 2.4 GB、4B が約 5.1 GB です。モデルをインストールする前はトグルが無効で、「번역 모델을 먼저 다운로드하세요.」（先に翻訳モデルをダウンロードしてください。）と表示されます。

번역 タブが表示されない場合 — お使いのビルドには翻訳エンジンが含まれておらず、翻訳機能自体を利用できません。

出力言語を選ぶ

設定は 2 か所にありますが、内容は同じです。使いやすいほうをどうぞ。

  • 첫 화면 → 회의 정보 → 출력 언어（最初の画面 → 会議情報 → 出力言語）— 会議を始めるときに。
  • 설정 (⌘,) → 번역 → 실시간 번역 (다중 대상)（設定 → 翻訳 → リアルタイム翻訳・複数ターゲット）— 한국어 / English / 日本語 / 中文 のトグル。

選んだすべての言語に各行を同時に翻訳し、原文のすぐ下に表示します。それぞれに言語タグが付きます。原文と同じ言語は自動的に除外されます。

参考

  • 出力言語は 最大 3 つ まで選べます。
  • 翻訳モデルがないと、出力言語はまったく選べません。

翻訳はタイプされるように表示されます

Madi は翻訳が完成するまで待ちません。単語は生成されるそばから画面に表示されていきます。まだ書いている途中の行末にはカーソル ▍ が点滅し、途中で切れたのではなく続いていることが分かります。

誰かがまだ話している間は、まず暫定的な翻訳が表示され、진행 중（進行中）と示されます。その行が確定すると、暫定訳はなめらかに確定訳へと切り替わります。確定訳が届くまで暫定訳は画面に残るため、翻訳が一瞬消える空白は生じません。

対面通訳 — 双方向

Madi は、同じ部屋で異なる言語を話す 2 人（例: 韓国人スタッフと日本人・中国人の来訪者）のために設計されています。

한국어 ともう 1 つの言語だけ を有効にすると（例: 한국어 + 일본어）、双方向通訳モードになります。

  • 方向は行ごとに判定されます。 日本語の行は韓国語にだけ、韓国語の行は日本語にだけ翻訳します。無駄がないぶん、より高速です。
  • 言語を交互に話しても、両方が正しく文字起こしされます。 セグメントごとに言語を再確認するため、一方が韓国語・もう一方が日本語で話しても、それぞれの発言が正確に書き起こされます。
  • この組み合わせは、後述の応答速度の下限の対象外です。

よく使うフレーズ辞書（即時翻訳）

同じ案内を繰り返す現場（例: 診察室での処置後の注意事項）向けに、よく使うフレーズの翻訳をあらかじめ登録しておけます。登録したフレーズと同じ言葉が出てくると、モデルを通さずに 即時（0 秒） で翻訳が表示されます。

いくつかのフレーズが最初から入っており、自分で追加・編集できます。

  • ファイル: ~/Library/Application Support/Sovereign/faq_translations.json
  • 安全のため、完全に一致 したときだけ動作します。

応答速度と翻訳品質

出力言語を 2 つ以上 にすると、原文の行の区切りの誤りがすべての言語に波及してしまうため、応答速度は下限の 보통 (7초)（標準 7 秒）まで下がります。빠름 (5초)（高速 5 秒）を選んでいた場合は、自動的に 7 秒になります。정확 (10초)（正確 10 秒）はそのまま使えます。

例外： 双方向 モード（한국어 + 他の言語ちょうど 1 つだけ）は強制されません。各行の実質的な翻訳対象が 1 つに減るためです。対面通訳では字幕がより速く表示されます。

翻訳が遅れると、「번역 중 · N줄 대기」（翻訳中・N 行待機）と表示されます。停止しているわけではありません。確定行を暫定プレビューより先に処理し、同じ行の古い要求は最新の文章に統合します。8 GB プロファイルはライブ待機を最大 4 ターンに制限し、後回しになった確定行は録音終了後に補完します。

AI 言語修正（録音終了後）

録音が終わると、オンデバイスの LLM が会話を読み取り、誤った言語で文字起こしされた行 を控えめに修正します。설정 (⌘,) → 번역 → AI 교정 (세션 종료 후)（設定 → 翻訳 → AI 修正（セッション終了後））の 화자·언어 자동 교정（話者・言語の自動修正）で切り替えます。話者 を参照してください。

字幕オーバーレイ

字幕オーバーレイ は、すべての最前面に浮かぶリアルタイム翻訳字幕のウィンドウです。Zoom や Teams の通話画面の上や、診察室のディスプレイの上に置いて、相手の話をリアルタイムで追えます。

上部ツールバーの 吹き出しアイコン でオン・オフします。出力言語を 1 つ以上選んで初めて、このボタンが表示されます。

  • ウィンドウは常に最前面にとどまりますが、フォーカスを奪わないため、通話アプリでクリックや入力を続けられます。
  • フルスクリーンのアプリの上にも浮かび、背景をつかんで好きな場所へドラッグできます。
  • いちばん大きな文字が翻訳文、その下の小さな文字が原文です。
  • 複数人いるときは、字幕にも 話者の色と名前 が付き、誰の発言か分かります。
  • 発話を待っている間は マイク入力レベルのバー が動き、システムが聞き取り中であることを知らせます。
  • ステータス文（「진행 중 / 번역 중… / 음성을 기다리는 중…」）は 見る人の言語で 表示されます — 日本語字幕なら「翻訳中…」、中国語字幕なら「翻译中…」。

スタッフ字幕 + 患者字幕（デュアル表示）

診察室での通訳では、字幕を 2 つ のパネルに分けられます。

  • スタッフ字幕 — メイン画面に小さく、スタッフの言語で。
  • 患者字幕 — 外部モニターに大きく、離れた位置から読めるように、患者の言語で。

설정 (⌘,) → 녹음 → 자막 오버레이 (진료실)（設定 → 録音 → 字幕オーバーレイ（診察室））でオンにします。スタッフの文字サイズ（14–48 pt）、患者の文字サイズ（24–96 pt）、使用するディスプレイ、患者の言語を設定できます。大きなサイズは、診察チェアとディスプレイの間の 1.5–2.5 m の距離でも読みやすいように設計されています。

05

AI 要約・質疑応答

文字起こしが終わると、オンデバイスの LLM が会議を構造化された要約にまとめ、その内容について自然言語で質問できます。要約と質疑応答は翻訳と同じハードウェア向けモデル（8 GB は DNA3.0-2B、16 GB 以上は 4B）を使い、文字起こしの内容も要約も、この Mac から外に出ることはありません。

アプリのインターフェースは韓国語です。韓国語の UI ラベルには、以下では日本語の訳を括弧で添えています。

まず：翻訳・要約モデル

要約と質疑応答は、翻訳と同じオンデバイスモデルを使います。これがないと、要約ボタンが表示されません。 ダウンロード方法は リアルタイム翻訳・通訳 または 設定 のページを参照してください。

会議の要約を作成する

  1. 文字起こしが終わったあと（録音中はできません）、上部ツールバーの ✦（キラキラ）ボタン を押します。または ⌘K のコマンドパレットから 요약 생성（要約を生成）を選びます。
  2. 회의 요약（会議の要約）シートが開き、ローカル LLM が要約を生成します。「文字起こしの内容はこの Mac から外に出ません」という案内も表示されます。
  3. 上部の 전체 / 화자별（全体 / 話者別）トグルで表示を切り替えます。
    • 전체（全体）— 会議全体の要約・アクション項目・決定事項。
    • 화자별（話者別）— 各話者が何について話したか（最初に選んだときに生成されます）。

参考

  • ✦ ボタンは、文字起こしがあり、録音中でないときだけ有効になります。文字起こしが空のときは淡色表示になります。

要約シートのボタン

  • 복사（コピー）— 要約テキストをクリップボードにコピーします。
  • 다시 생성（再生成）— 同じ文字起こしから要約を新しく生成します。
  • 슬라이드(HTML)（スライド（HTML））— オフラインで開ける HTML スライドを書き出し、Finder で表示します。
  • 리캡 카드（リキャップカード）— 共有できる 1 ページの要約を開きます（下記参照）。
  • 내보내기…（エクスポート…）— 要約を .md ファイルとして保存します。

リキャップカード

会議を 1 ページにまとめた、共有用の要約です。要約シートの 리캡 카드（リキャップカード）で開きます。次の内容が入っています。

  • タイトル + 日付
  • TL;DR（要点）
  • 決定事項のリスト
  • 担当者別のアクション項目
  • 話者ごとの発話時間
  • 一行の引用

복사（コピー）で Markdown としてコピーするか、내보내기…（エクスポート…）でファイルとして保存できます。

議事録に質問（質疑応答）

会議の内容を自然言語で質問すると、ローカル LLM が文字起こしを根拠に答えます。要約シートの下部にあります。

  1. 회의록에 물어보기（議事録に質問）欄に質問を入力します。例:「무엇을 결정했나요?」（何を決めましたか？）、「김부장이 맡은 일은?」（キム部長の担当は？）。
  2. 紙飛行機ボタンを押すか、Enter を押します。
  3. 이 회의 / 전체 워크스페이스（この会議 / ワークスペース全体）トグルで範囲を決めます。
    • 이 회의（この会議）— いま開いている文字起こしからのみ回答します。
    • 전체 워크스페이스（ワークスペース全体）— 保存された すべての 文字起こしを横断して検索します。例:「지난달 보안 결정은?」（先月のセキュリティに関する決定は？）。

参考

  • 回答中は「로컬 LLM이 답하는 중…」（ローカル LLM が回答中…）と表示されます。

プライバシー

要約も質疑応答も、この Mac 上で動作します。文字起こしの内容も要約も、この端末から外に出ることはありません。

06

確認と修正

文字起こしが終わったら、きれいに読むことも、細かく見て修正することもできます。Madi はあなたが行った修正を記憶し、次の会議で自動的に適用します。

アプリのインターフェースは韓国語です。韓国語の UI ラベルには、以下では日本語の訳を括弧で添えています。

내용（内容）と 상세（詳細）の表示

ウィンドウ上部の切り替えスイッチで、2 つの表示を行き来します。

  • 내용（内容）— タイムコードやマーカーのない、すっきりした表示。
  • 상세（詳細）— タイムコード、低信頼度の単語（琥珀色）、話者の重なりマーカー（⟨+name 겹침⟩）を追加します。

確認と編集は 상세（詳細）表示で行います。

行を編集する

  1. 修正したい行を ダブルクリック します（または 상세（詳細）表示で鉛筆ボタン。ツールチップは 「이 문장 편집」（この文を編集））。
  2. 내용（内容）表示からダブルクリックすると、自動的に 상세（詳細）表示に切り替わり、エディターが開きます。
  3. テキストを修正して 저장（保存、⌘↩）を押します。取り消すには 취소（キャンセル、Esc）。
  4. 編集した行には 편집됨（編集済み）マークが付きます。

原文を編集すると、古いテキストから生成中だった翻訳は破棄され、修正後のテキストで再実行されます。遅れて届いた AI の結果が、あなたの修正を上書きすることはありません。

翻訳文を修正する

確定した翻訳を ダブルクリック すると、번역 교정（翻訳の修正）欄が開き、その言語の翻訳を直接修正できます。

  • 保存した翻訳には鉛筆マークが付き、複数ターゲット翻訳の他の言語はそのまま保たれます。
  • 修正した原文・翻訳・話者名は Markdown と JSON に保存され、Markdown の文字起こしを開き直しても翻訳は保持されます。
  • SRT/VTT は常に、最終的に修正された原文を使います。

검토 필요（要確認）— 低信頼度の単語をまとめて確認

상세（詳細）表示は、信頼度のしきい値（既定 0.55）を下回って認識された単語を琥珀色で強調します。

  1. 上部のバーに 검토 필요 N개（要確認 N 件）と、現在位置（N/全体）が表示されます。
  2. ∧（前の要確認単語）と ∨（次の要確認単語）で、単語間を移動します。
  3. 一つずつ確認し、必要ならその場で修正します。

しきい値は 설정 (⌘,) → 저장 → 음성 인식（設定 → 保存 → 音声認識）の 저신뢰 표시 기준 (VAD)（低信頼度のしきい値（VAD））で調整します。値を上げると、より多くの単語が要確認になります。

耳で確認する

ファイルから文字起こししたセッションでは、Madi が要確認の各単語の音声を再生するので、耳で確認できます。

  1. 確認バーの再生ボタン（ツールチップ 「저신뢰 단어 귀로 검토」（低信頼度の単語を耳で確認））を押します。
  2. 要確認の単語が順に再生され、自動的に次へ進みます（ハンズフリー）。進行状況は 재생 N/전체（再生 N/全体）と表示されます。
  3. もう一度同じボタンを押すと停止します（ツールチップ 「귀로 검토 멈춤」（耳での確認を停止））。
注記： 耳で確認できるのは、元のメディアが存在する ファイル文字起こしのときだけ です。リアルタイムのマイク録音には元ファイルがないため、表示されません。

AI 修正（録音終了後）

録音が終わると、オンデバイスの LLM が会話全体を読み取り、明らかな話者の誤分割 と 誤った言語で文字起こしされた行 を控えめに修正します。

  • オンにする： 설정 (⌘,) → 번역 → AI 교정 (세션 종료 후)（設定 → 翻訳 → AI 修正（セッション終了後））の 화자·언어 자동 교정（話者・言語の自動修正）。
  • 修正が適用されると、文字起こしの上に案内が表示され、화자 교정 되돌리기（話者修正を元に戻す）ボタンが付きます — 1 回のクリックですべて元に戻せます。
  • ハードウェアに合わせて選択された DNA3.0 翻訳モデルが必要です。

個人用語集 — あなたの修正から学習する

文字起こしの 1 行を修正すると、Madi はその修正を学習します。단어장（用語集）スイッチをオンにしておくと、次の会議で同じ専門用語や名前の誤認識を自動的に修正します。

オンにする： 설정 (⌘,) → 단어장（設定 → 用語集）タブで、학습한 교정 자동 적용（学習した修正の自動適用）をオンにします。

注記： 学習はスイッチに関係なく 常に 行われ、このスイッチが切り替えるのは 適用 だけです。そのためオンにすると、それまでに学習した内容がただちに適用されます。

自動適用の基準（最小確認回数）

  • 최소 확인 횟수（最小確認回数）スライダーで、同じ修正を何回確認したら信頼して自動適用するか（1–5 回）を設定します。
  • 値が大きいほど控えめになります — 偶発的な編集 1 回が、あとの文字起こしを上書きしてしまうのを防ぎます。

学習した修正の管理

설정 → 단어장（設定 → 用語集）タブの一覧で、学習したルールを管理します。

  • 各ルールは 誤った単語 → 正しい単語 のように、確認回数とともに表示されます。
  • ルールの隣のゴミ箱ボタンで、そのルールだけを忘れさせます。
  • 전체 지우기（すべて削除）で、すべて消去します。

テキストの選択とコピー

文字起こし全体をドラッグで選択し、⌘C でコピーできます。

会議一覧

システムディクテーション（音声入力・今後提供予定）

準備中 — 現在のベータには含まれていません。 以下は今後提供予定の機能の紹介です。このバージョンでは設定に 받아쓰기（ディクテーション）タブがなく、ショートカットキーも動作しません。

システムディクテーション（音声入力）は、macOS のどこでも使える音声入力機能として準備を進めています。グローバルショートカットキーを押したまま話し、離すと、話した内容がデバイス上で文字に変換され、そのとき最前面にあるアプリ（メモ、メール、Slack、コードエディタなど）の入力欄にそのまま入力される — これが目標です。会議の文字起こし・翻訳と同様に、100% オンデバイスで動作するように設計しています。

予定している動作

  • プッシュトゥトーク — グローバルショートカットキーを押している間だけ録音し、離した瞬間に書き取ったテキストが入力されます。
  • 軽快で高速 — 大規模言語モデルを読み込まず、ディクテーション専用の音声認識だけを短時間実行して終了する方式のため、メモリの少ない Mac でも負担が少なくて済みます。
  • クリップボードの保持 — テキストを入力する際に既存のクリップボードを保存し、直後に元へ戻します。
  • 会議の録音中は無効 — ディクテーションと会議の録音は同じマイクを使うため、競合を防ぐために録音中はオフになります。

現時点では

現在のバージョンで使える機能は、会議の文字起こし・話者分離・オンデバイス翻訳・レビューと修正・AI 要約です。システムディクテーションは今後のアップデートで提供予定です。アップデートの確認は Madi メニュー → 업데이트 설치…（アップデートをインストール…）から行えます。

設定

設定は ⌘,（Command + カンマ） で開きます（左パネルの歯車ボタンでも同じです）。ここには、会議のたびに操作するものではなく、「一度だけ決めておく」 項目がまとまっています。ウィンドウ上部のタブで 녹음 · 저장 · 번역 · 단어장 · 모델（録音 · 保存 · 翻訳 · 用語集 · モデル）を切り替えます。

アプリのインターフェースは韓国語です。韓国語の UI ラベルには、以下では日本語の訳を括弧で添えています。
会議ごとに変わる項目（入力・出力言語、会議モード、話者数）は設定ではなく、最初の画面の 회의 정보（会議情報）にあります。録音と文字起こしを参照してください。
参考： 녹음（録音）タブの設定は、録音中・一時停止中はロックされます。変更するには録音を停止してから操作してください。

녹음（録音）

音源の取り込み方法、リアルタイム動作、画面表示を設定します。

입력（入力）

  • 음원（音源）— 何を聞き取るかを選びます。
    • 마이크（マイク）— 自分の声 / 対面の会議。
    • 시스템 오디오（システム音声）— Mac で再生されている音（Zoom・Teams・Slack・YouTube など）。初回使用時に「画面収録」の権限を要求します（音声のみ。画面は保存されません）。
    • 마이크+시스템（マイク＋システム）— オンライン会議（自分の声＋相手の声）に適しています。
  • 마이크（マイク）— （音源が 마이크 または 마이크+시스템 のとき）使用する入力デバイス。初期設定は「시스템 기본」（システム標準）です。
  • 언어（言語）— 자동 감지（自動検出）/ 한국어 / English から、文字起こしの言語を固定するか自動にします。

화자（話者）

  • 화자 분리（話者分離）— 誰が話したかを話者ごとに区別します。
  • 중첩 발화 감지（重なり発話の検出）— 2 人が同時に話す区間を検出します（詳細表示の重なりマーカー）。

실시간（リアルタイム）

  • 반응 속도（応答速度）— 빠름 (5초) / 보통 (7초) / 정확 (10초)（高速 5 秒 / 標準 7 秒 / 正確 10 秒）。高速はテキストがより頻繁に表示され体感が速く、正確は文脈を長く見るため品質が高くなります。
    • 出力言語が 2 つ以上の場合は、最低でも 보통 (7초)（標準 7 秒）まで下がります — 高速を選んでいても自動的に 7 秒になります。ただし、한국어 と他の言語 1 つだけを有効にした双方向通訳は例外です。
  • 실시간 프리뷰（リアルタイムプレビュー）— 区間が確定する前に、途中のテキストをグレーで先に表示します。確定文字起こしと同じ Whisper プロセスを共有し、2 個目のモデルは起動しません。

표시（表示）

  • 외관（外観）— システム / ライト / ダークのテーマを選びます。

자막 오버레이 (진료실)（字幕オーバーレイ — 診察室）

対面通訳用の字幕ウィンドウのサイズと、2 番目（患者用）の画面を設定します。リアルタイム翻訳を参照してください。

  • 직원 자막 크기（スタッフ字幕サイズ）— メイン画面の字幕文字（14–48 pt）。
  • 환자용 대형 자막 (별도 화면)（患者用の大型字幕 — 別画面）— 2 つ目のパネルを患者の言語で、離れた場所からでも読める大きな文字で表示します。オンにすると、以下の項目が現れます。
    • 환자 자막 크기（患者字幕サイズ）— 24–96 pt。
    • 환자 화면（患者画面）— モニターが 2 台以上あるとき、どの画面に表示するかを選びます。
    • 환자 언어（患者言語）— 自動（相手の言語）または特定の言語に固定。

저장（保存）

ファイルの保存と認識のしきい値を設定します。

자동 저장（自動保存）

  • 완료 시 .md 자동저장（完了時に .md を自動保存）— 文字起こしが終わると、Markdown ファイルとして自動保存します。
  • 폴더 / 변경…（フォルダ / 変更…）— 保存フォルダを指定します。このフォルダが、ワークスペースエクスプローラーに表示されるワークスペースです。
同じ設定は、ワークスペースエクスプローラーの下部にもあります。

음성 인식（音声認識）

  • 저신뢰 표시 기준 (VAD)（低信頼度のしきい値（VAD））— この信頼度（初期設定は 0.55）未満で認識された単語を 검토 필요（要確認）として表示します。範囲は 0.35–0.9 で、値を上げるとより多くの単語が対象になります。レビューと修正を参照してください。

번역（翻訳）

オンデバイス翻訳（韓国語・英語・日本語・中国語）のオン・オフを切り替える場所です。

翻訳エンジンを含まないビルドでは、このタブはまったく表示されません。

번역 모델（翻訳モデル：8 GB は DNA3.0-2B · 約 1.31 GB / 16 GB 以上は DNA3.0-4B · 約 2.78 GB）

  • 상태（状態）— 설치됨（インストール済み）/ 검증 중（検証中）/ ダウンロードの進捗率 / 미설치（未インストール）を表示します。
  • 번역 모델 다운로드（翻訳モデルをダウンロード）— この Mac に合わせて選択されたモデルを取得します。アプリには同梱されていません。エンジンプロセスの実測物理メモリは 2B が約 2.4 GB、4B が約 5.1 GB です。ダウンロード中は 취소（キャンセル）、インストール後は Finder에서 보기（Finder で表示）でファイルの場所を開けます。

실시간 번역 (다중 대상)（リアルタイム翻訳・複数ターゲット）

  • 한국어 / English / 日本語 / 中文 — トグルで対象言語を選びます（最大 3 つ）。選んだすべての言語に各行を同時に翻訳し、原文の下に表示します（原文の言語は自動的に除外されます）。
  • 先にモデルを取得する必要があります。対象が 2 つ以上の場合、応答速度は最低でも「보통 (7초)」（標準 7 秒）まで下がります（録音タブを参照）。

번역 반응 (실시간)（翻訳の応答・リアルタイム）

  • 마지막 줄 대기 (초)（最後の行を待つ（秒））— 話し終わった最後の行が変化しなくなってから、この時間（0.5–5.0 秒、初期設定は 3 秒）だけ待ってから翻訳します。短いほど字幕が早く表示されますが、未完成の文を翻訳してしまうことがあります。確定した（次の行が始まった）行は、この値に関係なく即座に翻訳され、文字起こし（STT）の応答速度とは別に動作します。

AI 교정 (세션 종료 후)（AI 修正・セッション終了後）

  • 화자·언어 자동 교정（話者・言語の自動修正）— 録音が終わると、オンデバイスの LLM が会話を読み取り、明らかな話者の誤分割や言語の誤った行を控えめに修正します。話者の修正は 1 回のクリックで元に戻せます。
  • ハードウェアに合わせて選択された DNA3.0 翻訳・要約モデルが必要です。

단어장（用語集・個人用語集）

よく誤認識される専門用語や名前をご自身で修正した内容を Madi が学習し、以降の会議で同様の誤りを自動的に修正します。レビューと修正を参照してください。

  • 학습한 교정 자동 적용（学習した修正の自動適用）— 学習した修正を実際に適用するかどうかを切り替えるスイッチです。学習は常に行われ、このスイッチは「適用」のみを切り替えます。（初期設定はオフ — ご自身でオンにしてください。）
  • 최소 확인 횟수（最小確認回数）— 同じ修正をこの回数（1〜5 回）以上確認してから自動適用します。値が大きいほど控えめになり、偶発的な編集 1 回が以降の文字起こしを上書きすることがありません。
  • 학습한 교정 목록（学習した修正の一覧）— 学習された規則（誤った単語 → 正しい単語、確認回数）を表示します。各行のゴミ箱ボタンで 1 つの規則だけを削除するか、전체 지우기（すべて削除）ですべて消去します。

모델（モデル）

文字起こし（Whisper）モデルの状態を確認・管理します。

  • 상태 / 위치（状態 / 場所）— モデルがインストールされているかどうかと、ファイルのパスを表示します。
  • 모델 재다운로드（モデルを再ダウンロード）— モデルをもう一度取得します。
  • Finder에서 보기（Finder で表示）— モデルファイルの場所を開きます。
選択された DNA3.0 翻訳モデルは 번역（翻訳）タブで管理します。
システムディクテーションは今後提供予定のため、現在のベータには 받아쓰기（ディクテーション）タブがありません。（システムディクテーション（音声入力・今後提供予定） を参照。）

8 GB Mac 利用ガイド

Madi は 8 GB クラスの Mac を検出すると、この文書を最初の一度だけ自動的に開きます。その後は ヘルプ → 8 GB Mac 利用ガイド からいつでも開き直せます。

自動的に適用される省メモリプロファイル

手動で調整する必要はありません。

  • DNA3.0-2B 翻訳モデル — 4B の代わりに 2B を選択します。ダウンロードは約 1.31 GB、エンジンプロセスの実測物理メモリは約 2.4 GB です（4B の実測約 5.1 GB より 53% 削減）。
  • 確定字幕を優先 — 発話途中の暫定翻訳より、確定した文字起こし行を先に翻訳します。
  • キューの統合 — 同じ行が再認識されると、古い翻訳要求を最新の文章に置き換えます。
  • 待機は最大 4 ターン — ライブ画面は最新の発話を追い、後回しになった確定行は録音終了後に再翻訳します。
  • 省メモリ Whisper 経路 — 大きな encoder キャッシュを保持せず、メモリ圧迫と swap を抑えます。

小さい 2B モデルは、難しい文で 4B より表現精度が下がる場合があります。Madi は原文の繰り返し、明らかに誤った文字体系、<think> の漏出、同一文の暴走反復を検出して一度だけ再生成し、それでも無効なら誤った翻訳を表示しません。

リアルタイム通訳の推奨設定

  1. 可能であれば出力言語は 1 つ にします。
  2. 対面通訳では 韓国語 + 相手の言語 1 つ のみを有効にします。各行の実際の翻訳先が 1 つになり、最も効率的です。
  3. まず 標準（7 秒） で始めます。原文の区切りを優先する場合は 正確（10 秒） を使います。
  4. 長時間の通訳では、多数のブラウザタブ、大規模 IDE、他のローカル LLM などメモリを多く使うアプリを閉じます。
  5. 「翻訳中・N 行待機」と表示されても停止しているわけではありません。確定字幕が先に処理され、古い暫定要求は自動的に整理されます。

期待される動作

  • 文字起こしと話者分離だけなら、翻訳モデルのダウンロードも起動も行いません。
  • 翻訳・要約・AI 修正を初めて使うとき、8 GB 用の 2B モデルを一度ダウンロードします。
  • ライブ中に古い確定行の翻訳が遅れる場合がありますが、録音終了後に保存用の行を再翻訳します。
  • メモリ圧迫が強いと macOS の swap により文字起こしと翻訳が同時に遅くなります。まず出力言語数と他アプリのメモリ使用量を減らしてください。

問題を確認するとき

  • 設定（⌘,）→ 翻訳で DNA3.0-2B · ~1.3 GB と表示されることを確認します。
  • 未インストールなら、同じ画面の 翻訳モデルをダウンロードを押します。
  • 翻訳を使わなくても、文字起こしと話者分離は正常に動作するはずです。
  • ヘルプのユーザーマニュアルとアップデート画面で、現在の Madi バージョンを確認できます。
すべての処理はこの Mac 内で — 文字起こし・翻訳・要約はデバイスから外に出ません。
