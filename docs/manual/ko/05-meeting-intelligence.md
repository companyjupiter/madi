# 회의 인텔리전스

Madi의 회의 인텔리전스는 회의록을 단순한 받아쓰기에서 "정리된 회의 자산"으로 바꿔 줍니다. 요약, 액션 아이템, 질의응답, 실시간 코칭, 후속 추적까지 모두 이 Mac 안의 로컬 LLM(DNA3.0-4B)이 처리합니다. **전사 내용과 요약은 절대 이 기기를 떠나지 않습니다.**

> 기능별로 필요한 조건이 다릅니다. 일부 기능은 요약 모델(LLM)이 설치되어 있어야 하고, 일부는 16GB 이상 메모리가 필요합니다. 각 항목에 표시해 두었습니다.

## A.I 요약

회의록을 구조화된 요약 + 액션 아이템 + 결정 사항으로 정리합니다.

1. 회의록 상단의 **요약** 버튼을 누릅니다 (반짝이 아이콘).
2. 로컬 LLM이 **회의 요약** 시트를 열고 요약을 생성합니다. "전사 내용은 이 Mac을 떠나지 않습니다"라는 안내가 함께 표시됩니다.
3. 시트 상단의 **전체 / 화자별** 토글로 보기를 바꿀 수 있습니다.
   - **전체** — 회의 전체의 요약·액션·결정
   - **화자별** — 화자마다 무슨 이야기를 했는지 정리 (처음 선택하면 그 자리에서 생성합니다)

요약 시트 아래쪽 버튼:

- **복사** — 요약 텍스트를 클립보드로 복사
- **다시 생성** — 같은 회의록으로 요약을 새로 생성
- **슬라이드(HTML)** — 오프라인에서 열리는 HTML 슬라이드 덱으로 내보내고 Finder에서 보여 줍니다
- **리캡 카드** — 공유용 요약 카드를 엽니다 (아래 "리캡 카드" 참고)
- **내보내기…** — 요약을 `.md` 파일로 저장

**필요 조건**
- 요약 모델(LLM)이 설치되어 있어야 합니다. 모델이 없으면 **요약** 버튼이 나타나지 않습니다.

## A.I 요약을 별도 파일로 저장

회의가 끝날 때 요약을 전사문과 **별개의 파일**로 자동 저장합니다.

1. 오른쪽 사이드 패널에서 **A.I 요약** 체크박스를 켭니다.
2. 회의가 완료되면, 전사문 옆에 `…요약.md` 파일이 함께 저장됩니다 (예: `회의록.md` → `회의록 요약.md`).

**필요 조건**
- 요약 모델(LLM)이 필요합니다.
- 전사문 자동 저장이 켜져 있어야 합니다.

## 회의록에 물어보기 (질의응답)

회의 내용을 자연어로 질문하면, 로컬 LLM이 회의록을 근거로 답합니다. 요약 시트 아래쪽에 있습니다.

1. **회의록에 물어보기** 입력란에 질문을 입력합니다. 예: "무엇을 결정했나요?", "김부장이 맡은 일은?"
2. 종이비행기 버튼을 누르거나 Enter를 칩니다.
3. **이 회의 / 전체 워크스페이스** 토글로 검색 범위를 정합니다.
   - **이 회의** — 지금 열려 있는 회의록에서만 답변
   - **전체 워크스페이스** — 저장된 **모든** 회의록을 가로질러 검색. 예: "지난달 보안 결정은?", "지난 분기 가격 결정 찾아줘"

**필요 조건**
- 요약 모델(LLM)이 필요합니다.

## 라이브 액션 추출

녹음 중에 결정·할 일·질문을 **실시간으로** 뽑아내, 회의가 끝나는 순간 이미 정리되어 있도록 합니다. 추출된 항목은 사이드의 **라이브 인텔리전스** 영역에 [결정]·[액션]·[질문] 카드로 (담당자와 함께) 쌓입니다.

1. 녹음을 시작하기 **전에**, 사이드 패널에서 **라이브 액션 추출** 체크박스를 켭니다.
2. 녹음을 시작하면 카드가 실시간으로 채워집니다.

**필요 조건**
- **16GB 이상 메모리**가 필요합니다. 메모리가 부족하면 토글이 비활성화되고 "16GB 이상 메모리 필요" 안내가 표시됩니다.
- 요약 모델(DNA3)을 전사와 동시에 구동하므로 메모리 사용이 큽니다.

**참고**
- 같은 모델을 쓰는 **실시간 번역**은 라이브 액션 추출이 켜진 동안 일시 중지됩니다.
- 녹음이 시작된 뒤에는 켜고 끌 수 없습니다. 반드시 녹음 **전에** 설정하세요.

## 라이브 코치 (텔레프롬프터)

녹음 중에 회의 진행을 도와주는 사이드 패널입니다. 어떤 Mac에서도 동작하며, 모델이 필요 없습니다.

1. 사이드 패널에서 **라이브 코치** 체크박스를 켭니다 (기본값은 꺼짐).
2. 녹음 중에 코치 패널이 다음을 실시간으로 보여 줍니다.
   - **안건 체크리스트** — 지난 결정·미해결 액션을 안건으로 띄우고, 라이브 전사가 그 내용을 다루면 자동으로 체크 표시(취소선)합니다. 상단에 "N / M 다룸" 진행도가 표시됩니다.
   - **미답변 질문** — 회의에서 나온 질문 중 아직 답이 안 된 항목
   - **지금 흐름** — 최근 발언 속도·겹침·침묵으로 추정한 회의 분위기를 **가열 / 안정 / 저조**로 표시 (작은 막대 그래프 포함)

**필요 조건**
- 없음 — 모델이 필요 없으며 모든 Mac에서 동작합니다.

**참고**
- 안건은 캘린더 일정이 잡혀 있을 때(지난 결정·액션이 모일 때) 더 풍부해집니다. 준비된 안건이 없으면 그 안내가 표시됩니다.

## 열린 항목 (후속 추적)

저장된 **모든** 회의에 걸쳐, 아직 마무리되지 않은 액션 아이템·열린 질문을 한곳에 모아 보여 줍니다. 워크스페이스 탐색기의 **열린 항목** 탭(파일 / 사람 옆)에서 볼 수 있습니다.

각 항목에는 다음이 표시됩니다.

- **종류 배지** — [결정] / [액션] / [질문]
- **담당자** (액션 아이템의 경우)
- **출처 회의** 이름
- **경과 일수** — 미해결이면 "12일째 후속 없음", 해결됐으면 "12일 경과"
- **후속 여부** — 이후 회의에서 다시 언급되었으면 "5일 후 ○○회의에서 언급됨"

항목은 **후속 필요**(오래된 순)와 **후속됨** 두 그룹으로 나뉩니다. 항목을 누르면 출처 회의록이 열립니다.

**필요 조건**
- 회의 요약에 [결정]·[액션]·[질문]이 기록되어 있어야 추적됩니다 (즉, 요약 모델로 정리된 회의록).

## 회의 준비 브리핑

회의를 시작하기 전(또는 캘린더 일정이 감지될 때), 이 참석자들과 관련된 지난 맥락을 한 장으로 정리해 보여 줍니다. 캘린더 + 사람 + 지난 회의 검색을 결합합니다.

브리핑에 담기는 내용:

- **회의 참석자** — 참석자별 지난 회의 이력
- **지난 결정** — 이 참석자들과 관련해 과거에 내려진 결정
- **미해결 액션** — 아직 끝나지 않은 액션 아이템
- **관련 논의** — 관련된 지난 회의 목록

하단의 **복사** / **내보내기…** 버튼으로 브리핑을 클립보드나 `.md` 파일로 저장할 수 있습니다.

**참고**
- 기본 브리핑(참석자·지난 결정·미해결 액션)은 워크스페이스에 저장된 회의록만으로 구성되며 요약 모델이 필요 없습니다.
- **워크스페이스에서 더 찾기** 토글을 켜면, 로컬 LLM이 워크스페이스 전체를 검색해 "관련 논의"에 추가 맥락을 보여 줍니다. 이 검색은 요약 모델이 필요하며, 기본값은 꺼짐입니다(요약 모델을 띄우면 번역 엔진이 잠시 내려갑니다).

## 제목 자동 생성 · 리캡 카드

**제목 자동 생성** — A.I 요약 자동 저장이 켜진 라이브 세션에서는, 회의가 끝날 때 로컬 LLM이 회의 제목을 직접 지어 파일 이름을 그 제목으로 바꿔 줍니다(요약본과 같은 이름으로 묶입니다). 파일 이름을 직접 입력하지 않았을 때만 동작합니다.

**리캡 카드** — 회의 한 장 요약 카드입니다. 요약 시트의 **리캡 카드** 버튼으로 엽니다. 다음이 담긴 공유용 카드입니다.

- 제목 + 날짜
- TL;DR (핵심 요약)
- 결정 목록
- 담당자별 액션
- 화자별 발화 시간(막대)
- 한 줄 인용

**복사**로 카드 한 페이지를 Markdown으로 복사하거나, **내보내기…**로 같은 내용을 파일로 저장할 수 있습니다.

**필요 조건**
- 제목 자동 생성과 리캡 카드의 요약 내용은 모두 요약 모델(LLM)이 필요합니다.

## 개인정보 보호

이 모든 기능은 이 Mac 안에서 동작합니다. 전사 내용도, 요약도, 질의응답도 이 기기를 떠나지 않습니다.
