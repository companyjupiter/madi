# 작업 폴더와 파일 관리

Madi는 저장 폴더를 통째로 하나의 작업 공간(워크스페이스)으로 보여줍니다. 화면 옆의 IDE 스타일 파일 트리에서 지난 회의록을 다시 열고, 새 폴더로 전환하고, 다양한 형식으로 내보낼 수 있습니다.

## 작업 폴더 탐색기 열고 닫기

회의록 옆에 파일 트리(탐색기)가 나타나, 저장 폴더가 하나의 작업 공간처럼 보입니다.

1. 상단의 폴더 버튼(사이드바 아이콘, 도움말 **"작업 폴더 탐색기"**)을 눌러 탐색기를 켜거나 끕니다.
2. 탐색기 안의 **탐색기 닫기** 버튼으로도 닫을 수 있습니다.

**팁 — 너비 조절:** 탐색기의 가장자리를 끌어 너비를 조절할 수 있습니다. 조절한 너비는 다음 실행 때도 기억됩니다.

## 탭 전환

탐색기 위쪽의 탭으로 보기를 바꿉니다.

- **파일** — 저장 폴더의 회의록과 하위 폴더를 트리로 보여줍니다.
- **사람** — 회의에 참여한 화자 분석을 보여줍니다.
- **열린 항목** — 아직 마무리되지 않은 결정·할 일 등 "열린 고리"를 모아 보여줍니다.

## 저장된 회의 다시 열기

1. **파일** 탭에서 회의록 파일(`.md`)을 클릭합니다.
2. 해당 회의록이 화면에 다시 열립니다.

## 회의록 미리보기(요지)

각 회의록 파일 이름 아래에는 한 줄짜리 **요지**(그 회의의 첫 결정·요약 줄)가 표시됩니다. 덕분에 트리가 회의 기록 피드처럼 한눈에 읽힙니다.

## 작업 폴더 선택·전환

선택한 폴더는 **저장**과 **내보내기**의 기본 위치가 됩니다(둘 다 같은 폴더).

1. 트리에서 폴더를 클릭하면, 그 폴더가 작업 공간이자 저장·내보내기 폴더가 됩니다.
2. 상위로 올라가려면 상단의 **상위 폴더로**(↑) 버튼을 누릅니다.
3. 완전히 다른 폴더를 고르려면 폴더-기어 버튼(도움말 **"작업 폴더 변경…"**)을 눌러 새 폴더를 선택합니다.
4. 폴더를 마우스 오른쪽 버튼으로 눌러 **이 폴더 열기 (작업 폴더로)** 를 선택해도 됩니다.

> **참고:** 새로 선택한 폴더가 곧바로 기본 **저장** 위치이자 기본 **내보내기** 위치가 됩니다.

## 저장 방식

- 회의는 작업 폴더에 **자동 저장**됩니다.
- **A.I 요약**을 켜 두면, 전사문과 별개로 **"…요약.md"** 파일이 함께 저장됩니다.

## 내보내기

상단의 **내보내기** 메뉴에서 형식을 고릅니다. 내보낸 파일은 기본적으로 작업 폴더에 저장됩니다.

- **Markdown (.md)** — 마크다운 회의록
- **Subtitles (.srt)** — SRT 자막
- **Subtitles (.vtt)** — VTT 자막
- **Plain text (.txt)** — 일반 텍스트
- **JSON (.json)** — JSON 데이터
- **슬라이드(HTML)** — HTML 슬라이드 덱
- **타이튼 컷 목록 (.csv)** — 잘라낼 필러·무음 컷 목록(CSV)
- **유튜브 챕터 (.txt)** — 챕터 목록 텍스트

## 클릭해서 그 순간 듣기

오디오·영상 **파일을 불러와 전사한 세션**(원본 파일이 디스크에 있는 경우)에서는, 각 줄에 재생 버튼이 표시됩니다.

1. 듣고 싶은 줄의 재생 버튼(도움말 **"이 구간 오디오 재생"**)을 누릅니다.
2. 그 줄이 말해진 정확한 순간이 원본 미디어에서 재생됩니다.

> **참고:** 실시간 마이크 녹음 세션에는 원본 파일이 없으므로 줄별 재생 버튼이 나타나지 않습니다.
