# 화자

Madi는 회의에서 누가 말했는지를 자동으로 구분합니다. 이 모든 처리는 이 Mac 안에서만 이루어집니다.

## 자동 화자 분리

녹음·전사가 진행되는 동안 Madi는 발언을 화자별로 자동으로 나눕니다.

- 각 화자에게 고유한 **색**과 **화자 N** 라벨이 붙습니다.
- 왼쪽 패널의 **화자 막대**가 회의 흐름에서 누가 언제 말했는지를 한 줄로 보여 줍니다.

**참고**
- 화자 분리는 **설정(⌘,) → 녹음 → 화자**의 **화자 분리** 스위치로 끌 수 있습니다.

## 화자 수 고정

방 안의 인원수를 알고 있다면 미리 지정해 정확도를 높일 수 있습니다.

1. 첫 화면 **회의 정보 → 화자**에서 고릅니다.
2. **자동 / 2명 / 3명 / 4명 / 5명 이상** 중에서 선택합니다. 1명 항목은 없습니다 — 단독 발표는 **화자 분리**를 끄는 쪽입니다.

**참고**
- 인원수가 분명할 때 고정하면 화자가 더 정확하게 나뉩니다. 확실하지 않다면 **자동**을 두세요.
- 녹음을 **시작하기 전에** 골라야 합니다. 녹음 중에는 잠깁니다.

### 미확인 화자

화자 수를 **고정**했을 때, 고른 인원 중 누구와도 뚜렷하게 다른 목소리가 들어오면 Madi는 그 발언을 **미확인**으로 따로 모읍니다. 지나가는 사람의 한마디나 갑자기 섞인 잡음이 정해 둔 화자 중 한 명으로 잘못 붙는 것을 막아 줍니다.

- **미확인**은 사람이 아니라 “여기 넣을 곳이 없다”는 표시입니다. 이름을 붙일 수 없습니다.
- 자동(화자 수 미고정)에서는 나타나지 않습니다.

## 화자 이름 지정

1. 전사에서 화자 이름(예: **화자 1**)이나 화자 칩을 클릭합니다.
2. **이름 (예: 김부장)** 입력란에 실제 이름을 입력합니다.
3. **저장**을 누릅니다. 입력한 이름이 **그 화자의 모든 발언과 내보내기**에 적용됩니다.

**참고**
- 이름은 **지금 이 회의록에만** 적용됩니다. 다음 회의에서 같은 사람을 자동으로 알아보지는 않습니다 — 회의마다 다시 지정해야 합니다.
- **미확인**에는 이름을 붙일 수 없습니다.

## AI 화자 교정 (녹음이 끝난 뒤)

녹음이 끝나면 온디바이스 LLM이 대화를 읽고 **명백한 화자 오분리**를 보수적으로 바로잡습니다. 한 사람의 말이 두 화자로 쪼개졌거나 한 줄이 엉뚱한 화자에게 붙은 경우를 정리합니다.

- **설정(⌘,) → 번역 → AI 교정 (세션 종료 후)** 의 **화자·언어 자동 교정**으로 켜고 끕니다.
- 교정이 적용되면 전사문 위에 안내가 뜨고, **화자 교정 되돌리기** 버튼으로 **한 번에 되돌릴 수 있습니다.**
- 하드웨어에 맞게 선택된 DNA3.0 번역 모델이 있어야 씁니다.

## 발언 겹침 표시

두 사람이 동시에 말하면 **상세** 보기에 **⟨+이름 겹침⟩** 표시가 나타나, 그 구간에 끼어든 두 번째 화자를 알려 줍니다.

**참고**
- 겹침 표시는 **상세** 보기에서만 나타납니다. 화면 상단에서 **내용 → 상세**로 전환하세요.
- **설정(⌘,) → 녹음 → 화자**의 **중첩 발화 감지**가 켜져 있어야 합니다.
