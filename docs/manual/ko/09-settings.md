# 설정

설정 창은 **⌘,(Command + 쉼표)** 로 엽니다. 매 회의마다 만지는 것이 아니라 “한 번 정해 두는” 항목들이 여기에 모여 있습니다. 창 위쪽 탭으로 **녹음 · 편집·저장 · 번역 · 단어장 · 모델 · 받아쓰기** 를 오갑니다.

> 참고: **녹음** 탭의 설정은 녹음 중·일시정지 중에는 잠깁니다. 바꾸려면 녹음을 멈춘 뒤 조정하세요.

---

## 녹음

음원 캡처 방식과 실시간 동작, 화면 표시를 정합니다.

### 입력

- **음원** — 무엇을 들을지 고릅니다.
  - **마이크** — 내 목소리/대면 회의.
  - **시스템 오디오** — Mac에서 재생되는 소리(Zoom·Teams·Slack·YouTube 등). 첫 사용 시 ‘화면 기록’ 권한을 요청합니다(오디오 전용, 화면은 저장하지 않음).
  - **마이크+시스템** — 온라인 회의(내 목소리 + 상대방 소리)에 적합합니다.
- **마이크** — (마이크/마이크+시스템일 때) 사용할 입력 장치를 고릅니다. 기본은 “시스템 기본”.
- **언어** — **자동 감지 / 한국어 / English** 중에서 받아쓰기 언어를 고정하거나 자동으로 둡니다.

### 화자

- **화자 분리** — 누가 말했는지 화자별로 구분합니다.
- **중첩 발화 감지** — 두 사람이 동시에 말하는 구간을 감지합니다.

### 실시간

- **반응 속도** — **빠름(5초) / 보통(7초) / 정확(10초)**. 빠름은 텍스트가 더 자주 떠 체감 속도가 좋고, 정확은 문맥을 길게 봐 품질이 좋습니다. *번역 대상이 2개 이상이면 자동으로 ‘정확(10초)’ 으로 고정됩니다.*
- **실시간 프리뷰** — 한 구간이 확정되기 전, 중간 텍스트를 회색으로 미리 보여 줍니다(정확도 손해 없음, 메모리 약 830 MB 추가).

### 표시

- **외관** — 시스템 / 라이트 / 다크 테마를 고릅니다.

### 자막 오버레이 (진료실)

대면 통역용 자막 창의 크기와 두 번째(환자용) 화면을 설정합니다.

- **직원 자막 크기** — 주 화면 자막 글씨(14–48pt).
- **환자용 대형 자막 (별도 화면)** — 두 번째 패널을 환자 언어로, 원거리 판독용 큰 글씨로 띄웁니다. 켜면 아래 항목이 나타납니다.
  - **환자 자막 크기** — 24–96pt.
  - **환자 화면** — 모니터가 둘 이상이면 어느 화면에 띄울지 고릅니다.
  - **환자 언어** — 자동(상대 언어) 또는 특정 언어로 고정.

### 자동 저장 관련

자동 저장 폴더 설정은 **편집·저장** 탭에 있습니다(아래 참고).

---

## 편집·저장

받아쓰기 후 분석(타이튼·챕터 등)과 파일 저장을 정합니다.

### 자동 저장

- **완료 시 .md 자동저장** — 전사가 끝나면 Markdown 파일로 자동 저장합니다.
- **폴더 / 변경…** — 저장 폴더를 지정합니다.

### 음성 인식

- **저신뢰 표시 기준 (VAD)** — 이 신뢰도(기본 0.55) 미만으로 인식된 단어를 ‘검토 필요’로 표시합니다.

### 편집 기능

- **편집 기능 사용** — 필러·무음 타이튼, 챕터, 리테이크, 하이라이트 분석을 켭니다. **기본은 꺼짐** — 필요할 때만 켜세요. (꺼져 있으면 아래 항목들은 비활성화됩니다.)

### 필러 · 무음 (타이튼)

- **필러 컷** — “음…”, “어…” 같은 군말을 감지합니다.
- **무음 컷** — 긴 무음 구간을 감지합니다.
- **무음 최소초** — 무음으로 간주할 최소 길이.

### 챕터

- **자동 챕터** — 대화 흐름에 따라 챕터를 자동으로 나눕니다.
- **휴지 경계초 / 최소 간격초** — 챕터를 나눌 휴지 길이와 최소 챕터 간격을 조정합니다.

### 리테이크 · 하이라이트

- **리테이크 감지** — 같은 말을 다시 한 “다시 찍기” 구간을 찾습니다. **유사도** 슬라이더로 민감도를 조정합니다.
- **하이라이트** — 중요한 구간을 강조합니다. **최소 신뢰도** 로 기준을 정합니다.

## 번역

온디바이스 번역(한국어·중국어·일본어·영어)을 켜고 끄는 곳입니다.

### 번역 모델 (DNA3.0-4B · 약 2.6 GB)

- **상태** — 설치됨 / 다운로드 진행률 / 미설치를 보여 줍니다.
- **번역 모델 다운로드** — 모델을 받습니다. 앱에 동봉되어 있지 않고, 켤 때 받습니다(메모리 약 3 GB 추가). 설치 후에는 **Finder에서 보기** 로 파일 위치를 열 수 있습니다.

### 실시간 번역 (다중 대상)

- **한국어 / English / 日本語 / 中文** — 토글로 대상 언어를 고릅니다. 선택한 모든 언어로 각 줄을 동시에 번역해 원문 아래에 표시합니다(원문 언어는 자동 제외).
- 모델을 먼저 받아야 이 항목을 쓸 수 있습니다. 대상이 2개 이상이면 녹음 반응 속도가 ‘정확(10초)’ 으로 고정됩니다(녹음 탭 참고).

## 단어장 (개인 단어장)

자주 틀리는 도메인 용어·이름을 직접 고친 내용을 Madi가 학습해, 이후 회의에서 비슷한 오인식을 자동으로 바로잡습니다.

### 개인 단어장

- **학습한 교정 자동 적용** — 학습한 교정을 실제로 적용할지 켜는 스위치입니다. **학습은 항상 동작**하며, 이 스위치는 ‘적용’만 켭니다. (기본 꺼짐 — 직접 켜세요.)

### 적용 기준

- **최소 확인 횟수** — 같은 교정을 이 횟수(1~5회) 이상 확인해야 자동 적용합니다. 값이 클수록 보수적이라, 우발적 편집 한 번이 이후 전사를 덮어쓰지 않습니다.

### 학습한 교정 목록

- 학습된 규칙(틀린 단어 → 맞는 단어, 확인 횟수)을 보여 줍니다. 각 줄의 휴지통 버튼으로 한 규칙만 ‘잊기’ 하거나, **전체 지우기** 로 모두 비울 수 있습니다.

## 모델

받아쓰기·언어 모델의 상태를 확인하고 관리합니다.

- **상태 / 위치** — 모델 설치 여부와 파일 경로를 보여 줍니다.
- **모델 재다운로드** — 모델을 다시 받습니다.
- **Finder에서 보기** — 모델 파일 위치를 엽니다.

번역 모델(DNA3.0-4B) 다운로드는 **번역** 탭에서도 할 수 있습니다.

## 받아쓰기

어느 앱에서나 쓰는 시스템 전역 받아쓰기(푸시투토크) 설정입니다. 자세한 사용법은 **받아쓰기** 매뉴얼 페이지를 참고하세요.

### 시스템 받아쓰기

- **어디서나 받아쓰기 사용** — 오른쪽 **⌥(Option)** 키를 누른 채 말하고 떼면, 어떤 앱이든 맨 앞 입력란에 받아쓴 텍스트가 들어갑니다. 모든 처리는 기기 안에서 이뤄집니다.

### 단축키

- **누르고 있는 동안 녹음** — 기본값은 오른쪽 **⌥ Option** 키입니다(명령 팔레트 ⌘K 와 겹치지 않도록 선택됨).

### 손쉬운 사용 권한

- **상태** — ‘손쉬운 사용(Accessibility)’ 권한 허용 여부를 보여 줍니다.
- **시스템 설정에서 허용** — 권한이 없으면 이 버튼으로 시스템 설정을 엽니다. 다른 앱에 텍스트를 넣으려면 이 권한이 필요하며, 허용 후 이 창으로 돌아오면 자동으로 인식됩니다.

### 상태

- **현재** — 받아쓰기의 현재 상태(대기 중 / 듣는 중 / 변환 중 / 입력 중 등)를 보여 줍니다.
