# 시스템 받아쓰기 (추후 제공)

> **준비 중 — 현재 베타에는 포함되지 않았습니다.** 아래는 앞으로 제공될 기능 소개이며, 지금 버전에서는 설정에 **받아쓰기 탭이 없고** 단축키도 동작하지 않습니다.

시스템 받아쓰기는 macOS 어디서나 쓸 수 있는 음성 입력 기능으로 준비하고 있습니다. 전역 단축키를 누른 채 말하고 떼면, 말한 내용이 **기기 안에서** 글자로 바뀌어 지금 맨 앞에 있는 앱(메모, 메일, Slack, 코드 편집기 등)의 입력란에 그대로 들어가도록 하는 것이 목표입니다. 회의 전사·번역과 마찬가지로 100% 온디바이스로 동작하도록 설계하고 있습니다.

## 계획된 동작

- **푸시투토크** — 전역 단축키를 누르는 동안만 녹음하고, 떼는 순간 받아쓴 텍스트가 입력됩니다.
- **가볍고 빠르게** — 큰 언어 모델을 올리지 않고, 받아쓰기 전용 음성 인식만 짧게 돌렸다가 종료하는 방식이라 메모리가 적은 Mac에서도 부담이 적습니다.
- **클립보드 보존** — 텍스트를 넣을 때 기존 클립보드를 저장했다 곧바로 되돌립니다.
- **회의 녹음 중 비활성** — 받아쓰기와 회의 녹음이 같은 마이크를 쓰므로 충돌을 막기 위해 녹음 중에는 꺼집니다.

## 지금은?

지금 버전에서 쓸 수 있는 기능은 **회의 전사·화자 분리·온디바이스 번역·검토와 교정·AI 요약**입니다. 시스템 받아쓰기는 이후 업데이트에서 제공될 예정입니다. 업데이트 확인은 **Madi 메뉴 → 업데이트 설치…** 에서 할 수 있습니다.
