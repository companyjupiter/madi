# 8GB Mac 사용 가이드

> Madi가 8GB급 Mac을 감지하면 이 문서를 최초 한 번 자동으로 엽니다. 이후에는 **도움말 → 8GB Mac 사용 가이드**에서 언제든 다시 볼 수 있습니다.

## 자동으로 적용되는 저메모리 프로필

별도 설정 없이 다음 정책이 적용됩니다.

- **DNA3.0-2B 번역 모델** — 4B 대신 2B를 선택합니다. 다운로드는 약 **1.31 GB**, 엔진 프로세스의 실측 물리 메모리는 약 **2.4 GB**입니다(4B 실측 약 5.1 GB 대비 53% 감소).
- **확정 자막 우선** — 말하는 중의 임시 번역보다 확정된 전사 줄을 먼저 번역합니다.
- **대기열 합치기** — 같은 줄이 다시 인식되면 오래된 번역 요청을 버리고 최신 문장 하나만 남깁니다.
- **4턴 대기 상한** — 실시간 화면은 최신 번역을 따라가며, 밀린 확정 줄은 녹음 종료 후 다시 채웁니다.
- **저메모리 Whisper 경로** — 큰 encoder 캐시를 보존하지 않아 메모리 압박과 swap을 줄입니다.

이 정책은 품질을 숨기지 않습니다. 2B는 4B보다 작아 어려운 문장에서는 번역 표현이 덜 정확할 수 있습니다. Madi는 원문 반복, 잘못된 문자 체계, `<think>` 누출과 반복 폭주를 감지해 한 번 다시 생성하고, 그래도 잘못되면 틀린 번역을 표시하지 않습니다.

## 실시간 통역 권장 설정

1. 출력 언어는 가능하면 **하나만** 고릅니다.
2. 대면 통역이라면 **한국어 + 상대 언어 하나**만 켭니다. 줄마다 실제 번역 대상은 하나가 되어 가장 효율적입니다.
3. 처음에는 **보통(7초)** 으로 시작합니다. 원문 경계가 더 중요하면 **정확(10초)** 을 씁니다.
4. 장시간 통역 중에는 브라우저의 많은 탭, 대형 IDE, 다른 로컬 LLM처럼 메모리를 많이 쓰는 앱을 닫습니다.
5. “번역 중 · N줄 대기”가 보이면 멈춘 것이 아닙니다. 확정 자막이 우선 처리되고 있으며 오래된 임시 요청은 자동으로 정리됩니다.

## 무엇을 기대하면 되나요?

- **전사와 화자 분리만 사용**하면 번역 모델을 내려받거나 실행하지 않습니다.
- **번역·요약·AI 교정**을 처음 켤 때 8GB용 2B 모델을 한 번 내려받습니다.
- 실시간 번역 중 오래된 확정 줄이 화면에서 늦어질 수 있지만, 녹음을 끝내면 저장할 기록을 위해 다시 번역합니다.
- 메모리 압박이 심하면 macOS의 swap 때문에 전사와 번역이 함께 느려질 수 있습니다. 이때는 출력 언어 수와 다른 앱의 메모리 사용량부터 줄이세요.

## 문제를 확인할 때

- **설정(⌘,) → 번역**에서 `DNA3.0-2B · ~1.3 GB`가 표시되는지 확인합니다.
- 모델을 아직 받지 않았다면 같은 화면의 **번역 모델 다운로드**를 누릅니다.
- 번역 없이도 전사·화자 분리는 정상 동작해야 합니다.
- 문제가 계속되면 도움말의 사용자 매뉴얼과 업데이트 화면에서 현재 버전을 확인하세요.
