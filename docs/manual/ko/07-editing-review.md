# 편집과 검토

전사가 끝나면 깔끔하게 읽거나, 자세히 들여다보며 고칠 수 있습니다. Madi는 여러분이 고친 내용을 기억해 다음 회의에서 같은 실수를 자동으로 바로잡고, 잘라낼 부분까지 짚어 줍니다.

## 내용 보기 vs 상세 보기

화면 상단의 전환 스위치(도움말 **"내용: 깨끗한 회의록 보기 · 상세: 시각·신뢰도·겹침 표시"**)로 두 가지 보기를 오갑니다.

- **내용** — 시각·표시 없이 깨끗하게 읽는 기본 보기.
- **상세** — 타임코드, 저신뢰 단어(호박색 강조), 화자 겹침 표시(⟨+이름 겹침⟩)를 함께 보여줍니다.

## 줄 직접 편집(인라인 편집)

1. 고치고 싶은 줄을 **더블 클릭**합니다(또는 **상세** 보기에서 연필 버튼, 도움말 **"이 문장 편집"**을 누릅니다).
2. **내용** 보기에서 더블 클릭하면 자동으로 **상세** 보기로 넘어가 편집창이 열립니다.
3. 텍스트를 고치고 입력을 마칩니다.
4. 고친 줄에는 **편집됨** 표시가 붙습니다.

원문을 고치면 이전 원문으로 생성 중이던 번역은 자동으로 폐기되고, 고친 원문을
기준으로 다시 번역됩니다. 늦게 도착한 예전 AI 결과가 사용자 교정을 덮어쓰지 않습니다.

## 번역문 직접 교정

확정된 번역문을 **더블 클릭**하면 언어별 번역을 직접 고칠 수 있습니다. 저장한
번역에는 연필 표시가 붙고, 다중 번역의 다른 언어는 그대로 유지됩니다. 교정된
원문·번역·화자 이름은 Markdown과 JSON에 함께 저장되며, Markdown 회의록을 다시
열어도 번역이 보존됩니다. SRT/VTT는 항상 최종 교정 원문을 사용합니다.

## 검토 필요 — 저신뢰 단어 빠르게 확인

**상세** 보기는 신뢰도가 낮은 단어(설정의 기준값 미만, 기본 0.55)를 호박색으로 표시합니다.

1. 상단에 **검토 필요 N개**가 표시됩니다.
2. **이전**(이전 검토 단어) / **다음**(다음 검토 단어) 버튼으로 표시된 단어들 사이를 건너뛰며 이동합니다.
3. 각 단어를 확인하고, 필요하면 그 자리에서 고칩니다.

## 귀로 검토 — 들으며 확인

파일을 불러와 전사한 세션에서는, 저신뢰 단어의 오디오 구간을 하나씩 자동으로 재생해 귀로 확인할 수 있습니다(클릭 재생 기능을 그대로 활용).

1. 검토바의 재생 버튼(도움말 **"저신뢰 단어 귀로 검토"**)을 누릅니다.
2. 표시된 단어들의 오디오가 순서대로 자동 재생되고, 한 단어가 끝나면 다음으로 넘어갑니다(핸즈프리).
3. 멈추려면 같은 버튼(도움말 **"귀로 검토 멈춤"**)을 다시 누릅니다.

> **참고:** 귀로 검토는 원본 미디어가 있는 파일 전사 세션에서만 켜집니다.

## 개인 단어장 — 교정을 기억하는 학습

전사문의 한 줄을 고치면 Madi가 그 교정을 학습합니다. **단어장** 기능을 켜 두면, 다음 회의에서 같은 도메인 용어·이름의 오인식을 자동으로 바로잡습니다.

**켜는 법:** **설정(⌘,) → 단어장** 탭에서 **학습한 교정 자동 적용**을 켭니다.

> **참고:** 학습은 스위치와 상관없이 항상 동작하며, 이 스위치는 "적용"만 켭니다. 그래서 켜는 즉시 그동안 쌓인 교정이 적용됩니다.

### 적용 기준(최소 확인 횟수)

- **최소 확인 횟수**(minHits) 슬라이더로, 같은 교정을 몇 번 확인해야 믿고 자동 적용할지 정합니다(1~5회).
- 값이 클수록 보수적입니다 — 우발적인 편집 한 번이 이후 전사를 덮어쓰지 않도록 막아 줍니다.

### 학습한 교정 관리·삭제

**설정 → 단어장** 탭의 목록에서 학습한 규칙을 관리합니다.

- 각 규칙은 `잘못된 단어 → 올바른 단어`와 확인 횟수로 표시됩니다.
- 규칙 옆 휴지통 버튼(도움말 **"이 교정을 잊기"**)으로 하나씩 잊게 합니다.
- 모두 지우려면 **전체 지우기**를 누릅니다.

## 타이튼 — 잘라낼 부분 찾기

**타이튼**은 잘라내도 되는 필러(말버릇)와 무음 구간을 찾아냅니다.

1. 컨트롤 패널에 **타이튼: N컷 · N초 절감 가능**이 표시됩니다.
2. 잘라낼 목록을 파일로 받으려면 **내보내기 → 타이튼 컷 목록 (.csv)** 를 선택합니다.

> **참고:** 타이튼은 깨끗한 회의록 본문은 건드리지 않습니다 — 잘라낼 후보만 알려 줍니다.

### 편집 보조 기능

**설정 → 편집·저장** 탭에서 다음 분석을 켜고 끕니다(기본은 꺼짐, 필요할 때만 켜세요).

- **챕터** — 자동 챕터 나누기.
- **리테이크 · 하이라이트** — 다시 말한 부분 감지, 하이라이트 표시.

## 텍스트 선택과 복사

전사문 전체에서 텍스트를 드래그로 선택하고 **⌘C**로 복사할 수 있습니다.
