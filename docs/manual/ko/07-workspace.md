# 작업 폴더와 내보내기

Madi는 저장 폴더를 통째로 하나의 작업 공간으로 보여 줍니다. 창 오른쪽의 **작업 폴더 탐색기**에서 지난 회의록을 다시 열고, 저장 위치를 바꾸고, 원하는 형식으로 내보냅니다.

## 작업 폴더 탐색기

탐색기는 창 오른쪽에 **항상 표시**됩니다. 위쪽은 회의 목록, 아래쪽은 자동저장·폴더·내보내기 조작부입니다.

### 파일 목록

- **파일** 탭에 저장 폴더의 회의록이 최근 순으로 쌓입니다.
- 회의록을 클릭하면 그 회의가 화면에 다시 열립니다.

## 자동 저장

- **자동저장** 스위치를 켜 두면 전사가 끝날 때 회의록이 **Markdown(.md)** 으로 자동 저장됩니다.
- **폴더** 줄에 현재 저장 위치가 표시됩니다. **변경**을 눌러 다른 폴더를 고를 수 있습니다.
- 고른 폴더는 **저장**과 **내보내기**의 기본 위치가 됩니다.

> 같은 설정이 **설정(⌘,) → 저장** 탭에도 있습니다. 편한 쪽에서 바꾸면 됩니다.

**팁** — **⌘K**를 눌러 **작업 폴더 변경**을 입력해도 폴더를 바로 고를 수 있습니다.

## 내보내기

탐색기 아래쪽의 **내보내기** 버튼을 누르면 **내보내기 형식**을 묻습니다. 형식을 고르면 저장 위치를 정할 수 있습니다.

| 형식 | 쓰임 |
|---|---|
| **Markdown (.md)** | 마크다운 회의록. 화자 이름·번역·교정이 함께 저장됩니다 |
| **Subtitles (.srt)** | SRT 자막 |
| **Subtitles (.vtt)** | VTT 자막 |
| **Plain text (.txt)** | 일반 텍스트 |
| **JSON (.json)** | JSON 데이터 |

**참고**
- 전사문이 비어 있으면 **내보내기** 버튼이 흐려집니다.
- SRT/VTT는 항상 최종 교정 원문을 사용합니다. (**검토와 교정** 참고.)

## 클릭해서 그 순간 듣기

오디오·영상 **파일을 불러와 전사한 세션**(원본 파일이 디스크에 있는 경우)에서는, 각 줄에 재생 버튼이 표시됩니다.

1. 듣고 싶은 줄의 재생 버튼(도움말 **“이 구간 오디오 재생”**)을 누릅니다.
2. 그 줄이 말해진 정확한 순간이 원본 미디어에서 재생됩니다.

> **참고:** 실시간 마이크 녹음 세션에는 원본 파일이 없으므로 줄별 재생 버튼이 나타나지 않습니다.

## 지난 회의 빨리 찾기

**⌘K** 명령 팔레트에 회의 이름을 입력하면 저장된 회의록으로 바로 이동합니다. 화자 이름으로도 찾을 수 있습니다.
