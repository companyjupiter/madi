# 시작하기

Madi(마디)에 오신 것을 환영합니다. Madi는 회의를 **전부 기기 안에서** 받아쓰고 이해하는 한국어 회의 인텔리전스 앱입니다. 실시간 받아쓰기, 오디오·영상 파일 전사, 화자 분리, 온디바이스 번역, 요약, 질의응답까지 — 모든 처리가 여러분의 Mac 안에서 일어납니다.

## Madi가 하는 일

- **실시간 전사** — 마이크나 회의 음성을 들으며 말이 끝나기 전에 텍스트가 화면에 나타납니다.
- **파일·영상 전사** — 녹음 파일이나 영상을 끌어다 놓으면 전체 대화를 받아씁니다.
- **화자 분리** — 누가 언제 말했는지 화자별로 구분합니다.
- **온디바이스 번역** — 한국어·영어·중국어·일본어를 서로 번역합니다.
- **요약 · 질의응답** — 회의 핵심, 결정 사항, 할 일을 정리하고 내용에 대해 질문할 수 있습니다.

### 100% 온디바이스 — 내 데이터는 Mac을 떠나지 않습니다

Madi의 핵심 약속은 **주권(sovereign)** 입니다. 음성, 전사문, 번역, 요약 어느 것도 클라우드로 전송되지 않습니다. 인터넷이 끊겨 있어도(모델을 이미 받았다면) 동작합니다. 회의 내용은 오로지 여러분의 기기 안에만 존재합니다.

## 모델 안내

Madi는 두 종류의 AI 모델을 씁니다.

- **Whisper 음성 모델** — 받아쓰기를 담당합니다. **앱에 기본 동봉**되어 있어 따로 받을 필요가 없습니다.
- **DNA3.0-4B 언어 모델 (약 2.6 GB)** — 번역, 요약, 질의응답, 제목 생성에 쓰입니다. 앱 용량을 줄이기 위해 **처음 쓸 때 다운로드**합니다.
  - 받는 곳: **설정 → 모델** 또는 **설정 → 번역**의 “번역 모델 다운로드” 버튼.
  - 다운로드 약 **2.6 GB**, 디스크 공간도 그만큼 필요합니다. (자세한 내용은 **번역**, **설정** 참고.)

## 메모리 안내 (솔직하게)

- **8 GB Mac (예: M1 MacBook Air)** — 받아쓰기와 화자 분리는 원활히 돌아갑니다.
- **16 GB 이상 권장** — 언어 모델을 전사와 **동시에** 돌리는 기능에서 필요합니다. 예를 들어 **라이브 액션 추출**(녹음 중 결정·할 일·질문 실시간 추출)이나 **실시간 번역·요약을 전사와 함께** 쓸 때입니다. 8 GB에서도 이런 기능을 켤 수는 있지만 메모리가 빠듯해질 수 있습니다.

## Madi가 요청할 수 있는 권한

권한은 미리 한꺼번에 묻지 않고, **그 기능을 처음 쓸 때** 필요한 것만 요청합니다.

- **마이크** — 녹음할 때. 녹음을 처음 시작할 때 요청합니다.
- **화면 기록** — 시스템 오디오(Mac에서 재생되는 소리, 예: Zoom·Teams·YouTube)를 녹음할 때만. macOS가 오디오 캡처를 화면 기록 권한으로 묶어두기 때문이며, **화면은 저장하지 않습니다.**
- **캘린더** — 선택 사항입니다. 회의 준비나 참석자 매칭에 쓰며, 쓰지 않아도 됩니다.
- **손쉬운 사용(Accessibility)** — **시스템 받아쓰기**(어느 앱에서나 받아쓰기) 기능을 쓸 때만 필요합니다. 받아쓴 텍스트를 다른 앱에 넣으려면 이 권한이 필요합니다. (**받아쓰기** 참고.)

권한을 거부했다가 나중에 켜고 싶으면 **시스템 설정 → 개인정보 보호 및 보안**에서 해당 항목(마이크 / 화면 기록 / 손쉬운 사용 / 캘린더)을 찾아 Madi를 켜면 됩니다.

## 처음 실행 빠른 시작

1. Madi를 엽니다.
2. (선택) 번역·요약·질의응답을 쓰려면 **설정(⌘,) → 모델** 또는 **번역**에서 번역 모델(DNA3.0-4B, 약 2.6 GB)을 다운로드합니다.
3. **녹음 시작** 버튼을 누르거나, 오디오·영상 파일을 창에 끌어다 놓습니다.
4. 화면에 실시간 전사문이 나타나는 것을 지켜봅니다.
5. 회의가 끝나면 **요약** 버튼을 눌러 AI 요약을 받습니다. (요약은 번역 모델이 설치되어 있어야 합니다.)

준비 완료입니다. 더 자세한 내용은 녹음, 번역, 받아쓰기, 설정 등 다른 매뉴얼 페이지를 참고하세요.
