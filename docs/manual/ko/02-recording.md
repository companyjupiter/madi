# 녹음 및 전사

마디는 회의 음성을 실시간으로 받아 적고, 이미 녹음된 오디오·영상 파일도 전사합니다. 모든 처리는 이 Mac 안에서만 이루어지며, 전사 내용은 기기를 떠나지 않습니다.

## 실시간 마이크 녹음

1. 화면 하단의 **녹음 시작** 버튼을 누릅니다.
2. 말하기 시작하면 가운데 영역에 전사가 실시간으로 흘러나옵니다.
3. 잠시 멈추려면 **일시정지**, 끝내려면 **정지**를 누릅니다.

**참고**
- 녹음을 시작하기 전, 아래의 **회의 모드**와 **화자 수**를 먼저 설정해 두면 결과 품질이 좋아집니다. 녹음 중에는 이 항목들이 잠깁니다.
- 상단의 **입력 레벨 막대**가 마이크 소리 크기를 보여 줍니다. 일시정지 중에는 0으로 내려갑니다.

### 말을 끝내면 자막이 바로 뜹니다

한 구간(윈도)이 다 차기를 기다리지 않고, **말을 멈추고 잠깐 조용해지면** Madi가 그 구간을 앞당겨 마감해 전사를 바로 내보냅니다. 짧게 주고받는 대화(예: 진료 상담)에서 대기 시간이 크게 줄어듭니다. 멀리서 들어오는 작은 목소리는 잘리지 않도록 자동으로 기준을 맞춥니다.

## 시스템 오디오 캡처 (Zoom·Teams·영상)

Mac에서 재생되는 소리(온라인 회의, 영상 등)를 그대로 전사할 수 있습니다.

1. **설정 → 녹음 → 입력**으로 이동합니다.
2. **음원**(Audio source)에서 입력 방식을 고릅니다.
   - **마이크** — 내 앞의 소리만
   - **시스템 오디오** — Zoom·Teams·Slack·YouTube 등 Mac에서 재생되는 소리
   - **마이크+시스템** — 온라인 회의용. 내 목소리와 상대 목소리를 함께
3. 평소처럼 **녹음 시작**을 누릅니다.

**참고**
- 시스템 오디오를 처음 쓸 때 macOS가 **‘화면 기록’ 권한**을 요청합니다. 오디오만 사용하며 화면은 저장하지 않습니다. 권한을 허용해 주세요.

## 파일 및 영상 전사

이미 가지고 있는 오디오 또는 영상 파일을 끌어다 놓으면 전사됩니다.

1. 오디오 또는 영상 파일(mp4·mov·m4v·mkv·webm·avi 등)을 마디 창 위로 **끌어다 놓습니다**. 드롭 영역에 **드롭하여 전사**가 표시됩니다.
2. 진행률이 **(N/전체 청크 · %)** 형태로 표시됩니다.
3. 전사가 끝나면 화면에 결과가 나타납니다.

**참고**
- 영상 파일의 음성은 자동으로 추출되어 전사됩니다. 별도 변환이 필요 없습니다.

## 화자 수 고정

방 안의 인원수를 알고 있다면 미리 지정해 화자 분리(diarization) 정확도를 높일 수 있습니다.

1. **설정 → 녹음 → 화자 수**로 이동합니다.
2. **자동(자동 감지) / 1 / 2 / 3 / 4명 이상** 중에서 고릅니다.

**참고**
- 인원수가 분명할 때 고정하면 화자가 더 정확하게 나뉩니다. 확실하지 않다면 **자동 감지**를 두세요.

## 회의 모드

회의의 성격에 맞춰 화자 수 · 요약 방식 · 강조 항목을 한 번에 맞춰 주는 프리셋입니다. **설정 → 녹음 → 회의 모드**에서 고릅니다.

- **일반** — 기본 설정 · 발화자 자동 감지
- **1:1** — 발화자 2명 · 결정과 후속 조치 강조
- **스탠드업** — 발화자 자동 · 액션과 블로커 강조
- **인터뷰** — 발화자 2명 · 질문·답변 흐름 보존
- **강의** — 발화자 1명 · 핵심 요점 위주 정리

**참고**
- 회의 모드는 녹음을 **시작하기 전에** 골라야 합니다. 녹음 중에는 잠깁니다.

## 전사 보기 전환

화면 상단의 토글로 두 가지 보기를 오갈 수 있습니다.

- **내용** — 깨끗한 회의록 읽기 보기 (기본값). 읽기에 집중할 때 좋습니다.
- **상세** — 시각(타임코드), 신뢰도가 낮은 단어(노란색 강조), 발언 겹침 표시까지 보여 줍니다. 내용을 검토·수정할 때 좋습니다.
- **대화** — 정확히 두 사람이 있을 때만 나타납니다. 첫 화자를 왼쪽, 상대를 오른쪽 말풍선에 놓는 메신저식 보기로, 통역·상담처럼 번갈아 읽을 때 좋습니다.

글자 크기는 **+ / −** 버튼으로 조절합니다.

## 개인정보

마디의 모든 전사는 이 Mac 안에서만 처리됩니다. 전사 내용은 절대 기기를 떠나지 않습니다.
