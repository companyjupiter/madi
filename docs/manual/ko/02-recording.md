# 녹음과 전사

Madi는 회의 음성을 실시간으로 받아 적고, 이미 녹음된 오디오·영상 파일도 전사합니다. 모든 처리는 이 Mac 안에서만 이루어지며, 전사 내용은 기기를 떠나지 않습니다.

## 첫 화면 — 회의 정보와 시작하기

앱을 열면 첫 화면이 두 칸으로 나뉩니다. 왼쪽에서 **이번 회의가 어떤 회의인지** 알려 주고, 오른쪽에서 **시작**합니다.

### 회의 정보 (왼쪽)

녹음을 시작하기 전에 골라 두면 결과 품질이 좋아집니다. **녹음 중에는 잠깁니다.**

- **입력 언어** — 말하는 언어. 자동 감지 또는 특정 언어로 고정합니다.
- **출력 언어** — 번역해서 보여 줄 언어(여러 개 선택 가능). 번역 모델이 있어야 쓸 수 있습니다. (**실시간 번역·통역** 참고.)
- **회의 모드** — 회의의 성격. 아래 참고.
- **화자** — 방 안의 인원수. 아래 참고.

### 시작하기 (오른쪽)

- **파일로 시작하기** — 파일을 고르거나 끌어다 놓은 뒤 누릅니다.
- **지금 녹음 시작** — 마이크를 골라 바로 녹음합니다.

## 실시간 마이크 녹음

1. **시작하기** 칸에서 마이크를 고릅니다(기본은 “시스템 기본”).
2. **지금 녹음 시작**을 누릅니다. 짧은 카운트다운이 지나면 녹음이 시작됩니다. 이때 **취소**할 수 있습니다.
3. 말하기 시작하면 가운데에 전사가 실시간으로 흘러나옵니다.
4. 왼쪽 패널의 **일시 정지**(⌘P)로 잠시 멈추고, **정지**(⌘R)로 끝냅니다.

**참고**
- 정지하면 거기까지의 기록이 정리됩니다. 자동저장이 켜져 있으면 파일로 저장됩니다.
- 자동저장이 꺼져 있으면 나가기 전에 안내가 뜹니다 — **내보내기**로 먼저 저장할 수 있습니다.

### 에너지 흐름

왼쪽 패널 아래의 **에너지 흐름** 그래프가 회의의 분위기를 한 줄로 보여 줍니다 — **발언 속도·겹침·침묵**을 종합한 흐름입니다.

- 그래프의 한 지점을 **클릭하면 그 구간으로 이동**합니다. 회의에서 가장 뜨거웠던 대목을 바로 찾아갈 때 좋습니다.
- 발언이 쌓이기 전에는 “발언이 쌓이면 흐름이 표시됩니다”라고 안내합니다.

### 녹음 중 마이크 바꾸기

실시간 녹음 중에는 왼쪽 패널의 **입력 마이크** 줄에서 마이크를 **녹음을 끊지 않고** 바꿀 수 있습니다. 회의 도중 헤드셋을 연결했을 때 유용합니다.

### 말을 멈추면 자막이 바로 뜹니다

한 구간(윈도)이 다 차기를 기다리지 않고, **말을 멈추고 잠깐 조용해지면** Madi가 그 구간을 앞당겨 마감해 전사를 바로 내보냅니다. 짧게 주고받는 대화(예: 진료 상담)에서 대기 시간이 크게 줄어듭니다. 멀리서 들어오는 작은 목소리는 잘리지 않도록 자동으로 기준을 맞춥니다.

## 시스템 오디오 캡처 (Zoom·Teams·영상)

Mac에서 재생되는 소리(온라인 회의, 영상 등)를 그대로 전사할 수 있습니다.

1. **설정(⌘,) → 녹음 → 입력**으로 갑니다.
2. **음원**에서 입력 방식을 고릅니다.
   - **마이크** — 내 앞의 소리만
   - **시스템 오디오** — Zoom·Teams·Slack·YouTube 등 Mac에서 재생되는 소리
   - **마이크+시스템** — 온라인 회의용. 내 목소리와 상대 목소리를 함께
3. 평소처럼 녹음을 시작합니다.

**참고**
- 시스템 오디오를 처음 쓸 때 macOS가 **‘화면 기록’ 권한**을 요청합니다. 오디오만 사용하며 화면은 저장하지 않습니다.

## 파일과 영상 전사

이미 가지고 있는 오디오 또는 영상 파일을 전사합니다.

1. 파일을 창에 **끌어다 놓거나**, **파일 선택 or 드래그 앤 드롭** 영역을 눌러 고릅니다. 드래그 중에는 **드롭하여 전사**가 표시됩니다.
2. **파일로 시작하기**를 누릅니다.
3. 진행률이 **전사 중 · N%** 로 표시됩니다.
4. 전사가 끝나면 결과가 화면에 나타납니다.

**참고**
- 파일을 놓기만 해서는 전사가 시작되지 않습니다. **파일로 시작하기**를 눌러야 시작합니다. 그 사이에 회의 정보를 고쳐도 됩니다.
- 영상(mp4·mov·m4v·mkv·webm·avi 등)의 음성은 자동으로 추출됩니다. 별도 변환이 필요 없습니다.
- 파일 전사에서만 쓸 수 있는 기능이 있습니다 — 줄별 **오디오 재생**과 **귀로 검토**. (**검토와 교정**, **작업 폴더와 내보내기** 참고.)

## 회의 모드

회의의 성격에 맞춰 화자 수와 강조 항목을 한 번에 맞춰 주는 프리셋입니다. 첫 화면 **회의 정보 → 회의 모드**에서 고릅니다.

| 모드 | 맞춰 주는 것 |
|---|---|
| **일반** | 기본 설정 · 발화자 자동 감지 |
| **1:1** | 발화자 2명 · 결정과 후속 조치 강조 |
| **스탠드업** | 발화자 자동 · 액션과 블로커 강조 |
| **인터뷰** | 발화자 2명 · 질문·답변 흐름 보존 |
| **강의** | 발화자 1명 · 핵심 요점 위주 정리 — **화자 분리를 자동으로 끕니다** |

**참고**
- 회의 모드는 녹음을 **시작하기 전에** 골라야 합니다. 녹음 중에는 잠깁니다.

## 화자 수

방 안의 인원수를 알고 있다면 미리 지정해 화자 분리 정확도를 높일 수 있습니다. 첫 화면 **회의 정보 → 화자**에서 **자동 / 2명 / 3명 / 4명 / 5명 이상** 중 고릅니다. **1명 항목은 없습니다** — 발표자가 한 명뿐이면 **설정 → 녹음 → 화자**의 **화자 분리**를 끄세요(**강의** 모드가 자동으로 그렇게 합니다).

인원수가 분명할 때 고정하면 화자가 더 정확하게 나뉩니다. 확실하지 않다면 **자동**을 두세요. 자세한 내용은 **화자** 페이지를 참고하세요.

## 전사 보기 전환

화면 상단의 토글로 두 가지 보기를 오갑니다.

- **내용** — 깨끗한 회의록 읽기 보기 (기본값). 읽기에 집중할 때 좋습니다.
- **상세** — 시각(타임코드), 신뢰도가 낮은 단어(호박색 강조), 발언 겹침 표시까지 보여 줍니다. 검토·수정할 때 좋습니다.

글자 크기는 상단의 **A− / A+** 버튼으로 조절합니다.

## 개인정보

Madi의 모든 전사는 이 Mac 안에서만 처리됩니다. 전사 내용은 절대 기기를 떠나지 않습니다.
