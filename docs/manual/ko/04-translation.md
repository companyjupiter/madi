# 실시간 번역

Madi의 번역은 100% 기기 안에서 동작합니다. 클라우드도, 계정도 필요 없습니다. 회의가 진행되는 동안 각 발화를 한국어·English·日本語·中文로 즉시 옮겨 원문 아래에 함께 보여 줍니다. 모든 번역은 동봉된 온디바이스 LLM(DNA3.0-4B)이 처리합니다.

## 먼저: 번역 모델 받기

번역은 별도의 모델(DNA3.0-4B, 약 2.6 GB)이 필요하며 앱에 동봉되어 있지 않습니다. 켤 때 한 번 내려받습니다.

1. **설정 → 번역**(또는 **모델**) 탭을 엽니다.
2. **번역 모델 다운로드** 버튼을 누릅니다.
3. 다운로드가 끝나면 실시간 번역 항목이 활성화됩니다.

메모리는 사용 중에 약 3 GB가 추가로 필요합니다. 모델을 받기 전에는 번역 토글이 비활성 상태이고, "번역 모델을 먼저 다운로드하세요."라는 안내가 표시됩니다.

## 실시간 번역 켜기 (다중 대상)

**설정 → 번역 → 실시간 번역 (다중 대상)** 에서 원하는 언어를 하나 이상 선택합니다.

- **한국어**
- **English**
- **日本語**
- **中文**

여러 언어를 동시에 켤 수 있습니다. 선택한 모든 언어로 각 줄을 한꺼번에 번역해 원문 바로 아래에 표시하며, 각 번역에는 언어 태그(한 / EN / 日 / 中)가 붙습니다. 원문과 같은 언어는 자동으로 제외됩니다.

> 참고: 번역 대상을 2개 이상 선택하면 실시간 반응 속도가 **정확(10초)** 으로 고정됩니다. 원문 줄 경계 오류가 모든 번역으로 번지지 않도록 가장 긴 문맥을 사용하기 때문입니다.

## 진행 중(중간) 번역

말하는 도중에도 기다릴 필요가 없습니다. 아직 끝나지 않은 줄에 대해 임시 번역이 먼저 표시되며 **진행 중** 으로 표시됩니다. 그 줄이 확정되면 임시 번역이 정식 번역으로 바뀝니다.

Madi는 진행 중에 만든 번역을 확정된 줄에 그대로 재사용하므로, 빠르게 뜨면서도 같은 문장을 다시 번역하지 않습니다.

## 자막 오버레이

**자막 오버레이** 는 화면 맨 위에 떠 있는 실시간 번역 자막 창입니다. Zoom·Teams 같은 통화 화면 위에 올려 두고 상대의 말을 실시간 번역으로 따라갈 수 있습니다.

- 사이드 패널의 **자막 오버레이** 버튼으로 켜고 끕니다.
- 창은 항상 맨 앞에 머물지만 포커스를 빼앗지 않으므로, 통화 앱에서 계속 클릭·입력할 수 있습니다.
- 전체 화면 위에서도 떠 있고, 배경을 잡아 원하는 위치로 끌어다 놓을 수 있습니다.
- 가장 큰 글씨는 번역문, 그 아래 작은 글씨는 원문입니다. 아직 번역 중일 때는 **진행 중** 으로 표시됩니다.

자막 언어는 선택한 번역 대상 중 첫 번째 언어를 사용합니다. 번역 대상을 모두 끄면 오버레이도 함께 닫힙니다(보여 줄 번역이 없기 때문).

## 성능 참고 — 메모리에 따라 달라집니다

실시간 번역과 회의 요약은 같은 LLM을 공유합니다. 그래서 동작 방식이 Mac의 메모리에 따라 달라집니다.

- **16 GB 이상 Mac**: 실시간 번역과 **라이브 액션 추출** 같은 기능이 함께 돌아갑니다. 번역 자막이 끊기지 않습니다.
- **16 GB 미만 Mac**: 한 번에 모델 하나만 메모리에 올릴 수 있습니다. **라이브 액션 추출** 같은 기능을 켜면 그동안 실시간 번역이 잠시 멈춥니다.

번역 자막을 끊김 없이 쓰고 싶다면 16 GB 미만 Mac에서는 라이브 액션 추출 같은 추가 기능을 끄는 것이 좋습니다.
