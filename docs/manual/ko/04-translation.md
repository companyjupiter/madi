# 실시간 번역·통역

Madi의 번역은 100% 기기 안에서 동작합니다. 클라우드도, 계정도 필요 없습니다. 회의가 진행되는 동안 각 발화를 한국어·English·日本語·中文로 즉시 옮겨 원문 아래에 함께 보여 줍니다. 모든 번역은 동봉된 온디바이스 LLM(DNA3.0-4B)이 처리합니다.

## 먼저: 번역 모델 받기

번역은 별도의 모델(DNA3.0-4B, 약 2.6 GB)이 필요하며 앱에 동봉되어 있지 않습니다. 켤 때 한 번 내려받습니다.

1. **설정 → 번역**(또는 **모델**) 탭을 엽니다.
2. **번역 모델 다운로드** 버튼을 누릅니다.
3. 다운로드가 끝나면 실시간 번역 항목이 활성화됩니다.

메모리는 사용 중에 약 3 GB가 추가로 필요합니다. 모델을 받기 전에는 번역 토글이 비활성 상태이고, "번역 모델을 먼저 다운로드하세요."라는 안내가 표시됩니다.

## 실시간 번역 켜기 (다중 대상)

**설정 → 번역 → 실시간 번역 (다중 대상)** 에서 원하는 언어를 하나 이상 선택합니다.

- **한국어**
- **English**
- **日本語**
- **中文**

여러 언어를 동시에 켤 수 있습니다. 선택한 모든 언어로 각 줄을 한꺼번에 번역해 원문 바로 아래에 표시하며, 각 번역에는 언어 태그(한 / EN / 日 / 中)가 붙습니다. 원문과 같은 언어는 자동으로 제외됩니다.

## 번역이 타이핑되듯 나타납니다

번역이 다 만들어질 때까지 기다리지 않습니다. Madi는 단어가 생성되는 대로 화면에 바로바로 채워 넣습니다(약 19밀리초에 한 글자꼴). 아직 쓰는 중인 줄 끝에는 커서 **▍** 가 깜빡여, 잘린 문장이 아니라 계속 이어지는 중임을 알려 줍니다.

말하는 도중에도 임시 번역이 먼저 뜨고 **진행 중** 으로 표시됩니다. 그 줄이 확정되면 임시 번역이 정식 번역으로 자연스럽게 바뀌며, 확정 번역이 도착할 때까지 임시 번역이 화면에 그대로 남아 있어 "번역이 잠깐 사라지는" 공백이 없습니다.

## 대면 통역 — 양방향 언어

Madi는 서로 다른 언어를 쓰는 두 사람의 대면 대화(예: 한국인 직원과 일본인·중국인 손님)를 위해 설계되었습니다.

**번역 대상으로 `한국어`와 다른 언어 하나만** 켜면 (예: 한국어 + 日本語) 양방향 통역 모드가 됩니다.

- **줄마다 방향을 자동으로 판별합니다.** 일본어로 말한 줄은 한국어로만, 한국어로 말한 줄은 일본어로만 번역합니다. 불필요한 번역이 없어 더 빠릅니다.
- **두 언어를 번갈아 말해도 양쪽 전사가 모두 정확합니다.** 세그먼트마다 어느 언어인지 다시 확인하기 때문에, 한 사람은 한국어·다른 사람은 일본어로 대화해도 각자의 말이 제대로 받아쓰기됩니다.
- 이 경우에는 반응 속도가 자동으로 느려지지 않습니다(아래 참고).

## 자주 쓰는 문구 사전 (즉시 번역)

같은 안내를 반복하는 현장(예: 진료실의 시술 후 주의사항)을 위해, 자주 쓰는 문구의 번역을 미리 저장해 둘 수 있습니다. 저장된 문구와 같은 말이 나오면 모델을 거치지 않고 **즉시(0초)** 번역이 표시됩니다.

기본으로 몇 가지 문구가 들어 있으며, 직접 문구를 추가·수정할 수 있습니다(저장 위치: `~/Library/Application Support/Sovereign/faq_translations.json`). 안전을 위해 정확히 일치하는 문구에서만 동작합니다.

## 반응 속도와 번역 품질

번역 대상을 **2개 이상**(예: 日本語 + 中文 + English) 선택하면, 원문 줄 경계 오류가 여러 언어로 번지지 않도록 반응 속도가 **정확(10초)** 으로 고정됩니다.

> 예외: `한국어` + 다른 언어 하나만 켠 **양방향 통역** 모드에서는 줄마다 실제 번역 대상이 한 개로 줄어들기 때문에 10초로 고정하지 않습니다. 대면 통역에서 자막이 더 빨리 뜹니다.

번역이 밀릴 때는 상단에 **"N줄 번역 대기"** 가 표시됩니다. 멈춘 것이 아니라 순서대로 처리 중이라는 뜻입니다(모델은 한 번에 한 줄씩 번역합니다).

## 자막 오버레이

**자막 오버레이** 는 화면 맨 위에 떠 있는 실시간 번역 자막 창입니다. Zoom·Teams 같은 통화 화면 위에, 또는 진료실 디스플레이에 올려 두고 상대의 말을 실시간 번역으로 따라갈 수 있습니다.

- 사이드 패널의 **자막 오버레이** 버튼으로 켜고 끕니다.
- 창은 항상 맨 앞에 머물지만 포커스를 빼앗지 않으므로, 통화 앱에서 계속 클릭·입력할 수 있습니다.
- 전체 화면 위에서도 떠 있고, 배경을 잡아 원하는 위치로 끌어다 놓을 수 있습니다.
- 가장 큰 글씨는 번역문, 그 아래 작은 글씨는 원문입니다.
- 여러 명이 있을 때는 자막에도 **화자 색점과 이름** 이 붙어 누구 말인지 알 수 있습니다.
- 말을 기다리는 동안 **마이크 입력 막대** 가 움직여, 시스템이 듣고 있음을 확인시켜 줍니다.
- 아직 번역 중일 때 상태 문구("진행 중 / 번역 중… / 음성 대기")는 **보는 사람의 언어로** 표시됩니다 — 일본어 자막이면 「翻訳中…」, 중국어 자막이면 「翻译中…」.

### 직원 자막 + 환자 자막 (이중 화면)

진료실 대면 통역을 위해 자막을 **두 개** 로 나눌 수 있습니다.

- **직원 자막** — 주 화면에 작게. 직원이 보는 언어(첫 번째 번역 대상).
- **환자 자막** — 외장 모니터에 크게(원거리 판독용). 환자 언어로 표시.

**설정 → 자막 오버레이(진료실)** 에서 켭니다. 직원 글씨(14–48pt)·환자 글씨(24–96pt)·패널 폭·환자 화면·환자 언어를 각각 지정할 수 있습니다. 진료 의자와 디스플레이 사이 1.5–2.5m 거리에서 읽기 좋게 큰 글씨를 씁니다.

## 대화(채팅) 보기

정확히 두 사람이 대화할 때, 전사를 **메신저처럼 좌우로** 나눠 볼 수 있습니다. 첫 화자는 왼쪽, 상대는 오른쪽 말풍선에 놓여 번갈아 읽는 통역에 적합합니다. 제어 바에 두 명이 감지되면 대화 보기 버튼이 나타납니다.

## 성능 참고 — 메모리에 따라 달라집니다

실시간 번역과 회의 요약은 같은 LLM을 공유합니다. 그래서 동작 방식이 Mac의 메모리에 따라 달라집니다.

- **16 GB 이상 Mac**: 실시간 번역과 **라이브 액션 추출** 같은 기능이 함께 돌아갑니다. 번역 자막이 끊기지 않습니다.
- **16 GB 미만 Mac**: 한 번에 모델 하나만 메모리에 올릴 수 있습니다. **라이브 액션 추출** 같은 기능을 켜면 그동안 실시간 번역이 잠시 멈춥니다.

번역 자막을 끊김 없이 쓰고 싶다면 16 GB 미만 Mac에서는 라이브 액션 추출 같은 추가 기능을 끄는 것이 좋습니다.
