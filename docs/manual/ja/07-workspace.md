# ワークスペースとエクスポート

Madi は保存フォルダ全体を 1 つのワークスペースとして表示します。ウィンドウ右側の**ワークスペースエクスプローラー**では、過去の会議を開き直したり、保存先を変更したり、必要な形式でエクスポートしたりできます。

> アプリのインターフェースは韓国語です。韓国語の UI ラベルには、以下では日本語の訳を括弧で添えています。

## ワークスペースエクスプローラー

エクスプローラーはウィンドウの右側に**常に表示**されます。上部は会議の一覧、下部は自動保存・フォルダ・エクスポートの操作部です。

### 会議一覧

- **파일**（ファイル）タブには、保存フォルダ内の会議記録が新しい順に積み重なって表示されます。
- 会議記録をクリックすると、その会議が画面に再び開きます。

## 自動保存

- **자동저장**（自動保存）スイッチをオンにしておくと、文字起こしが終わったときに会議記録が **Markdown（.md）** として保存されます。
- **폴더**（フォルダ）の行に現在の保存先が表示されます。**변경**（変更）を押すと別のフォルダを選べます。
- 選んだフォルダは、**保存**と**エクスポート**の両方の初期設定の保存先になります。

> 同じ設定は **설정 (⌘,) → 저장**（設定 → 保存）タブにもあります。使いやすい方で変更してください。

**ヒント** — **⌘K** を押して **작업 폴더 변경**（ワークスペースフォルダを変更）と入力すれば、すぐにフォルダを選べます。

## エクスポート

エクスプローラー下部の **내보내기**（エクスポート）ボタンを押すと、**내보내기 형식**（エクスポート形式）を尋ねられます。形式を選ぶと、保存先を指定できます。

| 形式 | 用途 |
|---|---|
| **Markdown (.md)** | Markdown 形式の会議記録。話者名・翻訳・修正も含まれます |
| **Subtitles (.srt)** | SRT 字幕 |
| **Subtitles (.vtt)** | VTT 字幕 |
| **Plain text (.txt)** | プレーンテキスト |
| **JSON (.json)** | JSON データ |

**参考**
- 文字起こしが空のときは、**내보내기**（エクスポート）ボタンが淡色表示になります。
- SRT/VTT は常に、最終的に修正された原文を使用します。**レビューと修正**を参照してください。

## クリックしてその瞬間を聞く

オーディオ・動画**ファイルを読み込んで文字起こししたセッション**（元のファイルがディスク上に残っている場合）では、各行に再生ボタンが表示されます。

1. 聞きたい行の再生ボタン（ツールチップ **「이 구간 오디오 재생」**（この区間の音声を再生））を押します。
2. その行が話された正確な瞬間から、元のメディアが再生されます。

> **参考：** リアルタイムのマイク録音セッションには元のファイルがないため、行ごとの再生ボタンは表示されません。

## 過去の会議をすばやく探す

**⌘K** のコマンドパレットに会議名を入力すると、保存された会議記録へ直接移動できます。話者名でも検索できます。
