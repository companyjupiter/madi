# 話者

Madi は会議中に誰が話したかを自動的に判別します。これらの処理はすべてこの Mac の中で行われます。

> アプリのインターフェースは韓国語です。韓国語の UI ラベルには、以下では日本語の訳を括弧で添えています。

## 自動話者分離

録音と文字起こしを行っている間、Madi は発言を話者ごとに自動的に分けます。

- 各話者には固有の**色**と **화자 N**（話者 N）ラベルが付きます。
- 左パネルの**話者バー**が、会議全体で誰がいつ話したかを 1 行で示します。

**参考**
- 話者分離は **설정 (⌘,) → 녹음 → 화자**（設定 → 録音 → 話者）の **화자 분리**（話者分離）スイッチでオフにできます。

## 話者数の固定

部屋にいる人数がわかっている場合は、設定すると精度が向上します。

1. 最初の画面で **회의 정보 → 화자**（会議情報 → 話者）へ進みます。
2. **자동**（自動）**/ 1명 / 2명 / 3명 / 4명 이상**（1 名 / 2 名 / 3 名 / 4 名以上）から選びます。

**参考**
- 人数が確かなときに固定すると、話者の分かれ方がより正確になります。確信がない場合は **자동**（自動）のままにしてください。
- 録音を**始める前に**選んでください — 録音が始まるとロックされます。

### 미확인（未確認）話者

話者数を**固定**しているとき、指定した人物の誰とも明らかに一致しない声は、**미확인**（未確認）としてまとめられます。これにより、通りすがりの人の一言や突発的なノイズが、実際の話者の誰かに誤って割り当てられるのを防ぎます。

- **미확인** は人物ではなく、「ここに入れる場所がない」ことを示します。名前を付けることはできません。
- 人数を自動のままにしている場合は表示されません。

## 話者に名前を付ける

1. 文字起こしで、話者ラベル（例: **화자 1** / 話者 1）または話者チップをクリックします。
2. **이름 (예: 김부장)**（名前、例: キム部長）の欄に実際の名前を入力します。
3. **저장**（保存）を押します。入力した名前は、**その話者のすべての発言とエクスポート**に適用されます。

**参考**
- 名前は**この文字起こしにのみ**適用されます。Madi が次の会議で同じ人物を自動的に認識することはありません — 会議ごとに付け直します。
- **미확인**（未確認）には名前を付けられません。

## AI 話者修正（録音終了後）

録音が終わると、オンデバイスの LLM が会話を読み取り、**明らかな話者の誤分離**を控えめに修正します — 1 人の発言が 2 人の話者に分かれてしまった場合や、ある行が別の人物に割り当てられてしまった場合を整理します。

- **설정 (⌘,) → 번역 → AI 교정 (세션 종료 후)**（設定 → 翻訳 → AI 修正（セッション終了後））の **화자·언어 자동 교정**（話者・言語の自動修正）でオン・オフを切り替えます。
- 修正が適用されると、文字起こしの上に案内が表示され、**화자 교정 되돌리기**（話者修正を元に戻す）ボタンが付きます — **1 回のクリックですべて元に戻せます。**
- 翻訳モデル（DNA3.0-4B）が必要です。

## 発言の重なりマーカー

2 人が同時に話すと、**상세**（詳細）表示に **⟨+name 겹침⟩**（重なり）マーカーが現れ、割り込んだ 2 人目の話者を示します。

**参考**
- 重なりマーカーは **상세**（詳細）表示で**のみ**表示されます。ウィンドウ上部で **내용 → 상세**（内容 → 詳細）に切り替えてください。
- **설정 (⌘,) → 녹음 → 화자**（設定 → 録音 → 話者）の **중첩 발화 감지**（重なり発話の検出）が有効になっている必要があります。
