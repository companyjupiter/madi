# AI 要約・質疑応答

文字起こしが終わると、オンデバイスの LLM が会議を構造化された要約にまとめ、その内容について自然言語で質問できます。録音中は、右側の **실시간 요약**（リアルタイム要約）パネルが要点の箇条書きを先に表示します（下の **リアルタイム要約（録音中）** を参照）。要約と質疑応答は翻訳と同じハードウェア向けモデル（8 GB は DNA3.0-2B、16 GB 以上は 4B）を使い、**文字起こしの内容も要約も、この Mac から外に出ることはありません。**

> Madi のインターフェースは **설정 (⌘,) → 표시 → 언어 / Language** で 한국어 / English / 日本語 を切り替えられます。本マニュアルは韓国語のラベルを先に示し、括弧内に日本語 UI での表記を添えています。

## まず：翻訳・要約モデル

要約と質疑応答は、翻訳と同じオンデバイスモデルを使います。これがないと、**要約ボタンが表示されません。** ダウンロード方法は **リアルタイム翻訳・通訳** または **設定** のページを参照してください。

## リアルタイム要約（録音中）

録音中も話の流れを見失わないように、会話がある程度たまると（6 行以上）、右側に **실시간 요약**（リアルタイム要約）パネルがすっと開き、要点をまとめた箇条書き 3〜6 個が約 30 秒間隔で更新されます。

- **最初は表示されません** — 最初の要約ができた瞬間にパネルが現れます。
- **録音が終わると消えます** — その役割は、セッション終了後の正式な AI 要約（要約シート）が引き継ぎます。
- パネルの下部には **온디바이스 · 방금 갱신**（オンデバイス・たった今更新）と表示されます（時間がたつと「N분 전 갱신」（N 分前に更新）に変わります）。要約の生成中は、小さなスピナーが回ります。

### 更新のしくみ — ローリング要約

各更新は **直前の要約 + それ以降の新しい発言** だけを反映します。そのため、非常に長いセッションでは、序盤の細かい内容が要約から押し出されることがあります — このパネルの目的は「ここまでの要点」であり、全体の内容は文字起こしとセッション後の要約にそのまま残ります。

要約テンプレート（会議 / 講義 / 面談）は、最初の画面で選んだ 회의 모드（会議モード）に合わせて **自動で** 反映され、ライブ中に選ぶ UI はありません。リアルタイム要約そのものは、テンプレートに関係なく常にフラットな箇条書きのリストです。

### リアルタイムの文字起こし・翻訳が常に優先です

リアルタイム要約は、字幕（文字起こし・翻訳）の処理に余裕があるときにだけ作られます。字幕が遅れているときは、その回の更新をスキップします。つまり、この機能をオンにしても **ライブ字幕の性能には影響しません。**

### 動作要件と設定

- **メモリ 16 GB 以上** と **翻訳・要約モデルのインストール** が必要です。16 GB 未満の Mac ではこの機能は無効になり、設定に案内が表示されます — セッション終了後の AI 要約をお使いください。
- オン / オフの切り替え: **설정 → 실시간 요약 → 「녹음 중 실시간 요약 탭」**（設定 → リアルタイム要約 → 「録音中のリアルタイム要約タブ」）トグル。既定ではオンです。
- ほかの機能と同じく、すべてオンデバイスで動作します — 文字起こしの内容もリアルタイム要約も、この Mac から外に出ることはありません。

## 会議の要約を作成する

1. 文字起こしが終わったあと（録音中はできません）、上部ツールバーの **✦（キラキラ）ボタン** を押します。または **⌘K** のコマンドパレットから **요약 생성**（要約を生成）を選びます。
2. **회의 요약**（会議の要約）シートが開き、ローカル LLM が要約を生成します。「文字起こしの内容はこの Mac から外に出ません」という案内も表示されます。
3. 上部の **전체 / 화자별**（全体 / 話者別）トグルで表示を切り替えます。
   - **전체**（全体）— 会議全体をひとまとめに整理します（どのセクションが出るかは、下のテンプレートに従います）。
   - **화자별**（話者別）— 各話者が何について話したか（最初に選んだときに生成されます）。
4. その右の **회의 / 강의 / 인터뷰**（会議 / 講義 / 面談）トグルで **요약 템플릿**（要約テンプレート）を選びます。すぐ下の行に、そのテンプレートが取り出すセクション構成が表示されます — たとえば **회의**（会議）を選ぶと「要約・アクション・決定」。既定値は最初の画面で選んだ 회의 모드（会議モード）から自動で決まるので、ふだんはそのままで構いません。下の **要約テンプレート** を参照してください。

**参考**
- ✦ ボタンは、文字起こしがあり、録音中でないときだけ有効になります。文字起こしが空のときは淡色表示になります。

### 要約シートのボタン

- **복사**（コピー）— 要約テキストをクリップボードにコピーします。
- **다시 생성**（再生成）— 同じ文字起こしから要約を新しく生成します。
- **슬라이드(HTML)**（スライド（HTML））— オフラインで開ける HTML スライドを書き出し、Finder で表示します。セクションごとにスライドが 1 枚作られ、**アクション項目** と **フォローアップ** はチェックボックスの形で出ます。
- **리캡 카드**（リキャップカード）— 共有できる 1 ページの要約を開きます（下記参照）。
- **내보내기…**（エクスポート…）— 要約を `.md` ファイルとして保存します。

## 要約テンプレート

同じ文字起こしでも、会議なのか講義なのか面談なのかで、残しておくべきものは変わります。要約シート上部の **회의 / 강의 / 인터뷰**（会議 / 講義 / 面談）トグルで、何を取り出すかを決めます。

| テンプレート | 取り出してくれるもの | こんなときに |
|---|---|---|
| **회의**（会議） | **요약**（要約）・**액션 아이템**（アクション項目）・**결정 사항**（決定事項） | 一般的な会議、1:1、スタンドアップ |
| **강의**（講義） | **요약**（要約）・**핵심 요점**（要点）・**용어·개념**（用語と概念） | 講義・発表・セミナー |
| **인터뷰**（面談） | **요약**（要約）・**문답**（質疑応答）・**후속 조치**（フォローアップ） | 面談、相談、診療 |

どのテンプレートも先頭に **2〜4 文の要約** が来て、その下のセクションは 1 行に 1 項目ずつ並びます。面談の **문답**（質疑応答）は、質問の行（`Q:`）のすぐ下に回答の行（`A:`）が続く形で出ます。

**参考**
- **회의**（会議）テンプレートの結果は、これまでとまったく同じです。以前に保存した要約や書き出したファイルも、そのまま開けます。
- 8 GB の Mac（DNA3.0-2B）と 16 GB 以上の Mac（4B）、どちらのモデルでも 3 つのテンプレートを確認しています。

### 既定のテンプレートは 회의 모드（会議モード）で決まります

最初の画面で選んだ **회의 모드**（会議モード）に合わせて、テンプレートが自動で決まります。ふだんは自分で選ぶ必要はありません。

| 회의 모드（会議モード） | 自動で使われるテンプレート |
|---|---|
| **일반**（一般）・**1:1**・**스탠드업**（スタンドアップ） | **회의**（会議） |
| **강의**（講義） | **강의**（講義） |
| **인터뷰**（面談） | **인터뷰**（面談） |

会議モードの選び方は **録音と文字起こし → 회의 모드**（会議モード）を参照してください。

### シートで切り替えると、その場で作り直します

- テンプレートを切り替えると、それまでに作った要約を **전체（全体）・화자별（話者別）とも破棄します。** 表示中の側はすぐに作り直し、もう一方はそのタブに切り替えたときに作ります。（화자별（話者別）のまとめ方そのものはテンプレートに左右されません。）
- 要約を作っている間はこのトグルが淡色表示になり、選べません。生成が終わると、また押せるようになります。
- シートで切り替えたテンプレートは **このセッションかぎりの一時的な変更** です。保存はされず、회의 모드（会議モード）を変えると、またモード基準に戻ります。これからも同じテンプレートを使いたい場合は、最初の画面で会議モードを変更してください。

### フォローアップはアクションとして扱われます

**인터뷰**（面談）テンプレートの **후속 조치**（フォローアップ）は、アクションと同じものとして扱われます。そのためリキャップカードのアクション一覧にも一緒に入ります。

**강의**（講義）テンプレートには決定もアクションもないため、リキャップカードの決定事項とアクション項目は空のままです。代わりに **핵심 요점**（要点）と **용어·개념**（用語と概念）が入ります。意図した動作です — 講義は要点と用語を残すことが目的だからです。

### 長い会議・講義

一度に読み切れないほど長い文字起こしは、分けて畳んでから 1 つにまとめます。このとき **何を残しながら畳むか** がテンプレートによって変わります — 講義は要点と用語を、面談は質問と回答の組、そしてフォローアップを優先して残します。

## リキャップカード

会議を 1 ページにまとめた、共有用の要約です。要約シートの **리캡 카드**（リキャップカード）で開きます。次の内容が入っています。

- タイトル + 日付
- TL;DR（要点）
- テンプレート固有のセクション — 講義の **핵심 요점**（要点）・**용어·개념**（用語と概念）、面談の **문답**（質疑応答）が TL;DR のすぐ下にそのまま入ります（会議の要約にはありません）
- 決定事項のリスト
- 担当者別のアクション項目 — 面談の **フォローアップ** もここに一緒に入ります
- 話者ごとの発話時間
- 一行の引用

**복사**（コピー）で Markdown としてコピーするか、**내보내기…**（エクスポート…）でファイルとして保存できます。

## 議事録に質問（質疑応答）

会議の内容を自然言語で質問すると、ローカル LLM が文字起こしを根拠に答えます。要約シートの下部にあります。

1. **회의록에 물어보기**（議事録に質問）欄に質問を入力します。例:「무엇을 결정했나요?」（何を決めましたか？）、「김부장이 맡은 일은?」（キム部長の担当は？）。
2. 紙飛行機ボタンを押すか、Enter を押します。
3. **이 회의 / 전체 워크스페이스**（この会議 / ワークスペース全体）トグルで範囲を決めます。
   - **이 회의**（この会議）— いま開いている文字起こしからのみ回答します。
   - **전체 워크스페이스**（ワークスペース全体）— 保存された **すべての** 文字起こしを横断して検索します。例:「지난달 보안 결정은?」（先月のセキュリティに関する決定は？）。

**参考**
- 回答中は「로컬 LLM이 답하는 중…」（ローカル LLM が回答中…）と表示されます。

## プライバシー

要約も質疑応答も、この Mac 上で動作します。文字起こしの内容も要約も、この端末から外に出ることはありません。
