# システムディクテーション（音声入力・今後提供予定）

> **準備中 — 現在のベータには含まれていません。** 以下は今後提供予定の機能の紹介です。このバージョンでは設定に **받아쓰기（ディクテーション）タブがなく**、ショートカットキーも動作しません。

システムディクテーション（音声入力）は、macOS のどこでも使える音声入力機能として準備を進めています。グローバルショートカットキーを押したまま話し、離すと、話した内容が**デバイス上で**文字に変換され、そのとき最前面にあるアプリ（メモ、メール、Slack、コードエディタなど）の入力欄にそのまま入力される — これが目標です。会議の文字起こし・翻訳と同様に、100% オンデバイスで動作するように設計しています。

## 予定している動作

- **プッシュトゥトーク** — グローバルショートカットキーを押している間だけ録音し、離した瞬間に書き取ったテキストが入力されます。
- **軽快で高速** — 大規模言語モデルを読み込まず、ディクテーション専用の音声認識だけを短時間実行して終了する方式のため、メモリの少ない Mac でも負担が少なくて済みます。
- **クリップボードの保持** — テキストを入力する際に既存のクリップボードを保存し、直後に元へ戻します。
- **会議の録音中は無効** — ディクテーションと会議の録音は同じマイクを使うため、競合を防ぐために録音中はオフになります。

## 現時点では

現在のバージョンで使える機能は、**会議の文字起こし・話者分離・オンデバイス翻訳・レビューと修正・AI 要約**です。システムディクテーションは今後のアップデートで提供予定です。アップデートの確認は **Madi メニュー → 업데이트 설치…**（アップデートをインストール…）から行えます。
