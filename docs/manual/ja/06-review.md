# 確認と修正

文字起こしが終わったら、きれいに読むことも、細かく見て修正することもできます。Madi はあなたが行った修正を記憶し、次の会議で自動的に適用します。

> アプリのインターフェースは韓国語です。韓国語の UI ラベルには、以下では日本語の訳を括弧で添えています。

## 내용（内容）と 상세（詳細）の表示

ウィンドウ上部の切り替えスイッチで、2 つの表示を行き来します。

- **내용**（内容）— タイムコードやマーカーのない、すっきりした表示。
- **상세**（詳細）— タイムコード、低信頼度の単語（琥珀色）、話者の重なりマーカー（**⟨+name 겹침⟩**）を追加します。

確認と編集は **상세**（詳細）表示で行います。

## 行を編集する

1. 修正したい行を **ダブルクリック** します（または **상세**（詳細）表示で鉛筆ボタン。ツールチップは **「이 문장 편집」**（この文を編集））。
2. **내용**（内容）表示からダブルクリックすると、自動的に **상세**（詳細）表示に切り替わり、エディターが開きます。
3. テキストを修正して **저장**（保存、⌘↩）を押します。取り消すには **취소**（キャンセル、Esc）。
4. 編集した行には **편집됨**（編集済み）マークが付きます。

原文を編集すると、古いテキストから生成中だった翻訳は破棄され、修正後のテキストで再実行されます。遅れて届いた AI の結果が、あなたの修正を上書きすることはありません。

## 翻訳文を修正する

確定した翻訳を **ダブルクリック** すると、**번역 교정**（翻訳の修正）欄が開き、その言語の翻訳を直接修正できます。

- 保存した翻訳には鉛筆マークが付き、複数ターゲット翻訳の他の言語はそのまま保たれます。
- 修正した原文・翻訳・話者名は Markdown と JSON に保存され、Markdown の文字起こしを開き直しても翻訳は保持されます。
- SRT/VTT は常に、最終的に修正された原文を使います。

## 검토 필요（要確認）— 低信頼度の単語をまとめて確認

**상세**（詳細）表示は、信頼度のしきい値（既定 0.55）を下回って認識された単語を琥珀色で強調します。

1. 上部のバーに **검토 필요 N개**（要確認 N 件）と、現在位置（**N/全体**）が表示されます。
2. **∧**（前の要確認単語）と **∨**（次の要確認単語）で、単語間を移動します。
3. 一つずつ確認し、必要ならその場で修正します。

しきい値は **설정 (⌘,) → 저장 → 음성 인식**（設定 → 保存 → 音声認識）の **저신뢰 표시 기준 (VAD)**（低信頼度のしきい値（VAD））で調整します。値を上げると、より多くの単語が要確認になります。

## 耳で確認する

ファイルから文字起こししたセッションでは、Madi が要確認の各単語の音声を再生するので、耳で確認できます。

1. 確認バーの再生ボタン（ツールチップ **「저신뢰 단어 귀로 검토」**（低信頼度の単語を耳で確認））を押します。
2. 要確認の単語が順に再生され、自動的に次へ進みます（ハンズフリー）。進行状況は **재생 N/전체**（再生 N/全体）と表示されます。
3. もう一度同じボタンを押すと停止します（ツールチップ **「귀로 검토 멈춤」**（耳での確認を停止））。

> **注記：** 耳で確認できるのは、元のメディアが存在する **ファイル文字起こしのときだけ** です。リアルタイムのマイク録音には元ファイルがないため、表示されません。

## AI 修正（録音終了後）

録音が終わると、オンデバイスの LLM が会話全体を読み取り、**明らかな話者の誤分割** と **誤った言語で文字起こしされた行** を控えめに修正します。

- **オンにする：** **설정 (⌘,) → 번역 → AI 교정 (세션 종료 후)**（設定 → 翻訳 → AI 修正（セッション終了後））の **화자·언어 자동 교정**（話者・言語の自動修正）。
- 修正が適用されると、文字起こしの上に案内が表示され、**화자 교정 되돌리기**（話者修正を元に戻す）ボタンが付きます — **1 回のクリックですべて元に戻せます。**
- 翻訳モデル（DNA3.0-4B）が必要です。

## 個人用語集 — あなたの修正から学習する

文字起こしの 1 行を修正すると、Madi はその修正を学習します。**단어장**（用語集）スイッチをオンにしておくと、次の会議で同じ専門用語や名前の誤認識を自動的に修正します。

**オンにする：** **설정 (⌘,) → 단어장**（設定 → 用語集）タブで、**학습한 교정 자동 적용**（学習した修正の自動適用）をオンにします。

> **注記：** 学習はスイッチに関係なく **常に** 行われ、このスイッチが切り替えるのは *適用* だけです。そのためオンにすると、それまでに学習した内容がただちに適用されます。

### 自動適用の基準（最小確認回数）

- **최소 확인 횟수**（最小確認回数）スライダーで、同じ修正を何回確認したら信頼して自動適用するか（1–5 回）を設定します。
- 値が大きいほど控えめになります — 偶発的な編集 1 回が、あとの文字起こしを上書きしてしまうのを防ぎます。

### 学習した修正の管理

**설정 → 단어장**（設定 → 用語集）タブの一覧で、学習したルールを管理します。

- 各ルールは `誤った単語 → 正しい単語` のように、確認回数とともに表示されます。
- ルールの隣のゴミ箱ボタンで、そのルールだけを忘れさせます。
- **전체 지우기**（すべて削除）で、すべて消去します。

## テキストの選択とコピー

文字起こし全体をドラッグで選択し、**⌘C** でコピーできます。
