# 録音と文字起こし

Madi は会議の音声を人が話すそばからリアルタイムで文字起こしし、すでにお持ちの音声・動画ファイルも文字起こしできます。すべての処理はこの Mac の中で行われ、文字起こしの内容がデバイスを離れることはありません。

> アプリのインターフェースは韓国語です。韓国語の UI ラベルには、以下では日本語の訳を括弧で添えています。

## 最初の画面 — 会議情報とはじめる

アプリを開くと、最初の画面が 2 つに分かれます。左側で **これがどんな会議なのか** を Madi に伝え、右側で **開始** します。

### 회의 정보（会議情報）— 左

録音を始める前にこれらを設定しておくと、結果の品質が向上します。**録音中はロックされます。**

- **입력 언어**（入力言語）— 話されている言語。自動検出するか、特定の言語に固定します。
- **출력 언어**（出力言語）— 翻訳先の言語（複数選択可）。翻訳モデルが必要です。**リアルタイム翻訳**を参照してください。
- **회의 모드**（会議モード）— 会議の性格。下記を参照してください。
- **화자**（話者）— 部屋にいる人数。下記を参照してください。

### 시작하기（はじめる）— 右

- **파일로 시작하기**（ファイルから開始）— ファイルを選ぶかドロップした後に押します。
- **지금 녹음 시작**（今すぐ録音を開始）— マイクを選んですぐに録音します。

## リアルタイムのマイク録音

1. **시작하기**（はじめる）でマイクを選びます（初期設定は「시스템 기본」/ システム標準）。
2. **지금 녹음 시작**（今すぐ録音を開始）を押します。録音が始まる前に短いカウントダウンが流れ、その間に**キャンセル**できます。
3. 話し始めると、ウィンドウ中央に文字起こしがリアルタイムで流れます。
4. 左パネルの **일시 정지**（一時停止、⌘P）で一時停止し、**정지**（停止、⌘R）で終了します。

**参考**
- 停止すると、そこまでに取り込んだ内容がまとめられます。自動保存がオンの場合、ファイルに保存されます。
- 自動保存がオフの場合、終了する前に Madi が確認を表示します — **내보내기**（エクスポート）で先に保存できます。

### 에너지 흐름（エネルギーフロー）

左パネル下部の **에너지 흐름** グラフは、会議の雰囲気を 1 本の線で示します — **発言の速さ・重なり・沈黙**を総合した流れです。

- **グラフ上の一点をクリックすると、その箇所へ移動します。** 会議で最も盛り上がった場面をすぐに探し出すのに便利です。
- 十分な発言がたまる前は「발언이 쌓이면 흐름이 표시됩니다」（発言がたまると流れが表示されます）と案内されます。

### 録音中のマイク切り替え

録音中は、左パネルの **입력 마이크**（入力マイク）の行で、**録音を中断せずに**マイクを切り替えられます — 会議の途中でヘッドセットを接続したときに便利です。

### 話し終わるとすぐに字幕が表示されます

Madi は 1 つの区間（ウィンドウ）がいっぱいになるのを待ちません。**話を止めて少しの間静かになると**、Madi はその区間を早めに区切り、文字起こしをすぐに送り出します — 短くやり取りする会話（例: 診療相談）では待ち時間が大きく減ります。遠くから入ってくる小さな声が途切れないよう、しきい値は自動で調整されます。

## システム音声のキャプチャ（Zoom・Teams・動画）

Mac で再生されている音声（オンライン会議、動画など）をそのまま文字起こしできます。

1. **설정 → 녹음 → 입력**（設定 → 録音 → 入力）へ進みます。
2. **음원**（音源）で、音声の取り込み方法を選びます。
   - **마이크**（マイク）— 目の前の音だけ
   - **시스템 오디오**（システム音声）— Mac で再生されている音: Zoom・Teams・Slack・YouTube など
   - **마이크+시스템**（マイク＋システム）— オンライン会議向け: 自分の声と相手の声を一緒に
3. いつものように録音を開始します。

**参考**
- システム音声を初めて使うとき、macOS が**画面収録**の許可を求めます。使用されるのは音声のみで、画面が保存されることはありません。

## ファイルと動画の文字起こし

1. ファイルをウィンドウに**ドロップ**するか、**파일 선택 or 드래그 앤 드롭**（ファイル選択 or ドラッグ＆ドロップ）の領域をクリックして選びます。ドラッグ中は **드롭하여 전사**（ドロップして文字起こし）と表示されます。
2. **파일로 시작하기**（ファイルから開始）を押します。
3. 進行状況が **전사 중 · N%**（文字起こし中 · N%）と表示されます。
4. 完了すると、結果が画面に表示されます。

**参考**
- ファイルを置いただけでは文字起こしは**始まりません** — **파일로 시작하기** を押す必要があります。その間に会議情報を先に調整できます。
- 動画（mp4・mov・m4v・mkv・webm・avi など）から音声は自動的に抽出されます。別途の変換は不要です。
- ファイルの文字起こしで**のみ**使える機能が 2 つあります — 行単位の**音声再生**と**耳で確認**です。**レビューと修正**および**ワークスペースとエクスポート**を参照してください。

## 회의 모드（会議モード）

会議の性格に合わせて、話者数と強調する項目を一括で調整するプリセットです。最初の画面の **회의 정보 → 회의 모드**（会議情報 → 会議モード）で選びます。

| モード | 調整される項目 |
|---|---|
| **일반**（一般） | 標準設定 · 話者を自動検出 |
| **1:1** | 話者 2 名 · 決定事項とフォローアップを強調 |
| **스탠드업**（スタンドアップ） | 話者は自動 · アクションとブロッカーを強調 |
| **인터뷰**（面談） | 話者 2 名 · 質問と回答の流れを保持 |
| **강의**（講義） | 話者 1 名 · 要点を中心に整理 |

**参考**
- 会議モードは録音を**始める前に**選んでください。録音中はロックされます。

## 화자（話者数）

部屋にいる人数がわかっている場合は、設定すると話者分離が向上します。最初の画面の **회의 정보 → 화자**（会議情報 → 話者）で、**자동**（自動）**/ 1명 / 2명 / 3명 / 4명 이상**（1 名 / 2 名 / 3 名 / 4 名以上）から選びます。

人数が確かなときに固定すると、話者の分かれ方がより正確になります。確信がない場合は **자동**（自動）のままにしてください。詳しくは**話者**ページを参照してください。

## 文字起こし表示の切り替え

ウィンドウ上部のトグルで、2 つの表示を切り替えます。

- **내용**（内容）— すっきり読みやすい文字起こし。初期設定で、読むのに最適です。
- **상세**（詳細）— タイムコード、信頼度の低い単語（琥珀色でハイライト）、話者の重なり表示が加わります。確認・修正に最適です。

文字サイズは上部の **A− / A+** ボタンで調整します。

## プライバシー

Madi のすべての文字起こしは、この Mac の中で処理されます。文字起こしの内容がデバイスを離れることは決してありません。
