# リアルタイム翻訳・通訳

Madi の翻訳は 100% お使いのデバイス上で動作します — クラウドもアカウントも不要です。会議の進行中、話された各行を韓国語・英語・日本語・中国語に翻訳し、原文のすぐ下に表示します。すべての処理はオンデバイスの LLM（DNA3.0-4B）が行います。

> アプリのインターフェースは韓国語です。韓国語の UI ラベルには、以下では日本語の訳を括弧で添えています。

## まず：翻訳モデルをダウンロード

翻訳には別途モデル（DNA3.0-4B、約 2.6 GB）が必要で、アプリには同梱されていません。最初に一度だけダウンロードします。

1. **설정 (⌘,) → 번역**（設定 → 翻訳）を開きます。
2. **번역 모델 다운로드**（翻訳モデルをダウンロード）を押します。
3. 完了すると、翻訳のオプションが使えるようになります。

使用中は約 3 GB のメモリが追加で必要になります。モデルをインストールする前はトグルが無効で、「번역 모델을 먼저 다운로드하세요.」（先に翻訳モデルをダウンロードしてください。）と表示されます。

> **번역 タブが表示されない場合** — お使いのビルドには翻訳エンジンが含まれておらず、翻訳機能自体を利用できません。

## 出力言語を選ぶ

設定は 2 か所にありますが、内容は同じです。使いやすいほうをどうぞ。

- **첫 화면 → 회의 정보 → 출력 언어**（最初の画面 → 会議情報 → 出力言語）— 会議を始めるときに。
- **설정 (⌘,) → 번역 → 실시간 번역 (다중 대상)**（設定 → 翻訳 → リアルタイム翻訳・複数ターゲット）— 한국어 / English / 日本語 / 中文 のトグル。

選んだすべての言語に各行を同時に翻訳し、原文のすぐ下に表示します。それぞれに言語タグが付きます。原文と同じ言語は自動的に除外されます。

**参考**
- 出力言語は **最大 3 つ** まで選べます。
- 翻訳モデルがないと、出力言語はまったく選べません。

## 翻訳はタイプされるように表示されます

Madi は翻訳が完成するまで待ちません。単語は生成されるそばから画面に表示されていきます。まだ書いている途中の行末にはカーソル **▍** が点滅し、途中で切れたのではなく続いていることが分かります。

誰かがまだ話している間は、まず暫定的な翻訳が表示され、**진행 중**（進行中）と示されます。その行が確定すると、暫定訳はなめらかに確定訳へと切り替わります。確定訳が届くまで暫定訳は画面に残るため、翻訳が一瞬消える空白は生じません。

## 対面通訳 — 双方向

Madi は、同じ部屋で異なる言語を話す 2 人（例: 韓国人スタッフと日本人・中国人の来訪者）のために設計されています。

**`한국어` ともう 1 つの言語だけ** を有効にすると（例: 한국어 + 일본어）、双方向通訳モードになります。

- **方向は行ごとに判定されます。** 日本語の行は韓国語にだけ、韓国語の行は日本語にだけ翻訳します。無駄がないぶん、より高速です。
- **言語を交互に話しても、両方が正しく文字起こしされます。** セグメントごとに言語を再確認するため、一方が韓国語・もう一方が日本語で話しても、それぞれの発言が正確に書き起こされます。
- この組み合わせは、後述の応答速度の下限の対象外です。

## よく使うフレーズ辞書（即時翻訳）

同じ案内を繰り返す現場（例: 診察室での処置後の注意事項）向けに、よく使うフレーズの翻訳をあらかじめ登録しておけます。登録したフレーズと同じ言葉が出てくると、モデルを通さずに **即時（0 秒）** で翻訳が表示されます。

いくつかのフレーズが最初から入っており、自分で追加・編集できます。

- ファイル: `~/Library/Application Support/Sovereign/faq_translations.json`
- 安全のため、**完全に一致** したときだけ動作します。

## 応答速度と翻訳品質

出力言語を **2 つ以上** にすると、原文の行の区切りの誤りがすべての言語に波及してしまうため、応答速度は下限の **보통 (7초)**（標準 7 秒）まで下がります。**빠름 (5초)**（高速 5 秒）を選んでいた場合は、自動的に 7 秒になります。**정확 (10초)**（正確 10 秒）はそのまま使えます。

> **例外：** **双方向** モード（`한국어` + 他の言語ちょうど 1 つだけ）は強制されません。各行の実質的な翻訳対象が 1 つに減るためです。対面通訳では字幕がより速く表示されます。

翻訳が遅れると、**「번역 중 · N줄 대기」**（翻訳中・N 行待機）と表示されます。止まっているのではなく、順番に処理しているということです（モデルは一度に 1 行ずつ翻訳します）。

## AI 言語修正（録音終了後）

録音が終わると、オンデバイスの LLM が会話を読み取り、**誤った言語で文字起こしされた行** を控えめに修正します。**설정 (⌘,) → 번역 → AI 교정 (세션 종료 후)**（設定 → 翻訳 → AI 修正（セッション終了後））の **화자·언어 자동 교정**（話者・言語の自動修正）で切り替えます。**話者** を参照してください。

## 字幕オーバーレイ

**字幕オーバーレイ** は、すべての最前面に浮かぶリアルタイム翻訳字幕のウィンドウです。Zoom や Teams の通話画面の上や、診察室のディスプレイの上に置いて、相手の話をリアルタイムで追えます。

上部ツールバーの **吹き出しアイコン** でオン・オフします。**出力言語を 1 つ以上選んで初めて、このボタンが表示されます。**

- ウィンドウは常に最前面にとどまりますが、フォーカスを奪わないため、通話アプリでクリックや入力を続けられます。
- フルスクリーンのアプリの上にも浮かび、背景をつかんで好きな場所へドラッグできます。
- いちばん大きな文字が翻訳文、その下の小さな文字が原文です。
- 複数人いるときは、字幕にも **話者の色と名前** が付き、誰の発言か分かります。
- 発話を待っている間は **マイク入力レベルのバー** が動き、システムが聞き取り中であることを知らせます。
- ステータス文（「진행 중 / 번역 중… / 음성을 기다리는 중…」）は **見る人の言語で** 表示されます — 日本語字幕なら「翻訳中…」、中国語字幕なら「翻译中…」。

### スタッフ字幕 + 患者字幕（デュアル表示）

診察室での通訳では、字幕を **2 つ** のパネルに分けられます。

- **スタッフ字幕** — メイン画面に小さく、スタッフの言語で。
- **患者字幕** — 外部モニターに大きく、離れた位置から読めるように、患者の言語で。

**설정 (⌘,) → 녹음 → 자막 오버레이 (진료실)**（設定 → 録音 → 字幕オーバーレイ（診察室））でオンにします。スタッフの文字サイズ（14–48 pt）、患者の文字サイズ（24–96 pt）、使用するディスプレイ、患者の言語を設定できます。大きなサイズは、診察チェアとディスプレイの間の 1.5–2.5 m の距離でも読みやすいように設計されています。
