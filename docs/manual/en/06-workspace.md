# Workspace & Files

Madi shows your entire save folder as a single workspace. An IDE-style file tree lets you reopen past meetings, switch working folders, and export to many formats.

## Opening & closing the workspace explorer

A file tree (the explorer) appears next to the transcript, showing your save folder as a workspace.

1. Click the folder button (sidebar icon, tooltip **작업 폴더 탐색기** / "Workspace explorer") at the top to show or hide the explorer.
2. You can also close it with the **탐색기 닫기** (Close explorer) button inside the panel.

**Tip — resize:** Drag the explorer's edge to change its width. The width you set is remembered across launches.

## Switching tabs

Use the tabs at the top of the explorer to change the view.

- **파일 (Files)** — your save folder's meetings and subfolders, as a tree.
- **사람 (People)** — speaker analytics for the people in your meetings.
- **열린 항목 (Open loops)** — unresolved decisions, to-dos, and other "open loops" gathered in one place.

## Reopening a saved meeting

1. In the **파일 (Files)** tab, click a transcript file (`.md`).
2. That meeting reopens in the view.

## Meeting preview (gist)

Under each transcript's filename, Madi shows a one-line **gist** — that meeting's first decision or summary line. This makes the tree read like a feed of your meetings at a glance.

## Selecting & switching the working folder

The folder you choose becomes the default location for **both saving and exporting**.

1. Click a folder in the tree to make it the workspace and the save/export folder.
2. To go up a level, press the **상위 폴더로** (Up to parent folder, ↑) button at the top.
3. To pick a completely different folder, press the folder-gear button (tooltip **작업 폴더 변경…** / "Change working folder…") and choose a new folder.
4. You can also right-click a folder and choose **이 폴더 열기 (작업 폴더로)** (Open this folder as the working folder).

> **Note:** The folder you choose immediately becomes both the default **save** location and the default **export** location.

## Saving

- Meetings **auto-save** to the working folder.
- With **A.I 요약** (AI summary) turned on, a separate **"…요약.md"** (summary) file is also saved alongside the transcript.

## Exporting

Choose a format from the **내보내기** (Export) menu at the top. Exports default to the working folder.

- **Markdown (.md)** — Markdown transcript
- **Subtitles (.srt)** — SRT subtitles
- **Subtitles (.vtt)** — VTT subtitles
- **Plain text (.txt)** — plain text
- **JSON (.json)** — JSON data
- **슬라이드(HTML)** (Slides) — an HTML slide deck
- **타이튼 컷 목록 (.csv)** (Tighten cut list) — the list of filler/silence cuts (CSV)
- **유튜브 챕터 (.txt)** (YouTube chapters) — a chapter list text file

## Click-to-play

For sessions transcribed from an **audio/video file** (where the original file is on disk), each line shows a play button.

1. Press the play button on a line (tooltip **이 구간 오디오 재생** / "Play this segment's audio").
2. The exact moment that line was spoken plays from the original media.

> **Note:** Live microphone sessions have no original file on disk, so per-line play buttons do not appear there.
