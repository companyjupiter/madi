사설(Sovereign) 원칙 — 대화는 이 기기를 떠나지 않습니다

음성 인식(Whisper), 번역·요약(DNA3.0-4B), 음성 인식 화자 매칭, 검색, 개인정보 마스킹까지 모두 로컬에서 실행됩니다. 최초 실행 시 모델을 내려받은 뒤에는 완전 오프라인으로 동작합니다. 클라우드 통역 서비스와 달리 진료 내용·회의 내용이 외부 서버에 남지 않습니다.

00

처음 시작하기

Madi는 Apple Silicon Mac(M1 이상)용 단독 앱입니다. 첫 실행 때 음성 인식 모델을 한 번 내려받으면 이후로는 인터넷 없이 쓸 수 있습니다.

음성 인식 모델 다운로드

첫 실행 시 Whisper 모델(약 830 MB, Q8)이 없으면 다운로드 시트가 열립니다. 내려받은 파일은 SHA-256으로 검증되고, 진행률·예상 시간이 표시됩니다.

확인 → 다운로드 → 검증 → 준비

번역 모델 (선택)

통역·요약을 쓰려면 DNA3.0-4B 모델(약 2.6 GB)을 추가로 내려받습니다. 번역 기능을 켜면 안내됩니다.

설정 › 번역

완전 오프라인

모델을 한 번 받은 뒤에는 네트워크 연결이 전혀 필요 없습니다. 진료실·병원 내부망 환경에서도 그대로 동작합니다.

네트워크 불필요
01

녹음

마이크·시스템 오디오·혼합 중에서 소리 소스를 고르고, 반응 속도와 라이브 미리보기를 조절합니다. 녹음 중에도 화자 분리와 인식이 실시간으로 진행됩니다.

소리 소스 — 마이크 / 시스템 / 혼합

내 마이크만, 화면에서 나는 소리(Teams·Zoom·YouTube)만, 또는 둘을 동시에 녹음합니다. 시스템 오디오는 화면 기록 권한이 필요합니다.

설정 › 입력 에서 선택 (녹음 시작 전)

입력 장치 선택

내장·USB·Bluetooth 마이크 중에서 지정하거나 시스템 기본값을 씁니다. 다채널 입력은 자동으로 모노로 합쳐집니다.

시작 전 변경만 가능

3·2·1 카운트다운

녹음 버튼을 누르면 3초 카운트다운 후 시작해 준비할 시간을 줍니다. 카운트 중 취소할 수 있습니다.

일시정지 / 재개

일시정지 구간의 음성은 무시되어 최종 전사에서 빠집니다 — 자연스러운 편집 효과입니다. 마이크는 켜진 채로 대기합니다.

반응 속도 (윈도 길이)

짧게(빠름)는 자막이 더 빨리 뜨지만 문맥이 줄어 경계 오류가 늘고, 길게(정확)는 그 반대입니다. 기본 10초.

설정 › 실시간 · 번역 2개 이상이면 정확(10초) 자동 고정

침묵 조기 마감

말을 끝내고 0.7초 이상 조용하면(2.5초 이상 발화 후) 윈도를 앞당겨 닫아 대기 시간을 없앱니다. 원거리 마이크의 작은 목소리는 적응형 기준으로 잘리지 않습니다.

지연 −3~5초

라이브 미리보기

윈도가 닫히기 전에 회색 "진행 중" 임시 텍스트를 보여줍니다. 별도 엔진이 처리하므로 최종 정확도에는 영향이 없습니다.

설정 › 실시간 › 라이브 프리뷰

입력 레벨 미터

상단 막대가 마이크 입력 크기를 실시간으로 보여줘 "듣고 있음"을 확인시켜 줍니다. 일시정지 중에는 0으로 내려갑니다.

02

화자

누가 말했는지 자동으로 나누고, 이름을 붙이고, 목소리를 기억해 다음 회의에서도 알아봅니다. 색상으로 화자를 한눈에 구분합니다.

자동 화자 분리

목소리 특성으로 화자를 자동 구분합니다(최대 8명). 참석 인원을 알면 1·2·3·4명 이상으로 고정해 정확도를 높일 수 있습니다.

설정 › 화자 수 — 자동 / 고정

화자 이름 지정

전사의 "화자 1" 칩을 클릭해 실제 이름을 입력하면 그 사람의 모든 발언에 적용됩니다.

녹음 중·후 모두 가능

목소리 등록 · 자동 인식

이름을 붙이면 목소리 특성이 저장되고, 다음 회의에서 같은 사람이 감지되면 자동으로 이름이 붙습니다. 자동 인식된 화자에는 ✓ 음성 인식됨 배지가 붙습니다.

설정 › 사람 에서 등록 목소리 관리·삭제

겹침·끼어들기 감지

둘 이상이 동시에 말한 구간을 찾아 ⟨+화자 N 겹침⟩ 마커로 표시합니다. 회의 흐름·중단 패턴 분석에 쓰입니다.

화자 색상

8색 팔레트로 화자마다 색을 배정해 이름표·발화 점·번역 줄·타임라인에서 일관되게 구분합니다.

사람 대시보드

등록된 사람별로 참석 회의 수·총 발화 시간·발언 수를 집계해 카드로 보여줍니다. 발화 시간 순으로 정렬됩니다.

탐색기 › 사람 탭
03

파일 전사

이미 녹음된 오디오·비디오 파일을 끌어다 놓으면 라이브와 같은 파이프라인으로 전사합니다. 전사 라인을 눌러 그 순간의 소리를 다시 들을 수 있습니다.

드래그 앤 드롭

m4a·mp3·aac·flac·wav·mp4·mov 등 대부분의 오디오·비디오를 창에 끌어다 놓습니다. 모두 16 kHz 모노로 자동 변환됩니다.

최대 4시간 · 2 GB

진행 상황

대용량 파일은 30초 청크 단위로 배치 처리하며 "청크 K / 총 N" 진행률을 표시합니다.

클릭-투-플레이

전사 라인을 클릭하면 원본 미디어에서 그 시점을 재생합니다(파일 전사 전용). 라인 시간이 소리와 동기화됩니다.

파일 전사 전용
04

실시간 번역·통역

발화가 확정되는 즉시 상대 언어로 번역이 타이핑되듯 나타납니다. 한 화면에서 한국어 직원과 외국어 환자가 서로의 말을 각자 언어로 봅니다 — 진료실 대면 통역을 위해 설계됐습니다.

실시간 다국어 번역

한 발화를 선택한 여러 언어(한·영·일·중)로 동시에 번역합니다. 온디바이스 DNA3.0-4B 모델이 처리합니다.

설정 › 번역 에서 대상 언어 체크

양방향 언어 라우팅

각 줄의 문자(한글·가나·한자)를 보고 소스 언어를 판별해 상대 언어로만 번역합니다. 일본어 줄 → 한국어, 한국어 줄 → 일본어. 줄당 번역 1회로 빨라집니다.

클리닉 통역

양방향 언어 자동 재감지

번역 대상이 {한국어, X} 쌍이면 세그먼트마다 언어를 다시 판별합니다. 한국인 직원과 외국인 환자가 번갈아 말해도 양쪽 전사가 모두 정확합니다.

토큰 스트리밍 + 타이핑 커서

번역이 완성될 때까지 기다리지 않고 단어가 생성되는 대로(약 19 ms/토큰) 화면에 자랍니다. 아직 쓰는 중인 줄에는 커서 ▍가 깜빡입니다.

첫 표시 ~절반

임시 번역 이월

말하는 동안 뜬 잠정 번역이, 줄이 확정된 뒤 정식 번역이 도착할 때까지 회색으로 유지됩니다 — 번역이 잠깐 사라지는 공백이 없어집니다.

자주 쓰는 진료 문구 사전

"시술 후 3일간 사우나를 피해 주세요" 같은 반복 안내문을 미리 번역해 저장해 두면, 같은 말이 나올 때 즉시(0 ms) 표시됩니다. 피부과 기본 문구가 들어 있고 직접 추가할 수 있습니다.

정확 일치 · 디스크 저장

번역 대기 표시

번역 턴이 밀리면 "N줄 번역 대기"를 보여줘, 멈춘 것이 아니라 순서대로 처리 중임을 알려줍니다.

정확 모드 자동 전환

번역 대상이 2개 이상이면 짧은 윈도의 경계 오류가 모든 언어로 퍼지지 않도록 10초 윈도를 강제합니다. 단, 한국어 양방향 쌍은 줄당 1개로 줄어들어 예외입니다.

05

자막 디스플레이

항상 위에 떠 있는 자막 창을 회의·통화 위에 겹쳐 띄웁니다. 직원용(작게, 주 화면)과 환자용(크게, 외장 모니터)을 나눠, 각자 자기 언어를 봅니다.

자막 오버레이

다른 앱·전체화면 위에 떠 있으면서 포커스를 빼앗지 않는 자막 창입니다. 드래그로 어디든 옮길 수 있습니다.

직원 · 환자 이중 패널

직원용은 주 화면에 작게, 환자용은 외장 모니터에 크게(원거리 판독용) 동시에 띄웁니다. 각 패널은 자기 청중의 언어로 표시됩니다.

설정 › 자막 오버레이(진료실)

글씨 크기 · 폭 · 외장 화면 선택

직원 자막 14–48 pt, 환자 자막 24–96 pt, 패널 폭, 환자 화면을 지정합니다. 진료 의자와 디스플레이 사이 1.5–2.5 m 거리를 위한 설정입니다.

번역중 상태 (환자 언어)

"진행 중 / 번역 중… / 음성 대기"를 보는 사람의 언어로 표시합니다 — 일본 환자에게는 「翻訳中…」, 중국 환자에게는 「翻译中…」.

화자 색점 + 이름

자막에도 화자 색점과 이름을 붙여, 여러 명이 있을 때 누구 말인지 바로 알 수 있습니다.

마이크 레벨 미터

말을 기다리는 상태에서 마이크 입력 막대가 움직여, 화자에게 시스템이 듣고 있음을 확인시켜 줍니다.

2인 대화(채팅) 레이아웃

정확히 두 명일 때, 첫 화자를 왼쪽·상대를 오른쪽에 놓는 메신저식 배치로 바꿉니다. 번갈아 읽는 통역에 최적입니다.

보기 전환 — 2인 감지 시 대화 버튼 노출
06

회의 인텔리전스

전사를 넘어, 회의를 이해합니다. 온디바이스 LLM이 요약·결정·액션을 뽑고, 진행 중에는 안건 커버리지를 코치합니다. 모두 이 기기 안에서 처리됩니다.

AI 회의 요약 · 액션 아이템

녹음이 끝나면 DNA3 LLM이 전체 내용을 요약·결정·액션으로 구조화합니다. 긴 회의는 청크로 나눠 재귀 요약합니다.

좌측 요약 버튼 · ⌘K
온디바이스

화자별 요약

누가 무엇을 말했고 누가 어떤 액션을 맡았는지 화자 기준으로 정리합니다.

리캡 카드

요약 후 한 페이지 카드(제목·날짜·TL;DR·결정·액션·화자별 발화 시간·핵심 인용)를 띄웁니다. 복사·내보내기 가능.

자동 제목

전사를 읽고 24자 이내 회의 제목을 만들어 저장 파일명으로 씁니다. 실패 시 날짜·시각으로 대체합니다.

한 줄 미리보기 (Gist)

저장된 회의록마다 "무슨 내용이었나" 한 줄을 파일 이름 아래에 표시합니다(결정 → 요약 → 첫 발언 순).

열린 항목 추적

지난 회의들의 결정·액션·질문을 모으고, 이후 회의에서 다시 언급되면 자동으로 "해결됨" 처리합니다. 미해결 항목은 오래된 순으로 보여줍니다.

탐색기 › 열린 항목

라이브 액션 레일

녹음 중 18초마다 최근 대화에서 새 결정·액션·질문을 실시간으로 뽑아 사이드 레일에 쌓습니다.

≥ 16 GB 메모리

라이브 코치 / 텔레프롬프터

안건 커버리지(다룬 항목 체크), 미답변 질문, 말하기 속도, 지금 흐름(가열🔥/안정/저조❄️)을 실시간으로 안내합니다. 추가 모델 없이 모든 기기에서 동작합니다.

모델 불필요

회의 준비 브리프

캘린더에서 감지한 참석자를 바탕으로, 지난 회의의 결정·미완료 액션을 시작 전에 미리 보여줍니다. 순수 검색 기반이라 빠릅니다.

회의 모드 프리셋

일반·1:1·스탠드업·인터뷰·강의 중 하나를 고르면 화자 수 기본값과 요약 방향이 한 번에 맞춰집니다.

에너지 아크

회의를 30개 구간으로 나눠 발화 밀도·겹침·침묵으로 "분위기"를 스파크라인으로 그립니다. 라이브 코치의 지금 흐름 판정에 쓰입니다.

캘린더 연동

macOS 캘린더에서 지금 시각 근처 일정을 읽어 제목·참석자를 채우고, 회의 후 참석 예정자 중 미발언자를 표시합니다. 읽기 전용(EventKit).

07

편집·검토

인식이 자신 없는 단어를 짚어주고, 그 구간만 골라 듣게 하고, 영상 편집용 컷 리스트까지 만들어 줍니다. 내용 보기·상세 보기·대화 보기 세 가지 모드를 지원합니다.

인라인 편집

줄을 클릭해 인식 텍스트를 바로 고칩니다. 수정은 자동 저장되고, 고친 내용은 개인 단어장에 학습됩니다.

저신뢰 단어 강조

모델 신뢰도가 낮은 단어(기본 < 0.55)를 이탤릭으로 표시해 확인할 곳을 짚어줍니다. 내보낸 파일에도 이 표시가 유지됩니다.

저신뢰 검토 큐

자신 없는 단어를 순서대로 오가며 확인합니다. 상세 모드 상단의 "검토 X/Y"로 이동합니다.

귀로 검토 (핸즈프리)

저신뢰 단어의 소리 구간을 하나씩 자동 재생해 눈과 귀로 함께 확인합니다(파일 전사 전용).

타임라인 스크러버

화자별 발화를 색 레인으로 그리고, 챕터 눈금과 겹침 점을 표시합니다. 구간을 눌러 해당 줄로 점프합니다.

에디터 컷 — 편집 도구 (기본 꺼짐)

파워 유저용 영상·팟캐스트 편집 분석. 설정에서 켜면 다음을 계산합니다:

필러 제거 — "음·어·um" 등 침묵 압축 — 0.6초+ 갭 한 번에 타이튼 — 필러+침묵 병합 자동 챕터 — 2.5초+ 갭 재테이크 감지 — 유사 반복 줄 하이라이트 후보 — 준비된 명확한 구간

보기 모드 — 내용 / 상세 / 대화

내용은 깔끔한 회의록, 상세는 시간·신뢰도·겹침이 보이는 편집용, 대화는 2인 좌우 배치입니다.

제어 바 세그먼트 전환 · 글자 크기 A− / A+
08

내보내기·저장

회의록을 여러 형식으로 내보내고, 끝나면 자동 저장합니다. 내보낼 때 주민번호·전화번호 같은 개인정보를 자동으로 가립니다.

내보내기 형식

.md — 화자·시간·요약 블록 .txt — 붙여넣기용 평문 .srt — 방송 자막 규격 .vtt — WebVTT .json — 단어별 신뢰도·분석 .csv — 영상 편집용 컷 리스트 챕터.txt — YouTube 챕터 .pptx — 요약 슬라이드 덱

SRT·VTT는 단어 단위로 재배치해 방송 자막 길이 규칙(줄당 글자·초당 글자)을 지킵니다. JSON은 프레임 정확 후처리 도구용으로 화자·시간·신뢰도·컷 분석을 모두 담습니다.

자동 저장

녹음·전사가 끝나면 지정 폴더에 Markdown으로 자동 저장합니다. 같은 이름이 있으면 번호를 붙여 덮어쓰지 않습니다.

설정 › 자동저장 — 폴더 지정

개인정보 마스킹

내보낼 때 이메일·주민번호·휴대폰·일반 전화를 [주민번호] 같은 태그로 가립니다. 화면 전사는 그대로 두고 파일에만 적용하며, 연도·시각은 오탐하지 않도록 보수적으로 설계했습니다.

온디바이스

요약 슬라이드 덱

요약을 자체 포함 HTML/PPTX 덱으로 만들어 브라우저에서 넘겨 보거나 PDF로 인쇄합니다(외부 리소스 없음, 오프라인).

09

작업공간·검색

저장한 회의록을 폴더 트리로 관리하고, 이 회의 또는 전체 회의에 자연어로 질문합니다. 검색·답변 모두 기기 안에서 이뤄집니다.

작업 탐색기

저장 폴더의 파일 트리를 좌측 패널에 IDE 스타일로 보여줍니다. 폴더 접기·펼치기, 너비 조절, Finder에서 보기를 지원합니다.

토글 ⌘\

지난 회의 다시 열기

저장된 .md를 클릭하면 전사 화면으로 복원됩니다. 이탤릭 단어는 저신뢰로, 시간은 줄 시작 기준으로 되살아납니다.

이 회의에 질문

현재 전사에서 질문과 관련된 줄만 골라 LLM에 넘겨 답합니다. 토큰 예산 안에서 관련도 높은 줄을 우선합니다.

전체 작업공간에 질문

저장된 모든 회의록을 교차 검색해 관련 부분을 추출·답변합니다(회의 간 RAG). 결과는 회의별로 묶여 안정적으로 정렬됩니다.

온디바이스 검색
10

용어·개인화

자주 틀리는 이름·전문 용어를 스스로 학습해 다음부터 바로잡습니다. 오작동을 막기 위해 보수적으로 설계됐습니다.

개인 단어장 — 학습

전사에서 단어를 고칠 때마다 "틀린 → 맞는" 매핑을 자동으로 익힙니다(3글자 이상, 조사 제거 후 저장).

개인 단어장 — 적용

학습한 교정을 새 전사에 자동 적용합니다. 신뢰도 낮은 단어에만, 정확 일치 또는 높은 음성 유사도에서만 바꿔 오작동을 막습니다.

설정 › 단어장 — 기본 꺼짐 · 최소 확인 횟수 조절

교정 규칙 관리

학습된 규칙을 "틀린 → 맞는 (N회)" 목록으로 보고, 개별 삭제하거나 전체를 지웁니다. 확인 횟수를 채운 규칙만 활성화됩니다.

11

시스템 받아쓰기

회의가 아닌 곳에서도, 어느 앱에서나 오른쪽 Option 키를 눌러 말하면 커서 위치에 받아쓰기가 삽입됩니다. 온디바이스 Whisper로 처리됩니다.

어디서나 받아쓰기

오른쪽 Option 키를 누르고 말하면 메일·메모 등 지금 앱에 텍스트가 들어갑니다. 클립보드를 잠깐 빌려 붙여넣고 원본을 즉시 복원합니다.

오른쪽 Option 눌러 말하기 (푸시-투-토크)

상태 표시 · 권한

듣는 중 / 변환 중 / 입력 중 / 차단됨을 표시합니다. 손쉬운 사용 권한이 필요하며, 설정에서 바로 이동할 수 있습니다.

자동 서식 · 안전장치

한중일 문자·구두점·괄호를 자연스럽게 다듬습니다. 진료 녹음 중에는 받아쓰기가 자동으로 차단되고, ⌘ 조합과 충돌하지 않습니다.
