# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. In short: be respectful, assume good faith, keep criticism
about the work and not the person, and no harassment of any kind. It applies to
issues, pull requests, discussions and every other project space.

Report unacceptable behaviour privately to the maintainer,
[@jupitersong](https://github.com/jupitersong). Reports are handled confidentially;
the maintainer may remove content, or restrict or ban a participant.

한국어: 이 프로젝트는 Contributor Covenant 2.1을 행동 강령으로 채택합니다. 서로
존중하고, 선의를 전제하며, 사람이 아닌 결과물을 비평해 주세요. 어떤 형태의 괴롭힘도
허용하지 않습니다. 문제가 있으면 관리자 [@jupitersong](https://github.com/jupitersong)에게
비공개로 알려 주세요.
